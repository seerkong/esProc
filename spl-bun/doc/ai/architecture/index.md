## 数据流

1. 用户在 Web IDE 的电子表格中编写 SPL 代码
2. 点击运行后，前端收集所有单元格内容
3. 发送 POST 请求到 `/api/execute`
4. 后端使用 `evaluateFlow()` 执行流程
5. 返回执行结果和最后一个查询的数据
6. 前端在 AG-Grid 中展示结果
