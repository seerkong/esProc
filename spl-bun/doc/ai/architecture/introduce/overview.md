# 系统整体概述

## 项目定位

SPL-Bun 是 esProc SPL (Structured Process Language) 的 TypeScript 重新实现。esProc 是一种基于网格的数据处理语言，类似于电子表格，但专注于数据计算和 ETL 操作。

## 核心特性

### 1. 网格执行模型

SPL 代码组织在二维网格中，每个单元格包含一个表达式或命令：

```
   A              B              C
1  sum = 0
2  for 3
3                 sum += A2
4  sum
```

- 单元格通过 `cellRef` 引用（如 `A1`, `B2`）
- 缩进（列位置）表示代码块层级
- 每行只能有一个可执行单元格

### 2. 表达式引擎

支持丰富的表达式语法：

- 算术运算: `+`, `-`, `*`, `/`, `%`, `\` (整除)
- 比较运算: `==`, `!=`, `>`, `<`, `>=`, `<=`
- 逻辑运算: `and`, `or`, `not`
- 集合运算: `&` (并集), `^` (交集), `\` (差集), `|` (交集)
- 赋值运算: `=`, `+=`, `-=`, `*=`, `/=`
- 成员访问: `obj.field`, `arr[0]`, `db.query("sql")`

### 3. 流程控制

支持完整的流程控制语句：

- 条件: `if`, `elseif`, `else`
- 循环: `for` (计数/范围/序列/条件)
- 跳转: `break`, `continue`, `goto`
- 子程序: `func`, `return`
- 异常: `try`
- 终止: `result`, `end`

### 4. 数据源集成

支持多种数据源：

- SQLite 数据库查询
- CSV 文件导入
- JSON 文件处理
- Excel 文件读写

## 与 Java esProc 的差异

| 特性 | Java esProc | SPL-Bun |
|------|-------------|---------|
| 运行时 | JVM | Bun (V8) |
| 单元格前缀 | 需要 `=` 或 `>` | 可选 |
| 注释 | `//` | `//` |
| `next` 关键字 | 支持 | 不支持 (使用 `continue`) |
| 数据库 | JDBC | bun:sqlite |

## 设计原则

1. **兼容性优先**: 尽量保持与 Java esProc 语法兼容
2. **类型安全**: 使用 TypeScript 提供类型检查
3. **模块化**: 清晰的包划分，便于独立使用
4. **可测试**: 每个功能都有对应的测试用例
