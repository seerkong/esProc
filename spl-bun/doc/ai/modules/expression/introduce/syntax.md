# 表达式语法

## 运算符

### 算术运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加法 | `1 + 2` → `3` |
| `-` | 减法 | `5 - 3` → `2` |
| `*` | 乘法 | `2 * 3` → `6` |
| `/` | 除法 | `7 / 2` → `3.5` |
| `%` | 取模 | `7 % 3` → `1` |
| `\` | 整除 | `7 \ 2` → `3` |
| `-` | 负号 | `-5` → `-5` |

### 比较运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `==` | 等于 | `1 == 1` → `true` |
| `!=` | 不等于 | `1 != 2` → `true` |
| `>` | 大于 | `2 > 1` → `true` |
| `<` | 小于 | `1 < 2` → `true` |
| `>=` | 大于等于 | `2 >= 2` → `true` |
| `<=` | 小于等于 | `1 <= 2` → `true` |

### 逻辑运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `and` | 逻辑与 | `true and false` → `false` |
| `or` | 逻辑或 | `true or false` → `true` |
| `not` | 逻辑非 | `not true` → `false` |
| `\|\|` | 逻辑或 (符号) | `true \|\| false` → `true` |

### 集合运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `&` | 并集 | `[1,2] & [3,4]` → `[1,2,3,4]` |
| `^` | 交集 | `[1,2,3] ^ [2,3,4]` → `[2,3]` |
| `\` | 差集 | `[1,2,3] \ [2]` → `[1,3]` |
| `\|` | 交集 (同 ^) | `[1,2,3] \| [2,3,4]` → `[2,3]` |

### 赋值运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `=` | 赋值 | `x = 5` |
| `+=` | 加法赋值 | `x += 1` |
| `-=` | 减法赋值 | `x -= 1` |
| `*=` | 乘法赋值 | `x *= 2` |
| `/=` | 除法赋值 | `x /= 2` |

## 访问器

### 成员访问

```
obj.field       // 对象属性
arr[0]          // 数组索引
obj["key"]      // 动态属性
```

### 成员函数调用

```
arr.count()           // 数组长度
arr.sum()             // 数组求和
db.query("sql")       // 数据库查询
str.upper()           // 字符串大写
```

## 函数调用

### 全局函数

```
len("hello")          // 5
upper("hello")        // "HELLO"
sum([1, 2, 3])        // 6
if(x > 0, "yes", "no")
```

### 选项语法 (@)

某些函数支持选项修饰符：

```
T@b("file.xlsx")      // @b = 无表头
like@c("Hello", "h*") // @c = 忽略大小写
regex@a(str, pat, "") // @a = 替换所有
```

### 分号语法 (;)

用于分隔参数组：

```
T("file.xlsx"; "Sheet2")           // 第二组参数指定 sheet
T("file.xlsx", data; "Sheet1")     // 写入数据到指定 sheet
```

## 逗号表达式

多个表达式用逗号分隔，返回最后一个值：

```
a = 1, a = a + 2      // 返回 3
x = 0, x += 1, x += 2 // 返回 3
```

## 运算符优先级

从高到低：

1. `()` 括号
2. `.` `[]` 成员访问
3. `-` `not` 一元运算符
4. `*` `/` `%` `\` 乘除
5. `+` `-` 加减
6. `&` `^` `|` 集合运算
7. `==` `!=` `>` `<` `>=` `<=` 比较
8. `and` 逻辑与
9. `or` `||` 逻辑或
10. `=` `+=` `-=` `*=` `/=` 赋值
11. `,` 逗号

## 测试用例参考

```typescript
// packages/expression/__tests__/expression.test.ts

// 运算符优先级
expect(evaluateExpression("a + b * 2", { a: 2, b: 5 })).toBe(12);
expect(evaluateExpression("(a + b) * 2", { a: 2, b: 5 })).toBe(14);

// 逻辑运算
expect(evaluateExpression("a > 1 and b < 10", { a: 2, b: 5 })).toBe(true);
expect(evaluateExpression("name == null", { name: null })).toBe(true);

// 集合运算
expect(evaluateExpression("left & right", { left: [1,2,3], right: [3,4] })).toEqual([1,2,3,4]);
expect(evaluateExpression("left ^ right", { left: [1,2,3], right: [3,4] })).toEqual([3]);

// 赋值
const local = { a: 1 };
expect(evaluateExpression("a = 5", local)).toBe(5);
expect(local.a).toBe(5);
```
