# SPL 流程控制 - 执行流程图

## 1. 整体执行流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      PgmCellSet.run()                           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                         主循环                                   │
│  while (true) {                                                 │
│      if (isInterrupted) break;                                  │
│      if (runNext2() == null) break;                            │
│      if (hasReturn()) { runFinished(); break; }                │
│  }                                                              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                      runNext2()                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 1. 初始化检查                                            │   │
│  │    if (curLct == null) {                                │   │
│  │        curLct = new CellLocation();                     │   │
│  │        setNext(1, 1, false);  // 从(1,1)开始            │   │
│  │        return curLct;                                   │   │
│  │    }                                                    │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 2. 获取当前单元格                                        │   │
│  │    cell = getPgmNormalCell(curLct.row, curLct.col)      │   │
│  │    command = cell.getCommand()                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 3. 执行分发                                              │   │
│  │    if (command == null) {                               │   │
│  │        cell.calculate();  // 普通表达式                  │   │
│  │        setNext(row, col+1, false);                      │   │
│  │    } else {                                             │   │
│  │        switch (command.getType()) { ... }               │   │
│  │    }                                                    │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

## 3. 条件分支执行流程 (if/elseif/else)

```
┌─────────────────────────────────────────────────────────────────┐
│                      runIfCmd()                                  │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
                    ┌─────────────────┐
                    │ 计算条件表达式   │
                    │ value = exp.    │
                    │   calculate()   │
                    └────────┬────────┘
                             │
              ┌──────────────┴──────────────┐
              │                             │
              ▼                             ▼
       value == true               value == false
              │                             │
              ▼                             ▼
    ┌─────────────────┐          ┌─────────────────┐
    │ setNext(row,    │          │   toElseCmd()   │
    │   col+1, false) │          │                 │
    │ 执行代码块内容   │          └────────┬────────┘
    └─────────────────┘                   │
                                          ▼
                              ┌─────────────────────┐
                              │ 在同行查找else/elseif│
                              └──────────┬──────────┘
                                         │
                    ┌────────────────────┼────────────────────┐
                    │                    │                    │
                    ▼                    ▼                    ▼
             找到 elseif            找到 else            都没找到
                    │                    │                    │
                    ▼                    ▼                    ▼
            递归 runIfCmd()      setNext(row,         跳到代码块后
                                  col+1, false)       setNext(endRow+1,
                                                        1, true)
```

### SPL 网格示例
```
    A           B           C           D
1   if x>0      =x*2                            ← 条件为真执行B1
2               =B1+1                           ← 继续执行B2
3   else if x<0 =-x                             ← 条件为假，检查elseif
4   else        =0                              ← 都不满足执行else
5   =result                                     ← if块结束
```

## 8. 代码块边界计算

```
┌─────────────────────────────────────────────────────────────────┐
│              getCodeBlockEndRow(prow, pcol)                      │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
                    ┌─────────────────┐
                    │ for row = prow+1│
                    │   to totalRow   │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ for c = 1       │
                    │   to pcol       │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ cell(row,c)     │
                    │ 是否非空?       │
                    └────────┬────────┘
                             │
                  ┌──────────┴──────────┐
                  │                     │
                  ▼                     ▼
                 是                    否
                  │                     │
                  ▼                     ▼
         return row - 1           继续检查
                                        │
                                        ▼
                               ┌─────────────────┐
                               │ 检查完所有行    │
                               │ return totalRow │
                               └─────────────────┘

示例：
    A       B       C
1   for     =x              ← prow=1, pcol=1
2           =y              ← 检查A2: 空，继续
3           =z              ← 检查A3: 空，继续
4   =next                   ← 检查A4: 非空! return 3

代码块范围: 行1-3, 列B及之后
```
