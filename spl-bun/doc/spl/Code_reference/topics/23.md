# 2.2.2 查找并替换子串

- 格式: 为 AI 阅读提取的 Markdown

## 类代码片段
```spl
=pos("abcdef","def")
=pos("abcdefdef","def",5)
=replace("abca","a","ABC")
=replace("abc'abc'","a","ABC")
=replace@q("abc'abc'","a","ABC")
```
