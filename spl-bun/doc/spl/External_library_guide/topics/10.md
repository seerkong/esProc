2. 需要 JRE 1.7 及以上。若 esProc 内置 JRE 版本不足，请安装更高版本并在 `安装目录\esProc\bin\config.txt` 中配置 `java_home`；若版本满足可跳过。

3. 如默认内存不足，可手动调整。Windows 下通过 `.exe` 启动时改 `config.txt`，通过 `.bat` 启动时改批处理脚本；Linux 下改 `.sh`。
Windows 下 `config.txt` 示例：

java_home=C:\ProgramFiles\Java\JDK1.7.0_11;esproc_port=48773; btx_port=41735;gtm_port=41737; jvm_args=-Xms256m-XX:PermSize=256M-XX:MaxPermSize=512M-Xmx9783m-Duser.language=zh

4. esProc 提供 `es_close()`、`es_delete()`、`es_export()`、`es_head()`、`es_open()`、`es_get()`、`es_post()`、`es_put()` 访问 ElasticSearch。可在【Help】-【Function reference】中查看用法。
