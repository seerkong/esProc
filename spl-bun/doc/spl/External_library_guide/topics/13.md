2. 使用 GCS 外部库前需添加网络代理。Windows 下通过 `.exe` 启动时在 `config.txt` 配置，通过 `.bat` 启动时在批处理脚本配置；Linux 下在 `.sh` 配置。
Windows 下 `config.txt` 示例：

java_home=C:\ProgramFiles\Java\jdk1.7.0_11;esproc_port=48773;btx_port=41735;gtm_port=41737;jvm_args=-Xms128m
-Xmx9669m -Duser.language=zh -Djava.net.useSystemProxies=true

3. 需要 JRE 1.7 及以上。若 esProc 内置 JRE 版本不足，请安装更高版本并在 `安装目录\esProc\bin\config.txt` 中配置 `java_home`；若版本满足可跳过。

4. esProc 提供 `gcs_open()`、`gcs_bucket()`、`gcs_copy()`、`gcs_file()`、`gcs_list()`、`gcs_close()` 访问 GCS 平台。可在【Help】-【Function reference】中查看用法。
