2. 从网络下载以下四个文件并放到 `安装目录\bin`：

hadoop.dll
hadoop.lib
libwinutils.lib
winutils.exe

注：以上文件仅 Windows 需要，Linux 不需要。`winutils.exe` 需按系统位数选择 x86 或 x64。

3. HbaseCli 需要 JRE 1.7 及以上。若 esProc 内置 JRE 版本不足，请安装更高版本并在 `安装目录\esProc\bin\config.txt` 配置 `java_home`。如安装 esProc 时已选择 JDK 1.6 及以上且 JRE 版本满足，可跳过。

4. 如默认内存不足，可手动调整。Windows 下通过 `.exe` 启动时改 `config.txt`，通过 `.bat` 启动时改批处理脚本；Linux 下改 `.sh`。
Windows 下 `config.txt` 示例：

java_home=C:\ProgramFiles\Java\JDK1.7.0_11;esproc_port=48773; btx_port=41735;gtm_port=41737; jvm_args= -Xms256m
-XX:PermSize=256M -XX:MaxPermSize=512M -Xmx9783m -Duser.language=zh
