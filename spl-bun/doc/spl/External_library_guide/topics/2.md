简介

esProc 可通过 ODBC 或 JDBC 连接数据库；若目标数据库不支持这两种方式，还可以使用 Search External Library 功能。

esProc 默认支持多种外部库：AlicloudCli、AvroCli、CassandraCli、CdcCli、DynamodbCli、ElasticsearchCli、FinancialCli、FtpCli、HbaseCli、HdfsFileCli、HiveCli、InfluxdbCli、InformixCli、KafkaCli、MathCli、MongoCli、Olap4jCli、OssCli、R2dbcCli、RedisCli、S3Cli、SalesforceCli、SapCli、SparkCli、WasCli、WebcrawlCli、WebserviceCli、ZipCli。

使用外部库通常分两步：
1. 部署外部库（见 Deployment）
2. 连接外部库（见 Connection）

下表为各外部库功能说明：

| External library | Functionality |
| --- | --- |
| AlicloudCli | 访问阿里云平台，执行连接、数据查询等操作。 |
| AvroCli | 处理 Avro 文件，包括读取与导出。 |
| CassandraCli | 访问 Cassandra 数据库，执行连接、查询等操作。 |
| CdcCli | 访问通过数据同步工具采集的数据。 |
| DebeziumCli | 为 CdcCli 提供 Debezium 数据同步能力。 |
| DynamodbCli | 访问 DynamoDB 数据库，执行建表、查询等操作。 |
| ElasticsearchCli | 访问 Elasticsearch 服务，执行 get/put 等操作。 |
| FinancialCli | 提供金融分析能力，例如净现值、终值等。 |
| FtpCli | 访问 FTP 服务，执行文件上传/下载等操作。 |
| GcsCli | 访问 Google Cloud Storage，执行数据复制、Bucket 管理等操作。 |
| HbaseCli | 访问 HBase 数据库，执行查询、过滤等操作。 |
| HdfsFileCli | 访问 HDFS 文件系统，执行文件上传/下载等操作。 |
| HiveCli | 访问 Hive 数据库，执行连接并读取 ORC/Parquet 数据等操作。 |
| InfluxdbCli | 访问 InfluxDB 数据库，执行连接、查询等操作。 |
| InformixCli | 访问 Informix 数据库，执行数据抽取、分片定义设置等操作。 |
| KafkaCli | 访问 Kafka 服务，读取消息、设置消费组 offset 等。 |
| MathCli | 提供数学分析能力，如协方差与标准差计算。 |
| MongoCli | 访问 Mongo 数据库，执行连接、查询等操作。 |
| OggCli | 为 CdcCli 提供 Ogg 数据同步能力。 |
| Olap4jCli | 访问多维数据库，执行连接、查询等操作。 |
| OssCli | 访问 OSS 云存储服务，执行数据复制、Bucket 管理等操作。 |
| R2dbcCli | 创建 R2DBC 连接，执行数据库连接、查询等操作。 |
| RedisCli | 访问 Redis 数据库，执行连接与命令调用。 |
| S3Cli | 访问 AWS S3 服务，执行数据复制、Bucket 管理等操作。 |
| SalesforceCli | 访问 Salesforce 云，通过 SOAP/REST API 建连并查询数据。 |
| SapCli | 访问 SAP 服务，执行连接、查询等操作。 |
| SparkCli | 访问 Spark 数据库，执行连接、查询等操作。 |
| WasCli | 访问 Windows Azure Storage，执行数据复制、Bucket 管理等操作。 |
| WebcrawlCli | 提供网页爬取工具能力。 |
| WebserviceCli | 访问 Web Service，执行连接、取数等操作。 |
| ZipCli | 提供压缩工具能力，执行压缩、解压等操作。 |
