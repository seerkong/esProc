3.24 SAP

1. 该外部库目录：`安装目录\esProc\extlib\SapCli`。对应 Raqsoft 核心 jar：`scu-sap-cli-2.10.jar`。

sapjco3.dll
sapjco3-2.10.jar

注：`sapjco3.dll` 需按系统位数选择 64 位或 32 位版本。

2. 需要 JRE 1.7 及以上。若 esProc 内置 JRE 版本不足，请安装更高版本并在 `安装目录\esProc\bin\config.txt` 中配置 `java_home`；若版本满足可跳过。

3. 如默认内存不足，可手动调整。Windows 下通过 `.exe` 启动时改 `config.txt`，通过 `.bat` 启动时改批处理脚本；Linux 下改 `.sh`。
Windows 下 `config.txt` 示例：

java_home=C:\ProgramFiles\Java\JDK1.7.0_11;esproc_port=48773;btx_port=41735;gtm_port=41737;jvm_args= -Xms256m -XX:PermSize=256M
-XX:MaxPermSize=512M -Xmx9783m -Duser.language=zh

4. esProc 提供 `sap_open()`、`sap_excute()`、`sap_getparam()`、`sap_table()`、`sap_cursor()`、`sap_close()` 访问 SAP。可在【Help】-【Function reference】中查看用法。
