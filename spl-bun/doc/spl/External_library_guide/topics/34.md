4.1 Within esProc IDE

在菜单中点击【Tool】-【Options】-【Environment】，会弹出配置窗口：

（原文含示意图，图像资源未迁移）

点击 Browse 按钮，会弹出“Select external libraries”窗口：

（原文含示意图，图像资源未迁移）

再次点击 Browse，选择外部库文件夹所在目录。默认目录为 `安装目录\esProc\extlib`。

外部库目录应包含：
- 对应 Raqsoft 核心 jar
- 该外部库启用所需的第三方 jar

在窗口中选择需要连接的外部库并点击 OK，随后重启 IDE 使配置生效。

注：

1. 可以自定义外部库目录。建议不要选择子目录过多的路径（加载较慢），也不要把多个外部库 jar 混放到同一目录（易产生 jar 冲突）。

2. 在无 GUI 场景（命令行执行 splx）下，可手动编辑 `安装目录/esProc/config/raqsoftConfig.xml` 添加外部库目录。例如：

```xml
<Esproc>
…
// Configure path of the external library folder
<extLibsPath>D:\raqsoft\esProc\extlib</extLibsPath>
<importLibs>
// Configure path of the external library folder
<lib>FtpCli</lib>
</importLibs>
</Esproc>
```
