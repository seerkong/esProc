## 提取内容
4.2 From a third-party application

很多场景下，外部库能力会和 esProc 一起嵌入到第三方应用中。这时需要在 `raqsoftConfig.xml` 的 `<Runtime><EsProc>...</EsProc></Runtime>` 节点下手动写入如下配置：

```xml
<extLibsPath>外部库目录路径</extLibsPath>
<importLibs>
  <lib>外部库目录名</lib>
</importLibs>
```

下面以“在 Java 应用中嵌入 esProc”说明外部库部署与连接：

1. 加载必要 jar
- 可参考 esProc Tutorial 中的 Deploying JDBC。
- 除 esProc 必需 jar 外，还需把目标外部库的 Raqsoft 核心 jar 与相关第三方 jar 放到目标目录。
- 各外部库所需 jar 可参考 Deployment 章节。

2. 配置 `raqsoftConfig.xml`
- 可参考 esProc Tutorial 中的 Configuring raqsoftConfig.xml 配置 `<lib>` 节点。
- 例如访问 WebserviceCli：核心 jar 位于 `C:\Program Files\raqsoft\esProc\extlib\WebserviceCli`，配置如下：

```xml
<extLibsPath>C:\Program Files\raqsoft\esProc\extlib</extLibsPath>
<importLibs>
  <lib>WebserviceCli</lib>
</importLibs>
```

- 若需访问多个外部库：

```xml
<importLibs>
  <lib>WebserviceCli</lib>
  <lib>FtpCli</lib>
</importLibs>
```

3. 部署并访问 WebserviceCli 的 splx 示例：

```spl
=ws_client("http://www.webxml.com.cn/WebServices/WeatherWebService.asmx?wsdl")
// Access the weather forecast server
=ws_call(A1,"WeatherWebService":"WeatherWebServiceSoap":"getSupportProvince")
// Access the domestic flights schedule server
```

splx 文件部署可参考 esProc Tutorial 中的 Java Invocation。完成后即可在 Java 应用中调用该 splx。
