## 提取内容
3.4 Cdc

1. CdcCli 提供 Cdc 外部库函数。目录：`安装目录\esProc\extlib\CdcCli`，对应 Raqsoft 核心 jar：`[安装目录]\esProc\extlib\CdcCli\scu-cdc-cli-2.10.jar`。
2. 需要 JRE 1.7 及以上。若需使用自定义 JRE，请在 `安装目录\esProc\bin\config.txt` 中配置 `java_home`；若版本满足可跳过。
3. 使用 CdcCli 需要数据同步工具（如 Debezium、Ogg）。

### 3.4.1 Debezium

Debezium 数据同步工具位于 `DebeziumCli` 目录（`[安装目录]\esProc\extlib\DebeziumCli`）。该工具依赖 Debezium（支持 3.0.0 及以上），将数据库（目前支持 MySQL、PostgreSQL）上的新增、删除、修改变更写入多路复用组表。

（1）对应 Raqsoft 核心 jar：`[安装目录]\esProc\extlib\DebeziumCli\scu-debezium-2.10.jar`。

（4）启动 MySQL 或 PostgreSQL。

（5）启动数据同步工具。命令与参数如下：

`start_server.bat 参数1 参数2`

- 参数1：同步数据文件目录，可用绝对/相对路径。同步完成后会在该路径下自动生成 `dirout` 目录存放多路复用组表。默认值为当前目录；该参数不可单独省略。
- 参数2：连接的 `.properties` 配置文件，默认 `mysql.properties`。

例如：
`start_server.bat F:/tmp/myTest postgres.properties`

表示使用 `postgres.properties`，同步产物保存到 `F:/tmp/myTest/dirout`。

（7）面向同步产物组表的函数为 `cdc_collect()` 与 `cdc_merge()`。可在【Help】-【Function reference】中查看用法。

### 3.4.2 Ogg

Ogg 数据同步工具位于 `OggCli` 目录（`[安装目录]\esProc\extlib\OggCli`）。该工具通过 Ogg 将数据库（目前支持 Oracle）的增删改变更写入多路复用组表。

（1）对应 Raqsoft 核心 jar：`[安装目录]\esProc\extlib\OggCli\scu-oggplug-2.10.jar`。

目录内还包括：

fastjson-1.2.2.jar

注：压缩包内已包含第三方 jar，用户可按具体场景选取。

（2）在现有 OGG 环境中，在目标端配置 `[OGG安装路径]/dirprm/javaue.properties`：

① 将 `gg.handler.sample.type` 设为 `com.scudata.lib.cdc.SplHandler`

② 加载以下 jar：
- OggCli 目录中的 `fastjson-1.2.7.jar`、`scu-oggplug-2.10.jar`
- esProc 类路径（`[安装目录]\esProc\lib`）中的 `esproc-bin-********xxxx.jar`（社区版为 `esproc-xxxx.jar`）、`icu4j-60.3.jar`、`lz4-1.3.0.jar`

`javaue.properties` 示例：

…
gg.handler.sample.type= com.scudata.lib.cdc.SplHandler
…
javawriter.bootoptions=-Djava.class.path=.,ggjava/resources/classes,ggjava/resources/lib/ggcmdui-12.2.0.1.2.001.jar,/ggjava/resources/lib/*,ggjava/ggjava.jar, /home/esProc/extlib/OggCli/fastjson-1.2.7.jar,/home/esProc/extlib/OggCli/scu-oggplug-2.10.jar,/home/esProc/lib/icu4j-60.3.jar,/home/esProc/lib/esproc-bin-********.jar,/home/esProc/lib/lz4-1.3.0.jar

（3）配置并启动 `javaue` 进程。

（4）启动后，可在数据库执行增删改，变更会记录到 `dirout` 下的多路复用组表：

（5）面向同步产物组表的函数为 `cdc_collect()` 与 `cdc_merge()`。可在【Help】-【Function reference】中查看用法。
