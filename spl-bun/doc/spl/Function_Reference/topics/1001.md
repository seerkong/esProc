webhdfs()
说明：
Implement an operation on file data, such as
download and upload.
语法：
webhdfs( url , localFile )
注意：
The
WebcrawlCli external library function (See External Library Guide ) implements any operations
within HDFS and WebHDFS.
参数：
|
url
|
URL
of the target file.
|
localFile
|
The
target file; can be omitted.
返回值：
Operation
successful or failed
示例：
|
=webhdfs("http://localhost:50070/webhdfs/v1/test/z1.zip?op=CREATE&user.name=root","D:/z1.zip")
|
Upload
folder D:/z1.zip .
|
=webhdfs("http://localhost:50070/webhdfs/v1/test/f2.png?op=CREATE&user.name=root&overwrite=true","
D:/f2.png")
|
Upload
folder D:/f2.png , and force an overwriting when a namesake folder
already exists .
|

|
Append
data in D:/f4.txt to f3.txt .
|
=webhdfs("http://localhost:50070/webhdfs/v1/test/f5.xlsx?op=OPEN&user.name=root","D:/f5.xlsx")

Download
f5.xlsx .
|
=webhdfs("http://localhost:50070/webhdfs/v1/test/?op=LISTSTATUS&user.name=root")
|

string .
|
