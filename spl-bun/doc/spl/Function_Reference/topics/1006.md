workdays()
说明：
Get
a sequence of workdays between two dates inclusive.
语法：
workdays( b , e,h )
注意：
The
function gets a sequence of workdays between date b and date e ; by default,
the two end points are included. Members of h
are either weekend or holidays. If there is an on-duty shift in a weekend day,
take it as the weekday.
参数：
|
b
|
A date value .
|
e
|
A date value .
|
h
|
A sequence composed of values of date data
type .
选项：
|
@n
|
Return
the number of workdays between.
|
@x
|
Do
not include date e
when getting the workdays between.
|
@b
|
Use
binary search algorithm when sequence h is ordered.
Return
value:
Sequence
