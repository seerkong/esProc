xlsclose()
说明：
Close an Excel file object.
语法：
xo. xlsclose ()
注意：
The function closes an Excel file object.
Note that An Excel file object opened with @r@w options must be closed.
参数：
|
xo
|
An Excel 对象 .
示例：
|
=file("E1.xls").xlsopen@r()
|
Read an Excel file and return the file
object .
|
=A1.xlsclose()
|
Close an Excel file object .
