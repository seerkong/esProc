f. xlsimport()
说明：
Retrieve contents of an Excel file and return
them as a table sequence.
语法：
f . xls import ( F i ,…; s , b : e;p )
注意：
The function retrieves field Fi from row b to row e from Excel file f ’s sheet s and returns them as a table sequence. Retrieve data from the first row to the
last one when both parameter b and
parameter e are
absent.
参数：

Excel file.
|

|

name or sheet number; use the first sheet when omitted.
|

|

number of rows. Retrieve rows backwards when e <0 .
|

The password for
