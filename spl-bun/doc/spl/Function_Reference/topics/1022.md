xo.xlsmove()
说明：
Move a worksheet in an
Excel 对象.
语法：
xo. xlsmove ( s , s’ ; xo’ )
注意：
The function moves a
worksheet named s in Excel 对象 xo to another Excel 对象 xo’ and rename it s' .
When xo’ is absent, the
function renames worksheet s in Excel 对象 xo s' . If parameter s' is also absent at
the same time, just delete worksheet s .
When parameter xo’ is present but
parameter s' is absent, worksheet s will continue to use the current
name.

|

object xo .
|

|
xo’
|
Excel 对象.
选项：
|
@c
|

返回值：
