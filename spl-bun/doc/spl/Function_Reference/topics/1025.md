xml()
说明：
Parse a string/a table sequence in an XML format.
语法：
xml ( x,s )
注意：
If
parameter x is
an XML string, the function parses it as multilevel records or a table
sequence; if x is a
table sequence, the function parses it into an XML string.
参数：
|
x
|
An
XML string/a table sequence.
|
s
|
The to-be-retrieved level; use the slash /
as the separator if there are multiple to-be-retrieved levels; retrieve data
from the root if it is absent.
选项：
|
@s
|
The options enables parsing an XML string
in the format of K F=v F=v …>D</K> into records made up of fields K,F,…
Three situations: If K’s value is D and D is multilevel XML data, the parsing
result is a record sequence; if <K …./K>, D is parsed into null; if <K…></K>,
D is parsed into an empty string .
|
@b
|
Won’t
convert data type automatically during parsing, but generate string values
for all data.
Return
value:
Table
sequence/XML string/Multilevel records
