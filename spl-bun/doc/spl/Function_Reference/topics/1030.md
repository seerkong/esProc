## 提取内容
ym2_env()
说明：
Initialize environment.
语法：
ym2_env ( appPath, configFile,
pythonPath )
注意：
YmodelCli external library function (See YModel User Reference ).
The function initializes
environment. It loads related files from the specified location by configuring
parameter appPath
only, which is
the YModel installation directory. Return 1 when the environment configuration
succeeds; otherwise return 0.
参数：
|
appPath
|
YModel installation directory.
|
configFile
|
Full path of configuration file userconfig.xml .
|
pythonPath
|
Full path of the executable file .exe for
starting the Python service .
Return
value:
1or

|
