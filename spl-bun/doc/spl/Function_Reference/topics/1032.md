## 提取内容
ym2_model()
说明：
Use a mcf file to build models.
语法：
ym2_model ( mcfFile, target )
注意：
YmodelCli external library function (See YModel User Reference ).
The function uses a mcf file to
build models and returns a pcf file object.
参数：
|
mcfFile
|
mcf
file object .
|
target
|
The
target variable; use the one set up in the mcf file by default .
Return
value:
pcf
file object
示例：
|
=ym2_env("F:/ymodel")
|
=ym2_mcfload("F:/ymodel/documents/csv/train.mcf")
|
Read an mcf file as an mcf object.
|
=ym2_model(A2,"Embarked")
|
Use
A2’s mcf file object to build models and set up the targe variable as
Embarked.
|
=ym2_model(A2)
|
Use
the target variable set up in A2 to build models.
|
>ym2_close()
|
