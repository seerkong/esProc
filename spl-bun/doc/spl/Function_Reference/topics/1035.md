## 提取内容
ym2_predict()
说明：
Perform data prediction.
语法：
ym2_predict ( pcfObj, data )
注意：
YmodelCli external library function (See YModel User Reference ).
The function performs data
prediction and returns prediction result object.
参数：
|
pcfObj
|
pcf
object .
|
data
|
Data
used for prediction, which can a .mtx/.csv file, a table sequence or a cursor .
Return
value:
Prediction
result object
示例：
|
=ym2_env("F:/ymodel")
|
Initialize
environment.
|
=ym2_pcfload("F:/ymodel/data/train.pcf")
|
Return
a pcf file object.
|
=ym2_predict(A2,"F:/ymodel/data/train.csv")
|
Use
a .csv file to perform the prediction.
|
=file("F:/ymodel/data/train.xls").xlsimport@t()
|
Read
train.xls file and return a table sequence.
|
=ym2_predict(A2,A4)
|
Use
the table sequence to perform prediction.
|
=file("F:/ymodel/data/train.txt").cursor@t()
|
Create
cursor based on train.xls to return.
|
=ym2_predict(A2,A6)
|
Use
the cursor to perform prediction.
|
>ym2_close()
|
Release
resources.
