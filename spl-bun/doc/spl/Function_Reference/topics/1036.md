## 提取内容
ym2_result()
说明：
Present the prediction result.
语法：
|
ym2_result ( preObj )
|
Display
the prediction result .
|
ym2_result@s ( mcfObj, varname )
|
Return
result of aggregation on a certain field of the mcf object .
注意：
YmodelCli external library function (See YModel User Reference ).
The function presents the
prediction result and returns a table sequence.
参数：
|
preObj
|
Prediction
result object / pcf object .
|
mcfObj
|
mcf
object .
|
varname
|
Field
name .
选项：
|
@p
|
Return
model performance information .
|
@r
|
Return
model display information .
|
@i
|
Return
the degree of importance .
|
@s
|
Return
information of aggregation on a field .
|
@j
|
Return
a JSON string; the option works with another option, such as @ij, but it does
not work with @s option .
Return
value:
Table
sequence
示例：
|
=ym2_env("F:/ymodel")
|
Initialize
environment.
|
=ym2_mcfload("F:/tmp/train.mcf")
|
Return
an mcf object.
|
=ym2_pcfload("F:/tmp/train.pcf")
|
Return
a pcf object.
|
=ym2_predict(A3,"F:/tmp/train.csv")
|
Perform
data prediction.
|
=ym2_result(A4)
|
Use
the prediction result object to present the prediction result.
|
=ym2_result@p(A3)
|
Use
a pcf object to present model performance.
|
=ym2_result@s(A2,"Age")
|
Return
information of aggregation on Age field in the mcf object.
|
=ym2_result@ij(A4)
|
Return
the prediction result’s degree of importance as a JSON string.
|
>ym2_close(A4)
|
Release
resources.
