T.attach(T’)
说明：
Open a composite table's attached table.
语法：
T. attach ( T’ )
注意：
The function opens composite
table T ’s attached table T’ ; can update or modify it.
Cannot read an attached
table record if its primary key value does not have a primary key match in the
base table; will not check the primary key match status between the attached
table and the base table when appending data to or updating data in the
attached table.
参数：
|
T
|
Base table.
|
T’
|
Attached table name.
返回值：
Attached table object
