zip_del()
说明：
Delete one or more files from a zip file.
语法：
zip_del( zip, files )
注意：
The
ZipCli external library function (See External Library Guide ) removes
one or more specified file from a zip file.
参数：
|
zip
|
zip file object .
|
files
|
compressed file or a FileObject; can be a sequence .
Return
value:
Boolean
示例：
|
=zip_open("D:/z2.zip")
|
Open
a zip file.
|
=zip_del(A1, "dir1/*.java")
|
Delete
all .java files in z2.zip.
|
>zip_close(A1)
|
Close
a zip file.
