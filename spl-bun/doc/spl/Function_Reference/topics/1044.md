## 代码片段
```spl
zip_extract()
=zip_open("D:/z2.zip")
=zip_extract(A1,"*.txt")

>zip_close(A1)
```

## 提取内容
zip_extract()
说明：
Extract one or more files from a zip file.
语法：
zip_extract( zip,
files, path )
注意：
The
ZipCli external library function (See External Library Guide ) extracts
one or more specified files from a zip file to a path and returns a list of
successfully extracted files.
参数：
|
zip
|
zip file object .
|
files
|
compressed file or a file object; can be a sequence .
|
path
|
path, which can be an absolute one or a relative one .
选项：
|
@s
|
Extract files from both the
current directory and its subdirectories of the compressed file; extract files
only from the current directory by default .
Return
value:
File list
示例：
|
=zip_open("D:/z2.zip")
|
Open
a zip file.
|
=zip_extract(A1,"*.txt")
|
Extract
txt files into D:/ directory
holding the zip file
|
=zip_extract(A1,"*.csv","D:/csvfile")
|
Extract
csv files into D:/csvfile
directory.
|
=zip_extract@s(A1,"empinfo.csv","D:/csvfile/file1")
|
Extract
empinfo.csv under z2.zip ’s subdirectory to D:/csvfile/file1 .
|
>zip_close(A1)
|
Close
a zip file.
