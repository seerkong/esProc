Batch Computation
说明：
Compute
a series of expressions one by one in an automatic fashion, and return the
result of the last expression.
语法：
( x 1 , x 2 ,…, x k )
注意：
The
later expressions can reference the variable values computed by the preceding
expressions for value assignment.
参数：
|
x k
|
Expressions
you want to compute in batch.
示例：
|
=(1,1+2,2+3)
|
=(a=1,b=a*3,c=b+5,a+b+c)
|
