avg()
说明：
Compute
average of members of a sequence.
语法：
|
A .avg( x )
|
avg ( x 1 ,…, x n )
|
Equivalent to A .avg() , where x 1 ,…, x n
are members of sequence A
注意：
The
function computes x with each member
of sequence A and returns average
value of the non-null members, during which non-numeric members are ignored.
When non-null, numeric members are zero, the average is null.
参数：
|
sequence.
|
x
|
An
expression; cannot be omitted when sequence A is a record sequence or a table sequence.
返回值：
数值型al
value
