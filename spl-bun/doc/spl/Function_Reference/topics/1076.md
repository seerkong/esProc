# Code comments

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
>A1=A1+A2
```

## 提取内容
Code comments
说明：
Code
comments explain the code.
语法：
/*...*/
注意：
Code comments explain the code and will be skipped during
parsing. The comments can be nested; and contents enclosed by double quotations are not a comment.
Cell names in a comment will be auto-adjusted during editing.
示例：
|
for 5
|
>A1=A1+A2
|
/* =A1 */
|
Skip
B4’s contents during parsing as they are a comment.
|
"/* =A1 */"
|
The
contents enclosed in double quotations are not a comment and the code returns
a string.
