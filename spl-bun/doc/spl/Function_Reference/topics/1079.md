## 提取内容
G.hlink
说明：
Get
the hyperlink string from a chart.
语法：
G . hlink ()
注意：
The
function gets a hyperlink string corresponding to a non-SVG image. After
hyperlink is set for a finished chart, click the chart displayed on the WEB
side and make the jump. Detailed uses can be found in Web Integration and
Hyperlink .
参数：
|
G
|
The
canvas object.
返回值：
Hyperlink
string
示例：
|
=canvas()
|
Define
a canvas object.
|
=A1.plot("Text",
"text":"hello
word!",
"htmlLink":"https://www.raqsoft.com/",
"width":200,
"height":200,
"barType":256,
"data1":250,
"data2":250)
|
Use
Text element to draw a 2D barcode.
"htmlLink": https://www.raqsoft.com/ means setting the hyperlink string in a chart element.
|
return
A1.draw@p(400,400),A1.hlink()
|
Return the image byte and image hyerlink.
