## 提取内容
G.plot()
说明：
Plot
elements the chart will use.
语法：
G . plot ( e,a i : x i : A i ,…)
注意：
The
function plots a chart element named e in canvas object G and
sets value of chart element parameter a i as x i .
If the parameter value has the corresponding coordinate axis, it is A i .
You
can check all available chart element parameters in Chart Elements . Among the chart elements, text element has properties for plotting
the 2D barcode.
参数：
|
G
|
The canvas object .
|
e
|
Chart element name, for example, MapAxis,
数值型Axis, EnumAxis, 日期Axis, BackGround, Column, Line, Dot, Polygon,
Text, Legend, Sector and so on.
|
a i
|
Parameters
of chart element, for example, the name, logicData, and physical Data
parameters in the chart element of MapAxis. For more details, please refer to
sections about chart element parameters.
|
x i
|
Parameter value .
|
A i
|
Coordinate axis corresponding to the
parameter value .
返回值：
Chart
element information
