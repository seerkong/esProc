pieType
Types of pie charts include
basic pie chart and 3D pie charts.
pieSpacing
Whether explode one of the
sectors of the pie or not.
pieRotation
It sets the rotation angle
by specifying the ratio of the length of the radial axis to that of the polar
axis in a 3D pie chart.
pieHeight
It sets the 3D pie chart
height by specifying the ratio of pie height to the radius.
pieJoinLineColor
The color for guide lines
for presenting label text in a 3D pie chart.

The categories of data. If
not specified, then select from the crossover sequence of the series and
categories. For example, from the crossover sequence =["Tom,
Maths","Tom, English","Tom, French","Mary,
Maths","Mary,English","Mary,French"], the
["Tom","Mary"] is auto-retrieved as the category values.
values
Plotting data of a
specified type of graph, referred to as data of multiple series in each
category.

Font for the chart title.

Whether the chart title
uses the bold or not.
graphTitleVertical
Whether the chart title
uses vertical text or not.
graphTitleSize
Font size for the chart
title.
graphTitleColor
Color for the chart title.

Angle of rotation of chart

The space left for the

Whether or not display

topData
It uses data with top
values to plot a chart. If there are many categories of data, use top rows of
data with greatest values to plot the chart, so that graphs in the resulting
chart will not be too dense to reduce the readability.
In this case, to maintain
data integrity, the system will combine the rest of the categories of data into
a whole and display them as an individual “Others” category.
