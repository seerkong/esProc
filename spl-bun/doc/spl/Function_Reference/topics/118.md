## 提取内容
bit1(x,y)
说明：
Calculate bitwise XOR and get the number of 1s in
complement of the result in binary.
语法：
bit1( x,y )
注意：
The function calculates bitwise XOR on x and y ,
returns the result, and then gets the number of 1s in complement of the result in
binary.
When both x and y are sequences, calculate
bitwise XOR on them, return result as a sequence, and then find the total
number of 1’s in complements of the result sequence’s all members in binary.
参数：
|
x
|
A long integer or a sequence of long integers .
|
y
|
A long integer or a sequence of long integers .
Return
value:
Integer
