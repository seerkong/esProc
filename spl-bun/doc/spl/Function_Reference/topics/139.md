## 提取内容
cdc_merge()
说明：
记录
the final updated data in a table when data synchronization tool is used to
perform summary.
语法：
cdc_merge (cdcPath
table, startTime[,endTime])
注意：
CdcCli
External library function (See External Library Guide ) .
The function merges data added, deleted and
modified in one of the zone tables of a multizone composite table, and returns
the final updated data.
参数：
|
cdcPath
|
The
path of dirout folder, which stores the multizone composite table generated
from data collection by the data synchronization tool.
|
table
|
Table
name (only support a single table); cannot be omitted.
|
startTime/endTime
|
The
starting and ending time of data collection. The format is yyyy-MM-dd
HH:mm:dd or yyyy-MM-dd. startTime cannot
be omitted. When endTime is absent, use the current time. When both
parameters are present, the value is a left-closed, right-open interval.
Return
value:
Table sequence

|

08:00:00","2023-06-01 10:00:00")
