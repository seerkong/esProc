## 提取内容
charencode()
说明：
Generate
the binary value of a string according to the character set the latter uses, or
vice versa.
语法：
charencode ( str/rawtext , [ charset ])
注意：
Character
sets the function supports include UTF-8, UTF-16, GBK, GB2312, GB18030, BIG5,
UNICODE, UnicodeEscape, ISO8859_1, ASCII, EUC_KR, EUC_JP, ISO-2022-CN-GB,
ISO-2022-CN-CNS, ISO-2022-JP and ISO-2022-KR.
参数：
|
str
|
A string .
|
rawtest
|
A binary value .
|
charset
|
A character set, such as UTF-8 and GB2312; default is the one currently
used by the system .
返回值：
Binary
value/字符串
示例：
|
>cs="GBK"
|
Set
the character set.
|
=charencode("abc 一二三 123")
|
Generate
the binary blob data according to the default character set.
|
=charencode("abc 一二三 123",
cs)
|
Generate
a binary value according to GBK.
|
=charencode (A2)
|
Return
the string of binary data according to the default character set.
|
=charencode (A3, cs)
|
Return
the string of binary value according to GBK .
