## 提取内容
chn()
说明：
Write a number with the Chinese numerals.
语法：
chn( x )
注意：
The function writes a number x
according to the number system based on Chinese characters that correspond to
numerals in spoken language.
参数：
|
x
|
When no options are present or when @a and
@u options work, parameter x should
be an integer
When @b option works, parameter x should be float type .
选项：
|
@a
|
Write the specific number with
the Chinese number system in the format of billion, ten thousand, thousand,
hundred, ten in order .
|
@u
|
Write the specific number with
upper case Chinese numerals .
|
@b
|
Write the specific number using
Chinese characters used for numbers on renminbi banknotes .
示例：
|
=chn(97)
|
Result: 九七 .
|
=chn(-97)
|
Result: 负九七 .
|
=chn@a(128)
|
Result: 一百二十八 .
|
=chn@a(-2594)
|
Result: 负二千五百九十四 .
|
=chn@u(128)
|
Result: 壹贰捌 .
|
=chn@u(-128)
|
Result: 负壹贰捌 .
|
=chn@b(1238.35)
|
Result: 一千二百三十八元三角五分 .
|
=chn@ub(100)
|
Result: 壹佰元整 .
