complex()

Create
a sequence of complex numbers.
语法：
|
complex (A,B)
|
Create
a sequence of complex numbers using sequence A of real parts and sequence B
of imaginary parts; if A and B do not have same length, automatically use 0
to fill the absent part.
|
complex (C)
|
Use
sequence C of number pairs to create a sequence of complex numbers; if a
member of C is a single value, take it as the real part by default and use 0
as the imaginary part.
