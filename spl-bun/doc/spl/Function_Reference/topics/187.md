说明：
Get
concatenation of all sequence-type members.
语法：
A .conj( x )
注意：
The
function concatenates all the sequence-type members in sequence A ; compute expression x by loop and then concatenate the
results when parameter x is present.
A.conj(x,…)
is equivalent to A.(x,…).conj().
选项：
|
@r

|

sequences; only supported by esProc Enterprise Edition.

|
A sequence whose members are sequences .
|
x
