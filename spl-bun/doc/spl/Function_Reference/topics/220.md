## 提取内容
A.cursor@m(n)
说明：
Generate a multicursor from a
sequence.
语法：
A. cursor@m ( n )
注意：
The function generates a
multicursor using sequence A .
参数：
|
A sequence.
|
n
|
Number of subcursors; by
default the value is 【 Default
subcursor count in a multicursor 】 configured in the designer; when integrating esProc in a third-party
application, its default value is cursorParallelNum value configured in raqsoftConfig.xml file .
选项：
|
@p
|
Assume the sequence is ordered by the 1 st field and
records having same 1 st field value won’t be put into two segments .
返回值：
多游标
示例：
|
=demo.query("select
CLASS,STUDENTID,SUBJECT,SCORE
from SCORES")
|
Return a sequence .
|
=A1.cursor@m()
|
Generate a multicursor from
A1’s sequence; as parameters are absent, use value of 【 Default subcursor count in a multicursor 】 as the default number of subcursors .
|
=demo.query("select
CLASS,STUDENTID,SUBJECT,SCORE
from SCORES").sort(CLASS)
|
Return a sequence ordered by
the 1 st field .
|
=A1.cursor@mp(3)
|
Generate a multicursor having
three subcursors; with @p option, the segmentation won’t put records having
same CLASS value in two segments .
