说明：
Synchronously
segment a cluster entity table according to a cluster multicursor and return a
cluster multicursor.
语法：
T. cursor ( x;C,…;wi;mcs )
注意：
The
function synchronously segments cluster entity table T according to cluster multicursor mcs , during which T ’s
dimension and mcs ’s key will be
matched, and returns a cluster multicursor; the way of distributing T and mcs among nodes must be the same and the fields for segmenting T and mcs should be consistent. If multiple cluster entity tables are
involved, use a cluster multicursor as a reference to make sure the
segmentation is synchronous.

supported by esProc Enterprise Edition.
