Generate multiple
derivative variables for a datetime sequence variable.
语法：

|
During
modeling, generate multiple variables for datetime variable A for building
models and return a binary sequence where the first bit is a table sequence
made up of all the derivative variables and the second bit is generation
process records Rec; the derivative variables automatically perform
subsequent pre-processing.

variables used for model building according to datetime variable A and
generation process records Rec.
