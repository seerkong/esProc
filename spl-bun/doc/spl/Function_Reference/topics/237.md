## 提取内容
P.datederive()
说明：
Generate multiple
derivative variables from a date table sequence/record sequence variable.
语法：
|
P.datederive( cn, T )
|
During
modeling, generate multiple variables for datetime variable cn for building
models and return a binary sequence where the first bit is a table sequence
made up of all the derivative variables and the second bit is generation
process records Rec; the derivative variables automatically perform
subsequent pre-processing.
|
P.datederive@r( cn, Rec )
|
During
scoring, generate a table sequence consisting of multiple derivative
variables used for model building according to datetime variable cn and
generation process records Rec.
注意：
MathCli external library
function (See External Library Guide ).
参数：
|
P
|
table sequence/record sequence.
|
cn
|
string/number, which is the name of column (or the column number starting
from 1) – the to-be-pre-processed variable – in a table sequence or record
sequence.
|
T
|
The
target variable value used to perform potential data smoothing.
|
Rec
|
sequence of generation process records.
选项：
|
@bnie
|
Each
option specifies a target type, and options are mutual-exclusive
automatically judge the type when no option is used; the order of priorities
of the options is binary, numeric, integer and enumerated.
返回值：
Sequence/Table sequence
