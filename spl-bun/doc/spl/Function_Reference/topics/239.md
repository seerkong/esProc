A.dateinterval()
说明：
Generate multiple date
difference variables for a datetime sequence/table sequence variable.
语法：
|
A.dateinterval( T )
|
During
modeling, generate multiple date difference variables for a sequence of
datetime variables and return a binary sequence where the first bit is a
table sequence made up of all the derivative variables and the second bit is
generation process records Rec; the derivative variables automatically
perform subsequent pre-processing.
|
A.dateinterval@r( Rec )
|
During
scoring, generate a table sequence consisting of multiple date difference
variables according to sequence A of datetime variables and generation
process records Rec.
注意：
MathCli external library function (See External Library Guide ).
It generates multiple date
difference variables for datetime sequence/table sequence variable A .
