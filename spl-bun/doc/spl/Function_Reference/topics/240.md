## 提取内容
P.dateinterval()
说明：
Generate multiple date
difference variables for a datetime table sequence/record sequence variable.
语法：
|
P.dateinterval( cns, T )
|
During
modeling, generate multiple date difference variables for sequence cns of
datetime variables and return a binary sequence where the first bit is a
table sequence made up of all the derivative variables and the second bit is
generation process records Rec; the derivative variables automatically
perform subsequent pre-processing.
|
P.dateinterval@r( cns, Rec )
|
During
scoring, generate a table sequence consisting of multiple date difference
variables according to sequence cns of datetime variables and generation
process records Rec.
注意：
MathCli external library
function (See External Library Guide ).
参数：
|
P
|
table sequence/record sequence.
|
cns
|
sequence of names of columns (or column numbers starting from 1) of a record
sequence.
|
T
|
sequence of target variable values used to perform potential data smoothing.
|
Rec
|
sequence of generation process records.
选项：
|
@bnie
|
Each
option specifies a target type, and options are mutual-exclusive
automatically judge the type when no option is used; the order of priorities
of the options is binary, numeric, integer and enumerated.
返回值：
Sequence/Table sequence
