## 提取内容
datetime()
说明：
Convert
a string or long integer to datetime value .
语法：
|
datetime( s )
|
Convert
string s into datetime
value according to system-defined datetime format; return null if the
conversion fails.
|
datetime( s , fmt :loc )
|
Convert
string s to datetime
type according to the format defined by parameter fmt and
return null if the conversion fails
When parameter fmt is
absent, the format of string s
should be the same as that of the datetime value in configuration information ; parameter loc is the
language, whose default is the system language.
|
datetime( l )
|
Convert
long integer type to datetime.
|
datetime( d , t )
|
Concatenate
date d and time t into a
datetime .
|
datetime( y , m , d , h , m , s )
|
Convert
y , m , d , h , m , s of integer type to datetime data .
注意：
The
format of the specified string should match the datetime format .
The
datetime format in the conversion result should be consistent with that
specified in the configuration file. Click Options -> Environment ->
日期time Format in IDE to perform the settings. When esProc is integrated
into a third-party application, set up the date format in raqsoftConfig.xml ’s
dateTimeFormat node.
参数：
|
s
|
字符串.
|
fmt
|
Format
string.
|
loc
|
Language
name, which is case insensitive. The most commonly used languages are Chinese
(zh) and English (en); see A.sort() to know other languages supported in
esProc.
|
l
|
Long
integer counted in microseconds.
|
d
|
日期
type.
|

|
Time
type.
|
y

|

|

integer, day.
|

integer, hour.
|

integer, minute.
|
s
|

integer, second.
