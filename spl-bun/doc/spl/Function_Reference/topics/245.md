## 提取内容
days()
说明：
Get
the number of days of the year, quarter or month to which the specified date
belongs.
语法：
days( dateExp )
注意：
The
function gets the number of days of the year, quarter or month to which the
specified date dateExp belongs.
参数：
|
dateExp
|
date or a date string of standard format.
选项：
|
@q
|
Get
the number of days of the quarter to which the specified date belongs.
|
@y
|
Get
the number of days of the year to which the specified date belongs
By
default, get the number of days of the month to which the specified date
belongs.
|
@o
|
Get
an integer according to the specified date.
返回值：
Integer
示例：
|
=days(datetime("19800227","yyyyMMdd"))
|
=days (datetime("2006-01-15 10:20:30"))
|
=days@y(datetime("19800227","yyyyMMdd"))
|
=days@q(datetime("2006-01-15 10:20:30"))
|
=days@o(date(“2022-12-12”))
