decimal()
说明：
Convert
a string or a numeric value to a big decimal number.
语法：
decimal( stringExp )
decimal( numberExp )
注意：
The parameter stringExp is a string consisting of a number (and sometimes a decimal point).
The parameter numberExp is a numeric value which is less than or equal to 64 bits. For
values more than 64 bits, you will have to use the stringExp to represent them.
参数：
|
stringExp
|
specified numeric string.
|
numberExp
|
numeric value.
返回值：
Big
decimal number

|
decimal("123456789012345678901234567890")
|
decimal(1234567890123456)
|
1234567890123456 (BigDecimal type)
