## 提取内容
P.derive ()
说明：
Generate
a table sequence according to a record sequence.
语法：
P . derive ()
注意：
The
function creates a table sequence by copying the data structure of record
sequence P in order to use the table
sequence functions.
参数：
|
P
|
record sequence .
选项：
|
@o
|
Do not copy the record sequence’s data
structure, which will change the record sequence’s structure and which will
adjust the number of fields as needed. The option will achieve a better
performance as well as an increased risk of error. It’s recommended to be
used only when the original record sequence is no longer needed. The option
is disabled when there are pure table sequence records in the record sequence .
Return
value:
Table
sequence
示例：
|
=demo.query("select * from SCORES")
|
=A1.select(SCORE>90)
|
Return
a record sequence.
|
=A2.derive()
|
Generate
a table sequence from the record sequence.
|
=A2.derive@o()
|
Directly
reference the records of the record sequence, instead of generating new ones.
