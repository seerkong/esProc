digits()
说明：
Convert
a numeric string of a certain number system to another number system.
语法：
digits ( x:ds,dd )
注意：
The
function converts string x
represented by number system ds to number
system dd ; supports base 62 at most.
When parameters ds or dd are absent, the default number system
is decimal.
参数：
|
x
|
数值型
string; use letters to represent a number greater than 10 .
|
ds
|
An
integer specifying a number system, which means x uses ds number system .
|
dd
|
An
integer specifying a number system, which means converting x into dd number system .
Return
value:
数值型
string
示例：
|
=digits("1515":10,16)
|
5eb
|
=digits("5eb":16,10)
|
