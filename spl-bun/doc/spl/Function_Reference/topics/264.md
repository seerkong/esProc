# directory(path)

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
directory(path)
directory( path )
=directory("D://*.txt")
=directory@d("D://tomcat5")
=directory@m("D://test")
=directory@r("D://test")
=directory@s("D://tomcat5")
=directory@p("D://tomcat5")
=directory@c("d://TOMCAT5/*.txt")
```

## 提取内容
directory(path)
说明：
List
the file name(s) satisfying a wildcard path.
语法：
directory( path )
注意：
The
function lists file name(s) satisfying wildcard path path , excluding the path names.
参数：
|
path
|
Wildcard
path, * represents 0 or multiple characters, and ? represents a single
character .
选项：
|
@d
|
List
the subdirectory of path .
|
@p
|
List
files with full paths under the directory .
|
@m
|
Create
a directory; mutually exclusive with @s and @d .
|
@r
|
Delete
a directory, which must be empty .
|
@s
|
Perform
recursive query to get all file names under all subdirectories; mutually
exclusive with @m and @r .
|
@c
|
Make
case-insensitive; without it the OS will have a say .
返回值：
Sequence
示例：
|
=directory("D://*.txt")
|
Return
the txt file list under the root directory on driver D.
|
=directory@d("D://tomcat5")
|
List
the subdirectory under the tomcat5 directory .
|
=directory@m("D://test")
|
Create
test folder under the root directory on driver D.
|
=directory@r("D://test")
|
Delete
D://test
directory, but the test
folder must be empty.
|
=directory@s("D://tomcat5")
|
Return
a list of files in subdirectories under the tomcat5 directory.
|
=directory@p("D://tomcat5")
|
List
full path of files under tomcat5
directory.
|
=directory@c("d://TOMCAT5/*.txt")
|
List
txt files under tomcat5 directory; must be case-insensitive.
