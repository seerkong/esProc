T.dup(h)
说明：
Copy
a local in-memory table onto nodes to create a duplicate cluster in-memory
table.
语法：
T. dup (h)
注意：
The
function copies local in-memory table T
onto node or node sequence h to
create a duplicate cluster in-memory table. The memory footprints will be
cleaned up once T.close() is executed.
Only
supported by esProc Enterprise Edition.
参数：
|
T
|
local in-memory table .
|
h
|
node or a node sequence .
Return
value:
Duplicate
cluster in-memory table
