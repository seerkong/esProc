说明：
Execute
a calculation on data in a DynamoDB table.
语法：
dynadb.execute( sql )

注意：
The
DynamodbCli external library function (See
External Library Guide ) executes insert, modification and delete
operations on a DynamoDB table.
It
allows batch insert, but needs to specify the fields to which data is inserted
at execution because DynamoDB stores data in the structure of key:value.
