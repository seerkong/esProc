dynadb.table()
说明：
Create
or delete a Dynamodb table.
语法：
dynadb.table( tableName,partiton键,type1,sort键,type2 )
dynadb.table@d( tableName )
注意：
DynamodbCli
external library function (See External Library Guide ).
Parameter
tableName and parameter partition键 should be present at
creation; return the table name if the creation succeeds and return false if
the creation fails. The deletion operation only needs option @d and parameter tableName
and returns a Boolean value.
参数：

default type is S; when type2 is present, type1 cannot be
omitted .
|

The
sorting key, which can be omitted at table creation .
选项：
|
