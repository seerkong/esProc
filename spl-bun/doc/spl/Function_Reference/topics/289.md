## 提取内容
es_delete()
说明：
Execute
the delete command and return a Boolean value.
语法：
es_delete ( fd, endpoint, entity ， header )
注意：
The ElasticsearchCli external library function (See External Library Guide )
executes the delete command and returns true if the deletion action is
successful or false if the deletion fails.
参数：
|
fd
|
A REST Client object .
|
endpoint
|
Rest API address .
|
entity
|
A parameter
transmitted through http body, which is a JSON string or a block of data in
JSON format .
|
header
|
A variable parameter
that passes http header; it is a key type JSON string .
Return
value:
Boolean
示例：
|
=es_open("localhost:9200","user":"un1234")
|
Connect
to ES server.
|
=es_delete(A1,"/accounts/person","user:jacker")
|
Delete
the record where user is jacker under the level where index is accounts and type is person .
|
=es_delete(A1,"/student")
|
Delete
the index file where the index is student.
