## 提取内容
es_export()
说明：
Export
data to the local.
语法：
es_export ( fd, filename:cs, indexName, colX )
注意：
The ElasticsearchCli external library function (See External Library Guide ) exports data to the local; only support exporting
data from a JSON or CSV file.
参数：
|
fd
|
restclient object .
|
filename
|
Name of the local file to which data is exported .
|
cs
|
字符集, which is GBK by default .
|
indexName
|
Index name .
|
colX
|
Column
names represented by a sequence; export all fields by default .
Return
value:
Boolean
示例：
|
=es_export(A1,"d:/tmp/emp1.json","emp")
|
Export
all records whose index is emp to the local file emp1.json
|
=es_export(A1,"d:/tmp/emp2.csv":"UTF-8","emp",["EID","NAME","GENDER","BIRTHDAY"])
|
Export
all records whose index is emp to the local file emp2.csv using UTF-8.
