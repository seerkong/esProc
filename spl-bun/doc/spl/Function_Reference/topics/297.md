## 提取内容
qvm.exec()
说明：
Execute
a SPL script file through QVS.
语法：
qvm. exec ( splx ,…; t )
注意：
The
function executes a SPL script file through QVS.
When
configuring cloud storage connection through QVS, execute the target script
file on the cloud storage platform; if the cloud storage is not configured,
execute the script in the QVM main directory.
参数：
|
qvm
|
QVM object .
|
splx
|
SPL script file .
|
…
|
Parameter(s)
of the splx file; multiple parameters are separated by comma .
|
t
|
Time-out
(unit: second); default is 120 .
选项：
|
@x
|
Automatically
close QVM when final value is returned .
Return
value:
Return
value of the SPL script file
示例：
Ø Execute script file on the cloud storage
platform
Create
script file sEmp.splx , for which cellset parameters arg1 and arg2
are added:
|
=Qfile("qtc01/Employees.txt")
|
Read
Employees.txt in storage bucket qtc01 .
|
=A1.import@t()
|
Return
file content as a table sequence.
|
=A2.select(Gender:arg1,Post:arg2)
|
Select
records meeting the specified condition.
|
return A3
|
Return
A3’s result.
Execute script file
sEmp.splx on the cloud storage platform through QVS:
|
=Qconnect("http://54.213.221.123:8080/qvs":"aws-qvs",30,300)
|
Request
QVA through QVS to access QVM.
|
=A1.load("qtc01/sEmp.splx")
|
Upload
script file sEmp.splx to storage bucket qtc01 on the cloud
storage platform.
|
=A1.exec@x("qtc01/sEmp.splx","Male","Sale";100)
|
Execute
script file sEmp.splx in storage bucket qtc01 , and pass Male to
parameter arg1 and Sale to parameter arg2 , and set time-out as
100s.
As
@x option is present, automatically close QVM when execution result is
returned.
Ø Execute script file in QVM main directory
Create
script file getfileqvm.splx , add cellcet parameter txtfile to it,
save the file and upload it to QVM main directory:
|
=file(txtfile)
|
Pass
txt format data file name through parameter txtfile .
|

|
Import
data file content.
Execute
script file getfileqvm.splx in QVM main directory:
|

|
Request
QVA through QVS to access QVM.
|
=A1.load("tran.txt")
|
Upload
data file tran.txt to QVM main directory.
|
=A1.load("getfileqvm.splx")
|
Upload
script file getfileqvm.splx to QVM main directory.

|
Execute
script file getfileqvm.splx in QVM main directory, and pass

|
