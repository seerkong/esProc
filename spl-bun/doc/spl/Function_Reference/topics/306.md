## 提取内容
exportavro()
说明：
Export
data to an Avro data file.
语法：
exportavro ( avrofile,A/cs,F i :T i,... )
注意：
AvroCli
external library function (See External Library Guide ).
The
function exports data in a table sequence or a cursor to an Avro data file and
returns a file object.
When
parameter T i is absent, esProc automatically identifies the
data type according to F i values of table sequence A
or cursor cs . As Avro data files do not have time data type such as
date, time and datetime, a field of such a data type needs to be specified as
long type and values will be exported in milliseconds. For example, the
exported value for 2023-11-29 00:45:24 is 1701189924000.
参数：
|
avrofile
|
Avro
file object that cannot be omitted; do not support remote file objects such
as httpfile() and Qfile()
|
A/cs
|
table sequence/ cursor .
|
F i
|
Field
name; export all fields by default .
|
T i
|
Specify
data type of the to-be-exported field(s), which can be string, boolean, bytes,
double, float, int and long .
选项：
|
@a
|
Append-export
overwrite the existing data by default .
Return
vlaue:
File
object
