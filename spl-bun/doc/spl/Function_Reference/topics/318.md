说明：
Equivalent
to Excel DURATION function.
语法：

注意：
The
FinancialCli external library
function (See External Library Guide ) returns
the modified duration of a security that pays periodic interest with an assumed
par value of ￥ 100. The duration is the weighted
average of the present value of the cash flows and is used to measure the
sensitivity of the price of the security to the interest rates. Annually . The day count basis method is US (NASD) 30/360 .
