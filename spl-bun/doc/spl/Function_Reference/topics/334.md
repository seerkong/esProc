# filename()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
filename()
filename( fn )
=filename("D://file/test.splx")
=filename@e("D://file/test.splx")
=filename@n("D://file/test.splx")
=filename@d("D://file/test.splx")
=filename@p("p2.txt")
=filename@p("")
=filename@s()
=filename@sd()
=filename@sn()
=filename@se()
=filename@sp()
```

## 提取内容
filename()
说明：
Split
up the full path and get the file name and extension.
语法：
filename( fn )
注意：
The
function splits the file name and extension from the full path fn.
参数：
|
fn
|
The
full path with the file name.
选项：
|
@e
|
Only
split the extension part from the full path.
|
@n
|
Split
out the file name without the extension.
|
@d
|
Split
out the directory under which the file is located, inclusive of address
string.
|
@p
|
Add
the main path before the file name of the non-absolute path. Return the main
path directly if fn is
""; if the main directory is empty, make the query according to the
rules defined in section 【 User reference – Main directroy 】 and return result.
|
@s
|
Get
name of the current script file.
示例：
|
=filename("D://file/test.splx")
|
Output
“ test.splx ”.
|
=filename@e("D://file/test.splx")
|
Output
“ splx ”.
|
=filename@n("D://file/test.splx")
|
Output
“ test ”.
|
=filename@d("D://file/test.splx")
|
Output
“ D://file ”.
|
=filename@p("p2.txt")
|
Output
“D:\Program
Files\raqsoft\esProc\demo\p2.txt”.
|
=filename@p("")
|
Output
the main directory
“D:\Program
Files\raqsoft\esProc\demo”.
Suppose
the current script file is D:\file\p1.splx :
|
=filename@s()
|
Get
name of the current script file and return p1.splx .
|
=filename@sd()
|
Get
the directory containing the current script file and return D:\file.
|
=filename@sn()
|
Get
name of the current script file without extension and return p1.
|
=filename@se()
|
Get
extension of name of the current script file and return splx.
|
=filename@sp()
|
Get
path of the current script file and return D:\file\ p1.splx .
