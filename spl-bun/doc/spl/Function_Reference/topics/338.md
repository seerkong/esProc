fillmthd()
说明：
Fill
missing values according to the specified method.
语法：
A.fillmthd( m )
注意：
MathCli
external library function (See External Library Guide ).
The
function fills missing values in vector/ matrix A according to the specified method.
There
are four methods for filling missing values:
1.
Or “previous”: The previous non-missing value
2.
Or “next”: The next non-missing value
3.
Or “nearest”: The nearest non-missing value
4.
Or “linear”: The neighboring non-missing value’s linear interpolation – only a
numeric value is valid; the double type (with the decimal point) is required
for data entry.
