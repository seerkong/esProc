Attach
a foreign-key-style association on a channel and return the original channel.
语法：
ch . fjoin ( w:T,x:F,…;… )
注意：
The
function attaches a computation to channel ch , which will compute expression w and then expression x
over each of its rows, and adding new field F to ch which uses results of x as its values, and returns the
original channel.
T is w ’s alias, which can be
referenced in expression x ; when x is represented by ~, it is
treated as w ; re-assign field F when it already exists in channel
ch .
primary table and a subtable can be associated through the foreign key in
parameter w .
