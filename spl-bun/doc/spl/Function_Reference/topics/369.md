## 提取内容
fork
....;hs, reduce
说明：
Execute
a code block in a node.
语法：
fork
….; hs reduce
注意：
The statement executes fork
code block on a sequence of nodes hs while distributing referenced
cellset variables (including cell names) among the nodes, and populates the
return values into the fork cell. The execution will be given to another node
if end msg failure happens. The redistribution will use the default method.
参数：
|
….
|
parameter sequence .
|
hs
|
The
node sequence in which each server is represented by a string in the form of
"address:port number", like " 192. 168. 0. 86: 4001 ".
|
s
|
sequence consisting of integer sequences; can be omitted .
|
reduce
|
The
parameter can be absent; when the number of tasks is greater than that of the
nodes, perform reduce on subtasks on the same node; store the last cumulative
value in fork cell and the current computing result in reduce cell; the
referenced cellset variables will be distributed among the nodes .
