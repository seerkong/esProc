## 提取内容
Fsyd()
说明：
Equivalent
to Excel SYD function.
语法：
Fsyd( cost,salvage,life,period )
注意：
The FinancialCli external library function (See External Library Guide ) returns depreciation of an asset for a
specified period, using the sum-of-years’ digits method.
参数：
|
cost
|
The initial cost of the asset .
|
salvage
|
The value of the asset at the end of the
depreciation (also known as asset residual value) .
|
life
|
The number of periods over which the asset
is to be depreciated (sometimes called expected useful life of the asset) .
|
period
|
The
period for which the asset’s depreciation is calculated (it must use the same
unit as life ) .
示例：
|
Fsyd(500000, 5000,10,
1)
|
90000.0
