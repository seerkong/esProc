## 提取内容
gcs_bucket()
说明：
Manage
Google cloud storage buckets.
语法：
gcs_bucket (fd,bucket)
注意：
This
GcsCli external library function (See External Library Guide ) manages storage buckets,
including create, delete and check whether a bucket exists or not. When not
working with any options, the function only finds whether a storage bucket
exists.
参数：
|
fd
|
GCS
connection object .
|
bucket
|
Storage
bucket name .
选项：
|
@c
|
Create
a storage bucket; won’t create anew if the storage bucket having the same
name already exists .
|
@d
|
Delete
a storage bucket; cannot delete a non-empty bucket .
Return
value:
Boolean
示例：
|
=file("F: /gcs .json").read()
|
Read
a JSON file.
|
=gcs_open(A1)
|
Connect
to the GCS service.
|
=gcs_bucket(A2,"test")
|
Check
whether the bucket named test exists or not.
|
= gcs _bucket@d(A 2 ,"test1")
|
Check
whether the bucket named test1 exists or not, and delete it if it exists
(cannot delete it if it isn’t empty) .
|
= gcs _bucket@c(A 2 ,"test2")
|
Check
whether the bucket named test2 exists or not, and create a bucket named test2
if it does not exist.
|
> gcs _close(A 2 )
|
Close
the GCS connection.
