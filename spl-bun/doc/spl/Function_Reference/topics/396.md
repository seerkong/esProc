## 提取内容
gcs_copy()
说明：
Copy
files in a storage bucket to the local, or local files to a storage bucket.
语法：
gcs_copy( fd,bucket:key, [localFile] )
说明：
GcsCli
external library function (See External Library Guide ).
参数：
|
fd
|
GCS
connection object .
|
bucket
|
Storage
bucket name .
|
key
|
File
name in the storage bucket .
|
localFile
|
local file name; save the file in the main directory by default .
选项：
|
@u
|
Copy
a local file to a GCS storage bucket; when the local file path is a relative
path, it is relative to the main directory .
Return
value:
Boolean
示例：
|
=file("F: /gcs .json").read()
|
=gcs_open(A1)
|
Connect
to the GCS service.
|
=gcs_copy(A2,
"test1":"test1.txt")
|
Copy
test.txt in storage bucket test1 to 【 main directory 】 /test1 .
|
= gcs _copy(A 2 ,
"test1":"test1.txt","D:/myBucket/test2.txt")
|
Copy
test.txt in storage bucket test1 to the local directory D:/myBucket/test2.txt .
|
= gcs _copy@u(A 2 ,
"test1":"test3.txt","D:/myBucket/test2.txt")
|
Copy
the local file D:/myBucket/test2.txt to test3.txt in storage
bucket test1 .
|
