gcs_file()
说明：
Get
the specified object in a storage bucket.
语法：
gcs_file( fd,bucket,key[:cs] )
注意：
GcsCli
external library function (See External Library Guide ).
The
function supports calculating file-related functions, including f.exists(),
f.name(), f.size(), f.date(), f.read(), f.import() and f.export(), on the
returned file object.
参数：
|

GCS

|

|
Storage
bucket .
|

File
name in the storage bucket .
|

|
Encoding
name; use this encoding to save or open a file .
Return
value:
File
object

=file("F: /gcs .json").read()
