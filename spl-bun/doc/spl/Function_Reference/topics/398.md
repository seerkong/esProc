## 提取内容
gcs_list()
说明：
List
storage buckets in the Google Cloud Storage platform or files in the specified
storage bucket.
语法：
gcs_list (fd,[bucket])
注意：
GcsCli
external library function (See External Library Guide ).
The
function lists storage buckets in the Google Cloud Storage platform or files in
the specified storage bucket. The returned table sequence contains files or
certain properties of the storage bucket.
When
all parameters are present, list all files in the specified storage bucket
named bucket ; in this case in the returned table sequence, 键 field
represents file name, Size represents file size which use byte as the unit, and
日期 represents the creation time or the last modified time of the current
file.
When
parameter bucket is absent, list all storage bucket on the GCS platform
in the returned table sequence, 键 represents bucket name and Size field won’t
be displayed.

connection object .
|

|
