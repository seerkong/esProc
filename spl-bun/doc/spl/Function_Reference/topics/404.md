ch.g roup()
说明：
Attach an operation of grouping
records in a channel by comparing each one with its next and return the
original channel.
语法：
ch . group ( x,… )
注意：
The function attaches a computation to
channel ch , which will group its records by expression x , whose
value is compared only with the directly next each record, and returns the
original channel ch . This is equivalent to a merge and ch should
be ordered.
This is an attachment computation.
选项：

being a Boolean expression, start a new group if the result of x is true. Be sure there’s only one x in this case .
|

the first record of every group to form a record sequence and return it to
the original channel (here it is number 1 rather than letter l) .
