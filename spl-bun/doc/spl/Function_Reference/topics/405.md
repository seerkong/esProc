cs.g roup()
说明：
Attach the action of grouping
records by comparing only adjacent records to the cursor and return the
original cursor.
语法：
cs. group ( x,… )
注意：
The function attaches a computation to
cursor cs , which groups cursor cs by expression x , whose
value is compared only with the adjacent records, and returns the original
cursor. 游标 cs should be ordered. The operation is equal to a merge
and supports multicursors.
This
is a delayed function.
选项：
|
@i
|
x is a Boolean expression. Begin a new group when a record makes it
return true. In this case there should be only one x .
|

Get

the original cursor; here it is number 1 instead of letter l .
|
@v

When
parameter cs is a cursor based on pure table sequence, copy each grouped
subset as a new pure table sequence; only supported by esProc Enterprise
Edition. .
