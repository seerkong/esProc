cs.group()
说明：
Group a cluster cursor by
comparing each record with its next neighbor.
语法：
cs . group ( x,… )
注意：
The function groups records in
ordered cluster cursor cs according to expression x by comparing
the value of x only with its next neighbor, and returns the cluster
cursor containing a sequence of groups. The operation is equivalent to a merge
and supports multicursors.
Only supported by esProc
Enterprise Edition.
