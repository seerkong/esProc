cs.g roupx()
说明：
Group
the ordered records in a cursor and return result as a cursor.
语法：
cs . groupx ( x:F, … ;y:G … ;n )
注意：
The function groups records
in a cursor by grouping expression x to create a new cursor consisting of fields F ,... G ,… sorted by the grouping field x . T he G field gets
values by computing y – the
aggregate function with which records of cs
is aggregated – on each group. The cursor the function returns is
irreversible.
选项：
|
@n
|
x gets assigned with group numbers which can be used to define the
groups.
|
@u
|
Won’t sort the result set by parameter x ; mutually exclusive with @n.
|
@g
|
Treat
parameter n as the segmentation expression by which records are first
segmented and then grouped and sorted.

avg/iterate. When the function works with the iterate( x,a;G i ,… ) function, the latter’s parameter Gi should
be omitted.

to a temporary file; its value is n times of the default, which is
automatically calculated, if n<1.
