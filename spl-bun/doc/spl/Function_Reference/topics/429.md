## 提取内容
cs.groupx()
说明：
Group records in a cluster cursor and return a synchronously
segmented cursor.
语法：
cs . groupx ( x:F,…;y:G…;n )
注意：
The function groups records in cluster cursor cs by grouping expression x to create a
new cluster cursor consisting of fields F ,... G ,… sorted by the grouping field x . G field gets
values by computing y – the aggregate function with which
records of cs is aggregated –
on each group.
Only supported by esProc Enterprise Edition.
参数：
|
cs
|
A cluster cursor .
|
x
|
Grouping expression .
|
F
|
Resulting field name
|
y
|
An aggregate
function on cs , which only supports sum/count/max/min/top/avg/iterate ; when the function works with
iterate( x,a;G i ,… ) function, the latter’s parameter Gi should be omitted .
|
G
|
Aggregate field name .
|
n
|
Number of buffer
rows; if the number of groups reaches n, write the grouping result to a
temporary file; its value is n times of the default, which is automatically calculated,
if n<1 .
返回值：
Cluster cursor
