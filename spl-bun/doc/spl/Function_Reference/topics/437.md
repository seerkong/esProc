## 提取内容
hbase_open()
说明：
Create
a HBase connection.
语法：
hbase_open (hdfsUrl,/zkUrl)
注意：
This
HbaseCli external library function (See
External Library Guide ) connects to a HBase database. The format of
parameter hdfsUrl is hdfs://ip, and
the format of parameter zkUrl is
zkServerIp. Can connect to multiple nodes.
参数：
|
hdfsUrl
|
HDFS
connection information.
|
zkUrl
|
Zookeeper
connection information.
返回值：
游标
示例：
|
=hbase_open("hdfs://192.168.0.8:9000")
|
Connect
to the HBase database using hdfsUrl format.
|
=hbase_open("192.168.0.76, 192.168.1.66")
|
Connect
to the HBase database using zkUrl format.
