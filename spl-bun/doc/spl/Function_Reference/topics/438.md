## 提取内容
hbase_rest()
说明：
Get cluster information
and execute a complete HTTP request independently.
语法：
hbase_rest( restUrl, method, content; httpHeader1, httpHeader2, … ) .
注意：
The HbaseCli external
library function (See External Library Guide ) gets
cluster information and performs a certain operation on data, without creating
an HBase connection in advance.
参数：
|
restUrl
|
The REST URL.
|
method
|
An HTTP method, whose
value is GET, PUT, POST or DELETE.
|
content
|
An HTTP request
message, which can be omitted when the current method does not submit one
|
httpHeader1/httpHeader2
|
The HTTP request
header; can be omitted.
返回值：
Table sequence
示例：
|
=hbase_rest("http://127.0.0.1:3456/namespaces","GET")
|
Query data using the
GET method.
|
<?xml version="1.0"
encoding="UTF-8"?>
<TableSchema
name="Orders">
<ColumnSchema
name="infos" />
<ColumnSchema
name="datas" />
</TableSchema>
|
=hbase_rest("http://127.0.0.1:3456/Orders/schema","PUT",A2;"Content-Type:text/xml","Accept:
text/xml")
|
Handle data using the
PUT method.
