## 提取内容
hdfs_open()
说明：
Connect
to the HDFS file system and return a connection object.
语法：
hdfs_open(; url,user )
注意：
This HdfsFileCli external library function (See External Library Guide ) connects to the Hadoop server. When all parameters are absent, Hadoop
configuration file needs to be placed under the external library directory, and
in this case, the function returns the default connection.
参数：
|
url
|
The URL format is scheme://authority/path .
Scheme is the HDFS protocol name; authority is the host name; and path is a string of the file (or
directory) path.
|
user
|
A Hadoop user; default is root.
Return
value:
Connection
object
示例：
|
=hdfs_open(;"hdfs://192.168.0.76:9000","root")
|
Connect
to the HDFS.
|
=hdfs_open(;"hdfs://192.168.0.8:9000")
|
Connect
to the HDFS with parameter user omitted
|
=hdfs_open()
|
Put Hadoop configuration file in the external
library directory as all parameters are absent .
