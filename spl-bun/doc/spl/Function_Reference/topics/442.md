hdfs_dir()
说明：
Get
the list of all files in a specified path.
语法：
hdfs_dir( hd , path )
注意：
This
HdfsFileCli external library function (See External Library Guide ) lists
names of all files in a specified path in an HDFS file system.
参数：
|
hd
|
An hd
connection.
|
path
|
relative path within the path containing the HDFS file.
选项：
|
@d
|
List
names of all directories in the specified path.
|
@p
|
List the full paths of all directories and
files in the specified path.
|
@m
|
Create
a directory; return true if the directory is created, otherwise return false.
|
@r
|
Delete
a directory; return true if the operation is successful, otherwise return
false.
Return
value:
Sequence/Boolean
