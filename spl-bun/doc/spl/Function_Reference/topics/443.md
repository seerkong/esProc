## 提取内容
hdfs_download()
说明：
Download a local file to a specific position.
语法：
hdfs_download( hd, local,remote )
注意：
The HdfsFileCli external library function (See External Library Guide ) downloads a remote file or
folder remote to a local file/folder local .
参数：
|
hd
|
An hd connection.
|
local
|
A local file or folder.
|
remote
|
remote file or folder.
|
localPath
|
A local file name.
选项：
|
@d
|
Download all files in the specified folder to
the local machine, and require both the source and directories are folders.
返回值：
Boolean
示例：
|
=hdfs_open("hdfs://192.168.0.8:9000")
|
Connect to HDFS file system .
|
=hdfs_download(A1,"
/test "," /emp/emp.txt ")
|
Download
emp.txt in /emp folder to the local folder /test .
|
=hdfs_download(A1,"
/test/emp1.txt "," /emp/emp.txt ")
|
Download
emp.txt in /emp folder to the local folder /test , and
rename the file emp1.txt .
|
=hdfs_download@d(A1,"/s1","/h1")
|
Download
all files under folder /h1 to the local folder /s1 .
|
=hdfs_close(A1)
|
