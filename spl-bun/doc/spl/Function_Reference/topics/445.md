## 提取内容
hdfs_file()
说明：
Open a specified directory and return an HDFS file flow.
语法：
hdfs_file( hd , file:cs )
注意：
The HdfsFileCli external library function (See External Library Guide ) returns an HDFS file flow. The file extension determines the compression
method; support writing data in a stream style into a non-segmental file, but
there is no such a restriction on reading data in.
参数：
|
hd
|
An hd connection.
|
file
|
The
name of the to-be-loaded Hadoop file.
|
cs
|
The
charset embedded in JVM; by default, it is the default value for a virtual
machine
Return
value:
File
object

=hdfs_open("hdfs://192.168.0.8:9000")
