# hdfs_upload()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
hdfs_upload()
hdfs_upload( hd, local, remote )
=hdfs_open("hdfs://192.168.0.8:9000")
=hdfs_upload(A1,"emp.txt","/user")
=hdfs_upload(A1,"stu.txt","/user/stu1.txt")
=hdfs_upload(A1,"/h1","/s1")
=hdfs_upload@d(A1,"/h1","/s1")
=hdfs_close(A1)
```

## 提取内容
hdfs_upload()
说明：
Upload a local file to a specific position.
语法：
hdfs_upload( hd, local, remote )
注意：
The HdfsFileCli external library function (See External Library Guide ) uploads a local file or folder
local to a remote file/folder remote .
参数：
|
hd
|
An hd connection.
|
local
|
local file or folder.
|
remote
|
A remote file or folder.
选项：
|
@d
|
Upload all files in the specified folder to the
specified path, and require both the source and directories are folders .
返回值：
Boolean
示例：
|
=hdfs_open("hdfs://192.168.0.8:9000")
|
Connect to HDFS file system .
|
=hdfs_upload(A1,"emp.txt","/user")
|
Upload
local file emp.txt to the path /user .
|
=hdfs_upload(A1,"stu.txt","/user/stu1.txt")
|
Upload
local file stu.txt to the path /user, and rename it stu1.txt .
|
=hdfs_upload(A1,"/h1","/s1")
|
Upload
local file /h1 to path /s1 .
|
=hdfs_upload@d(A1,"/h1","/s1")
|
Upload
all files in the local folder /h1 to path /s1 .
|
=hdfs_close(A1)
|
