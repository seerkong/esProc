hive_table()
说明：
Obtain a list of certain
table names in the specified Hive database and locations of the corresponding
HDFS files.
语法：
hive_table ( con,[dbname] )
注意：
HiveCli
external library function (See External Library Guide for uses).
It gets a list of
certain table names in the specified Hive database and locations of the
corresponding HDFS files. List all tables when no option works.
参数：
|

|
Database connection

|

Database name; return

选项：

|
@p

List Parquet tables.
返回值：
Table
sequence
