## 提取内容
htmlparse()
说明：
Get
text data under a specified tag in an html file.
语法：
s. htmlparse ( tag : i : j ,…)
注意：
The
function gets the j th text
file under the i th tag
from html file s .
Retrieve
the first text file under the i th
tag when parameter j is absent
get all text data under all tags when parameter i is absent; get all text data in the html
file when there aren’t parameters.
参数：
|
s
|
Content
of an html file .
|
tag
|
tag in an html file; if the tag’s value is “table”, get all data under it .
|
i
|
An
integer .
|
j
|
An
integer .
选项：
|
@0
|
Retain
null values; null values will be removed by default.
|
@p
|
Parse the html file as numbers of corresponding
data type.
Return
value:
Sequence
示例：
|
=file("D:/test.html").read()
|
Read the content of an html file .
|
=A1.htmlparse("a":11:0)
|
Get the 1 st text file under the
12 th <a> from A1’s html file .
|
=A1.htmlparse("a":11:0,
"span":8:0)
|
Get text files under two tags from A1’s
html file .
|
=A1.htmlparse("table":7)
|
Get all content under the 8 th
<table> .
|
=file("rq.html").read()
