T.icursor( C,…;w;f,… )
说明：
Use index to query data in
an entity table/in-memory table.
语法：
T. icursor ( C,…;w;f,… )
注意：
The
function uses index file f to query
fields C ,… in entity table/in-memory
table T according to filter condition w .
With
a HASH index, only perform query by equivalent values and the filter field in w
should be same as that in the indexed field.
With
a full-text index, w only applies to 字符串 type fields. The function
supports like("*X*") style queries.
参数：
|
T
|
An
entity table/in-memory table .
|
To-be-retrieved
columns in the entity table; get all columns when the parameter is absent .
|
w
|
Filtering
condition, which cannot be omitted and in which the filtering field for T must be same as the indexed field
support >, >=, <, <=, == and contain in its syntax .
|
f
|
Index
file object; the program will automatically use the suitable one when there
are multiple index files; when T is an in-memory table, f is
name of the in-memory table index .
选项：
|
@s
|
Order
result set by the indexed field and support large result sets .
|
@u
|
Handle multiple conditions joined up with
&& from left to right while the default is handling them in an
optimal order .
Return
value:
Unicursor
