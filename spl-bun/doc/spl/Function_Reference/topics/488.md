ifv()
说明：
Check whether a variable
exists.
语法：
ifv( v )
注意：
This function is mainly used to find if any variable is added to the
current execution environment by the external program when the external program
calls the program cellset. Generally, there is no need to check the defined
variable in the cellset script. They are there for sure if you've defined them.
参数：
|
v
|
Parameter name
返回值：
Boolean
示例：
|
>arg1=1
|
=ifv(arg1)
