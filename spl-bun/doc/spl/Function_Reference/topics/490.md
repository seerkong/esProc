ifx_conn()
说明：
Create Informix database
connection.
语法：
ifx_conn ( url; fragfile )
ifx_conn ( driver,url; fragfile )
注意：
The InformixCli
external library function (See External Library Guide ) connects
to the external Informix database. The format of the parameter url is the same as that of the JDBC URL.
参数：
|
driver
|
Name of JDBC driver for connecting
to Informix database; the format is com.informix.jdbc.IfxDriver .
|
url
|
The URL to connect to
Informix server .
|
fragfile
|
Fragmentation information file that records the
fields and every field’s max and min values in each fragmented file .
返回值：
Ifxconn object

|
="d:/frag.txt"
|
A fragmentation
information file.
