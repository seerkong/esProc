## 提取内容
ifx_savefrag()
说明：
Save the fragmentation
information file stored in the memory as a new file.
语法：
ifx_savefrag ( ifxconn, file )
注意：
The InformixCli
external library function (See External Library Guide ) saves
the fragmentation information stored in the memory as a new file. The new file
can be the same as the file fragfile
created via ifx_conn() , or one saved
in another name.
参数：
|
ifxconn
|
An ifxconn object .
|
file
|
A fragmentation
information file .
返回值：
Table sequence
示例：
|
="d:/frag1.txt"
|
Create
and save a fragmentation information file.
|
=ifx_conn("com.informix.jdbc.IfxDriver","jdbc:informix-sqli:192.168.0.7:8000/tpch:informixserver=tramsserver&user=informix&pwd=informix";A1)
|
Connect
to Informix database.
|
=ifx_takefrag(A2)
|
Extract
the fragmentation information of all specified tables.
|
=ifx_savefrag(A2,A1)
|
Save the fragmentation information stored
in the memory as the file frag1.txt .
|
