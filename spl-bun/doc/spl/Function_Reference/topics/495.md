ifx_takefrag()
说明：
Extract fragmentation
information from the database.
语法：
ifx_takefrag (ifxconn, table1,table2,...)
注意：
The InformixCli
external library function (See External Library Guide ) extracts
the fragmentation information of the specified table(s) from the database and
writes it into the Ifxconn object. As there isn’t the fragmentation information
in fragfile file, the txt file is empty; get the fragmentation
file of all tables being fragmented if parameter table is absent.
参数：
|
ifxconn
|
An Ifxconn object .
|
table
|
The table being
fragmented; can be omitted and can have multiple number of it .
示例：
|
="d:/frag1.txt"
|

and save a fragmentation information file.
