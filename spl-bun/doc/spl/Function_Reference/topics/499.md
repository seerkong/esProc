## 提取内容
T.import()
说明：
Get a table
sequence based on a pseudo table.
语法：
T.import( x i : C i ,… )
注意：
The function gets a table
sequence based on pseudo table T by specifying field
expressions x i and field names C i , which,
by default, field names in the pseudo table. It gets a table sequence using all
fields of the pseudo table when parameters x i : C i are
absent.
Only supported by esProc Enterprise Edition.
参数：
|
T
|
A pseudo table .
|
x i
|
A field expression .
|
C i
|
字段名 in the result table sequence .
返回值：
Table sequence
示例：
|
=create(file).record(["D:/file/pseudo/empT.ctx"])
|
=pseudo(A1)
|
Generate a pseudo table
object.
|
=A2.import()
|
Get a table sequence from
A2’s pseudo table using all its fields since no parameters are present.

|
=A2.import(EID:eid,NAME,SALARY:salary)
|
Retrieve fields EID, NAME
and SALARY from the pseudo table to form a table sequence, and rename fields
eid, NAME and salary respectively.
