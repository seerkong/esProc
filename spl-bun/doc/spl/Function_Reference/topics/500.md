Import

importavro ( avrofile,F i ...;schemafile )
注意：
AvroCli
External library function (See External Library Guide ).
The
function imports an Avro data file. When parameter schemafile , the avsc
file object that describes the data structure, is present, read the avro data file
as such a data structure. When both field name(s) F i and file
schemafile are specified, the former has greater priority than the
latter; when both are absent, read all fields in the avrofile file.
