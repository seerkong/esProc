influx_query()
说明：
Query InfluxDB database.
语法：
influx_query (hd,sql)
注意：
The InfluxdbCli external library function (See External Library Guide ) queries InfluxDB database. It is valid only with InfluxDB 1.x.
参数：
|
hd
|
Connection object .
|
sql
|
The SQL query statement or database search
statement .

value:
