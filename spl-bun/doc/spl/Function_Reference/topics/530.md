invoke()
说明：
Invoke the static function of class in the
package.
语法：
invoke ( p.c.f , a i ,…)
注意：
The function calls the static function f of class c in the package p , which
can be omitted. Do not allow overload methods (with the
same name but different signatures).
When invoking a user-defined
function, you should put the user-defined function class file in the format of
.class in the path [esProc install-root
directory]/esProc/classes/{p} ; if the user-defined
function is used at the web side, then you should put the corresponding
function in path WEB-INF/classes /{p} .

Create a customized class LineReaders

users can retrieve a various types of data files using the file cursor. The
file path can be defined as a parameter to be passed to the customized class.

by skipping certain individual rows; and the cursor can thus be closed in a
