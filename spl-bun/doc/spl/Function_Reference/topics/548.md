j()
说明：
Join multiple sequences according to positions and return a pure
table sequence.
语法：
j ( A i : F i ,…)
注意：
The function joins multiple sequences A i ,… according
to positions and generates a pure table sequence consisting of F i ,… fields, which are assigned
corresponding members in A i – that is, F i references records in the original sequence A i .
注意： The number of members (records) each of sequences A i ,… should be same. Only supported by esProc Enterprise Edition.
