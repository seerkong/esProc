cs.joinx()
说明：
Join up a cursor and an entity table by the
foreign key.
语法：
cs . joinx ( C:…,T:K:…,x:F,…;…;…;n )
注意：
The function matches the foreign key fields C , … in
cursor cs with the key K in entity table T , which is ordered by K , to find the corresponding record in T , and makes the record’s expression x
a new field F and adds it to cs to generate a new cursor. The
value corresponding to a mismatched record will be recorded as null.
选项：
|
@i
|
Discard the records whose foreign key
values can’t be matched; represent them as nulls by default
When parameters x:F are absent, only perform the
filtering on the cursor/multicursor.
|
@d
|
Delete
records matching the foreign key and perform the filtering operation only on cursor
cs ; in this
case, parameters x:F are absent .
|
@q
|
Speed up the matching action according to
a certain order when the cursor contains a relatively small amount of data or
it is a sequence cs Speed up the join when the cursor
contains relatively small amount of data or is a sequence
|
@u
|
Speed up the matching operation by
shuffling records in the cursor.
|
@m
|
Can use MERGE method to perform the
association when the cursor/multicursor is ordered by its foreign key and
when the entity table is ordered by the primary key.
