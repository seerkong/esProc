kafka_open()
说明：
Connect
to Kafka server.
语法：
kafka_open (filename
or fileObject, topic,..., partitionSize)
注意：
The
KafkaCli external library function (See
External Library Guide ) connects to Kafka server, and stores
attribute parameter properties in the configuration file with . properties
extension.
参数：
|
topic
|
Query
one or more specified topic s.
|
filename
|
The
attribute parameter file with the . properties extension, which
contains the send key, value encoding and message decoding; all of them
should correspond to each other one by one.
|
fileObject
|
file object.
|
partitionSize
|
The
number of partitions in a topic ; if a corresponding topic already
exists, ignore the parameter, which means SPL does not support changing the
partition size in a topic.
Return
value:
Connection
object
示例：
|
=kafka_open("D://kafka.properties","topic-test")
|
Connect
topic-test’s configuration file kafka.properties to Kafka server using
a topic .
|
=kafka_open(file("D://kafka.properties"),"topic-test",3)
|
Connect
topic-test’s configuration file kafka.properties to Kafka server using
a file object .
|
=kafka_close(A1)
|
