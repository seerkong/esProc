kafka_poll()
说明：
Return
records in a Consumer topic as a table sequence.
语法：
kafka_poll (fd, timeout ,[partition1, partition2, … ] )
注意：
The KafkaCli external library function (See External Library Guide ) gets records of the current Consumer topic. The function traverses all partitions in the topic when parameter partition is absent.
参数：
|
fd
|
Consumer object.
|
timeout
|
The
interval of consumer poll loop; default is 1000ms.
|
partition
|
The
number of partitions in a topic, which is an integer or a sequence.
选项：
|
@c
|
Enable
a cursor-based query.
Return
value:
Table
sequence or cursor
