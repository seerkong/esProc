kafka_send()
Descripition:
producer publishes messages to topics.
语法：
kafka_send (fd, [key,] value)
kafka_send (fd, partition, key, value)
注意：
KafkaCli
external library function (See External Library Guide ) .
When
there aren’t partitions, parameter key can be absent; and when there are partitions, parameters partition , key and value must be present.

|

|
connection object.
|

key word of a message.
|
value
|
Value
of a message.
|
partition
|
Index
numbers of partitions, which is an integer or a sequence beginning from 0.
