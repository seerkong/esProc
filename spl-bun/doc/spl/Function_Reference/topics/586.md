# like()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
like()
like( stringExp , formatExp )
like@s("abc123", "abc1_3")
like@s("abc123", "abc%")
```

## 提取内容
like()
说明：
Find
if a string matches a format string.
语法：
like( stringExp , formatExp )
注意：
The
function checks if the string stringExp matches the format string formatExp. In
the format string, the asterisk "*" matches 0 or multiple characters
and the question mark "?" matches a single character. An escape
character is used to make "*" match the character itself, for
example, \* is escaped to * and \\ to \.
参数：
|
stringExp
|
string expression.
|
formatExp
|
format string expression.
选项：
|
@c
|
It
makes the matching case-insensitive, while the default is case-sensitive.
|
@s
|
Use
SQL wildcard characters; % matches zero or multiple characters and __ matches
a single character; this option does not work with @c option.
返回值：
Boolean
示例：
|
like("abc123",
"abc*")
|
true
|
like("abc123",
"abc1?3")
|
true
|
like("abc123",
"abc*34")
|
false
|
like("abc123",
"ABC*")
|
false
|
like@c("abc123",
"ABC*")
|
true
|
like
("abc*123", "abc\*")
|
true
|
like("abc*123",
"abc\\**")
|
true abc\\** is escaped
to abc\**
|
like@s("abc123", "abc1_3")
|
true
|
like@s("abc123", "abc%")
|
true
