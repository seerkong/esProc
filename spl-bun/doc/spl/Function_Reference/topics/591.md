## 提取内容
qvm.load()
说明：
Switch
file(s) or homo-name files group between the local and QVM.
语法：
qvm. load ( l : z , r : z )
注意：
The
function switches file(s) or homo-name files group between the local and QVM.
When
parameters r:z are absent, upload l ,
the file(s)/homo-name files group in the relative path relative to the local
main directory, to the relative path relative to QVM main directory
When
parameters l:z are absent, download r ,
the file(s)/homo-name files group in the relative path relative to QVM main
directory, to the relative path relative to local main directory.
参数：
|
qvm
|
QVM
object.
|
l
|
Local
file(s)/homo-name files group to be uploaded.
|
r
|
To-be-downloaded
file(s)/homo-name files in the QVM main directory.
|
z
|
The
parameter is a zone table number or a sequence of zone table numbers when
parameters l and r are homo-name files group.
Return
value:
Boolean
示例：
|
=Qconnect("http://54.213.221.123:8080/qvs":"aws-qvs",30,300)
|
Request
QVA through QVS to access QVM .
|
=A1.load("tran.txt")
|
Upload
tran.txt in the local main directory to QVM main directory .
|
=A1.load("f1/aa.txt")
|
Upload
aa.txt in local main directory’s f1 directory to QVM main
directory’s f1 directory .
|
=A1.load("empN.ctx":[1,2])
|
Upload
homo-name files group 1.empN.ctx and 2empN.ctx in the local
directory to QVM main directory .
|
=A1.load(,"tran.txt")
|
Download
tran.txt in QVM main directory to the local main directory .
|
>A1.close()
|
Close
QVM .
