lower()
说明：
Convert
all characters of a string to lower case.
语法：
lower( s )
注意：
The
function converts all characters of a string to lower case.
参数：
|
s
|
The
string you want to convert to lower case.
选项：
|
@q
|
A quoted string won’t be converted.
返回值：
string
示例：
|
lower("ABCdef")
|
abcdef
|
lower("defABC")
|

lower@q("\'AD\'")
