median()
说明：
Divide
a sequence into multiple segments and return the specified bordering member(s).
语法：
A . median ( k:n,x )
注意：
Divide
sequence A into n segments evenly according to its length and return the bordering
member between the k th
segment and the (k+1) th
segment. When parameter x is present, compute the expression with
members of A and then segment the sequence.
When
parameter k is absent while parameter n is present, return a
sequence of bordering members of all segments.
When
parameters k,n are absent, if the length
of the sequence is an odd, return the median member value; if it is an even,
return the average value of the two members in the middle. Perform a logical
division if the length of the sequence is indivisible.
