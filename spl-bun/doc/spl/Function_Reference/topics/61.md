## 提取内容
${macroExp}
说明：
This
is used to complete the macro replacement operation.
语法：
${ macroExp }
注意：
The
macro here is taken as an expression to be computed, the result must be a
string, which will replace the ${ macroExp } .
The
macro enclosed in quotation marks or populated in the constant cell will not be
replaced.
参数：
|
macroExp
|
macro expression.
返回值：
字符串
示例：
|
="1"
|
=${A1}+3
|
After
replacing, the expression becomes =1+3 and the return value
is 4.
|
="${A1}+3"
|
Macro
is enclosed in quotation marks, so it will not be replaced, and the return
value is still " ${ A1 }+ 3 " .
