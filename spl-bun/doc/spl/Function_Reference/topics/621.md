## 提取内容
P.mi ()
说明：
Create indicator variable
for missing values for a table sequence/record sequence variable during modeling.
语法：
P.mi(cn)
注意：
The MathCli external
library function (See
External Library Guide ) creates indicator
variable for missing values in variable cn during modeling; return 1 for
a missing value and 0 for a non-missing value. If the missing value rate is ≤ 5% or ≥ 95%, do not generate the
indicator variable and return null.
参数：
|
P
|
A table sequence/record sequence .
|
cn
|
A string/number, which is the name
of column (or the column number starting from 1) – the to-be-pre-processed
variable – in a table sequence or record sequence .
Return
value:
Table sequence
示例：
|
=T("D://house_prices_train.csv")
|
=A1.mi(4)
|
（原文含示意图，图像资源未迁移）
Return indicator variable for
missing values in column 4.
|
=A1.mi("Alley")
|
（原文含示意图，图像资源未迁移）
Return indicator variable for
missing values of variable “Alley”.
