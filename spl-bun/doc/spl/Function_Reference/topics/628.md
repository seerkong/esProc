Calculate the mean value within a matrix or a multidimensional
matrix.
语法：
mmean ( A , n )
注意：
A MathCli external library function (See External Library Guide ) where parameter n is the sequence
number of the level on which the summarization is performed. If n is
absent, the desired dimension is the first one whose size is not 1 in matrix A .
