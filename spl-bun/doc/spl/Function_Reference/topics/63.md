## 提取内容
>statement
说明：
Generate
the contextual execution statement through esProc JDBC and return every
possible result set once the statement is executed
语法：
> statement
注意：
This
statement works similarly to the expression in the esProc execution cell if it
contains only a single line. There will be no result set
returned once it is executed.
If it contains multiple lines separated by tab/enter ,
every possible result set will be
returned once it is executed. In the esProc JDBC, the Statement can be generated by directly using con .createStatement() . Use st .execute() to execute the statement
directly.
参数：
|
statement
|
statement/a clause.
示例：
1.
The statement contains merely a single line:
