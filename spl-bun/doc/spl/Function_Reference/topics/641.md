## 提取内容
movefile(fn,h;path,hs)
说明：
Move
a file from a node to another.
语法：
movefile( fn,h;path,hs )
注意：
The
function moves file fn on node h , which is the local
machine when omitted, to path path on node hs , which can be a node sequence. It renames fn when hs is
absent, deletes fn when both path and hs are absent, removes
files on hs when path and h
are absent but hs is non-null.
参数：
|
fn
|
file name .
|
h
|
node .
|
path
|
path (that contains file name) to which a file is moved, or a file name .
|
hs
|
node or a node sequence .
选项：
|
@y
|
Force
moving to overwrite a namesake file while default is failure, and deletion
when path is null .
|
@c
|
Copy
the file, and the copy fails if there is already a namesake file .
Return
value:
Boolean
示例：
|

tmp.txt on node "192.168.31.165:8281" to D:/p1 on
node "192.168.31.39:8281" .
|

|
Move
t1.txt , which is a local file as parameter h is absent, to a sequence of nodes .

Rename
