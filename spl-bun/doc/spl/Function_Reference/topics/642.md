## 提取内容
movmthd()
说明：
Fill
missing values with moving window method.
语法：
A.movmthd( window )
注意：
MathCli
external library function (See External Library Guide ).
The
function fills missing items in vector A with the moving window average whose length is window .
If
window value is an odd number, the window’s center is the current
element and the number of neighboring elements is window -1; if window
value is an even number, the window’s center is the current and the
previous elements.
参数：
|
One-dimensional
sequence .
|
window
|
An
integer .
选项：
|
@i
|
Fill
missing items with median of moving window .
Return
value:
Sequence
示例：
|
=[,2.0,,3.0,4.0,5.0,,,,7.0,,9.0,,12.0,11.0]
|
=A1.movmthd(5)
|
Use
the moving average whose window length is 5 to fill the missing values .
|
=A1.movmthd@i(5)
|
Use
the moving median whose window length is 5 to fill the missing values .
