mstd()
说明：
Calculate the standard deviation on a matrix or a multidimensional
matrix.
语法：
mstd ( A , n )
注意：
A MathCli external library function (See
External Library Guide ) where parameter n is the sequence
number of the level on which the summarization is performed. If n is
absent, the desired dimension is the first one whose size is not 1 in matrix A .
参数：
|
A matrix or a multidimensional matrix .
|
n
|
A positive integer .
选项：
|
@s
|
Perform the calculation using a statistical method, during which
the n-1 is the divisor .
|
@a
|
Calculate the standard deviation on all elements of matrix A
and parameter n is invalid .
Return
value:
Sequence/Number
