norm()
说明：
Normalize a matrix or a vector.
语法：
norm( A )
注意：
The function normalizes a matrix or a vector by subtracting
the mean from each element of every row and then dividing each element by the
square root of the sum of squares.
参数：
|
A matrix or a vector .
选项：
|
@0
|
Enable subtracting the mean from each row only without
keeping lengths same; the mean value after normalization is 0 .
|
@s
|
0-1 normalization; mean value after normalization is 0,
and standard deviation is 1 .
返回值：
Sequence
