## 提取内容
orc()
说明：
Retrieve data from an
ORC file.
语法：
f .orc ([ col,… ] ; [ n ])
注意：
External
library function (See External
Library Guide ).
The function retrieves
data from a local ORC file or an ORC file in HDFS.
参数：
|
f
|
A file object.
|
col
|
To-be-retrieved
fields; return all fields by default.
|
n
|
A positive integer
representing the number of records to be retrieved; return all records when
this parameter is absent. This parameter becomes invalid when @c option
works.
选项：
|
@c
|
Return a cursor.
|
@m
|
Retrieve data in
multiple threads. When @c option is present, retrieve data through and from
multiple cursors.
示例：
|
=file("F:/tmp/mytest.orc")
|
Open a local ORC file.
|
=A1.orc()
|
Retrieve data from A1’s
file and return all fields.
|
=A1.orc@c()
|
Return a cursor.
|
=file("hdfs://localhost:9000/user/hive/warehouse/test1.orc")
|
Open an ORC file in
HDFS.
|
=A4.orc("product","store";10)
|
Retrieve the specified
fields and return the first 10 records only.
|
=hive_open("hdfs://localhost:9000","thrift://localhost:9083","hive","asus")
|
Connect to the HIVE
database.
|
=hive_table@o(A6)
|
Find all ORC tables.
|
=A7.select(tableName=="myOrc")
|
Select myOrc table.
|
=file(A8.location)
|
Load a file in HDFS.
|
=A9.orc(;10)
|
Retrieve data from A9’s
table and return the first 10 records only.
|
=A9.orc@cm()
|
Retrieve data using
multiple cursors.
|
=A11.fetch(10)
|
Same as A10.
|
=hive_close(A6)
