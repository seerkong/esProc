oss_copy()
说明：
Copy
a file in the OSSS bucket to local, or a local file to the OSS bucket.
语法：
oss_copy( fd,bucket:key, [localFile] )
注意：
OssCli
external library function (See External
Library Guide ).
参数：
|
fd
|
OSS
connection object .
|
bucket
|
Bucket
name .
|
key
|
File
name in the storage bucket .
|
localFile
|
local file name; save the file in the main directory if the parameter is
absent .
选项：
|
@u
|
Copy
a local file to the OSS bucket; when the local file path is a relative one,
it is relative to the main directory .
Return
value:
Boolean

|

|
Copy
