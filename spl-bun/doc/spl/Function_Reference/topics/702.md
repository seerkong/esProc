## 提取内容
pad()
说明：
Pad
a string to the specified length with another string added on the left.
语法：
pad ( s,c,l )
注意：
The function pads
string s to a new length of l by continuously adding
characters of string c to the left side.
参数：
|
s
|
string expression .
|
c
|
A string
expression
|
l
|
A number or
an expression whose result is the numeric value.
选项：
|
@r
|
Pad
to the right side of a string, to a new length .
返回值：
字符串
示例：
|
=pad("Soth","Miss",10)
|
The
return value is "MissMiSoth" .
|
=pad@r("Soth","er",8)
|
The
return value is "Sotherer" .
