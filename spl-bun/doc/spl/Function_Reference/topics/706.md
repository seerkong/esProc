parse ( s )

## 提取内容
parse()
说明：
Parse
a string into the corresponding data type.
语法：
parse ( s )
注意：
This
function analyzes string s and parses
it into corresponding data type.
参数：
|
s
|
string.
选项：
|
@e
|
Remove
quotes of the string before starting an escape sequence including the escape
character and unicode. By default, the string will not be escaped.
|
@ n
|
Retrieve
a substring with enough length starting from the left side and parse it,
while ignoring the non-numeric rest. Note that the string needs to begin with
the numeric value.
|
@q
|
If
a string starts with the quotation marks, parse it until the next quotation
marks appear and leave the rest of the string alone, and return a string.
Return
value:
Data
of different data types
示例：
|
="10:20:30"
|
=parse(A1)
|
10:20:30 . The string is parsed into time data type .
|
\u4e2d\u56fd
|
a\tb
|
=parse@e(A3)
|
中国 . The
string is automatically parsed into the corresponding Unicode characters .
|
=parse@e(A4)
|
a b . Escape characters are handled automatically .
|
=parse@n( "12sadsdxc23" )
|
12 . Retrieve and
parse the first numeric value .
|
=parse@q("\'sadsdxc\'+23")
|
'sadsdxc'
the string begins with quotation marks and the parsing stops at the next
quotation marks .
