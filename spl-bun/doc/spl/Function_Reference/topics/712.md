pearson()
说明：
Calculate Pearson’s correlation coefficient between two
vectors.
语法：
pearson( A,B )
注意：
The function calculates the Pearson’s correlation
coefficient between vector A and
vector B . Default value of B is an integer sequence made up of
numbers from 1 to vector A ’s length.
参数：
|

|
@a
|
Equivalent to @a (…; k )
