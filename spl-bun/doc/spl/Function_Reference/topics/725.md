T.pjoin ()
说明：
Create
an association between a pseudo table and a table sequence/in-memory pseudo
table through the join key.
语法：
T. pjoin ( K :.., x : F ,…
T’ : z , K i :…, x i : F i ,…
…)
注意：
The
function associates pseudo table T and
table sequence/in-memory pseudo table T’ through the join key and returns a new pseudo
table consisting of x : F ,… and x i : F i ,….
By default, x : F ,… involves
all fields of T ; b oth T and T’ should
be ordered by the join key.
When relationship between T and T’ is one-to-many, x i is an aggregate expression.
When relationship between T and T’ is many-to-one,
records of T’ will
appear repeatedly in the result set.
Parameter z specifies the
join type. It can be absent or null. Perform an inner join when z is absent, and a left join when z is null; and only retain records
of T that cannot find matches when z is null and both parameters x i : F i
are absent.
Only supported by esProc
Enterprise Edition.
