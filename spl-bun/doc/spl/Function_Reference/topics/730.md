A.p min()
说明：
Get positions of
members holding the minimum value in a sequence.
语法：
A .pmin ( x )
注意：
The function
computes expression x with each member of
sequence A and returns the sequence numbers of the members
whose computations are the minimum. Can be
used to find the positions of the minimum value in a sequence.
参数：
|
sequence.
|
x
|
field name or an expression, in which " ~ "
is used to reference the current record.
选项：
|
@a

sequence numbers of all members that make expression x get the smallest value.
|
@z
|
Perform
the search backwards from the last member; by default, perform the search
from the first member.
|
@0
|
Do
not skip null members.

Sequence
