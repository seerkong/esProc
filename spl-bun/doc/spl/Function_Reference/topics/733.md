## 提取内容
A.pos(x,k )
说明：
Get
the position of a member in a sequence.
语法：
A .pos( x,k )
注意：
The
function locates member x in sequence A where x may
appear repeatedly. Return null if the member cannot be found; return different values according to
different options and return the position of the first-found member if no
option is present. When parameter k is present, begin the search from
the k th member.
参数：
|
sequence object or an expression that returns one.
|
x
|
member.
|
k
|
Search
from the k th member.
选项：
|
@b
|
Use the
binary search to query the location. In this case A is by default an
ordered sequence. Both increasing and decreasing are applicable .
|
@a
|
Return an n -integer sequence consisting of sequence numbers of all the members
that fulfill the query condition .
|
@z
|
Perform
the search backwards from the last member; perform the search from the first
member by default.
|
@s
|
With
an ordered A and the binary search,
return the position of x if it is a member of A ; otherwise,
return the opposite number for the sequence number representing the position
where x can be inserted
sequentially.
|
@p
|
Find position of the sequence x ,
which needs to be treated as a single value, in A , which, in this
case, is a sequence of sub-sequences .
|
@n
|
Return
the result of the length of A plus
1 if x cannot be found in A . This option and @a are mutually exclusive.
返回值：
sequence number or a sequence composed of sequence numbers
