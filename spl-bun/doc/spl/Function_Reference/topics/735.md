# pos()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
pos()
pos("abcdef","def")
pos("abcdefdef","def",5)
pos("abcdef","defa")
pos@z("abcdeffdef","def",7)
pos("abcdeffdef","def",7)
pos@c("abcdef","Def")
pos ("a'b'cbe","b")
pos@q("a'b'cbe","b")
pos("aab,aa","aa")
pos@w("aab,aa","aa")
pos@h("abcdef","abc",3)
```

## 提取内容
pos()
说明：
Get
the position of a substring in its parent string.
语法：
pos ( s 1 , s 2 {,
begin } )
注意：
The
function finds the position of substring
s 2 in the parent string s 1 , which starts from the position begin , and returns null if the substring cannot be found.
参数：
|
s 1
|
The
parent string where you want to search for a substring.
|
s 2
|
Substring
of interest.
|
begin
|
The
position from which the search starts; the default search is from the
beginning.
选项：
|
@z
|
Perform
the search leftward starting from begin ,
while the search will be done rightward by default.
|
@c
|
Case-insensitive.
|
@h
|
Search
for the substring at the beginning of the parent string by ignoring parameter
begin .
|
@q
|
Skip
quoted strings when searching the parent string.
|
@w
|
Only
locate a same and whole substring.
返回值：
Integer
type
示例：
|
pos("abcdef","def")
|
pos("abcdefdef","def",5)
|
pos("abcdef","defa")
|
(null)
|
pos@z("abcdeffdef","def",7)
|
pos("abcdeffdef","def",7)
|
pos@c("abcdef","Def")
|
4 ; @c option makes
case-insensitive .
|
pos ("a'b'cbe","b")
|
pos@q("a'b'cbe","b")
|
6; use @q option to
skip quoted strings .
|
pos("aab,aa","aa")
|
pos@w("aab,aa","aa")
|
5 ; use @w option to
locate the same and whole substring only.
|
pos@h("abcdef","abc",3)
|
1; use @h option to
match the parent string from the beginning. That is, ignore parameter begin
and search for the substring from the 1 st character of parameter s1 .
