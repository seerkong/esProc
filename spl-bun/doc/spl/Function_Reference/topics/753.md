## 提取内容
T.pseudo(T ’ ,…)
说明：
Segment a pseudo table
according to the segmentation way of another.
语法：
T. pseudo ( T’ ,…)
注意：
The
function sets up pseudo table T’ ,…,
which should be a pseudo table object from which a multicursor can be obtained,
according to pseudo table T . The
former is segmented the same way as the latter.
Only supported by esProc Enterprise Edition.
参数：
|
T
|
segmented pseudo table object.
|
T’
|
pseudo table object.
示例：
|
=create(file).record(["emp1.ctx"])
|
=pseudo(A1,3)
|
Generate
a pseudo table object having 3 subcursors from a composite table.
|
=create(file).record(["emp2.ctx"])
|
=pseudo(A3,5)
|
Generate
a pseudo table object, with the number of subcursorss being 5.
|
=A2.pseudo(A4)
|
Segment
pseudo table A4 the same way as pseudo table A2.
|
=A4.cursor()
|
Get
a multicursor having 3 subcursors from pseudo table A4.
