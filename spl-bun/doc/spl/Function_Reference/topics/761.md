## 提取内容
Qconnect()
说明：
Request
QVA through QVS to access QVM.
语法：
Qconnect ( url:v,wt,it )
注意：
The
function requests QVA through QVS to be assigned a QVM and returns a QVM
object.
Return
null if no QVM is assigned.
参数：
|
url
|
QVS
address, whose format is http://host:port/QVSServerName ; omit the parameter when
using the embedded QVS, but it should not be omitted in all other cases.
|
v
|
Validation
string.
|
wt
|
Maximum
wait time (unit: second) .
|
it
|
QVM’s
maximum idle time (unit: second), whose default is 120 ； QVM will automatically close when the max idle time is reached,
and will close permanently when its value is specified as 0.
选项：
|
@r
|
Clear
buffer when QVM is closed.
Return
value:
QVM
object
示例：
|
=Qconnect("http://54.213.221.123:8080/qvs":"aws-qvs",30,300)
|
Request
QVA through QVS to access QVM; QVS address is http://54.213.221.123:8080/qvs , validation string is aws-qvs, maximum wait time is 30 seconds,
and QVM’s maximum idle time is 300 seconds; return a QVM object.
|
=A1.exec("qtc01/imp_txt.splx";100)
|
Execute
SPL script file.
|
>A1.close()
|
Close
QVM.
