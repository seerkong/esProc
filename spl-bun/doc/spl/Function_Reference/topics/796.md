## 提取内容
redis_command()
说明：
Execute
Redis commands.
语法：
redis_command( redisConn,commandParts )
注意：
The
RedisCli external library function (See
External Library Guide ) is used to execute various Redis commands.
参数：
|
redisConn
|
Redis connection .
|
commandParts
|
sequence of Redis commands .
返回值：
Sequence
示例：
|
=redis_open("127.0.0.1:6379")
|
Connect
to Redis external library.
|
=redis_command(A1,["COMMAND"])
|
Execute
the Redis command COMMAND to get definitions of all commands from A1.
|
=redis_command(A1,"SCAN 0
COUNT 5".split(" "))
|
Execute
the Redis command SCAN to get a list of key names.
