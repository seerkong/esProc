# replace(s,a,b)

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
replace(s,a,b)
replace ( s , a , b )
replace("123321","2","two")
replace("abc'abc'def","a","China")
replace@q("abc'abc'def","a","China")
replace@1("abcabcdef","a","China")
replace@c("abcabcdef","A","China")
replace("1212341",["1","2"],["8","9"])
replace@s("1212341","12","89")
replace("aaa,aab,aa","aa","AA")
replace@w("aaa,aab,aa","aa","AA")
```

## 提取内容
replace(s,a,b)
说明：
Replace
a specified substring of a source string.
语法：
replace ( s , a , b )
注意：
The
function replaces substring a of
string s with string b . When parameters a and b are sequences, replace members of a with corresponding members of b .
参数：
|
s
|
Source
string.
|
a
|
substring of the source string, or a sequence of substrings.
|
b
|
The
string or a sequence of strings with which the specified substring will be
replaced.
选项：
|
@q
|
quoted specified string won’t be replaced.
|
@1
|
Replace
the first-found specified substring only.
|
@c
|
Case-insensitive.
|
@s
|
Split
content of a and b respectively into a sequence and perform the replacement
correspondingly.
|
@w
|
Only
replace the substring with the same number of characters.
返回值：
字符串
示例：
|
replace("123321","2","two")
|
1two33two1 .
|
replace("abc'abc'def","a","China")
|
Chinabc'Chinabc'def .
|
replace@q("abc'abc'def","a","China")
|
Chinabc'abc'def ; the “a”
enclosed by the single quotes are not replaced .
|
replace@1("abcabcdef","a","China")
|
Chinabcabcdef; only the first “a” is replaced .
|
replace@c("abcabcdef","A","China")
|
ChinabcChinabcdef; case-insensitive .
|
replace("1212341",["1","2"],["8","9"])
|
8989348.
|
replace@s("1212341","12","89")
|
8989348.
|
replace("aaa,aab,aa","aa","AA")
|
Return AAa,AAb,AA.
|
replace@w("aaa,aab,aa","aa","AA")
|
Use @w option to replace the
substring having the same number of characters only; here the function
returns aaa,aab,AA:
