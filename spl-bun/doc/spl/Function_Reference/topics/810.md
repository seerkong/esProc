## 提取内容
report_export()
说明：
Export
a report/report group file.
语法：
report_export ( rpt , filePath )
注意：
The
Report5Cli external library function (See
The Programmer’s Reference) exports a report as a pdf, docx, xlsx/xls,
html/mht or rpr file; rpr file is the default.
The
function only supports @p, @d, @x and @h when exporting a report group file.
参数：
|
rpt
|
report object.
|
filePath
|
The
URL through which a report is exported, which can be an absolute path or a
relative path; When it is the relative path, the base directory is the path
specified in esProc main directory’s < mainPath > node in the configuration
file.
选项：
|
@ p
|
Export
as a pdf file, paginated by default.
|
@ d
|
Export
as a docx file.
|
@x
|
Export
as an xlsx file, paginated by default.
|
@h
|
Export
as an html file.
|
@n
|
Export
as a non-paginated file; need to work with @p or @x.
|
@s
|
Export
as an xls file; need to work with @x.
|
@m
|
Export
as an mht file; need to work with @h.
|
@f
|
Export
as an Excel file with formulas; need to work with @x or @xs.
Return
value:
Report
file export path
示例：
|
>report_config("config\\raqsoftConfigReport.xml")
|
=report_open("D:\\test.rpx")
|
=report_run(A2)
|
=report_export@d(A2,"D:\\test.docx")
|
Export
as test.docx .
|
=report_export@d(A2,"
D:\\test ")
|
Same
as above; automatically export as a docx file when the file extension is
absent.
|
=report_export@p(A2,"D:\\test")
|
Export
as a paginated test.pdf .
|
=report_export@xn(A2,"D:\\test")
|
Export
as a non-paginated test.xlsx .
|
=report_export@xsf(A2,"D:\\test")
|
Export
as test.xls with formulas.
|
=report_export@hm(A2,"D:\\test")
|
Export
as test.mht .
|
=report_export(A2,"D:\\test")
|
Export
as test.rpr .
|
=report_export@pdxh(A2,"D:\\test")
|
Export
as a paginated test.pdf ; order of priorities of the options is @p>@d>@x>@h.
