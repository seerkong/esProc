## 提取内容
report_open()
说明：
Read
a report/report group file.
语法：
report_open ( filePath )
注意：
This
Report5Cli external library function (See
The Programmer’s Reference) reads a report file and returns report
object rpt .
参数：
|
filePath
|
The
URL through which a report is opened, which can be an absolute path or a
relative path; When it is the relative path, the base directory is the path
specified in esProc main directory’s < mainPath > node in the
configuration file.
Return
value:
Report
file object
示例：
|
>report_config("config\\raqsoftConfigReport.xml")
|
=report_open("D:\\test.rpx")
|
Read
the report file test.rpx .
|
=report_open("test1.rpx")
|
With
a relative path parameter, the report file path is the one set in <mainPath>
node in the configuration file.
function:
report_config()
