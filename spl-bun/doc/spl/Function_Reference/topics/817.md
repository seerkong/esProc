# report_write()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
report_write()
=report_open("D:\\wordFile.docx")
=report_insert(A1,"Text1"," 插入的测试文字 ")
=report_replace(A1,"sql","SPL")
=report_write(A1,"D:\\outFile.docx")
report_open()
report_insert()
report_replace()
```
