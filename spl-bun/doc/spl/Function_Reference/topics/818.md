## 提取内容
reportlite_config()
说明：
Read
information from the ReportLite configuration file.
语法：
reportlite_config ( filePath )
注意：
This
ReportLiteCli external library function (See ReportLit e
User Reference ) reads information from the ReportLite
configuration file, including the application’s resource path, the report
layout and so on.
参数：
|
filePath
|
file path, which is an absolute path or a relative path, or a class path; for
a relative path, its base directory is the application root directory; esProc
default is the root directory.
Return
value:
Configuration
file object
示例：
|
>reportlite_config("config\\raqsoftConfigReportLite.xml")
|
relative path; filePath is relative to esProc directory.
|
>reportlite_config("D:\\esProc\\config\\raqsoftConfigReportLite.xml")
|

absolute path.

|
