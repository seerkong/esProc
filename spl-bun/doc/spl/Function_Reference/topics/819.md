## 提取内容
reportlite_export()
说明：
Export
a ReportLite(group) file.
语法：
reportlite_export( rpt , filePath )
注意：
The
ReportLiteCli external library function (See ReportLite
User Reference ) exports the report as a pdf, docx, xlsx/xls, html/mht
or rptr file; by default, it exports the report as a rptr file.
It
supports @p, @d, @x and @h only when exporting a report group file.
参数：
|
rpt
|
report object.
|
filePath
|
The
URL through which a report is exported, which can be an absolute path or a
relative path; when it is the relative path, the base directory is the path
specified in esProc main directory’s <mainPath> node in the
configuration file.
选项：
|
@p
|
Export
as a pdf file, paginated by default.
|
@d
|
Export
as a docx file.
|
@x
|
Export
as an xlsx file, paginated by default.
|
@h
|
Export
as an html file.
|
@n
|
Export
as a non-paginated file; need to work with @p or @x.
|
@s
|
Export
as an xls file; need to work with @x.
|
@m
|
Export
as an mht file; need to work with @h.
|
@f
|
Export
as an Excel file with formulas; need to work with @x or @xs.
Return
value:
File
export path
示例：
|
>reportlite_config("config\\ raqsoftConfigReportLite .xml")
|
=reportlite_open("D:\\test.rptx")
|
=reportlite_run(A2)
|
=reportlite_export@d(A2,"D:\\test.docx")
|
Export
as test.docx .
|
=reportlite_export@d(A2,"D:\\test")
|
Same
as above; automatically export as a docx file when the file extension is
absent.
|
=reportlite_export@p(A2,"D:\\test")
|
Export
as paginated test.pdf .
|
=reportlite_export@xn(A2,"D:\\test")
|
Export
as non-paginated test.xlsx .
|
=reportlite_export@xsf(A2,"D:\\test")
|
Export
as test.xls with formulas.
|
=reportlite_export@hm(A2,"D:\\test")
|
Export
as test.mht .
|
=reportlite_export(A2,"D:\\test")
|
Export
as test.rptr .
|
=reportlite_export@pdxh(A2,"D:\\test")
|
Export
as a paginated test.pdf ; the order of priorities of the options is
@p>@d>@x>@h.
