# reportlite_insert()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
reportlite_insert()
=reportlite_open("D:\\wordFile.docx")
=reportlite_insert(A1,"Text1"," 插入的测试文字 ")
=reportlite_insert(A1,"Text2"," 替换掉模板的文字 ")
=img=file("D:\\pic.jpg")
=reportlite_insert(A1,"Image1",img)
=reportlite_insert(A1,"Image2",img)
=reportlite_open("D:\\test.rptx")
=reportlite_run(A7)
=reportlite_insert@p(A1,"Report1",A7)
=reportlite_write(A1,"D:\\outFile.docx")
reportlite_open()
reportlite_write()
```

## 提取内容
reportlite_insert()
说明：
Insert
a report, an image or text at the position specified by a bookmark in a
template file.
语法：
reportlite_insert ( D,
bookmark, content )
注意：
ReportLiteCli external library
function (See ReportLite
User Reference ).
At
the position specified by parameter bookmark , the function inserts a
report, an image or text specified by parameter content or replaces the existing content with them while keeping the
original text layout or image size.
参数：
|
D
|
The
DocxChanger object.
|
bookmark
|
Name
of the bookmark in a docx template file.
|
content
|
The
report, image or text to be inserted or replaced.
选项：
|
@ p
|
Paginate
a report before inserting it.
Return
value:
Boolean
示例：
|
=reportlite_open("D:\\wordFile.docx")
|
Read
template file wordFile.docx .
|
=reportlite_insert(A1,"Text1"," 插入的测试文字 ")
|
There
isn’t content at the position specified by bookmark “Text1”, so the text is
directly inserted there.
|
=reportlite_insert(A1,"Text2"," 替换掉模板的文字 ")
|
There
is content at the position specified by bookmark “Text2”, so replace the
existing content with the new text while keeping the original layout.
|
=img=file("D:\\pic.jpg")
|
=reportlite_insert(A1,"Image1",img)
|
There
isn’t content at the position specified by bookmark “Image1”, so insert the
image pic.jpg directly there.
|
=reportlite_insert(A1,"Image2",img)
|
There
is an image at the position specified by bookmark “Image2”, so replace it
with pic.jpg while keeping the original size.
|
=reportlite_open("D:\\test.rptx")
|
=reportlite_run(A7)
|
Compute
report file test.rptx .
|
=reportlite_insert@p(A1,"Report1",A7)
|
There
isn’t content at the position specified by bookmark “Report1”, @p option
enables directly inserting a paginated report.
|
=reportlite_write(A1,"D:\\outFile.docx")
|
function:
reportlite_open()
reportlite_write()
