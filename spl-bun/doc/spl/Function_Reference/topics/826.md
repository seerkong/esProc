# reportlite_write()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
reportlite_write()
=reportlite_open("D:\\wordFile.docx")
=reportlite_insert(A1,"Text1"," 插入的测试文字 ")
=reportlite_replace(A1,"sql","SPL")
=reportlite_write(A1,"D:\\outFile.docx")
reportlite_open()
reportlite_insert()
reportlite_replace()
```

## 提取内容
reportlite_write()
说明：
Write
content of a template file to a docx file after insert or replace operation is
finished.
语法：
reportlite_write ( D,
outFilePath )
注意：
ReportLiteCli external library
function (See ReportLite
User Reference ).
参数：
|
D
|
DocxChange
object.
|
outFilePath
|
Path
of the docx to which the template file is exported, which can be an absolute
one or a relative one. When it is the relative path, the base directory is
the path specified in esProc main directory’s <mainPath> node in the
configuration file.
Return
value:
File
export path

|
=reportlite_open("D:\\wordFile.docx")
