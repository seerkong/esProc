## 提取内容
rgb()
说明：
Convert
the red, green, blue, and transparency values respectively to the corresponding
color value.
语法：
rgb( redIntExp , greenIntExp , blueIntExp {, alphaIntExp } )
注意：
The
value of redIntExp , greenIntExp , blueIntExp , alphaIntExp should be between 0-255.
参数：
|
redIntExp
|
The
integer expression indicating the red, whose value is between 0-255
|
greenIntExp
|
The
integer expression indicating the green, whose value is between 0-255.
|
blueIntExp
|
The
integer expression indicating the blue, whose value is between 0-255
|
alphaIntExp
|
The
integer expression indicating the transparency, whose value is between 0-255
0 represents total transparency and 255 indicates total opaqueness; the other
values represent various levels of transparency respectively; default value
is 255.
返回值：
64-bit
long integer
示例：
|
rgb(123,123,123)
|
-8684677
|
rgb(123,123,123,123)
|
rgb(123,123,123,255)
|
-8684677
|
rgb(123,123,123,0)
|
