## 提取内容
right()
说明：
Get a substring of a string ending at the
rightmost side.
语法：
right( s , n )
注意：
The
function gets a substring from source string s starting from the n th -to-last character to the
end. If n <0, get a substring starting from the abs(n) th
character to the end.
参数：
|
s
|
The
source string.
|
n
|
The
n th -to-last character of source string s; return an empty
string when the absolute value of n is greater than the length of s .
返回值：
字符串
示例：
|
right("abced",2)
|
"ed"
|
right("abced",-2)
|
"bced"
|
right("abced",-8)
|
Return an empty string .
相关函数：
l e f t ()
mid()
