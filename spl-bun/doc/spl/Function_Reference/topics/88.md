## 提取内容
T.alter(F:x,…;F’,…)
说明：
Alter one or more fields in an entity table.
语法：
T.alter( F:x ,…; F’ ,… )
注意：
The function, supported only when a table is of columnar
storage, adds a field F to entity table/multizone entity table T
and deletes an old field F’ . Values of the new field are obtained by
calculating expression x and populated to the table. The dimension and
sorting field before it must not be modified.
参数：
|
T
|
An entity table/multizone entity table .
|
F
|
Name of the to-be-added field .
|
x
|
An expression .
|
F’
|
An existing field .
返回值：
Entity table/Multizone entity table
