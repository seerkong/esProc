## 提取内容
sf_wsdlopen()
说明：
Connect
to Salesforce server cloud service through soap api.
语法：
sf_wsdlopen( username, password )
注意：
The SalesforceCli external library function (See External Library Guide ) establishes
a connection in the enterprise style by default. It downloads WSDL file to
generate a jar package, which is enterprise.wsdl, metadata.wsdl, or
partner.wsdl.
参数：
|
username
|
User name .
|
password
|
密码 .
选项：
|
@p
|
partner
style connection .
返回值：
Connection object
示例：
|
=sf_wsdlopen("user","pwd")
|
enterprise
style connection.
|
=sf_wsdlopen@p("user","pwd")
|
partner
style connection.
