## 提取内容
sf_wsdlquery()
说明：
Query
data and return query result.
语法：
sf_wsdlquery( sql )
注意：
The SalesforceCli external library function (See External Library Guide ) queries
data and returns query result. The cases used by involved fields should
strictly conform to SObject Field defined in Salesforce at query. At present,
the function supports simple user-defined SQL statements.
参数：
|
sql
|
A SQL statement; does not
support select * from table. Users can refer to the value returned by
sf_wsdlview() to write corresponding fields .
返回值：
Table sequence
