T.append(cs)
说明：
Append
records in a cursor/table sequence to an entity table.
语法：
T. append ( cs )
注意：
The
function append-writes records in cursor/table sequence cs to entity
table T .
When
T is a multizone composite table, cs can be a multicursor. Each cursor part
of the multicursor corresponds to one zone of T uniquely.
If
a table has an attached table, appending data to the parent table requires that
data be ordered by the key and be unique; otherwise, error will be reported.
The
parent table can have records that don’t have matches in a sub table, but the
opposite situation is not allowed; otherwise, the appending to an attached
table will be disabled.
When
data is being appended, do not open the multizone composite table from multiple
locations in case of data collision.
参数：
|
T
|
An
entity table/multizone composite table.
|
cs
|
cursor/table sequence.
选项：
|
@i
|
Real-time appending whenever a retrieval happens; force
an appending when a composite table is closed; by default, an appending is
executed only when there is a specified number of new records .
|
@x
|
When
appending data in a unicursor to a multizone composite table, compute them
with zone expression and write result to the corresponding zone table.
|
@m
|
Write
data through merge-append; append data after the last record by default; do
not support attached tables for the time being.
|
@y
|
Append
records of cs to an in-memory zone table rather than the external
storage; mutually exclusive with other options
Return

the in-memory zone table when T is a composite table.
