Query

语法：

SparkCli external library

The

and returns result data.
参数：

Database

|

|

A table name (query

parameter warehouse in configuration file .properties, such as hdfs://localhost:9000/user/hive/warehouse/tableName, which shows the location of the table
in HDFS.

|
