# spark_read()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
spark_read()
spark_read ( con,sfile,k:v,.. . )
=spark_open()
=spark_read(A1,"D:/people.txt","sep":"
=spark_read@c(A1,"D:/student.csv","sep":",")
=spark_read@t(A1,"D:/score.txt","sep":"\t")
=spark_read(A1,"D:/people.json")
>spark_close(A1)
=spark_open("spark.properties")
=spark_read@x(A7,"hdfs://localhost:9000/user/hive/warehouse/people.csv")
```

## 提取内容
spark_read()
说明：
Read
a file stored in a local Spark database or a Spark standalone.
语法：
spark_read ( con,sfile,k:v,.. . )
注意：
SparkCli external library
function (See External Library Guide ).
The
function reads content of a file stored in a local Spark database or a Spark
standalone, and returns result as a table sequence.
参数：
|
con
|
Database
connection string, which can be a local connection or a connection to Spark
standalone .
|
sfile
|
File
name .
|
k:v
|
Separator setting for txt and csv files. For example, to set " # "
as separator of a txt file, the parameters will be "sep":"#" . By default, use comma
as the separator for a txt file, and semicolon as the separator for a csv
file.
选项：
|
@c
|
Read
content of a file and return result as a cursor .
|
@t
|
Read
the first row of a text file as field names; by default, use the
automatically generated field names c0, _c1… .
|
@x
|
Close
Spark database connection .
返回值：
Table
sequence/游标
示例：
|
=spark_open()
|
Connect
to a local Spark database.
|
=spark_read(A1,"D:/people.txt","sep":"
")
|
Read
a tab-separated txt file.
|
=spark_read@c(A1,"D:/student.csv","sep":",")
|
Read
a comma-separated csv file and return a cursor.
|
=spark_read@t(A1,"D:/score.txt","sep":"\t")
|
Read
a tab-separated txt file and use the first row as field names.
|
=spark_read(A1,"D:/people.json")
|
Read
content of file people.json .
|
>spark_close(A1)
|
Close
the Spark database connection.
|
=spark_open("spark.properties")
|
Connect
to a Spark database.
|
=spark_read@x(A7,"hdfs://localhost:9000/user/hive/warehouse/people.csv")
|
Read
people.csv stored in the Spark database and the close the connection.
