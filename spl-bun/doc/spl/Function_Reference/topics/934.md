# substr()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
substr()
substr ( s 1 ,s 2 ,n)
=substr("abcdef","cd")
=substr@l("abcdef","cd")
=substr@q("ab\'cdef\'","cd")
=substr@c("abCdef","cd")

substr@z("11-22-33","-",2)
```

## 提取内容
substr()
说明：
Find a substring and
return the string after the substring.
语法：
substr ( s 1 ,s 2 ,n)
注意：
The function finds the n th
string named s 2 in string s 1 starting from the left and
returns the string after s 2
return null if there is nothing after s 2 .
参数：
|
s 1
|
A string .
|
s 2
|
A string .
|
n
|
A positive integer whose default value is 1.
选项：
|
@l
|
Return the string
before s2 ; return null if there is
nothing before s2 .
|
@z
|
Perform the search
from back to front.
|
@q
|
Skip the quoted string .
|
@c
|
Case-insensitive .
返回值：
字符串
示例：
|
=substr("abcdef","cd")
|
ef .
|
=substr@l("abcdef","cd")
|
ab .
|
=substr@q("ab\'cdef\'","cd")
|
No return value .
|
=substr@c("abCdef","cd")
|
ef .
|
substr("11-22-33","-",2)
|
substr@z("11-22-33","-",2)
|
22-33
