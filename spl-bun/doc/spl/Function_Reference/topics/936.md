stax_open()
说明：
Create
connection to the Cassandra database.
语法：
stax_open ( nodes[:port][,keyspace][,user:pwd][,compressor][,version:verX][,clusterName:nameX][,query选项：optionX] )
注意：
CassandraCli external library function (See External Library Guide ). The username and password are
not required if the Cassandra database is started under the 密码Authenticator mode; but required if the
Cassandra database is started under the authorizer: AllowAllAuthorizer mode. Use keyspace.table format in a CQL query when parameter keyspace is absent.

|

|

|

|
compression algorithm, which is LZ4, Snappy and none; default is none .
|

|

details in Cssandra documentation .
