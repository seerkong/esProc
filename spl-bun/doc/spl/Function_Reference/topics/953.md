ch.switch(Fi,Ai:x;… )
说明：
Attach
a referencing field-based switch operation to a channel and return the original
channel.
语法：
ch . switch ( F i , A i : x ;…)
注意：
The function attaches a
computation to channel ch , which will
switch values of field F i to the
referenced records of A i ,
and return the original channel ch .
x is A i ’s primary key or logical primary key. The matching condition for
the switch is F i = x . By default, display F i value as null when no match can be found in A i for F i .
This is an attached
computation.
