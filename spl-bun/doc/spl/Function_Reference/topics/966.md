time()

Convert
a string or integer to time data.

|
time ( stringExp )

string string into time
value according to system-defined datetime format; return null if the
conversion fails .
|
time ( stringExp {, format } :loc )
|
Convert
the string stringExp to time data type
according to the format specified by format and return null if the
conversion fails. If there is no parameter format , format of stringExp must be in consistent with the time format in the configuration
information. Parameter loc is the language used in
stringExp ; default is the system language .
|
