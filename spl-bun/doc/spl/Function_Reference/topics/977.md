# trim()

- 格式：为 AI 阅读提取的 Markdown

## 代码片段
```spl
trim()
trim( s )
trim@a("a bc")

```

## 提取内容
trim()
说明：
Remove
the blank characters from both ends of a string.
语法：
trim( s )
注意：
The
function removes the blank characters on both ends of string s .
参数：
|
s
|
Source
string from which you want to remove the blank characters.
选项：
|
@l
|
Remove
spaces to the left of the string, with the parameter being letter l .
|
@r
|
Remove
spaces to the right of the string; by default, remove spaces on both ends.
|
@a
|
Remove
all extra whitespaces; if there is one or continuous whitespaces within the
string, retain only one whitespace; remove the whitespaces between a
character and a word, but retain the whitespaces within the quotation marks.
返回值：
字符串
示例：
|
trim(" abc
")
|
"abc"
|
trim(" a bc
")
|
"a bc"
|
trim@l(" abc def
")
|
"abc def "
|
trim@l("def abc
")
|
"def abc "
|
trim@r(" abc def
")
|
" abc def"
|
trim@r("def abc
")
|
"def abc"
|
trim@a(" a bc
")
|
"a bc"
|
trim@a("a bc")
|
"a bc"
|
trim@a("a\' bc\' ")
|
"a' bc'"
|
trim@a("abc !")
|
"abc!"
