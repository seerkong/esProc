## 提取内容
was_copy()
说明：
Copy a file in the WAS
storage bucket to local, or a local file to the WAS storage bucket.
语法：
was_copy( fd,bucket:key,
[localFile] )
注意：
WasCli
external library function (See
External
Library Guide ).
参数：
|
fd
|
WAS connection object.
|
bucket
|
Storage bucket name.
|
key
|
File name in the storage
bucket.
|
localFile
|
A local file name; save
the file in the main directory if the parameter is absent.
选项：
|
@u
|
Copy a local file to the
WAS storage bucket; when the local file path is a relative one, it is
relative to the main directory.
返回值：
Boolean
示例：
|
=was_open(" mywas ","MSU 4 nLvFd+uYaFw8EtB 2 GzJ8e==","core.windows.net","https")
|
Create a WAS connection.
|
= was _copy(A1,
"test1":"test1.txt")
|
Copy test1.txt in
storage bucket test1 to 【 main directory 】 /test1 .
|
=was_copy(A 1 ,
"test1":"test1.txt","D:/myBucket/test2.txt")
|
Copy test1.txt in
storage bucket test1 to D:/myBucket/test2.txt .
|
=was_copy@u(A 1 ,
"test1":"test3.txt","D:/myBucket/test2.txt")
|
Copy the local file D:/myBucket/test2.txt
to test3.txt in storage bucket test1.
|
>was_close(A 1 )
|
Close the WAS connection.
