## 提取内容
was_file()
说明：
Get the specified object in
a WAS storage bucket.
语法：
was_file( fd,bucket,key[:cs] )
注意：
WasCli
external library function (See
External
Library Guide ).
The returned file object
supports file handling functions such as f.exists(), f.name(), f.size(),
f.date(), f.read(), f.import() and f.export().
参数：
|
fd
|
WAS connection object.
|
bucket
|
Storage bucket name.
|
key
|
File name in the storage
bucket.
|
cs
|
Encoding name; use the
encoding to save or open the file.
返回值：
文件对象
示例：
|
=was_open(" mywas ","MSU 4 nLvFd+uYaFw8EtB 2 GzJ8e==","core.windows.net","https")
|
Create a WAS connection.
|
=was_file(A1, " test1 ","emp.txt")
|
Load emp.txt in
storage bucket test1.
|
=A2.name()
|
Get the full path
containing the file name.
|
=A2.import@t()
|
Return the file data as a
table sequence.
|
=A2.cursor@t().fetch(10)
|
Retrieve data in the way
of cursor.
|
>was_close(A1)
|
Close the WAS connection.
