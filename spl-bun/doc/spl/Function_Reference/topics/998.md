was_list()
说明：
List files in Windows Azure
Storage buckets or the specified bucket.
语法：
was_list (fd,[bucket])
注意：
WasCli
external library function (See
External
Library Guide ).
The function lists files in
Windows Azure Storage buckets or the specified bucket and returns a table
sequence containing the files or certain properties of the storage buckets.
It lists all files in the
specified storage bucket bucket when all parameters are present; in the
returned table sequence, 键 field contains file names, Size field records file
sizes in the unit of byte, and 日期 field is the creation time or the last
modified time of the current file.
It lists all WAS storage
buckets when parameter bucket is absent; in the returned table sequence,
键 field represents the storage bucket name and Size field won’t be displayed.
参数：
|
fd
|
WAS connection object.
|
bucket
|
Storage bucket name.
返回值：
Table sequence
