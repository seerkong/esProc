前言
大数据的技术本质是高性能。只有在具备足够性能的条件下，大数据分析才能真正落地。
性能优化应当在有限的硬件条件下实施。软件无法改变硬件速度。我们能做的是设计更低复杂度的算法，减少实际计算量，自然就能获得更高的计算性能。
有些大数据算法具有较好的通用性，几乎在所有情况下都能工作，但通常更保守，难以获得高性能。为了减少计算量，应当认真研究并利用数据与任务的特征，根据实际条件设计合适的存储方案和计算方法。
本书内容旨在描述针对不同场景和目标的适用存储方案与优化算法。程序员熟悉这些基础算法的原理与应用前提后，可以灵活组合并用于业务中的高性能问题。理解这些算法及其特征后，也能在大数据产品的技术选型与理解上取得很大进步。
本书算法主要面向结构化数据计算，涉及检索、过滤、分组、排序和连接等操作。这些是大数据计算的基础内容，也是数据分析与计算中最常见的任务。
本书并非只是简单罗列和总结历史算法，许多算法和优化技术为业内首次成书。本书不仅讨论高性能算法的理论，还涉及在复杂度上没有特殊优势但能在工程实践中提升性能的技术手段。
本书不适合初学者，对读者有一定的专业要求：
1）掌握关系数据库与 SQL 的各类操作，本书不再解释其含义。
2）理解相当于大学计算机专业数据结构课程的知识，相关概念将直接引用。
3）理解算法复杂度分析的基础知识。
4）最好熟悉 C/C++ 或 Java 编程语言、操作系统的内存管理机制以及基础局域网知识。
部分算法的原理和过程较为繁琐且困难，应用程序员不必完全掌握。只要理解算法的适用条件并熟悉应用代码示例，也可使用。
本书将使用 SPL 编写应用代码示例，并直接使用 SPL 的数据类型和语法来描述计算目标，这要求读者预先理解。具备 SPL 知识的读者可以轻松将这些术语转换为其他编程语言的对应词汇。
SQL 是最常用的结构化数据操作语言，但它过于粗糙，难以应用本书中的大多数优化算法。Java、C/C++ 等编程语言也缺乏结构化数据操作的必要概念，从头定义会占用过多篇幅。而且即使可以实现这些算法，代码也会很长，精力会消耗在细节上。
SPL 可能是业内唯一能够不那么繁琐地应用这些算法的编程语言。理解这些算法机制后，你也可以在 Java、C/C++ 等语言中自行实现，并获得更好的性能。
