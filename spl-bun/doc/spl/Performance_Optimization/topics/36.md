5.2
有序分组子集
当数据表按分组键有序时，可以以游标形式逐个读出分组子集，从而完成一些复杂操作。
以一年期账户交易表为例，我们要统计：在 n 个连续自然日内交易次数超过 m 的账户数量，n 和 m 由用户在程序界面输入，且希望能即时得到结果。
这是一个较复杂的操作，难以用简单聚合函数（甚至迭代函数）来写。通常在把某一账户下的交易记录读入内存后计算会很容易。由于单个账户下的记录一般不多，内存足够容纳。
按账户分组的子集就是该账户的交易记录，但账户数量可能非常多，这属于典型的大分组，无法将所有分组子集存入内存。若每次取某账户的交易记录且没有索引，就要全表遍历，完全不可接受；即便有索引，过多的取数次数也会导致计算变慢，因为原始数据表通常按交易时间排序（参见 3.7 节：返回集合的查找）。
若预先按账户排序数据表（账户内按日期排序），再用有序分组技术，就能轻松取出分组子集进行计算：
|
=file("trades.ctx").open().cursor(id,dt)
|
>m-=1,n-=1
|
for A1;id
|
if (k=A2.(dt).len()-m)<=0
|
=@+if(k.pselect(A2(#+m)-A2(#)<=n),1,0)
|
return B3
|
对有序游标而言，for 语句会一次取出一个分组子集，然后判断是否存在 n 天内 m 次交易。
实际操作中，可进一步优化为每次读取更多账户。
这些代码也可合并进 group 函数：
|
=file("trades.ctx").open().cursor(id,dt)
|
>m-=1,n-=1
|
=A1.group(id).((k=~.(dt).len()-m)>0 &&
k.pselect(~(#+m)-~(#)<=n)
|
return A2.total(count())
对 group() 取出的每个分组子集，计算一个逻辑表达式；结果为真表示 n 天内有 m 次交易。A2 仍返回游标，只需遍历并统计为真的数量即可。
若数据表使用上一节所述的组合表分段方法，该操作也可基于多游标完成，只需在生成游标的函数上加选项：
|
=file("trades.ctx").open().cursor@m(id,dt;;4)
|
>m-=1,n-=1
|
=A1.group(id).((k=~.(dt).len()-m)>0 && k.pselect(~(#+m)-~(#)<=n)
|
return A2.total(count())
前面章节已讨论有序数据的维护与追加方法。只要预先排序数据，并采用之前提到的日期转整数技术，即便数据量很大也能获得高性能的即时响应。这种计算方法比传统数据库游标计算快一到两个数量级（你无法用单条 SQL 实现这类逻辑）。
有序分组子集技术对提升海量账户的复杂分析性能非常有用。
有了分组子集，也很容易实现 DISTINCT，只需在每组取一条记录。例如，计算交易表中每个账户在哪些月份发生过交易：
|
=file("trades.ctx").open().cursor(id,dt)
|
=A1.group(id,month(dt)).(~(1))
从 A2 得到的游标可知交易发生的账户和月份，实际上只取了每个分组子集的第一条记录。注意这是游标，仍需 fetch() 才能实际计算并取数。下面还会有很多类似示例，我们只需获取游标即可，因为结果集可能太大而无法全部取出。获取游标后可继续计算或将结果集保存为文件。
取出分组子集的操作较常见，SPL 提供了选项：
|
=file("trades.ctx").open().cursor(id,dt)
|
=A1.group@1(id,month(dt))
group@1() 将完成与上例相同的功能，但不会先生成分组子集，从而降低内存消耗，也适用于分组子集有时较大的情况（但通常属于小分组）。实际上，group@1() 可理解为 DISTINCT，效果与 id() 函数基本相同。数据有序时 DISTINCT 可高效执行，数据无序时 DISTINCT 的复杂度与分组相当。
再看上述账户交易表，我们现在要为每条记录增加月累计金额信息，即该账户在本月内截至该交易的累计交易额，然后筛出每月累计金额首次超过 100 的交易（含日期）。
读取分组子集后即可计算：
|
=file("trades.ctx").open().cursor(id,dt,amonut)
|
=A1.group(id,month(dt)).(~.derive(itertate(~~+amount,0):mca))
|
=A2.(~.select@1(mca>=100))
这种累计计算可用明细数据的迭代函数实现。该迭代函数仍具前述特性：有初始结果，每遇到一条明细数据就计算新结果。不同于只返回最终结果的聚合函数，明细数据上的迭代函数会在每次计算时返回当前结果。因此，A2 的 derive 中增加的字段可得到每笔交易当时的月累计金额。
需要注意的是，A2 的游标取数得到的是表序列，A3 要在表序列中做过滤（取出累计金额首次达到要求的记录），而不是直接过滤游标。
然而，这种算法需要先取出分组子集。若换个场景：订单表按产品和日期排序，需求改为计算每个产品的月累计订单金额首次超过 100 的日期，则先取分组子集再计算的方法不可行，因为某个产品可能有很多交易记录，分组子集会很大。
对于有序游标上的累计计算，也可用迭代函数的分组参数实现：
|
=file("orders2.ctx").open().cursor(product,dt,amount)
|
=A1.derive( iterate( ~~+amount,0; prudoct,month(dt) ):
mca )
|
=A2.select(mca>=100).group@1(product,moth(dt))
iterate() 中分号后的参数用于表示分组字段。当这些字段（或表达式）变化时，SPL 会重新开始新一轮迭代计算（将计算结果重置为初始值并继续迭代）。迭代计算过程中只需比较上一条记录，无需先取出整个分组子集，从而降低内存占用并支持大分组子集。此外，累计金额字段会加入原始记录，A3 中的 select() 可直接对游标执行。
最后需用 group@1() 做 DISTINCT。此时取出的是分组子集的第一条记录。虽然分组键是产品和月份，但取出的记录是分组前记录，即包含 dt 字段的记录。
