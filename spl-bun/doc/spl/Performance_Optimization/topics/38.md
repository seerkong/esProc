## 提取内容
5.4
前半有序分组
仍以上述交易表示例，若要改变其排序方式，将同一账户的交易记录按发生日期的星期几排序，即把周日发生的交易放一起、周一放一起、周二……本质上是改变原表的排序方式，但属于大排序操作。大排序会生成缓冲文件，性能不会好。
然而我们发现，原表已按账户有序，可视为“半有序”表，并且每个（有序）账户内的无序数据量不大。这种情况下，可用上节的程序游标执行大排序。
|
func
|
=file("trades.btx").cursor@b()
|
for B1;id
|
return B2.sort(day@w(dt))
|
return cursor@c(A1)
对每个账户取数并对“后半部分”排序，程序游标收集结果即可得到所需的大排序结果。
当然，该方法也可用于分组。例如，要计算每个账户在每周各天的交易总额，只需将上述 A3 改为：
return
cursor@c(A1).group(id,day@w(dt);sum(amount))
也可在子程序中处理，这样返回数据更少：
|
func
|
=file("trades.btx").cursor@b()
|
for B1;id
|
return B2.groups(id,day@w(dt);sum(amount))
|
return cursor@c(A1)
现实中这种情况并不少见。SPL 在 group() 函数上直接提供了一个选项：
|
=file("trades.btx").cursor@b()
|
=A1.group@q(id;day@w(dt);sum(amount))
注意 group@q() 有三组参数：第一组表示有序分组键，第二组表示无序分组键，第三组是聚合表达式。通过 @q 选项与三组参数，SPL 会先利用有序游标取出相同 id 的数据，再按 day@w(dt) 分组。
这段代码也可直接用于排序：
|
=file("trades.btx").cursor@b()
|
=A1.group@qs(id;day@w(dt))
若加入 @s 选项，表示只排序不分组，即把相同 id 的数据按 day@w(dt) 排序。
