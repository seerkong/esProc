后记
本书共 60 节，介绍了数十种针对大规模结构化数据的高性能基础算法或存储方案。这些方法在许多实际场景中得到灵活应用。与传统关系数据库中的 SQL 相比，SPL 中实现的算法往往能将性能提升数倍甚至上百倍。
作为编程语言，SPL 理论上不会比 SQL 更快。SPL 实际运行更快的原因在于它能够实现 SQL 无法实现的高性能算法。若某计算任务在 SQL 中已经采用了最佳算法，用 SPL 重写也不会更快。然而有太多高性能算法难以用 SQL 实现，只要代码稍复杂，几乎总能找到可改变存储方案和算法的优化点。我们在十余个场景的实践中，每次都能找到提升点，此时用 SPL 重写能有效提升整体性能。当然，用 C/C++ 或 Java 也可能获得更高性能，但开发效率太低。
需要再次强调的是，本书中的每种算法都有其适用场景；且某些算法因相互矛盾而不能同时使用，因此应根据实际情况选择算法。我们一再强调，必须先充分理解任务目标与数据特征，再结合实际条件设计优化方案。现实中的大数据计算任务并不与书中的算法一一对应，而是综合性任务，因此应当适度组合这些基础算法以应对真实任务。因此，学习分析方法更为重要。
受篇幅所限，本书未给出所有示例与测试。若希望了解更多测试案例与代码，请前往 Raqforum 查找。
