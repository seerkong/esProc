3.3 条件循环

for n 和 for a,b 都是循环次数确定的循环，但有时我们不知道要循环多少次。只有当条件为真（或不为真）时才结束循环，在此之前重复执行循环体，这种循环称为条件循环。

事实上，for n 和 for a,b 也可以理解为这样的循环，即当循环变量超过 n 和 b 时结束循环（超过不一定意味着大于）。条件循环是更一般的循环形式。

有一种计算两个数的最大公约数的经典方法，叫做辗转相除法。两个正整数 a 和 b，假设 a>b，用 a 除以 b 的余数替换 a，现在 a<b，然后用 b 除以 a 的余数替换 b，然后 a>b，...，如此反复，直到 a 或 b 中有一个为 0，那么另一个不为 0 的就是原来 a 和 b 的最大公约数。因为 a 和 b 反复交换位置来计算余数，所以叫辗转相除法。

这是希腊几何学家欧几里得在 2000 多年前发明的方法。有兴趣的读者可以自己证明。我们这里用程序代码来实现它。

将原来的两个数设置在单元格 A1 和 B1 中。

|
for B1>0
|
=A1%B1
|
>A1=B1
|
>B1=B2

计算结果将显示在 A1 中。

单元格 A2 的代码是 for B1>0，for 后面跟着一个布尔表达式。当它计算为 true 时，循环体将被执行一次，然后返回 A2 再次计算布尔表达式。如果仍然为 true，循环体将再次执行...；直到布尔表达式计算为 false，循环结束。

这个逻辑可以实现辗转相除法。我们不知道要循环多少次，只知道当 B1 为 0 时，循环可以终止。

大多数编程语言都有条件循环，但它们通常使用 while。

像 if、else、for 这样的词会在程序代码中用来表示某些特殊语句，称为程序语言的保留字或关键字。这些保留字具有特殊意义，不能用作变量名等标识符。所有编程语言都有一些自己的保留字。

SPL 不想有太多保留字，而且用 for 来表示条件循环也不会产生歧义，所以它没有保留更常见的保留字 while。

让我们再做一个与约数相关的练习，质因数分解，这是小学数学课的内容。

方法很简单。给定一个正整数 n，我们用它除以 2，如果能整除，就得到一个因子 2。我们用 n 除以 2 得到一个新的 n，继续除以 2，...；直到不能被 2 整除，如果此时 n 变成 1，就结束了。如果 n 不是 1，继续除以 3 并重复这个过程；继续用 n 除以 4、5...；最后，n 总是变成 1，就结束了。

正如我们之前所说，因为我们还没有学习集合，所以我们可以输出找到的质因数。

先让 n 填入单元格 A1。

|
=2
|
for A1>1
|
for A1%B1==0
|
>output(B1)
|
>A1=A1\B1
|
>B1+=1
|

注意单元格 C3 中使用的是 \，表示整数除法，否则会计算出浮点数，下一个 A1%B1 就无法继续了。

这是一个两层循环的代码。它也可以写成单层循环：

|
D
|
=2
|
for A1>1
|
if A1%B1==0
|
>output(B1)
|
>A1=A1\B1
|
>B1+=1
|

将单元格 B2 的 for 替换为 if，然后在单元格 D3 中添加一个 next。

我们已经知道 if 的功能。这里的 next 有什么功能？

next 意味着进入下一轮循环头，不再执行循环体中它之后尚未执行的代码。这里，如果代码执行到 D3 的 next，意味着 B4 将被跳过而不执行，程序将直接进入下一个循环，即回到 A2 判断 A1>1 并决定是否继续执行循环体。

仔细想想这个逻辑过程。B1 从 2 开始。如果 A1 能被 2 整除，在 C2 输出 2，将 A1 除以 2，然后再次回到 A2 进入下一个循环。此时，B1 仍然是 2，因为 next 会跳过 B4，语句 B1+=1 没有执行。当所有 2 的因子都计算完后，单元格 B2 的 if 将不成立，然后进入单元格 B4 执行 B1+=1，将 B1 变成 3，然后进入下一个循环。这个单层循环可以达到与上面两层循环相同的效果。

应该注意的是，如果在 for n 或 for a,b 的循环中使用 next，循环变量在下一个循环中仍然会变化。例如，前面求奇数和的例子也可以用 next 来写：

|
=0
|
for 200
|
if A2%2==0
|
>A1+=A2
|

当遇到偶数时，B2 的条件成立，它将执行到 C2 的 next 进入下一个循环，循环变量仍然会加 1。

当数字是奇数时，它将执行到 B3 执行累加，循环体将被执行 200 次。

在多层循环中，next 后面跟着循环单元格的名称可以使外层循环直接进入下一轮。例如，上面提到的水仙花数也可以写成如下形式：

|
D
|
E
|
F
|
for 9
|
=100*A1
|
=A1*A1*A1
|
for 0,9
|
=B1+10*B2
|
=C1+B2*B2*B2
|
if C2<D2
|
next A1
|
for 0,9
|
=C2+C3
|
=D2+C3*C3*C3
|
if D3==E3
|
>output(D3)
|
else if D3<E3
|
next B2
|

看起来使用 next 达到了与 break 相同的效果，但机制不同。单元格 E5 的 next B2 将直接进入 B2 循环的下一轮，而如果是 break，它将跳出 C3 循环。在这个例子中，两者的效果是一样的，因为 C3 循环结束后没有 B2 循环的代码，B2 循环也结束了。
