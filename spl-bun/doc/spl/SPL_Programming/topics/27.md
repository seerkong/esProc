5.7 Lambda 语法 *

回顾一下 A.pos(x) 和 A.select(x) 这两个函数，我们说前者不是循环函数，参数 x 中不能使用 ~、# 等符号，而后者是循环函数，参数中可以使用 ~、# 等符号。事实上，在这两个函数的计算过程中，两者都会遍历 A，即它们会逐个处理 A 的成员。这两个函数的参数有什么区别？

在引入循环函数之前，所有函数 f(x) 都有一个特点。如果它的参数 x 是一个计算表达式，它会在计算这个函数 f() 之前被计算。例如，max(3+5,2+1)，当计算机计算 max() 函数时，得到的参数已经是 8 和 3 了。即使参数中可能有变量也是一样的。max(x+5,y+3) 的计算表达式在 x 和 y 没有赋值时无法计算，而在 x 和 y 赋值后，x+5 和 y+3 会先被计算，然后传递给 max 函数进行计算。

这没问题。这就是我们在数学课上学到的关于函数的知识。A.pos(x) 的参数也是如此。

然而，A.select(x) 不同。这个 x 可能在计算 select() 函数之前无法计算。它只能在计算 select() 函数的过程中计算。例如，A.select(~%2==0)，我们不能在计算 select() 函数之前计算 ~%2==0。有一个未知的 ~，它只能在循环 A 的过程中确定，然后我们才能计算这个表达式。

对于序列的函数，它的参数是一个待计算的表达式，只能在循环序列的过程中计算。具有这种特点的函数称为循环函数。因此，A.pos(x) 和 A.pseg(x) 不是循环函数，而 A.(x)、A.run(x)、A.select(x) 和 A.max(x) 是循环函数。

对于非循环函数，即使参数写成表达式，在传入时也会被计算为具体的值。

对于循环函数，要传入函数的参数是一个表达式，其中包含一些未知变量如 ~、#。事实上，这个表达式可以被视为一个以这些未知变量为参数的函数。换句话说，循环函数的参数本质上是另一个函数，而不是简单的值。

这是循环函数和非循环函数的本质区别，它以函数作为参数。

最早的编程语言不支持函数作为参数，当时人们还缺乏经验。他们只是简单地使用数学中函数的经验（事实上，数学家早就从事泛函分析，研究函数的函数，但毕竟比较深奥）。后来，为了使代码重用更方便，人们引入了函数指针的概念，将函数作为参数传递给另一个函数，以便前者可以被后者调用。然而，仍然需要用一段代码明确定义被调用的函数。代码复杂且难以理解。

例如，我们例子中的 A.select(~%2==0)，传统语法分为两步：首先，定义一个函数 f(x) 为 x%2==0，然后使用 A.select(f) 来计算。在 select() 函数的循环计算中，A 的当前成员作为参数传入函数 f()。计算后，得到返回值，并决定是否将这个成员添加到 select() 的返回值中。

事实上，许多需要用作参数的函数的计算逻辑并不复杂。它可以用一个简单的表达式清楚地描述，例如，这个 x%2==0 非常简单。为这样的事情定义一个 f 函数太麻烦了。

因此，人们进一步发明了直接用表达式定义函数的编程语法。不需要提前定义 f 函数，可以直接写入 select() 函数的参数中：

A.select( f(x):{x%2==0} )

这种在参数中临时定义函数的方法在业界称为 lambda 语法。

有了 lambda 语法，代码编写容易多了。现在许多编程语言已经开始支持这种语法。

仍然有问题。

要传入的函数必须是一个带参数的函数，这些参数用于引用宿主函数（本例中的 select()）计算过程中产生的一些变量（这里是 A 的成员）。否则，如果没有参数，它应该在调用宿主函数之前就被计算了。

因此，在上面的 f(x):{x%2==0} 语法中，必须有一种方法来指定参数。在 f(x) 中使用 x 来告诉计算机 x%2==0 中的 x 是作为参数的函数的参数（有点绕），等待宿主函数传入值。如果我们只写 x%2==0，计算机不知道 x 是什么，还是它是其他地方的变量？

理解起来仍然有点繁琐和混乱，但这是大多数支持 lambda 语法的编程语言的现状。

还没完。

A 的成员的序号（即 #）也可能在 select() 的宿主函数中使用。函数 f() 只有一个参数是不够的，因为 select() 函数需要接受各种函数作为参数，这些函数的参数必须统一，否则 select() 函数无法调用它们。

因此，这个函数必须至少有两个参数，语法必须写成如下形式：

A.select( f(x,y):{x%2==0} )

在这个例子中，我们没有使用为序号（即 #）准备的 y 参数，但我们必须在定义中写上它。

然而，我们知道 select() 也可能使用 ~[-1] 等。还会传入多少？这些参数需要提前定义为 f() 的参数。太麻烦了。只需传入整个 A 和当前序号。反正可以计算。

最后，可能是这样的：

A.select( f(x,y):{x(y)%2==0} )

参数 x 表示宿主函数要计算的序列，参数 y 表示宿主函数正在计算的成员的序号。其余的写在这个定义中。

但那又不方便了。

事实上，大多数支持 lambda 语法的编程语言都没有走到这一步，它们只支持到 f(x):{x%2==0} 的级别。也就是说，没有办法在表达式中引用序号和进行相邻引用。

那么，我们怎样才能使代码简单且具有描述能力呢？

这就是 SPL 现在做的。

SPL 通过使用 ~、# 和 [] 等符号来表示作为参数的函数的参数，从而简化了这件事。因此，写 ~%2==0 就可以了，不需要写 f(x) 来指定参数名。

这样，编写和理解都很简单，而且由于这些丰富的符号，描述能力也得到了加强。
