### 6.1 用户自定义函数

仍然假设没有阶乘函数，现在我们要计算组合数（原文含示意图，图像资源未迁移）。

|   | D |
|---|---|
| =1 |   |
| for A1 |   |
| >A2=A2*B2 |   |
| =1 |   |
| for B1 |   |
| >A3=A3*B3 |   |
| =1 |   |
| for A1-B1 |   |
| >A4=A4*B4 |   |
| =A2\A3\A4 |   |

n 和 k 分别填在 A1 和 B1 中，第二、三、四行分别计算 n!、k! 和 (n-k)!。

这样计算是可以的，但几乎相同的代码写了三遍。

如果问题更麻烦，例如，我们需要计算二项式定理的系数序列（原文含示意图，图像资源未迁移）（即杨辉三角的一行）。循环函数可以在一条语句中计算多个值，但必须容易写成表达式。如果需要几行代码才能实现计算，就必须使用循环语句：

|   | D |
|---|---|
| =1 |   |
| for A1 |   |
| >B1=B1*C1 |   |
| for A1-1 |   |
| =1 |   |
| for A2 |   |
| >B2=B2*C2 |   |
| =1 |   |
| for A1-A2 |   |
| >B3=B3*C3 |   |
| =@|(B1\B2\B3) |   |
| =1|B4|1 |   |

实际上，大多数编程语言，包括 SPL，都允许我们把要重复的代码写成自己的函数，然后反复调用。

|   | D |
|---|---|
| func |   |
| =1 |   |
| for A1 |   |
| >B1=B1*C1 |   |
| return B1 |   |
| =func(A1,10) |   |
| =func(A1,4) |   |
| =func(A1,6) |   |
| =A3\B3\C3 |   |

单元格 A1 的 func 语句定义了一个函数，由 A1 标识。它的代码是 A1 的代码块。当 SPL 遇到 func 单元格时，会跳过这个代码块，执行后续代码。

单元格 A3 中有 func() 函数。第一个参数是要调用的用户自定义函数的位置。这里是 A1，表示调用在 A1 定义的函数。下一个参数 10 是要传入用户自定义函数 A1 的参数。SPL 会把这个参数填入 A1，然后让程序跳转到 A1 的代码块执行，即开始执行 B1:D2。

我们可以理解 B1:D1 的代码，它可以计算 A1 的阶乘并填入 B1。当 A1 填入 10 时，这段代码计算 10!，并填入 B1。然后单元格 B2 的 return 语句返回 B1 的值。此时，程序会跳回调用函数的地方，即 A3，并且已经得到了 func() 的返回值 10!，A3 的单元格值就是 10!。

也就是说，自定义函数 A1 会计算其参数的阶乘值并返回。

类似地，B3 会计算 4!，C3 会计算 6!，最后在 D3 中计算出组合数（原文含示意图，图像资源未迁移）。

整个过程看起来有点复杂，但无论如何，三个阶乘值都是用同一段代码计算的，不需要把代码写三遍。

总结：func 语句用于定义函数，其中需要 return 语句来返回计算结果。然后使用 func() 函数传入参数来调用这个函数。

func() 是一个函数。它可以像其他函数一样使用。可以放在表达式中参与计算。

|   | D |
|---|---|
| func |   |
| =1 |   |
| for A1 |   |
| >B1=B1*C1 |   |
| return B1 |   |
| =func(A1,10)\func(A1,4)\func(A1,6) |   |

这样也可以正确计算出结果。

而且，定义了自定义函数后，可以在循环函数中使用。

|   | D |
|---|---|
| func |   |
| =1 |   |
| for A1 |   |
| >B1=B1*C1 |   |
| return B1 |   |
| =func(A1,A3) |   |
| =1|(A3-1).(B3\func(A1,~)\func(A1,A3-~))|1 |   |

二项式系数的计算看起来也更清晰了。

让我们再看一个实际的例子：在平面上的一批点中找出离群点。方法如下：计算每个点到其他点的距离之和，然后从大到小排序。前 10% 的点被认为是离群点，因为它们相对远离其他点。

|   | D |
|---|---|
| >X=A1.(rand()) |   |
| >Y=A1.(rand()) |   |
| =to(A1) |   |
| =A2.(A1.sum(func(A5,X(A2.~),X(~),Y(A2.~),Y(~)))) |   |
| =B2.psort@z().to(int(A1*0.1)) |   |
| func |   |
| return sqrt((A5-B5)*(A5-B5)+(C5-D5)*(C5-D5)) |   |

在 A5 中定义了一个函数来计算两点之间的距离。它有四个参数，分别是两个点的横坐标和纵坐标。使用勾股定理，可以计算两点之间的距离。当用户自定义函数有多个参数时，会从定义单元格向右填充。这个函数定义在 A5，它的四个参数会分别填入 A5、B5、C5 和 D5。因此，我们把函数体写在下一行，即单元格 B6。

函数定义可以在任何地方，在主程序前面或后面都不会影响代码执行。

在主程序中，随机生成了 100 个点的横坐标和纵坐标。然后在单元格 B2 中，可以调用用户自定义函数 A5 来计算距离之和。这是一个两层循环函数。内层计算 100 个距离并求和（一个点到自身的距离是 0，多加一个不会出错，我们不必排除点本身），外层循环 100 个点。注意内层循环中 A2.~ 和 ~ 的区别。

然后使用 psort 排序，得到前 10% 点的序号。
