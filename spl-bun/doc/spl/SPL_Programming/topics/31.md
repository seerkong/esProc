### 6.3 可重用脚本

到目前为止，我们一直在单元格中编写代码。这个单元格可以保存为扩展名为 .dfx 的文件，我们称之为**脚本**。

现在我们已经学会了编写可以反复调用的自定义函数，但这个函数只能在一个脚本中使用。创建新脚本后，我们必须再次复制它。不像库函数，可以在任何脚本中使用。

如何实现库函数的效果呢？

SPL 提供了一个函数，可以在一个脚本中调用另一个脚本。让我们以计算离群点的代码为例来说明如何做到这一点。

首先，创建一个新脚本，然后使用程序菜单下的参数功能弹出这样一个对话框：

（原文含示意图，图像资源未迁移）

首先在这里填写要调用的脚本的参数。假设这个脚本将接收一批点的坐标作为参数，计算离群点的序列并返回。我们设计三个参数：X 是一个序列，存储横坐标；Y 是一个与 X 长度相同的序列，存储纵坐标；ratio 是一个比例，表示取距离最大的多少比例的点（序号）作为离群点。

完成的对话框看起来像这样：

（原文含示意图，图像资源未迁移）

值列是指默认值。调用这个脚本时，如果没有输入参数，就会使用这个默认值。这里我们只写几个。

现在在单元格中写代码：

|   | D |
|---|---|
| =X.(Y.sum(func(A3,X(X.#),X(#),Y(X.#),Y(#)))) |   |
| return A1.psort@z().to(int(X.len()*ratio)) |   |
| func |   |
| return sqrt((A3-B3)*(A3-B3)+(C3-D3)*(C3-D3)) |   |

脚本也使用 return 语句返回结果。在脚本中，参数可以直接用作变量名。实际上，如果我们执行它，可以在右下角的变量表中看到参数。对于 SPL，脚本参数和命名变量是同一回事。

单元格 A1 使用参数的变量名来确定多层循环函数中 # 的层级。

保存脚本并给它一个名字，比如 outlier.dfx。现在，用一个新脚本，我们可以调用刚才写的脚本。

|   |   |
|---|---|
| >rand@s(0) |   |
| =call("outlier.dfx",A1.(rand()),A1.(rand()),0.1) |   |
| >rand@s(0) |   |
| =call("outlier.dfx",A1.(rand()),A1.(rand())) |   |

使用 call() 函数调用另一个脚本并获取返回值。

需要注意的是，这个新脚本需要保存并存储在与 outlier.dfx 相同的路径中。SPL 通常会在当前脚本的路径中查找被调用的脚本。如果脚本没有保存，就没有路径。如果路径错误，很可能找不到。

我们在写 outlier.dfx 时有一个默认值，所以 A5 可以省略一个参数，而且因为我们使用了 rand@s()，A3 和 A5 会返回相同的结果。

如果脚本仍然报错说找不到 outlier.dfx，可能是因为搜索路径或主路径写错了。使用工具菜单下的选项功能打开对话框，切换到环境页面。搜索路径可能填写了不合适的内容，被调用的脚本会首先在这个路径下搜索。

（原文含示意图，图像资源未迁移）

好处是我们可以写一些常用脚本放在这个路径中，这样存储在任何路径的脚本都可以调用这些常用脚本，不需要把被调用的脚本复制到调用脚本的路径。

如果搜索路径为空时仍然找不到被调用的脚本，可能是主路径有错误。对于使用相对路径的文件名（包括脚本名），esProc 首先搜索主路径。当主路径填写为空时，会搜索当前脚本的路径。这个规则有点复杂，是为开发有很多脚本的复杂应用程序而设置的。

SPL 还提供了 register() 函数，可以把脚本注册为普通函数。

|   |   |
|---|---|
| >register("outlier","outlier.dfx") |   |
| =outlier(A2.(rand()),A2.(rand()),0.1) |   |

把自己写的脚本注册为函数时，最好使用绝对路径或把脚本放入搜索路径，否则可能因为调用脚本的路径不同而找不到。注册的函数对所有脚本有效，不仅对当前脚本有效。重复注册会替换原来的。

我们可以用一个脚本来注册其他常用的脚本，作为我们自己的函数来调用。以后，每次启动 esProc 并执行这个脚本来注册其他脚本，就相当于添加了很多库函数。
