## 提取内容

### 7.1 字符串

到目前为止，我们在程序中处理的数据，除了 output() 中的少量文本外，都是数值或数值序列。实际上，计算机也可以很容易地处理文本。在编程语言中，我们把这些文本称为**字符串**。字符串是不同于整数和浮点数的另一种数据类型。

在 SPL 中，直接在单元格中写文本，如果不能被识别为其他有意义的数据类型或语句，默认会被当作字符串常量。在表达式中，我们也可以用双引号括起文本来表示字符串常量。

|   |   |
|---|---|
| 集算器 | SPL |
| ="集算器" | ="SPL" |
| 3+5 | ="3+5" |
| =3*4 | '=3*4 |
| 2020-1-1 | '2020-1-1 |
| for 10 | 'for 10 |

A1 是字符串常量"集算器"，A2 是普通计算单元格，其计算结果也是"集算器"，与 A1 相同；类似地，B1 和 B2 的单元格值都是"SPL"；A3 以数字开头，但不能解释为数值，所以也是字符串。像 B3 一样，它是"3+5"。

A4 是一个可以计算出数值的计算单元格，所以它不是字符串。如果我们想写一个以 = 开头的字符串常量，应该在单元格开头加一个单引号 '。这个额外的单引号不是字符串的一部分，A4 的单元格值是"=3*4"。注意只需要一个单引号，不要在右边再写一个。如果写了，右边的单引号也会被当作字符串的一个字符。

类似地，A5 是一个可以识别的日期常量，它不是字符串。如果我们想生成这样的字符串，也应该在单元格开头使用单引号 '；同样，A6 是一个合法的语句，不会被识别为字符串。要获得这样的字符串常量，也应该在单元格开头使用单引号 '。

字符串也是一种数据类型，可以进行操作。它最常见的操作是连接，即把两个字符串连接成一个更长的字符串。

|   |   |
|---|---|
| 集算器 |   |
| =A1+"2020" | 集算器2020 |
| =A1+2020 |   |
| =A1+string(2020) | 集算器2020 |
| =A1/2020 | 集算器2020 |
| =A1/"2020" | 集算器2020 |

用 + 号连接两个字符串（A2）；但是需要注意，当字符串和数值相加时，字符串部分会被忽略（A3）。这是 SPL 的特殊规定。大多数其他编程语言不这样规定。它们要么报错，要么把数值转换成字符串然后连接。通过用 string() 函数把数值转换成字符串，可以正常与其他字符串连接（A4）。如果用斜杠 / 连接字符串和数值，数值会自动转换成字符串（A5）。斜杠 / 也可以直接连接两个字符串（A6）。

现在，我们可以用字符串来改造质因数分解的代码，把结果显示为完整的表达式。

|   |   |
|---|---|
| =2 | =string(A1)+"=1" |
| for A1>1 |   |
| if A1%B1==0 |   |
| >C1=C1+"*"+string(B1) |   |
| >A1=A1\B1 |   |
| >B1+=1 |   |

执行这个程序后，会在单元格 C1 中得到一个字符串：7215=1*3*5*13*37，质因数分解的结果被写出来了。如果你仔细解读程序的执行过程，可以想象它是如何一步步连接起来的。

有连接就有拆分。SPL 还提供了以下函数：

|   |   |
|---|---|
| 集算器2020 |   |
| =len(A1) | '7 |
| =left(A1,2) | '集算 |
| =right(A1,3) | '020 |
| =mid(A1,3,2) | '器2 |
| =A2.(mid(A1,~,1)) | ["集","算","器","2","0","2","0"] |

len() 函数返回组成字符串的字符数，也称为字符串的**长度**。注意这个 len() 函数的名称与获取序列长度的函数相同，但写法不同。这里应该把字符串当作参数，而不是写成 A1.len()。还应该注意，SPL 采用 unicode，一个中文字符或一个数字（或英文字母）只是一个字符。在一些早期的编程语言中，一个中文字符会是两个字符。

A3、A4 和 A5 的 left()、right() 和 mid() 函数会从字符串中取出一部分形成新字符串并返回。函数名已经反映了要取的部分。然后观察运算结果。很容易理解其参数的含义，这里不再详述。几乎所有能处理字符串的编程语言都有这些函数，命名和参数规则都一样。

A6 用循环函数把字符串拆分成字符序列，你可以再次理解 mid() 函数。单个字符也是字符串，即长度为 1 的字符串。

质因数分解的结果总是会在前面写一个 1*，这是因为我们在循环中每次都把一个 * 和一个因子连接到结果字符串。如果不写第一个 1，就会得到 7215=*3*5*13*37 的结果，这是错误的。

但无论如何，这个 1* 有点多余。我们能怎么办呢？

可以通过拆分字符串来解决。

|   |   |
|---|---|
| =2 | =string(A1)+"=" |
| for A1>1 |   |
| if A1%B1==0 |   |
| >C1=C1+if(right(C1,1)=="=","","*")/B1 |   |
| >A1=A1\B1 |   |
| >B1+=1 |   |

连接因子时，判断当前字符串是否以 = 结尾。如果是，说明是第一个因子，不连接 * 号，否则就连接。现在我们可以得到想要的结果 7215=3*5*13*37。

我们也可以事后处理，去掉多余的 1* 部分：

|   |   |
|---|---|
| =2 | =string(A1)+"=1" |
| for A1>1 |   |
| if A1%B1==0 |   |
| >C1=C1+"*"+string(B1) |   |
| >A1=A1\B1 |   |
| >B1+=1 |   |
| =pos(C1,"=1*") |   |
| >C1=left(C1,A6+1)+mid(C1,A6+3) |   |

这里我们遇到了另一个函数 pos()，它会在一个字符串中查找另一个字符串。前者称为**子串**。找到子串后，会返回位置，即从这个位置开始，原字符串的字符就是这个子串。如果找不到，会返回 null。这与序列的 pos() 函数非常相似，但也需要把字符串写成参数而不是对象语法。

我们确定现在计算出的结果字符串中一定有子串 =1*（加上 = 后只会有一个，否则中间可能有以 1 结尾的质因子，但 pos 只找第一个也不会错，不过我们这里更严谨）。找到它的位置后，我们可以通过拆分和连接来去掉 1* 部分。

我们也可以用 replace() 函数直接替换：=replace(C1,"=1*","=")。同样，把 =1* 替换成 =，而不是把 1* 替换成空字符串。

SPL 提供了很多字符串处理函数，这里不一一列举。需要时可以查看帮助文档。

我们刚才用 == 来比较字符串。当然，我们也可以用 !=。那么，像 >、< 这样的符号对字符串有意义吗？

有的。

本质上，计算机只能处理数值。处理字符时，也应该用数值来表示，这就是编码方式。正如我们前面说的，SPL 采用的编码方式叫做 Unicode。

既然是数值，就可以用数值来比较。比较字符串时，是用字符编码来比较的。比较规则与序列非常相似，即先比较两者的第一个字符。如果不同，大的那个就大。如果相同，再比较第二个字符，...，直到不同或其中一个不够长。实际上，这就是字典序这个术语的真正来源。

那么，我们怎么知道两个字符哪个大哪个小呢？比如"1"和"2"，或者"1"和"A"？

简单地说，我们可以写代码来比较。但是，死记硬背所有的太累了。让我们看看这些编码有没有什么规律。SPL 提供了 asc() 函数来返回字符的编码。

|   |   |
|---|---|
| =asc("0") |   |
| =9.(asc(string(~))) |   |
| =asc("A") |   |
| =asc("C") |   |
| =asc("a") |   |
| =asc("z") |   |
| =asc("集") |   |
| =asc("算") |   |

我们不一一解释。请执行这些代码看看结果。这里直接写出编码规则：
1) "0"-"9"的编码是连续的，从 48 到 57
2) "A"-"Z"的编码是连续的，从 65 到 90
3) "a"-"z"的编码是连续的，从 97 到 112
4) 中文字符的编码很复杂，没有明确的规律。

这个编码标准最初叫做 ASCII，unicode 是在 ASCII 基础上扩展的，所以这个函数也叫 asc()。

与 asc() 函数相反，SPL 还有一个 char() 函数，可以把编码转换成字符。

我们可以用 char() 函数和刚才发现的规则来写一个函数：给定两个整数 r 和 c，计算 Excel 中第 r 行第 c 列的单元格名称。

|   | D |
|---|---|
| >r=2,c=123 |   |
| >rc="" |   |
| =1 | =26 |
| for c>C2 |   |
| >c-=C2 |   |
| >C2*=26 |   |
| >B2+=1 |   |
| >c-=1 |   |
| for B2 |   |
| >rc=char(65+c%26)+rc |   |
| >c\=26 |   |
| return rc/r |   |

计算单元格名称的主要难点是计算列名。先计算需要多少个字母（B1），然后计算列对应的字母字符串。

反过来，asc() 函数可以用来从单元格名称 rc 反算行号和列号：

|   | D |
|---|---|
| >rc="PG45" |   |
| =len(rc).(upper(mid(rc,~,1))) |   |
| >r=c=0 |   |
| =-1 | =1 |
| for A2 |   |
| if A4>="A" |   |
| >c=c*26+asc(A4)-65 |   |
| >B3+=C3 |   |
| >C3*=26 |   |
| else |   |
| >r=r*10+asc(A4)-48 |   |
| return [r,c+B3+1] |   |

upper() 函数用于把字母转换成大写。

Excel 单元格名称的规则看起来简单，但想出正确的计算逻辑并不容易。正如我们前面说的，程序代码不会帮我们解决问题，只会帮我们实现解决方案。
