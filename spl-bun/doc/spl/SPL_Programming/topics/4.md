1.2 变量和语句

圆的面积是 πr²。现在我们编写一段代码来计算指定半径的圆的面积。这里我们取 3.14 作为 π 的值。

|
=3.14*A1*A1

执行代码并查看 A2 的值，这就是半径为 5 的圆的面积。

要计算另一个半径为 7.8 的圆的面积，我们只需要将 A1 改为特定的值，然后执行代码。现在 A2 的值就是当前圆的面积。

看起来 Excel 更方便。电子表格工具可以在您输入新值后自动计算。但这不是重点。我们暂且不管它。

让我们检查 A2 中的表达式。它包含一个单元格名称。它在计算时引用 A1 的值，并在 A1 发生变化时使用新值。也就是说，这个表达式通过包含它的单元格名称来引用一个值。

对于熟悉 Excel 的人来说，这很容易理解。

编程语言将命名的数据称为变量，如 A1 和 A2（我们可以在 A3 中写 =A2*4 来计算以 A1 为半径的球的面积）。A3 也是一个变量。单元格集中的所有单元格都是变量。

然后我们可以在计算表达式中引用变量。用新的变量值重新计算表达式将得到新的结果。因此只需编码一次就可以计算多个相同模式的表达式。这既方便又不容易出错。计算机确实擅长做重复性工作。

Excel 也有这个优点。

变量之所以这样命名，是因为它是可变的吗？

正是如此。变量可以在程序中获得新值，如下面这段代码所示：

|
=3.14*A1*A1
|
>A1=7.8
|
=3.14*A1*A1

A2 和 A4 有相同的表达式，但执行后得到不同的结果。A3 在执行时将 A1 的值修改为 7.8。然后 A4 使用 A1 的新值进行计算。

这与 Excel 不同。电子表格工具无法通过在另一个单元格中编写公式来修改单元格值。

A3 的代码不是以等号 = 开头，而是以大于号 > 开头。在 SPL 中，内容以 = 开头的单元格称为计算单元格，内容以 > 开头的单元格称为可执行单元格。计算单元格计算等号后面的表达式并将结果放入当前单元格。可执行单元格执行大于号后面的操作，但不会将任何值放入当前单元格。在上面的代码中，A3 执行后其值仍然为空。

上面这段代码中的单元格 A1，既没有等号也没有大于号，在 SPL 中称为常量单元格。它用于定义常量。

许多编程语言都有常量变量的概念，可以理解为命名的常量。常量变量的值一旦设置，在程序运行时就不能更改。常量变量也可以被视为只能赋值一次的变量。引入常量变量的目的是为了避免在代码编写错误时更改应该保持不变的变量值。

SPL 没有严格的常量变量概念。上面代码中常量单元格 A1 的值可以通过执行可执行单元格来修改。

通常，用编程语言编写的程序是文本格式的，一句一句的。在早期编程语言编写的程序中，这种逐句格式更加明显。每个句子描述一个要执行的操作。这样的句子称为程序语句。一段程序由一组程序语句组成。

SPL 没有这种逐句编码格式的特点。在 SPL 程序中，单元格中的代码可以被视为一条语句。计算单元格和可执行单元格都是语句。

在大多数编程语言中，程序员需要为变量命名。SPL 也支持用户自定义名称，如下面的程序所示：

|
>r=5
|
=3.14*r*r
|
>r=7.8
|
=3.14*r*r

这里使用字母 r 而不是 A1 来命名变量。结果是一样的。

有意义的用户自定义变量名的优点是令人难忘且不容易混淆，比如上面程序中使用的 r。它与圆面积公式中的 r 是一样的。

有时当变量用于存储中间结果时，您可以给它一个不那么有意义的名称。但有可能会重名。在 SPL 中，您可以用单元格名称来命名变量。这是网格式编码格式具有而文本编码格式不具有的小便利之一。

例如，有两个变量 a 和 b，我们需要交换它们的值。一般程序如下：

|
>a=5
|
>b=3
|
>c=a
|
>a=b
|
>b=c

新定义的变量 c 可以用单元格名称重命名：

|
>a=5
|
>b=3
|
=a
|
>a=b
|
>b=A3

像在 Excel 中一样，当在 SPL 中使用单元格名称作为变量名时，当插入或删除行或列时，表达式中引用的单元格名称将自动调整以获得正确的结果。SPL 的另一个类似 Excel 的特性是使用美元符号 $ 在插入或删除行或列时将单元格固定到特定的行和列。

esProc 还在编辑菜单上提供了一些命令及其快捷键。当您熟悉 SPL 的特性后，您会发现它的网格式编码格式比文本编码格式方便得多。

顺便说一下，SPL 是一种区分大小写的编程语言。小写的 r 和大写的 R 产生不同的效果。用作变量名的单元格名称应该是大写的。A1 代表一个单元格变量，而 a1 只是一个普通变量。有些编程语言不区分大小写，其中小写的 r 和大写的 R 产生相同的效果。

可以用作变量名的符号通常由字母和数字组成，且不能以数字开头。它可以包含下划线（符号 _ 通常被视为字母，可以放在开头）。SPL 还允许在变量名中使用中文字符。标识符是可以包含在变量名中的符号的术语。

另一个问题：变量有数据类型吗？

有两种类型的编程语言。一种是强类型语言，如 Java 和 C/C++。它们要求在使用变量之前声明变量的数据类型。如果变量 x 被声明为整数类型，它就不能用来存储浮点数。如果给它赋一个浮点数，它将自动转换为整数（并在此过程中丢失信息）。另一种是弱类型语言，如 SPL。在 SPL 中，用户不需要为变量声明数据类型；在计算过程中会自然生成适当的类型。

这是否说明弱类型语言使用起来更方便？

从使用便利性来说确实如此。但由于强类型语言提前声明了变量的数据类型，计算机在执行前就知道如何存储变量，因此性能更好。弱类型语言在获得结果后才决定存储方法，这使得计算性能较差。此外，如果数据类型被错误地更改，它无法检测到错误。

没有完美的东西。

以圆面积公式为例。S=πr² 本质上是一个方程。它表明圆的面积 S 等于 πr²。事实上，如果它们交换位置，方程仍然成立。

现在我们用 SPL 语句编写公式来计算圆的面积：

>S=3.14*r*r

这也是一个方程吗？

不是！

在编程语言中，设置变量值的语句称为赋值语句。它代表一个操作，而不是一个数学方程。它不应该写成如下形式：

>3.14*r*r=S

这没有意义。计算机会为此报错。

赋值语句计算等号 = 右边的表达式，并将结果赋给等号 = 左边的变量。表达式的计算与变量无关。赋值只有在计算完成后才开始。

这样，一个在数学上不可能的方程将成为一个常见的赋值语句，如下所示：

>X=X+1

它表示当前 X 值加 1，结果将赋给 X。假设 X 的值是 3，那么执行后它的值将变成 4。

如果您能弄清楚 X=X+1 的含义，您基本上就理解了变量的概念。这可以算是学习程序设计过程中的第一个小障碍，也是 Excel 没有的概念。

看看这段代码：

|
>a=5
|
>b=3
|
>a=a+b
|
>b=a-b
|
>a=a-b

尝试多次更改 a 和 b 的初始值并执行程序，看看两个变量的最终值。您可以先猜测，然后尝试用变量赋值原理来证明您的结论。

早期计算机内存很小。少一个变量意味着更少的内存使用，程序员发明了这种疯狂的代码来实现这个目标。
