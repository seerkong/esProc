## 提取内容

### 8.4 循环函数

既然记录序列（序表也是记录序列）可以看作序列，我们也应该能对这些对象使用循环函数。我们已经用过 new() 和 derive()。让我们试试之前学过的循环函数，继续使用用 new() 创建的 100 条记录的序表。

计算这些人的平均身高、最大体重和最小 BMI。

|   |   |
|---|---|
| =100.new(string(~):name, if(rand()<0.5,"Male","Female"):sex,50+rand(50):weight,1.5+rand(40)/100:height) |   |
| =A1.(height).avg() |   |
| =A1.avg(height) |   |
| =A1.(weight).max() |   |
| =A1.max(weight) |   |
| =A1.min(weight/height/height) |   |

把记录序列当作序列，A.(x) 操作可以正常执行。它经常用于获取由某个字段的值组成的序列。结构化数据有多个字段，所以很容易形成一些有业务意义的表达式。因此，基于记录序列的聚合函数往往会直接用表达式计算（这里的 B2、B3 和 A4）。

结构化数据的选择函数也会比常规数据更有业务意义。

找出体重最大的人和 BMI 最小的人：

|   |   |
|---|---|
| ... |   |
| =A1.maxp(weight) |   |
| =A1.maxp@a(weight) |   |
| =A1.minp(weight/height/height) |   |

A2 只找第一个并返回，B2 用 @a 找出所有使体重最大的记录。

这往往是我们更关心的，即对应最大值和最小值的记录，而不是最大值和最小值本身。

按条件选择的记录也可以进行各种集合操作，以及进一步的聚合和选择操作：

|   |   |
|---|---|
| ... |   |
| =A1.select(height>=1.7) | =A1.select(sex=="Female") |
| =A2^B2 |   |
| =A1.select(height>=1.7 && sex=="Female") |   |
| =A2\B2 |   |
| =A1.select(height>=1.7 && sex!="Female") |   |
| =A2.maxp@a(weight) | =B2.minp(weight/height/height) |
| =A3.avg(height) | =A4.max(weight) |

A2 选择身高不低于 1.7 的人，B2 选择女性。A3 计算两者的交集，B3 用逻辑运算表达与 A3 相同的计算结果。A4 和 B4 的情况类似。A5 和 B5 对选择的记录序列做进一步选择，A6 和 B6 继续对选择的记录序列做聚合。

排序也是常见操作：

|   |   |
|---|---|
| ... |   |
| =A1.sort(height) |   |
| =A1.select(sex=="Female") |   |
| =A3.sort(-weight) |   |
| =A1.sort(height,-weight) |   |
| =A1.top(-3,weight) |   |
| =A1.top(-3;weight) |   |
| =A1.ranks(height) |   |
| =A1.derive(A6(#):hrank) |   |

我们知道 sort() 函数的默认排序方向是从小到大，可以用 @z 来反转顺序。然而，涉及结构化数据时，往往有多个字段要排序，这些参数的排序方向不同。这种情况下，没办法只用一个 @z 来控制。SPL 给出的方法是把参数写成相反数（加负号），这样如果我们继续从小到大排序，就会实现原值的逆序。写负号变成相反数的方法也适用于字符串和日期时间数据。

这样，A2 按身高从低到高排序，B3 按体重从大到小对女性排序。A4 会先按身高从小到大排序，身高相同的按体重从大到小排序。

在 top() 函数中使用负数是表示逆序的另一种方式，相当于排序后取最后几个（如果是正数，取前几个）。A5 和 B5 分别计算三个最大的体重和三个体重最大的人。A5 的计算结果是由三个数字组成的序列，而 B5 返回由三条记录组成的记录序列。

SPL 还支持排名函数。A6 的 ranks 函数可以计算每个人按身高的排名。

我们觉得用 Male 和 Female 表示性别太长了。只用一个字母 M 和 F。以后写比较表达式时会更短。可以用 run() 函数来做。

|   |   |
|---|---|
| ... |   |
| >A1.run(sex=left(sex,1)) |   |

用循环函数给字段赋值时，我们也可以直接用字段名表示当前记录的字段，不用写成 ~.sex。

derive() 可以用来追加字段生成新序表。有时我们需要追加多个字段，后面要追加的字段需要从前面要追加的字段计算。例如，我们需要添加一个 BMI 字段，然后根据 BMI 的值添加一个肥胖标志字段。用 derive()，会写成这样：

|   |   |
|---|---|
| ... |   |
| =A1.derive(weight/height/height:bmi) |   |
| =A2.derive(if(bmi>25,"FAT","OK"):flag) |   |

然而，derive() 的计算非常复杂。它需要创建新记录和序表并复制原数据。性能较差。原则上应该尽量少用。更好的方法是用 derive() 和 run() 来完成任务：

|   |   |
|---|---|
| ... |   |
| =A1.derive(weight/height/height:bmi,:flag) |   |
| =A2.run(flag=if(bmi>25,"FAT","OK")) |   |

在 A2 中一次追加两个字段，然后在 A3 中用 run() 计算 flag 字段的值。derive() 函数只执行一次，减少了创建和复制序表的动作，可以大大提高运算性能。

从这些例子中，我们可以再次认识到，结构化数据的多个字段很容易形成很多有业务意义的计算表达式。循环函数中有很多对字段表达式的操作，但在单值序列计算中相对不常见。

结合读写 Excel 文件的函数，我们现在可以用程序代码对一批 Excel 文件进行合并、过滤、添加计算结果、排序和其他操作。

类似于序列的循环函数，记录序列也会有多层嵌套。

例如，我们想计算这群人中男女之间的最小身高差：

|   |   |
|---|---|
| ... |   |
| =A1.select(sex=="Male") |   |
| =A1.select(sex=="Female") |   |
| =A2.min(B2.min(abs(height-A2.height))) |   |

当内层需要引用外层循环的记录字段时，也应该写外层循环函数对应的变量名来表示当前记录，仍然不需要写 ~。

要找出哪些男女配对使最小身高差成立，就更麻烦了。

|   |   |
|---|---|
| ... |   |
| =A1.select(sex=="Male") |   |
| =A1.select(sex=="Female") |   |
| =A2.conj(B2.([A2.~,~])) |   |
| =A3.minp@a(abs(~(1).height-~(2).height)) |   |

这里，我们需要用 ~ 来保留记录，形成男女配对，然后用选择函数找出。B3 中的 A3 不再是记录序列，如果省略 ~ 来引用字段名是没有意义的。

记录序列的成员是有多个字段的记录，信息内容相对丰富。选择函数得到的结果也是由这些记录组成的记录序列。因此，pselect、pmax 和 pmin 等定位函数返回的位置所包含的信息很少需要，但涉及与顺序相关的计算时仍然需要获取位置。

现在让我们讨论与顺序相关的循环函数，并重新生成一个与日期相关的序表。

|   |   |
|---|---|
| =100.new(date(now())-100+~:dt,rand()*100:price) |   |
| =A1.select(day@w(dt)>1 && day@w(dt)<7) |   |

随机生成从 100 天前到今天的股票价格表。dt 字段是日期，price 字段是价格。因为周末没有交易，生成数据后过滤掉周末日期，以后使用这个 A2。day@w() 函数返回日期是星期几，但注意它的返回值周日是 1，周六是 7。由于历史原因，计算机系统使用西方人的习惯。周日是一周的第一天。

首先，我们想计算每日涨幅和移动平均价格：

|   |   |
|---|---|
| ... |   |
| ... |   |
| =A2.derive(price-price[-1]:gain) |   |
| =A2.derive(price[-1:1].avg():mavg) |   |

在记录序列的循环函数中，我们可以在字段后面加 [±i] 来引用相邻记录的字段，加 [a:b] 来引用由相邻记录的字段值组成的序列。这些与序列的循环函数相同。

计算这只股票的最大连续上涨天数：

|   |   |
|---|---|
| ... |   |
| ... |   |
| =0 |   |
| =A2.(if(price>price[-1],A3+=1,A3=0)).max() |   |

按自然思维，先填 0，涨一天加 1，不涨就清零。我们可以计算到某一天的连续上涨天数，然后取最大值。

计算股价最高那天的涨幅：

|   |   |
|---|---|
| ... |   |
| ... |   |
| =A2.pmax(price) |   |
| =A2(A3).price-A2.m(A3-1).price |   |

这里，用定位函数 pmax() 计算最大值所在的序号，然后用这个序号计算涨幅。如果需要考虑最高价可能出现在多个日期，使用 @a 选项。

|   |   |
|---|---|
| ... |   |
| ... |   |
| =A2.pmax@a(price) |   |
| =A3.new(A2(~).dt,A2(~).price-A2.m(~-1).price:gain) |   |

先计算由最大值所在的记录序号组成的序列，然后基于这个序列用 new() 生成一个两字段序列，以日期和涨幅为字段。这种情况下，new() 也可以省略字段名。你可以看看生成的序表的字段名会是什么。

类似地，计算股价超过 90 元那些天的平均涨幅：

|   |   |
|---|---|
| ... |   |
| ... |   |
| =A2.pselect@a(price>90) |   |
| =A3.new(A2(~).dt,A2(~).price-A2.m(~-1).price:gain) |   |

对于这种针对某个位置的跨行计算，SPL 提供了定位计算函数。前面的代码也可以写成这样：

|   |   |
|---|---|
| ... |   |
| ... |   |
| =A2.pmax(price) |   |
| =A2.calc(A3,price-price[-1]) |   |

定位计算函数 calc() 允许循环函数中的 ~、#、[] 等语法在非循环函数中使用。

|   |   |
|---|---|
| ... |   |
| ... |   |
| =A2.pmax@a(price) |   |
| =A2.calc(A3,price-price[-1]) |   |
| =A3.new(A2(~).dt,A4(#):gain) |   |

calc() 函数也可以用于序列，但不涉及结构化数据时，有业务意义的场景很少，所以我们在这里举一些例子。
