## 提取内容

### 8.5 字段上的计算

正如我们前面说的，结构化数据在行和列方向的能力是不对称的。方便的批量操作通常只为行方向提供，列总是作为独立的个体出现。然而，我们有时也需要在列方向上执行一些整体操作，即把一批字段作为集合一起处理。

让我们再做一次合并 Excel 的问题。把要求改为：把文件名拼在所有列的前面。

derive() 函数只能在末尾追加字段。要改变字段的顺序，目前只能用 new() 函数重新创建，我们需要知道序表中已经有哪些字段并再次复制它们。

fname() 函数可以返回序表中字段名的序列，即字符串序列。但这还不够。即使我们把新字段连接到前面，我们仍然不知道如何写这个 new() 函数，比如下面的代码：

|   |   |
|---|---|
| =10.new(rand(10):a,rand(20):b,rand(30):c) |   |
| =A1.fname() |   |
| =A1.new(0:NewField,A2) |   |

A1 是一个序表，A2 获取它的字段名序列，但 A3 是没有意义的。SPL 会生成一个名为 A2 的字段，它的值是 A2 的当前单元格值，即 A1 的字段名序列。当 SPL 执行到这里时，它不知道要把 A2 的值连接到这段代码中，而是会把 A 和 2 这两个字符作为代码的一部分执行。

我们该怎么办？

SPL 提供了动态程序的语法。上面的代码写成这样，就可以正确执行：

|   |   |
|---|---|
| =10.new(rand(10):a,rand(20):b,rand(30):c) |   |
| =A1.fname().concat(",") |   |
| =A1.new(0:NewField,${A2}) |   |

我们用过 concat() 函数。它会用指定的分隔符连接字符串序列，这里我们用逗号。这里 A1 有三个字段 a、b、c，A2 的计算结果是字符串 "a,b,c"。

A3 中 ${} 的含义是告诉 SPL 计算大括号中的表达式（它会是一个字符串），然后把字符串作为语句的一部分拼接，然后执行。A2 现在是 "a,b,c"，${A2} 会把这个字符串拼接到 A3 的语句中。结果，A3 要执行的实际语句是
=A1.new(0:NewField,a,b,c)

这就是我们想要的。

${} 的语法叫做**宏**。使用宏，我们可以动态拼接一些代码来执行，实现非常灵活的操作效果。与不确定数量字段相关的计算经常使用宏。

使用宏，我们可以解决合并 Excel 时把文件名拼到前面的问题：

|   |   |
|---|---|
| =directory@p("data/*.xlsx") |   |
| for A1 |   |
| =file(A2).xlsimport@t() |   |
| =B2.new(filename@n(A2):File,${B2.fname().concat@c()}) |   |
| =@|B3 |   |
| =file("all.xlsx").xlsexport@t(B4) |   |

concat@c() 表示用逗号分隔。只要计算结果是字符串，就可以在 ${} 中写计算表达式。

使用宏，我们可以轻松生成学生成绩表：

|   |   |
|---|---|
| [English,Maths,Science,Arts,PE] |   |
| =A1.("rand(100):"+~).concat@c() |   |
| =100.new(string(~,"0000"):id,${A2}) |   |

A2 的计算结果会是一个字符串：
"rand(100):English,rand(100):Maths,rand(100):Science,rand(100):Arts,rand(100):PE"

拼接到 A3 后，我们会得到一个 100 个学生的成绩表，id 字段是学生的学号。

现在我们想为每个学生计算一个总分字段 Total 并追加到末尾。

|   |   |
|---|---|
| ... |   |
| ... |   |
| =A3.derive(English+Maths+Science+Arts+PE:Total) |   |

当然可以，但如果科目很多，就很难写。

SPL 提供了一种把记录字段转换成序列的方法，当字段值需要批量处理时会方便得多：

|   |   |
|---|---|
| ... |   |
| ... |   |
| =A3.derive(~.array().to(2,).sum():Total) |   |

r.array() 获取记录 r 的字段值形成序列并返回。这样，不管有多少科目，代码都是这样。需要注意的是，由于每个字段值的数据类型可能不同，array() 的返回值可能不是由相同数据类型的成员组成的序列。

假设有一批这样的文件，每个文件存储一个人的信息。现在我们希望提取这些数据并做成行表格，使用这个表中的字段名：ID、name、sex、position、birthday、phone、address、postcode。

如果有几百个这样的文件，手动做显然太累了。我们用程序来做。

要做到这一点，我们还需要使用两个 Excel 相关函数 xlsopen() 和 xlscell()。

xlsopen() 可以打开一个 Excel 文件形成 Excel 对象，xlscell() 可以从 Excel 对象中读取单元格的内容。有了它们，我们可以完成工作。

|   |   |
|---|---|
| =create(ID,Name,Sex,Position,Birthday,Phone,Address,PostCode) |   |
| =directory@p("data/*.xlsx") |   |
| for A2 |   |
| =file(A3).xlsopen() |   |
| =B3.xlscell("C1") | =B3.xlscell("C2") |
| =B3.xlscell("F2") | =B3.xlscell("C3") |
| =B3.xlscell("C4") | =B3.xlscell("D5") |
| =B3.xlscell("C7") | =B3.xlscell("C8") |
| =A1.insert(0,B4,C4,B5,C5,B6,C6,B7,C7) |   |
| >file("all.xlsx").xlsexport@t(A1) |   |

代码逻辑不复杂，我们不详细解释。

然而，写起来还是有点麻烦，如果表格样式和数据结构改变，需要改很多。

我们用宏和循环函数来简化它。

|   |   |
|---|---|
| [ID,Name,Sex,Position,Birthday,Phone,Address,PostCode] |   |
| [C1,C2,F2,C3,C4,D5,C7,C8] |   |
| =directory@p("data/*.xlsx") |   |
| for A3 |   |
| =file(A4).xlsopen() |   |
| =B2.(B4.xlscell(~)) |   |
| =@|C4 |   |
| =create(${A1.concat@c()}).record(B5) |   |
| >file("all.xlsx").xlsexport@t(A6) |   |

把字段和对应的单元格做成两个序列，从每个 Excel 文件获取数据并做连接就容易多了。代码不仅更短，而且更通用。如果遇到新格式，只需修改前两行。

反过来，我们可能用行表格的数据生成多个这样的自由样式 Excel。显然，手动做会非常累。

我们仍然用程序来完成这个任务。我们需要再学一点知识：xlscell() 函数也可以把数据填入 Excel 对象的单元格；然后学一个 xlswrite() 函数，它可以把处理过的 Excel 对象写入文件。

|   |   |
|---|---|
| [ID,Name,Sex,Position,Birthday,Phone,Address,PostCode] |   |
| [C1,C2,F2,C3,C4,D5,C7,C8] |   |
| =file("temp.xlsx").xlsopen() |   |
| =file("all.xlsx").xlsimport@t() |   |
| for A4 |   |
| =A1.(A5.field(~)) |   |
| >A2.(A3.xlscell(~;B5(#))) |   |
| =file(A5.ID/".xlsx").xlswrite(A3) |   |

首先做一个这种格式的模板 Excel 文件，读入 Excel 对象，然后对每条记录把相关值填入 Excel 对象，然后写入文件。反复填入并写出，就完成了。

做人工智能任务时，我们经常遇到填充缺失值的问题，即按一定规则填入缺失的数据，比如众数（其他非缺失值中出现最多的）或平均值（从其他非缺失值计算）。

让我们试试这个任务。假设 data.xlsx 存储原始数据：

（原文含示意图，图像资源未迁移）

空白部分表示缺失。我们的规则是：如果这列是整数，用众数方案填充；如果是浮点数，用平均值方案填充。

|   |   |
|---|---|
| =file("data.xlsx").xlsimport@t() |   |
| for A1.fname() |   |
| =A1.field(A2) |   |
| =B2.sum() |   |
| =B2.sum(int(~)) |   |
| =if(B3==C3,B2.mode(),B2.avg()) |   |
| =B2.(if(~,~,B4)) |   |
| >A1.field(A2,B5) |   |
| >file("dataNew.xlsx").xlsexport@t(A1) |   |

把数据读入序表 A1，A2 循环每个字段。B2 中的 field() 函数会获取所有记录的某个字段的所有值形成序列。它有点像 A1.(x)，但区别是这里 field() 函数的参数是字符串，而 A1.(x) 中的 x 是字段名。如果写成 A1.(x)，需要使用宏，应该写成 A1.(${A2})。

计算整列的和，与整数化后成员的和比较，如果相等，可以认为都是整数，则执行众数方案，否则执行平均值方案。mode() 函数可以返回序列的众数。

然后在 B5 中计算填充缺失值后的字段值序列。field() 函数也可以把序列填入字段。这里，也可以用宏写成 A1.run(${A2}=B5(#))，但用 field() 函数显然更清晰简单。
