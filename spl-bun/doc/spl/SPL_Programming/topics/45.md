## 提取内容

如前所述，记录序列和序列是有序的，成员的位置信息经常参与计算。分组也不例外，分组键也可能与成员的序号相关。

例如，我们想把人员表按每三条记录分成一组：

| =100.new(string(~):name, if(rand()<0.5,"Male","Female"):sex,50+rand(50):weight,1.5+rand(40)/100:height) |
| =A1.group((#-1)\3) |

A2 中的分组没有使用 A1 中记录的任何信息，只使用了序号，这也是一种合理甚至常见的分组方式。毕竟，分组的本质是将一个大集合拆分成小集合。只要有明确的拆分方法，就是合理的。

要将人员表分成三组，可以使用前面提到的 step() 函数，或者直接使用 group：

| … |
| =A1.group(#%3) |

顺便说一下，这两个例子的分组键值都是整数。我们也可以修改前面提到的序号分组（需要确保分组键值是从 1 开始的自然数）：

| … |
| =A1.group@n((#+2)\3) |
| =A1.group@n(#%3+1) |

除了直接使用序号作为分组键值外，分组还可能与相邻成员相关。

例如，给定一个由字母和数字组成的字符串，需要将其拆分成连续的字母和数字，如 abc1234wxyz56mn098pqrst，拆分成小字符串 abc、1234、wxyz、56、mn、098、pqrst。

| abc1234wxyz56mn098pqrst |
| =A1.split().group@o(isdigit(~)).(~.concat()) |

group@o() 函数会依次扫描整个序列。当分组键值与前一个成员相同时，该成员会被添加到当前分组子集中。如果分组键值发生变化，则会生成一个新的分组子集，并将当前成员添加到其中。扫描完成后，会得到一批分组子集，完成分组操作。

isdigit(x) 在 x 是数字字符时返回 true，否则返回 false。我们已经学过 A1.split()，它会将字符串拆分成单字符序列。因此，分组键值表达式 isdigit(~) 会对这个单字符序列依次计算为：

false false false true true true true false …

即遇到字母时为 false，遇到数字时为 true。从数字变为字母或从字母变为数字会导致 isdigit(~) 发生变化，从而产生新的分组子集，所以 group@o() 的返回值将是：

[[a,b,c],[1,2,3,4],[w,x,y,z],[5,6],....]

即将相邻的字母或数字分为一组，然后用 concat() 将每组连接成字符串。

这种分组很难用我们之前学过的分组操作来描述。

这是另一个直接对序列进行分组的例子。

如果我们知道分组键值本身是有序的，普通的等值分组也可以用 @o 来完成。例如，如果订单数据按日期有序，我们想按月分组汇总，可以这样写：

| =T("data.xlsx") |
| =A2.groups@o(month@y(OrderDate);sum(Amount),count(Amount)) |

@o 对 groups() 也有效。这里使用或不使用 @o 结果没有区别，但如果数据有序时使用 @o，groups() 只需要比较分组键值与相邻成员，计算速度会快很多。

@o 还有一个变体 @i，使用它时分组键是一个逻辑表达式，每当计算出 true 时就会生成一个新的分组子集。

让我们回顾一下之前计算股票最大连续上涨天数的问题。另一种思路是按日期对交易数据排序（通常已经有序），然后依次扫描这些数据进行分组。如果某一天的价格高于前一天，就继续与前一天分在同一组；如果没有上涨，就生成一个新组。扫描完成后，我们会得到一些子集。在每个子集中，股价连续上涨。然后我们只需要看哪个子集的成员最多。

| =100.new(date(now())-100+~:dt,rand()*100:price) |
| =A1.select(day@w(dt)>1 && day@w(dt)<7) |
| =A2.group@i(price<=price[-1]).max(~.len()) |

顺便说一下，SQL 完成这个任务最简单的方法也是使用这个思路，但代码是这样的（仅对应 A3 中的代码）：

```sql
SELECT max(consecutive_day)
FROM (SELECT count(*) consecutive_day FROM
      (SELECT sum(rise_or_fall) OVER(ORDER BY dt) day_no_gain FROM
        (SELECT dt, CASE when price>lag(price) OVER(ORDER BY dt)
                    then 0 else 1 end rise_or_fall
         FROM T ) )
      GROUP BY day_no_gain)
```

你可以感受一下差异。

需要使用顺序和位置信息的分组操作称为**有序分组**。

有序分组在解析文本时非常有用。

有些文本文件不是非常整齐的 TXT 或 CSV 格式，而是有规律的文本字符串，其中会有结构化数据，如果需要重用就需要通过编程来解析，例如：

一般来说，日志中会描述一批事件，每个事件会占用几行文本。结构分析就是提取每个事件的字段值。

使用有序分组，可以很容易地将这些日志文本以事件为单位分成小段。日志通常按以下方式划分事件：

1) 每 N 行对应一个事件，可以用 group((#-1)\N) 拆分：

| =file("S.log").read@n() |
| =create(…) |
| for A1.group((#-1)\3) |
| … |
| >A2.insert(…) |

2) 行数不固定。每个事件前会有一个固定的起始字符串，可以用 group@i 拆分：

| for A1.group@i(~=="---start---") |
| … |

3) 行数不固定。同一事件的每一行都有相同的前缀（如日志的用户 ID），可以用 group@o 拆分：

| for A1.group@o(left(~,6)) |
| … |

拆分后，代码可以专注于从每个段的字符串中解析字段值。当然，这通常不是一个简单的任务。
