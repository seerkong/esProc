## 提取内容

分组后再汇总，我们通常会得到一个比原集合更小的集合，这相当于聚合。那么，有没有分组的逆运算，通过某些规则用较小的数据表计算出较大的数据表呢？

我们把这种操作称为**展开**或**逆分组**。

然而，汇总后的数据通常已经丢失了详细信息，无法实现逆向计算。展开操作需要明确的展开规则。

表序列包含一些客户的贷款信息，包括贷款期数和金额。现在我们需要按等额本息法计算这些人的月还款额，利率是一个常数。

| =10.new(string(~):id,rand(20):number,rand(100):amount) |
| >rate=0.05/12 |
| =A1.news(number;id,month@y(elapse@m(now(),#)):ym,amount*(1-rate*power(1+rate,number)/power(1+rate,number)):payment) |

A2 中的 news() 函数会为 A1 的每个成员生成 number 条记录。字段名和计算公式由后面的参数描述。这个分期贷款的计算公式是从网上复制的，不是重点。

想想参数中的 #。news() 函数本质上是一个两层循环函数。首先，它遍历 A1 的成员，然后遍历第一个参数 number。分号后面的参数实际上是针对内层循环函数的，即 # 是针对 number 层的，即贷款期数，而不是 A1 的成员。

这段代码的计算量有点大。因为在等额本息法中，月还款额实际上是相同的，没有必要计算这么多次。只需为每个 A1 成员计算一次即可。

| … |
| =A1.(amount*(1-rate*power(1+rate,number)/power(1+rate,number))) |
| =A1.news(number;id,month@y(elapse@m(now(),#)):ym,A2(A1.#):payment) |

注意这里使用 A1.# 来引用外层循环函数的序号。

让我们实现上一节字符串合并的逆操作。

| =100.new(string(~):name, if(rand()<0.5,"Male","Female"):sex) |
| =A1.group(sex;~.(name).concat@c():Names) |
| =A2.news(Names.split@c();~:name,sex) |

A3 会将 A2 中连接的字符串拆分，并展开成与 A1 行数相同的记录。

同样，news() 本质上是一个两层循环函数。参数中的 sex 是外层循环函数的字段。因为在内层找不到这个字段，SPL 会自动在外层查找，所以我们不必写 A2.sex。而 ~ 是内层循环函数的当前成员，即拆分后的 name。

还有一种更常见的展开操作：将数据表的列（字段）展开成行（记录）。

我们需要使用之前用过的学生成绩表：

| [English,Maths,Science,Arts,PE] |
| =A1.("rand(100):"+~).concat@c() |
| =100.new(string(~,"0000"):id, ${A2}) |

A3 会生成一个有 6 个字段的数据表。除了 id 字段外，其他都是一个科目（一个科目的分数）。

当我们讨论结构化数据的概念时，我们提到由于这些科目地位相等，可能会对这些科目（分数）进行统计。因此，更常见的数据结构将是三个字段：id、subject、score。现在数据表的字段名将成为新数据表 subject 字段的字段值，原表的每条记录将变成新表的 5 条记录（有 5 个科目），这就导致了展开操作。

我们可以用 news() 来写：

| … |
| =A3.fname().to(2,) |
| =A3.news(A4;id,~:subject,A3.~.field(~):score) |

A4 列出所有科目字段，A5 执行展开操作。注意 A3.~.field(~) 中的两个 ~，前者是 A3.~，即 A3 的当前记录，也就是正在展开的记录，后者 ~ 是 A4，即一个科目字段。

这种操作非常常见，SPL 提供了一个专门的函数来处理它：

| … |
| =A3.fname().to(2,) |
| =A3.pivot@r(id;subject,score;${A4.concat@c()}) |

对于除 id 外所有字段都需要展开的情况，可以进一步简化为：

| … |
| =A3.pivot@r(id;subject,score) |

细心的读者可能会发现 pivot() 函数使用了 @r 选项，那么不使用 @r 选项会计算什么呢？

没有 @r 时，它是其逆运算，相当于分组。

| … |
| =A3.pivot@r(id;subject,score) |
| =A4.pivot(id;subject,score) |

我们会发现 A5 又变回了 A3，但字段顺序变了，科目字段按字母顺序排列，不过数据没有问题。如果我们想按原来的字段顺序，需要在参数中写入字段列表：

| =A4.pivot(id;subject,score;${A1.concat@cq()}) |

concat() 加上 @q 表示拼接额外的引号，后面会解释。

pivot() 函数也称为转置操作，加上 @r 称为逆转置。

转置是分组操作的一种变体，也可以通过分组来实现：

| … |
| =A3.pivot@r(id;subject,score) |
| =A4.id(subject) |
| =A4.group(id;${A5.("~.select@1(subject==\""+~+"\").score:"+~).concat@c()}) |

可以看到这里的 A6 也变回了 A3（科目字段也排序了。如果要使用原来的顺序，在 A6 表达式中用 A1 替换 A5）。

A6 表达式中的宏很复杂，但仔细研究可以理解，即取当前分组子集中科目名称相同的 score 作为分组后表序列中科目字段的值。因为 A4 中的 subject 是字符串，分组子集由 A4 中的记录组成，所以比较时也要加引号。前面使用 pivot 的代码也是同样的原理，所以 concat() 中要加 @q 选项。这种语法确实很麻烦，所以 SPL 提供了 pivot() 函数来直接实现这种分组和汇总。

换句话说，转置只是一种分组和汇总操作；相应地，逆转置是展开操作。

需要强调的是，这里的转置与 Excel 中的转置不同。Excel 中的转置相当于矩阵的转置，是简单的行列交换（行变列，列变行）。这里的转置实际上是多维分析中的透视。它是分组操作的扩展变体（逆转置是逆分组的变体）。通常，一个字段用作分组键，这个字段是稳定的，不会被转换成列。转置实际上是本书语境中指透视的通俗说法。

然而，SPL 的转置与普通分组略有不同。从 A6 的表达式可以看出，它不会聚合分组子集，而只是简单地获取第一项。实际上，这个操作假设用目标表的字段名过滤后，每个分组子集中只有一条记录（或没有）。如果此时有多条记录（理论上可能），pivot() 函数没有地方描述如何聚合这些记录。更好的方法是先做一轮分组聚合，然后再做 pivot() 函数。

| [English,Maths,Science,Arts,PE] |
| =100.new(string(rand(10),"0000"):id, A1(rand(5)+1):subject,rand(100):score) |
| =A2.pivot(id;subject,score) |
| =A2.groups(id,subject;sum(score):score) |
| =A4.pivot(id;subject,score) |
| =A2.pivot@s(id;subject,sum(score)) |

我们在 A2 中生成的表序列有重复的 id 和 subject，这样在 pivot() 时用字段名过滤后分组子集会有多条记录。直接 pivot() 可能得不到想要的结果（A3）；需要先做一轮分组聚合（A4），然后再 pivot()（A5）；如果所有字段的聚合方式相同，也可以简化为 A6。选项 @s 表示需要多做一步聚合，聚合函数写在参数中。如果不同（例如有些计算 sum，有些计算 max），我们只能先做 A4 的聚合。

使用 pivot() 函数不带第三段参数（第二个分号之后）非常方便，但由于缺少数据，结果表序列中可能不会生成一些想要的字段。

| [English,Maths,Science,Arts,PE] |
| =100.new(string(~,"0000"):id, A1(rand(5)+1):subject,rand(100):score) |
| =A2.select(subject!="Arts") |
| =A3.pivot(id;subject,score) |
| =A3.pivot(id;subject,score;${A1.concat@cq()}) |

A3 过滤掉 Arts 科目然后做 pivot()。结果会少一列，没有 Arts 科目。要按 A5 强制列出所有科目，结果表序列中缺少数据的字段对应值将填充为 null。
