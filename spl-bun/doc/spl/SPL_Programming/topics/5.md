1.3 函数

正如我们所说，数据有类型。除法运算可能得到浮点数结果。如果我们需要得到一个整数，例如通过四舍五入结果，我们应该怎么做？

看起来我们还没有介绍这样做的方法。即使结果是整数（如 6/3），它也会用浮点数表示（3.0）。它如何转换为计算机可以识别的整数？

我们需要 int() 函数来完成这个任务。

|
=int(6/3)
|
=int(100/3+0.5)

int(x) 计算 x 的整数部分：
int(3.0)=3，int(3.1)=3
int(-3.0)=-3，int(-3.1)=-3

（这里 = 表示数学方程而不是赋值语句）

函数的概念早在高中数学教科书中就已经介绍过了。目前，我们可以认为编程语言中的函数概念与数学中的相同。两者都有自变量（在编程语言中称为参数）和因变量（在编程语言中称为返回值）。在方程 y=f(x) 中，x 是参数，y 是返回值，或者我们可以说 f(x) 返回 y。

int(x) 以数字 x 作为参数，返回 x 的整数部分。它被称为整数函数。

顺便说一下，int(x) 返回一个 32 位整数。long(x) 用于将数字（整数、浮点数或长整数）转换为长整数。还有 float(x) 函数用于将数字转换为浮点数。

通常，用特定语言编写的实际程序会使用该语言预定义的许多现成函数。这些现成的函数也称为库函数，就像它们存储在函数库中并从中检索一样。一般来说，熟练的程序员需要熟悉数百个常用的库函数。如果您想掌握一门编程语言，学习使用库函数是重要且必要的。

库函数的意义在于可重用性。打包成库函数的特定操作的现成代码可以随时随地方便使用，而重写既麻烦又容易出错。

此外，大多数时候开发高级应用程序的程序员无法编写实现低级操作的代码。它们只能通过库函数来实现。在 SPL 中几乎不可能实现 int(x) 函数（说几乎是因为如果完全不考虑效率，硬编码可以做到。当您完成本书的相关章节后，可以尝试这样做）。

您可能会好奇，既然库函数不能用您当前使用的语言编写，它们是如何产生的？

一般来说，一种编程语言是用另一种更基础的编程语言开发的。它的库函数可以用这种更基础的语言编写。例如，SPL 是用 Java 开发的，所以它不能编写的库函数是用 Java 编写的；Java 是用 C 语言开发的，所以它不能编写的库函数是用 C 语言编写的；而汇编语言可以编写任何库函数（尽管这个级别的函数已经面目全非了）。

这是另一个问题。

实际上，编程语言中函数的概念比高中数学中的更广泛。

函数不一定有参数。例如，SPL 的 pi() 函数只返回 π。要计算圆的面积，我们使用以下代码：

>S=pi()*r*r

函数可能没有返回值，如 output(x) 函数。

|
>output("Hello,World")

output(x) 函数将 x 的值输出到右下角部分的输出窗口，所以它不会返回值。

不返回值的函数执行的是一个操作。它更像是一条语句。

"function"这个词也有目的或活动的含义。这表明返回值是我们想要实现的目的或目标活动。对于程序员来说，返回值不是函数的唯一意义，他们用函数来做任何可以做的事情。

从这个意义上说，我们有时把使用函数称为调用它，就像它被召唤来执行特定任务一样。

像数学中的函数一样，编程语言中的函数可能有多个参数。例如，max(x,y) 返回 x 和 y 中较大的一个。

有些函数有固定数量的参数。返回 a^x 的幂函数 power(a,x) 总是有两个参数。然而，max() 函数可以有更多参数。max(1,2) 和 max(3,4,5) 都是允许的。

SPL 函数的参数可以有默认值。pi() 函数中的参数 n 以 1 为默认值。pi(n) 表示 nπ，但在大多数情况下，函数返回 π。所以 pi() 意味着 pi(1)。了解参数默认值很重要，否则您可能无法理解别人编写的代码。

并非所有编程语言都支持参数默认值。
