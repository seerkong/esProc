# 10.3 归并

- 格式：供 AI 阅读的 Markdown 提取内容

## 代码片段
```spl
=T("data1.xlsx")
=T("data2.xlsx")
=[A1,B1].merge@uo()
>T("data.xlsx",A2)
=[A1,B1].merge@io()
=T("data1.xlsx").keys(ID)
=T("data2.xlsx").keys(ID)
=[A1,B1].merge@uo()
=[A1,B1].merge@io(ID)
=[B1,A1].merge@io(ID)
=[A2,B2].merge@do()
=A3.(ID)
```

## 提取内容

如果有两个 Excel 文件，比如前面提到的订单表，它们可能分别由两个人制作，可能有一些重复的记录。我们需要挑出这些重复的记录，并将它们合并成一个没有重复记录的表。

本来，这是一个非常简单的集合并集任务。我们已经学过集合运算，可以直接使用交集和差集等运算符。然而，我们也知道表序列中不同的记录永远不会相等，不同表序列中的记录也永远不会相等。当然，从 Excel 文件读取的表序列是不同的表序列。在这种情况下，它们不适合进行集合运算。

SPL 提供了归并操作函数来完成这个任务：

| =T("data1.xlsx") |
| =T("data2.xlsx") |
| =[A1,B1].merge@uo() |
| >T("data.xlsx",A2) |

很简单，merge() 函数比较记录的内容。@u 选项表示取并集。没有这个选项，它会直接连接两个表序列，即取连接（即 |）。@o 我们稍后再讲。

同样，merge() 函数也可以取交集，即获取重复的记录，只需将 @u 替换为 @i。

| =T("data1.xlsx") |
| =T("data2.xlsx") |
| =[A1,B1].merge@io() |
| >T("data.xlsx",A2) |

merge() 函数会比较整条记录的所有字段。如果任何字段不同，就会认为两条记录不同。这样的比较很耗时，有时也没有必要。例如，对于这个订单问题，我们相信制作者是认真负责的。只要订单号正确，订单内容就不会错。然而，在订单收集过程中可能会有重复和遗漏，导致两个文件中有重复的订单号。我们只需要挑出订单号重复的记录。

| =T("data1.xlsx") |
| =T("data2.xlsx") |

通过给 merge() 函数添加一个参数，我们可以让它只比较这个字段。

或者对于设置了主键的记录，merge() 函数只会比较主键。

| =T("data1.xlsx").keys(ID) |
| =T("data2.xlsx").keys(ID) |
| =[A1,B1].merge@uo() |
| >T("data.xlsx",A2) |

交集的操作相同，只需将 @u 替换为 @i。

如果情况更复杂，两个制作者都可能出错。我们需要看看两个文件中订单号相同的记录内容是否不同。因此，我们需要选择订单号相同的记录，并比较整个内容看是否相同。

| =T("data1.xlsx") |
| =T("data2.xlsx") |
| =[A1,B1].merge@io(ID) |
| =[B1,A1].merge@io(ID) |
| =[A2,B2].merge@do() |
| =A3.(ID) |

A2 会计算 A1 中与 B1 订单号重复的那些记录，但保留由 A1 记录组成的记录序列。相应地，B2 会保留 B1 中与 A1 订单号重复的记录。A2 和 B2 都是 A1 和 B1 的交集，但它们只是在比较订单号意义上的交集，整个内容不一定相同。然后在 A3 中使用 merge@d() 计算 A2 和 B2 之间的全内容差集，这样我们就可以得到 A2 中与 B2 中对应订单内容不同的记录，并在 B3 中得到这些订单的订单号，即需要审核的订单。

当集合运算涉及结构化数据时，就会出现这种复杂性。相同的主键（或相对关键的字段）并不意味着整条记录相同。当我们在做交集、并集或差集时需要判断记录相同，可能只使用主键或整条记录。如果只使用主键，交换律将不满足。这不仅是成员顺序可能不同，内容也可能完全不同。写代码时要特别注意。

现在让我们谈谈这个 @o 选项。默认情况下，merge() 函数假设数据是有序的（例如，从小到大），因此比较速度非常快，不需要排序。@o 选项告诉 merge 函数数据是无序的，需要先排序。在我们当前的例子中，订单是按订单号顺序排列的。不写 @o 也没关系。

另一个注意事项是 merge() 函数前面是一个序列（[A1,B1]），它可以同时计算多个记录序列的并集或交集结果。然而，这相对不常见，这里不举例。

merge() 函数对序列也有效，但单值序列通常直接使用集合运算符，很少使用 merge() 函数。
