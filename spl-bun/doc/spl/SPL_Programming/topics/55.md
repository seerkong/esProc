## 提取内容

让我们看看游标上的 group() 函数。

如前所述，对于游标，我们不能将分组后的所有分组子集保存在内存中继续计算，但将它们放在外存中会非常麻烦，严重影响性能，往往得不偿失。

然而，有一种情况可以将分组子集放在内存中处理。如果游标中的数据对分组键值是有序的（总是从小到大或从大到小），并且每个分组子集不大，我们可以始终在内存中保留一个分组子集。完成相关汇总操作后，可以丢弃当前分组子集，然后读入下一个分组子集，依此类推。这样，我们可以在不需要大内存的情况下完成一些必须依赖分组子集的操作。

这就是游标上的 group() 函数，它要求游标对分组键值是有序的。

而且，这个函数返回一个延迟游标！

| =file("data.txt").cursor@t() |
| =A1.group(dt) |
| =A2.fetch(2) |

fetch() 的结果不是表序列，而是一个有两个成员的序列（因为 fetch(2)）。双击其中一个查看：

（原文含示意图，图像资源未迁移）

这看起来像一个表序列。它是一组，由从游标数据中取出的记录组成的记录序列。实际上，它是一个分组子集。

与序列不同，游标的 group() 和 groups() 不对应。group() 函数要求游标数据对分组键值有序，并返回延迟游标，它不会立即计算；groups() 会立即遍历游标进行计算。

数据对某个键值有序的游标称为**有序游标**。

使用这个分组子集，我们将计算每天订单金额最大的地区的订单金额和订单数量。这需要对分组子集再做一次分组聚合，并获取最大值所在的记录。使用我们之前学过的代码，很容易：

| =file("data.txt").cursor@t() |
| =A1.group(dt) |
| =A2.(~.groups(area;sum(amount):S,count(amount):C).maxp@a(S)) |
| =A3.conj().fetch() |

可以看到 A.() 等函数也可以用于游标，它也是延迟游标。而且，在基于延迟游标的下一轮计算中，可以像循环函数一样使用 ~ 表示当前成员，但不能使用 # 或 []。因为游标的相对位置信息很复杂，SPL 还没有实现，后续数据还没有读出，无法实现向前的相邻引用。

maxp@a() 会返回一个序列（这里实际上是记录序列），所以 A3 实际上会是一个相当于两层序列的游标。还需要一个 conj() 才能变成单层序列。conj() 也返回延迟游标。还需要一个 fetch() 来获取结果。没有参数的 fetch() 会获取所有数据。我们知道数据只有 1000 天，最终结果集不会很大，可以完全获取。

而且，从 group() 本身和这里，我们也可以看到游标并不总是读出表序列。它可能 fetch() 出两层序列。实际上，游标对应的是序列，不总是表序列。fetch() 的结果也是子序列，它的成员可以是任何可以作为序列成员的数据。

group() 也有 @i 选项，与记录序列的 group@i() 一样，它被解释为当条件为真时分成新组，它也返回延迟游标。另外，游标的 group(…;…) 函数也会像内存记录序列一样被解释为 group(…).new(…)，也会返回延迟游标。

groups 也有 @o 和 @i 选项，可以执行有序分组以提高运行性能，但 groups() 总是立即计算，即使对于有序游标也会立即遍历。

| =file("data.txt").cursor@t(dt,amount) |
| =A1.groups@o(month@y(dt);sum(amount):S,count(amount):C) |

这段代码的结果与不带 @o 的相同，但带 @o 时，使用有序数据性能更好。

与之前关于有序分组的讨论类似，有序游标也可以用于辅助日志解析。通常，日志确实很大，无法读入内存，所以更需要使用有序游标。SPL 还扩展了 for 语句，直接支持每次从有序游标中获取一个分组子集。

与小数据的情况类似，我们也分三种情况讨论：

1) 每 N 行对应一个事件：

| =file("S.log").cursor@si() |
| =create(…) |
| for A1,3 |
| … |
| >A2.insert(…) |

注意用游标读取文本时，在 cursor() 函数中添加 @si 选项，这样它会读出由字符串组成的序列。如果没有选项，它会尝试将其解释为表序列，但日志数据通常很乱，直接解析为表序列很可能出错。

2) 行数不固定。每个事件前会有一个固定的起始字符串：

| for A1.group@i(~=="---start---"),1 |
| … |

添加参数 1，表示每次读出一个分组子集，或者直接使用扩展的 for 语句：

| for A1;~=="---start---":0 |
| … |

注意游标和后面条件之间是分号。

3) 行数不固定。同一事件的每一行都有相同的前缀（如日志的用户 ID）：

| for A1.group(left(~,6)),1 |
| … |

每次读入一个分组子集，或者使用扩展的 for 语句：

| for A1;left(~,6) |
| … |
