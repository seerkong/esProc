## 提取内容

要绘制图形，我们必须首先建立**坐标系**的概念。我们在中学都学过一些平面解析几何和直角坐标系的知识。我们知道平面上的所有点都可以用坐标表示。计算机绘图也是如此，通常使用直角坐标系来确定位置。

与我们习惯的坐标系不同，画布坐标系的原点在左上角，Y 轴方向是从上到下，整个画布在它的第一象限。

| =A2.draw(400,300) |
| =A2.draw(600,400) |

显然，右上角的点是 A3 画的，左边可以形成斜线的一排点是 A4 画的。为什么这一排的点画成不同的颜色？我们稍后解释。

plot() 函数可以一次画一个点，也可以一次画多个点，只要给出坐标值序列。Data1 和 Data2 分别对应 X 轴和 Y 轴。注意，如果画多个点，两个坐标序列应该等长。

你可以尝试使用 plot() 编辑界面改变一些外观，如点的形状和颜色。

坐标值以像素为单位，所以 A5 和 B5 画出的结果是一样的，都在整个画布的左上部分，大小也一样。然而，我们通常希望图形随大小变化（像上一节的成品图），所以用像素作为坐标单位是不合适的。

SPL 还提供了相对坐标。如果坐标值小于 1，则被认为是相对于画布的比例，即整个画布的坐标范围在 [0,1] 区间内。让我们试试。

| =10.((~-1)*0.1) |
| =A1.(~*~) |
| =canvas() |
| =A2.plot("Line","data1":A1,"data2":B1) |
| =A2.draw(400,300) |
| =A2.draw(600,400) |

现在可以画半条抛物线，B4 比 A4 大，实现了等比例缩放。

这次用 line 来画。图中的点被连接起来。你可以自己改变图元的各种外观属性。你也可以选择不画点。

理论上，有了这个坐标系，我们可以画任何图形。通常，不用于专业图形的编程语言能提供的绑图机制只能提供上述内容（当然，会有一些函数来完成复杂的组合动作）。然而，这显然不方便。有时绑图位置不完全在 [0,1] 范围内或画布的像素范围内，所以你需要自己做一些变换。虽然 SPL 有很强的计算能力，完成这些事情不是问题，但还是有点麻烦。

而且，在之前的成品图中，我们在代码中传递给图元的参数直接是地区名称和金额值，它可以画得很好。如果我们能这样画会方便得多。

当使用像素坐标和相对坐标绘制图形时，我们使用的是画布固有的一套坐标系，称为**物理坐标**。SPL 允许程序员用自己的数据作为坐标值来绘图，这需要建立**逻辑坐标系**。

我们知道直角坐标系总是有两个轴：横轴和纵轴。只要确定了轴，坐标系就确定了。SPL 用这种方法建立逻辑坐标系。让我们看看图元编辑框右上角的图元列表。第一部分是轴。有三种类型：

左边的三个属性表示它是横轴，值范围是 [-3,3]（默认值不是这个，但这是可以修改的属性，包括上面两个勾选项，默认是勾选的）。轴的实际位置在右边定义。因为定义轴时只有物理坐标，它的位置只能用物理坐标描述。这些 0.1、0.9 和 0.5 是前面提到的相对坐标（这些不是默认值）。

使用图元编辑界面向代码添加一个图元，使用上图中的属性值，未列出的属性使用默认值。注意你还应该给这个轴命名（属性列表的第一行），这里叫 x。

同样，添加一个名为 y 的纵轴，设置范围为 [-3,3]，取消勾选范围上面的两项。轴的位置填为 0.9、0.1 和 0.5。注意纵轴的位置应该填在右图下半部分的纵轴属性中，起点是 0.9，终点是 0.1，从大到小。这样，y 轴可以从下到上，符合我们的习惯。

SPL 图形主要用于为结构化数据绘制统计图表。这些图元的默认属性并不简单。例如，一个点会有不同的大小以便看清楚。一般来说，轴会有刻度，绘制坐标系时默认会有条纹。这些可以通过修改属性来调整，但改成非默认值后，plot() 函数的参数会更长，不方便在书中列出，所以我们尽量使用默认属性，但画函数图有点奇怪。然而，这不影响对知识点的理解。

这些我们自己定义的轴称为**逻辑轴**，而画布原来的两个轴称为**物理轴**。绑图图元时，绘制两个轴意味着将使用这两个轴建立的逻辑坐标系，然后我们可以用更方便的值作为坐标值。如果没有选择逻辑轴，意味着将使用物理坐标，如本节开头的图形。

逻辑轴的本质是将熟悉的业务值映射到物理轴的坐标值。定义轴后，图形绑图中使用业务值。逻辑轴负责找到正确的位置。修改逻辑轴和物理轴之间的映射关系后，图形绑图代码不需要改变，图形会以另一种方式绘制。

例如，我们可以把 y 轴往上移一点，把它的起止位置改为 0.5 和 0.1，同时让 SPL 自动找到坐标轴的范围：

| … |
| =A1.plot("NumericAxis","name":"x","autoRangeFromZero":false,"xEnd":0.9,"xPosition":0.5) |
| =A1.plot("NumericAxis","name":"y","location":2,"autoRangeFromZero":false,"yStart":0.5,"yPosition":0.5) |

要让 SPL 自动计算坐标轴范围，勾选值范围上面两项中的第一项，第二项不勾选。值范围可以留空。

SPL 提供三种逻辑轴：数值轴、枚举轴和日期轴。这是按业务数据的数据类型划分的。业务数据是数值时使用数值轴，是序列时使用枚举轴，是日期类型时使用日期轴。

在之前的成品图中，使用的是枚举轴，地区值在一个序列中。这时，我们可以让 SPL 在横坐标为 East、纵坐标为 10 的位置画一个柱子。至于 East 对应画布的具体位置，由逻辑轴解决。写绑图代码时，只关心它的业务意义。

让我们尝试用逻辑轴重新绘制之前的柱状图。

| [10,20,40,30,50] |
| [East,North,West,South,Center] |
| =canvas() |
| =A2.plot("EnumAxis","name":"area") |
| =A2.plot("NumericAxis","name":"amount","location":2) |
| =A2.plot("Column","axis1":"area","data1":B1,"axis2":"amount","data2":A1) |
| =A2.draw(600,400) |

A3 创建枚举轴作为横轴，命名为 area，其他属性使用默认值；A4 使用常规数值轴作为纵轴，命名为 amount，也使用默认属性。然后 A5 用 A1 和 B1 的数据在两个轴建立的逻辑坐标系中绘图。

（原文含示意图，图像资源未迁移）

还有一个问题。现在这些柱子从左到右的顺序是 B1 中数据的顺序。如果我们想改变顺序，或者有些地区没有出现在业务数据中，但仍然想在图中有一个位置，我们是否必须修改 B1 中的业务数据？

不，如何找到物理位置应该是轴的任务，与业务数据无关。

修改代码：

| [10,20,40,30] |
| [East,North,West,South] |
| =canvas() |
| [East,North,Center,West,South] |
| =A2.plot("EnumAxis","name":"area","categories":B2) |
| … |

我们故意少填一个 A1 和 B1 的数据，但 B2 中有完整的地区序列。A3 建立枚举轴时，把它的"categories"属性填为 B2，再画一次：

（原文含示意图，图像资源未迁移）

如何找到物理位置确实是轴的任务，与用于绘图的数据无关。只有当轴的相应属性没有填写时，SPL 才会自动填一个。

总之，SPL 通过逻辑轴实现从业务数据到物理位置的转换。如果理解了这个原理，日期轴就很容易理解（只是把日期转换成位置）。逻辑轴图元的属性也很容易理解。例如，数值轴上也可以做对数和指数变换。这些内容不再涉及知识点，而是具体的语法和编辑方案。需要时请参考 SPL 文档。
