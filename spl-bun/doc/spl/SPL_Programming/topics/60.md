## 代码片段
```spl
=canvas()
=A2.plot("EnumAxis","name":"area","location":3)
=A2.plot("NumericAxis","name":"amount","location":4)
=A2.plot("Column","axis1":"area","data1":B1,"axis2":"amount","data2":A1)
=A2.draw(600,400)
=B1.(","+~)
=A2.plot("Column","stackType":1,"axis1":"area","data1":B2,"axis2":"amount","data2":A1)
=A2.plot("Sector","axis1":"area","data1":B1,"axis2":"amount","data2":A1)
```

## 提取内容

我们在第一节也看到了饼图，但用坐标系来描述这些圆和扇形的位置似乎太麻烦了。它是怎么画的？

除了直角坐标系，SPL 还提供了**极坐标系**。

极坐标系也需要两个轴（平面图形总是需要两个轴）：极轴和角轴。除了选择横轴和纵轴，轴图元的位置属性还可以选择极轴和角轴：

（原文含示意图，图像资源未迁移）

有极坐标系知识的读者可以很容易理解这两个轴图元的位置属性，这里不再重复。

把之前的柱状图改成极坐标系：

| [10,20,40,30,50] |
| [East,North,West,South,Center] |
| =canvas() |
| =A2.plot("EnumAxis","name":"area","location":3) |
| =A2.plot("NumericAxis","name":"amount","location":4) |
| =A2.plot("Column","axis1":"area","data1":B1,"axis2":"amount","data2":A1) |
| =A2.draw(600,400) |

只修改了轴的定义，A5 中的图元语句完全没有改变。

但它画成这样：

（原文含示意图，图像资源未迁移）

这不是我们想要的。但仔细想想，SPL 是对的。它把横轴和纵轴变成了极轴和角轴。横轴的位置变成了极轴的半径，而纵轴的值变成了角轴的角度。柱状图元在极坐标系中没有问题。

我们需要把这些"柱子"堆叠在一个位置。我们发现图元确实有这个属性，但使用后，它画了五个完整的圆，没有堆叠在一个位置。

原来枚举轴的坐标对应由两段成员组成的序列。前一段叫类别，后一段叫系列。堆叠只能在系列之间进行。实际上，类别和系列相当于两个层次，但用两层序列不容易描述。它需要一个有字段的表序列，很麻烦，所以 SPL 用逗号分隔的字符串来描述这种关系。如：

["USA,NY","USA,CA","USA,TX",…, "CHN,BJ","CHN,SH","CHN,TJ",…, …]

它可以描述两层关系。前一段相同的被认为是同一类别。不同类别下的系列可以相同也可以不同。

在我们当前的情况下，我们应该把这些地区看作一个类别下的系列，只有一个类别。

调整代码：

| [10,20,40,30,50] |
| [East,North,West,South,Center] |
| =canvas() |
| =B1.(","+~) |
| … |
| =A2.plot("Column","stackType":1,"axis1":"area","data1":B2,"axis2":"amount","data2":A1) |
| =A2.draw(600,400) |

A5 应使用百分比堆叠，这将确保填满整个 360 度角轴。同时，第一个轴的数据应改为 B2，前面加逗号把地区列表变成系列（只有一个空类别）。

现在画成这样，有点熟悉了。剩下的是调整"柱子"的宽度，还缺少指示信息。这些可以一步步实现。

（原文含示意图，图像资源未迁移）

然而，这还是太麻烦了。SPL 直接提供了扇形图元，它会自动把类别转换成系列并堆叠：

| … |
| =A2.plot("Sector","axis1":"area","data1":B1,"axis2":"amount","data2":A1) |
| =A2.draw(600,400) |

使用图元的默认属性来绘制，只是外观与之前的图不同。只需调整属性。

（原文含示意图，图像资源未迁移）

你可能已经发现，我们没有定义逻辑坐标系，而是每次为图元设置两个轴。那么，如果我们有三个轴 x、y1 和 y2，x 和 y1 可以组成一个逻辑坐标系，x 和 y2 可以组成另一个逻辑坐标系吗？

可以。这就是双轴图。

| [10,20,40,30,50] |
| [4,2,3,4,9] |
| [East,North,West,South,Center] |
| =canvas() |
| =A2.plot("EnumAxis","name":"area") |
| =A2.plot("NumericAxis","name":"amount","location":2) |
| =A2.plot("NumericAxis","name":"quantity","location":2,"yPosition":0.8) |
| =A2.plot("Column","axis1":"area","data1":C1,"axis2":"amount","data2":A1) |
| =A2.plot("Line","axis1":"area","data1":C1,"axis2":"quantity","data2":B1) |
| =A2.draw(600,400) |

A4 和 A5 定义了两个纵轴。A6 使用 A3 和 A4 组成的坐标系，A7 使用 A3 和 A5 组成的坐标系。绘制的双轴图：
