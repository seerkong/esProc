## 提取内容

本书用 12 章从零开始介绍了编程的基本概念和逻辑，以及最常用的结构化数据及其操作，包括大数据处理方法和统计绑图。这些内容涵盖了常规编程的各个方面，日常数据处理的知识储备已经足够。

然而，本书侧重于与概念知识点相关的内容，没有详细介绍各种函数和选项的使用方法。如果想让工作中的数据处理更方便，需要多加练习，特别是熟悉各种常用库函数。

由于时间不足，本书没有附带练习。你可以去润乾公司的"乾学院"查阅资料。那里也有丰富的练习、课程视频、评论和其他资料。本书之后，我们还会编写一套职场数据处理的常规集，对日常工作中遇到的常见数据问题进行分类整理，放在乾学院供参考，包括表格合并、拆分、提取、汇总、转换等多个方面。欢迎关注进度。

虽然学完本书后可以完成许多日常任务，但本书对专业人员来说只是基础。然而，有了这些基础，学习其他编程语言会更容易。特别是本书介绍的结构化数据操作非常全面。理解这些内容后，学习 SQL 和从事数据库应用开发非常容易。SQL 的计算能力只是 SPL 的一个子集。

你也可以继续关注 SPL。

SPL 不仅是非专业人员的编程语言，也适合程序员在应用软件开发中作为计算引擎。借助 SPL，应用架构和开发效率也会大大提高。我们还会整理一套面向应用的常规集放在乾学院，包括非数据库源操作、跨库操作、简化 SQL 和数学计算。

而且，SPL 也是专业的大数据计算语言，可以编写更简洁的代码，性能远优于传统数据仓库（SQL 在这方面非常弱）。这需要深入学习高性能算法，不容易。乾学院已经有相应的课程和许多例子，我们将来会把这些资料重新整理成一本书。
