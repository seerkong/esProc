2.1 逻辑运算

如果我们想计算一个数的绝对值（实际上，SPL 有一个 abs() 函数，但这里我们用其他方法来尝试），我们需要判断这个数是大于 0 还是小于 0。我们引入 if() 函数来实现这一点：

=if(x>0,x,-x)

if(a,b,c) 函数有三个参数，其中 a 是条件。如果条件成立，返回 b，否则返回 c。

使用 if 函数，max(x,y) 也可以实现：

=if(x>y,x,y)

大多数现代编程语言都有一种叫做布尔的数据类型。它只有两个值：true 和 false。

条件判断，如上面的 x>0 或 x>y，在编程语言中也被理解为一种计算表达式，就像我们传统的算术表达式一样，只是它的计算结果是布尔值。当这个条件成立时，它的计算结果是 true，否则计算结果是 false。

if(a,b,c) 函数的更严格描述如下：如果 a 为 true，返回 b；否则返回 c。

要将其他类型的数据转换为布尔值，可以使用 bool(x) 函数。如果 x 不为空，它将返回 true，否则返回 false。实际上，在 SPL 中 null 和 false 没有区别。

由于布尔值也是一种数据，它应该能够参与运算。让我们举一个更复杂的例子：给定一个年份，计算那一年有多少天。

我们知道平年有 365 天，闰年有 366 天，所以我们只需要判断这一年是否是闰年。完整的规则是这样的：如果一年能被 4 整除且不能被 100 整除，或者能被 400 整除，它就是闰年。例如，2004 年是闰年（能被 4 整除但不能被 100 整除），2000 年是闰年（能被 400 整除），1900 年不是闰年（能被 4 整除但也能被 100 整除）。SPL 表达式如下（y 是要判断的年份）：

=if(y%4==0 && y%100!=0 || y%400==0,366,365)

最后两个参数很容易理解。让我们解释第一个参数，即 y%4==0 && y%100!=0 || y%400==0。

% 用于计算除法运算的余数，== 用于判断操作数是否相等，y%4==0 表示 y 除以 4 的余数是否等于 0，即 y 是否能被 4 整除。如果 y 能被 4 整除，那么 y%4==0 的结果是 true，否则是 false。例如，2004%4==0 是 true，而 1998%4==0 是 false。

SPL 保留了 C 语言的习惯，使用 != 表示"不等于"，而许多编程语言使用 <> 表示"不等于"。SPL 中的其他比较运算符，如 >=、<= 等，与大多数程序相同。

所以，y%100!=0 可以判断 y 是否不能被 100 整除。同样，1900%100!=0 是 false，而 1998%100!=0 是 true。同样，y%400==0 将用于判断 y 是否能被 400 整除。

剩下的 && 和 || 是什么？

这些是布尔运算符，&& 代表"与"，在编程中通常称为 AND；|| 代表"或"，在编程中称为 OR。&& 和 || 都是二元运算符，也就是说，像加法一样，它们有两个操作数。&& 和 || 的运算规则如下：

true && true = true
true && false = false
false && true = false
false && false = false
true || true = true
true || false = true
false || true = true
false || false = false

实际上，它们就是"与"和"或"的正常含义。&& 的优先级高于 ||，也就是说，如果没有括号，会先计算 && 然后再计算 ||，就像先乘除后加减一样。如果这个表达式写成 y%400==0 || y%4==0 && y%100!=0，它将得到相同的结果。

还有一个非常常见的单操作数运算符 !，意思是"非"，运算规则如下：

!true = false
!false = true

! 有点像算术中的负号"-"，它的优先级高于 &&。

SPL 保留了 C 语言的运算符，而一些编程语言直接使用单词 AND、OR 和 NOT 来表示 &&、|| 和 !。

现在，我们可以理解 y%4==0 && y%100!=0 || y%400==0，它确实正确地表达了闰年判断的规则。

这里还有一个问题。为什么我们使用两个等号 ==，而不是像算术表达式中那样使用一个等号？

这是因为 SPL 保留了 C 语言的习惯，将赋值语句如 a=x 视为运算表达式，它也有计算结果，即 x。例如，如果我们在单元格 A1 中写 =a=5，SPL 不会报错而是正常执行，我们可以看到不仅变量 a 的值是 5，单元格 A1 本身的值也是 5。因为 a=5 也被理解为一个计算公式，它的计算结果是 5，可以赋给单元格 A1。

但在这样的约定之后，如果我们也用 = 来判断相等，就无法区分了。因此，C 语言规定应该使用两个等号 == 来判断相等，这样就不会与赋值运算混淆。SPL 也应用了这个规则。

习惯之后，我们会看到这个约定的优点，它可以使代码简单得多。但也有风险。在应该写 == 的时候很容易写成 =。本来我们想判断相等，却做了赋值。写代码时应该特别注意这一点。

应该注意的是，并非所有编程语言都是这样规定的。例如，BASIC 语言不把赋值视为运算符。a=5 只完成赋值而没有计算结果。它也使用一个等号来判断相等。优点是不容易出错，但代码有时会很繁琐。

仍然没有完美的东西。
