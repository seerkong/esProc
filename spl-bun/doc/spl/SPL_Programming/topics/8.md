2.2 分支结构

我们可以用 if() 函数做一些判断，但在某些情况下，我们需要 if 语句。

让我们回顾一下中学学过的一元二次方程 ax²+bx+c=0。我们可以用公式 x=(-b±√Δ)/2a 来求解，但需要注意 Δ=b²-4ac。如果它大于 0，有两个解。如果它等于 0，只有一个解。如果它小于 0，没有实数解。

我们将编程求解方程。系数 a、b、c 将填入单元格 A1、B1、C1，结果解要求写入单元格 A2 和 B2。如果有两个解，A2 和 B2 都填入；如果只有一个解，只填入 A2；如果没有解，则不填入。

|
=B1*B1-4*A1*C1
|
if A3>0
|
>A2=(-B1+sqrt(A3))/2/A1
|
>B2=(-B1-sqrt(A3))/2/A1
|
if A3==0
|
>A2=-B1/2/A1
|

B4 和 C4 中的 sqrt() 是平方根函数，无需详细解释。重点是 if 语句出现在 A4 和 A5 中。

if 后面跟着一个逻辑表达式。如果这个表达式的结果为 true，程序将继续执行 if 单元格右边的单元格；如果表达式的结果为 false，程序将跳过 if 单元格右边的那些单元格，直接到下一行执行。

注意这个 if 不是前一节提到的 if() 函数。它后面可以不跟括号（如果确实有括号，括号将被视为逻辑表达式的一部分，表达式外面加一层括号不会改变表达式的计算结果），而且它必须写在单元格代码的开头。

这是 if 语句的最简单形式：如果条件为真，就向右执行，否则直接向下执行。

这段代码没有错误，但有一个小问题。在单元格 A4 中判断 A3 是否大于 0，如果为真，将继续执行 B4 和 C4。然后呢？程序仍然会执行到 A5，再次判断 A3 是否等于 0，但这是一个不必要的操作，浪费时间。只有当"A3 大于 0"不成立时，才有必要判断 A3 是否等于 0。

如何避免这个多余的操作？代码可以这样写：

|
=B1*B1-4*A1*C1
|
if A3>0
|
>A2=(-B1+sqrt(A3))/2/A1
|
>B2=(-B1-sqrt(A3))/2/A1
|
else
|
if A3==0
|
>A2=-B1/2/A1

单元格 A4 中的 if 和单元格 A5 中的 else 形成一对。如果 A4 中的判断为真，将执行 A4 右边的单元格。如果不为真，程序将查看 A4 下面是否有 else。如果有，它将执行这个 else 右边的单元格。

else 的意思是"否则"，即当前面的 if 不成立时要执行的操作。

这个程序使用了一元二次方程的公式，但前提是方程确实是二次的，也就是说，它假设 A1 不为 0。如果 A1 为 0，上面程序的 B4、C4 和 C5 将除以 0。让我们继续改进这段代码，使它能够处理 A1 为 0 的情况，即方程退化为一元一次方程。

|
D
|
if A1==0
|
>A2=-C1/B1
|
else
|
=B1*B1-4*A1*C1
|
if B4>0
|
>A2=(-B1+sqrt(B4))/2/A1
|
>B2=(-B1-sqrt(B4))/2/A1
|
else
|
if B4==0
|
>A2=-B1/2/A1

看这段代码，很明显 B4:D6 是从前一段的 A3:C5 移过来的，即 A3 中的判断不成立后要执行的 else 处理。然而，B4:D6 占用了三行，不仅仅是 A4 右边的单元格。

这时，我们将介绍 SPL 代码块的概念。

对于任何单元格，如果它的下方和左下方都是空的，那么由它的右边和右下方单元格形成的块区域称为它的代码块。以 A4 为例，它下面的 A5 和 A6 都是空的，所以从 B4 到 D6 的块区域称为 A4 的代码块。对于 A3，它下面的 A4 不是空的，所以它的代码块只有 B3:D3，不能扩展到第 4 行（A4 不是空的）。也就是说，一个单元格右边的所有单元格必须属于它的代码块，但单元格右下方的行是否属于它的代码块取决于它下方和左边的单元格是否为空。

A1 的代码块是 B1:D4，因为 A2:A4 是空的而 A5 不是
B1 的代码块是 C1:D1，因为 B2 不是空的
B2 的代码块是 C2:D3，因为 A3:B3 是空的而 B4 不是
C3 的代码块是 D3:D3，因为 B4 不是空的
A5 的代码块是 B5:D6，因为 A6 是空的。

代码块的设计是为了限制语句的作用范围。如果 if 的条件为真，将执行 if 所在单元格的代码块；如果不为真，将执行相应 else 单元格的代码块。

一些编程语言使用花括号或 BEGIN...END 来包围要执行的语句。使用这种方案的编程语言对书写格式没有要求。然而，为了可读性，人们仍然使用文本缩进将代码写成这种阶梯形状，以查看每个语句的作用范围。SPL 不使用括号方案，而是直接使用阶梯状的代码块来限制语句的作用范围，这将强制代码具有一定的格式。

当方程退化为 0=0 时，代码不填入任何解，并在右下角输出一个 any。

像上面的代码一样，else 的代码块中有 if。这种情况在现实中并不少见，这会导致代码很宽，因为每增加一层 if 就需要向右缩进，代码不太美观也不易阅读。

许多编程语言，包括 SPL，提供了将 else 与其后的 if 绑定的语法，上面的代码也可以写成如下形式：
