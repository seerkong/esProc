# esProc 文档

## 内容摘要
esProc 软件包含以下文档。点击超链接可阅读相关内容。

| 名称 | 描述 |
| --- | --- |
| Tutorial（教程） | 面向 esProc 初学者的快速入门指南。 |
| Function Reference（函数参考） | esProc 函数用户指南，主要涵盖语法、描述、参数、选项和示例。 |
| User Reference（用户参考） | 按照 esProc 设计器菜单结构编排，方便用户查找功能。 |
| Code Reference（代码参考） | 常用 esProc 脚本代码示例，面向熟悉 esProc 基础并希望深入学习的用户。 |
| External Library Guide（外部库指南） | esProc 外部库的部署和使用指南。 |
| Data File Tool Manual（数据文件工具手册） | 讨论如何使用数据文件工具访问、编辑数据文件和数据库表，并说明如何使用 ETL 功能加速数据查询和处理。 |
| DQL Tutorial（DQL 教程） | esProc DQL 指南。用户可以使用 DQL 建立表之间的关系，并通过简洁的语法查询数据。 |
| Cluster Server Manager Manual（集群服务器管理器手册） | 集群服务器管理器服务端和客户端功能说明。 |
| SPL WIN Manual（SPL WIN 手册） | SPL WIN 用于执行 SPL 命令。其功能是对 txt/csv/xls/xlsx/btx/ctx 格式的数据文件进行操作，包括读取文件数据并执行添加、删除、修改或导出操作。 |
