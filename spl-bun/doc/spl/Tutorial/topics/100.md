# 3.5.1 外键字段

## 代码示例
```spl
=demo.query("select EID,NAME,SURNAME,BIRTHDAY from EMPLOYEE")
=A1.derive(NAME+" "+SURNAME:FULLNAME,age(BIRTHDAY):AGE)
=demo.query("select * from CITIES")
=demo.query("select STATEID,NAME,ABBR,CAPITAL from STATES")
=A1.derive(A2.select@1(STATEID==A1.STATEID):State)
=A3.derive(State.ABBR:SA)
=A2.derive(A1.select(STATEID==A2.STATEID):Cities)
```

## 内容说明

### 3.5.1 外键字段

esProc 中使用 `A.derive()` 函数向记录序列添加一列或多列。例如：

|   |
|---|
| =demo.query("select EID,NAME,SURNAME,BIRTHDAY from EMPLOYEE") |
| =A1.derive(NAME+" "+SURNAME:FULLNAME,age(BIRTHDAY):AGE) |

A1 检索员工信息。A2 向 A1 的序表添加计算列 - FULLNAME 和 AGE，返回新序表，并计算员工的全名和年龄。

添加计算列后，A2 得到如下新序表：

（原文含示意图，图像资源未迁移）

学习了如何向序表添加计算列后，我们将探讨计算列与创建表之间关系的联系。

两个数据库表之间通常存在关系。在 esProc 中，这种关系可以通过一个序表直接引用另一个序表的记录来表示，使数据搜索和展示简单，数据结构清晰。

使用 `A.derive()` 函数，您可以向序表添加列，并使值的数据类型为从另一个序表引用的记录或记录序列，从而创建用于链接两个表的外键。例如：

|   |
|---|
| =demo.query("select * from CITIES") |
| =demo.query("select STATEID,NAME,ABBR,CAPITAL from STATES") |
| =A1.derive(A2.select@1(STATEID==A1.STATEID):State) |
| =A3.derive(State.ABBR:SA) |
| =A2.derive(A1.select(STATEID==A2.STATEID):Cities) |

A1 和 A2 分别从数据库表 CITIES 和 STATES 检索数据：

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

CITIES 表通过 STATEID 字段与 STATES 表相关联。这种数据库存储模式可以保持数据一致性，使数据易于维护，同时节省存储空间。

A3 向 CITIES 添加 State 字段，创建用于存储城市所在州记录的外键。为便于后续检查，A4 继续向 CITIES 添加 SA 字段以列出这些州的缩写。A5 向 STATES 添加 Cities 字段作为存储每个州城市记录的外键。

A5 的数据如下：

Cities 字段包含每个州的城市记录。双击每个值可查看详情。

通过创建外键，A4 和 A5 的两个序表都获得了数据库中两个原始表 STATES 和 CITIES 的所有信息；两个表之间的关系已建立。注意这些外键字段的数据类型不同。A4 中的外键 State 是记录数据类型，而 A5 中的外键 Cities 是记录序列（即记录的序列）数据类型。

实际上，STATES 表中的 STATEID 字段通常是主键，通过它可以使用 `switch` 函数将第二个表（如 CITIES）链接到它。有关该函数的详细信息，请参阅"主键与索引"。
