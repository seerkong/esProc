## 内容说明

### 3.5.3 连接操作

关联表的另一种方式是 SQL 连接操作。esProc 的 `join` 函数可以实现类似的结果。然而，有了引用记录和记录序列的机制以及 `align` 函数，连接操作的使用变得较少。

#### 等值连接

外键引用基于表之间的对应关系将一个表的字段映射到另一个表的记录。`join` 函数执行的连接也是基于对应关系，通过引用链接来自两个或多个表的记录。例如：

|   |
|---|
| =demo.query("select STATEID,NAME,POPULATION,ABBR from STATES") |
| =demo.query("select * from CITIES") |
| =A1.select(NAME>"C") |
| =A2.groups(STATEID:ID;count(~):Count) |
| =join(A3:StateInfo,STATEID;A4:CityCount,ID) |
| =join@1(A3:StateInfo,STATEID;A4:CityCount,ID) |
| =join@f(A3:StateInfo,STATEID;A4:CityCount,ID) |

默认情况下，通过 `join` 函数进行表连接的结果只包括两个表中州 ID 可以匹配的记录。结果可以被视为由外键字段组成的序表，每个外键字段引用相应表中的记录。

通常 `join` 函数相当于以下 SQL 语句：

`select Ai.* as Fi,... from Ai,... where Ai.xj=... and ...`

这是 SQL 连接最常见的语法。

#### 按序号连接序表

`join` 函数基于记录的对应关系来连接不同序表中记录的引用。此外，序表也可以根据记录位置进行连接。使用 @p 选项来实现。例如：

|   |
|---|
| =demo.query("select STATEID,NAME,POPULATION,ABBR from STATES order by STATEID") |
| =demo.query("select * from CITIES") |
| =A2.groups(STATEID:ID;count(~):Count) |
| =join@p(A1:StateInfo;A3:CityCount) |

#### 交叉连接

交叉连接是一种将第一个序列的每个成员与第二个（或第 n 个）序列的每个成员组合的连接操作。它是最基本的连接操作。没有任何过滤条件，它只是列出所有可能的组合。使用 `xjoin` 函数执行此操作。例如：

|   |
|---|
| [1,2,3,4] |
| [a,b,c] |
| =xjoin(A1:Number;A2:Letter) |
