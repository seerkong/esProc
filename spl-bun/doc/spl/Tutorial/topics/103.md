## 内容说明

### 3.5.4 递归查询

外键关联使序表能够引用另一个序表的记录，在序表之间建立指针类型的引用关系。您也可以利用外键执行自连接，其中序表引用自身的记录，创建称为树的层次数据结构。要在这种树结构中进行数据查询，需要创建递归查询。

#### 自连接

将序表与自身连接就像连接多个序表一样。例如：

|   |
|---|
| =file("Geography.txt").import@t() |
| >A1.switch(Parent,A1:ID) |

#### 递归查询记录的层次外键值

对于自连接产生的层次引用结构，使用 `r.prior(F, r', n)` 函数查询记录 r 引用的外键 F 的每一级数据。通过指定 r'，函数递归查询直到在 F 的引用中找到包含指定 r' 值的被引用记录。可以为递归查询设置最大递归深度 n：

|   |
|---|
| =file("Geography.txt").import@t() |
| >A1.switch(Parent,A1:ID) |
| =A1.select@1(Entry=="Alabama") |
| =A1.select@1(Entry=="South") |
| =A1.select@1(Entry=="West") |
| =A3.prior(Parent) |
| =A3.prior(Parent,A4) |
| =A3.prior(Parent,A5) |

#### 递归查询给定节点的子节点

`prior()` 函数返回记录外键每一级引用的记录。相反，`P.nodes(F, r, n)` 函数查找记录序列 P 中外键 F 下引用的所有记录。这相当于在具有层次引用结构的表中查找记录 r 下的记录。例如：

|   |
|---|
| =file("Geography.txt").import@t() |
| >A1.switch(Parent,A1:ID) |
| =A1.select@1(Entry=="South") |
| =A1.nodes(Parent,A3) |
| =A1.nodes@d(Parent,A3) |
| =A1.nodes@p(Parent,A3) |
