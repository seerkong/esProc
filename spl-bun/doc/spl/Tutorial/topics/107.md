# 3.6.3 switch 函数

## 代码示例
```spl
=file("PersonnelInfo.btx")
=A1.import@b()
=A1.import@b()
=demo.query("select * from STATES")
=now()
>A2.(State=A4.select@1(ABBR:A2.State))
=interval@ms(A5,now())
=now()
>A3.switch(State,A4:ABBR)
=interval@ms(A8,now())
```

## 内容说明

### 3.6.3 switch 函数

除了 `find` 和 `pfind` 函数外，`switch` 函数也通过自动使用为主键值创建的索引表在序表中搜索记录。例如：

|   |
|---|
| =file("PersonnelInfo.btx") |
| =A1.import@b() |
| =A1.import@b() |
| =demo.query("select * from STATES") |
| =now() |
| >A2.(State=A4.select@1(ABBR:A2.State)) |
| =interval@ms(A5,now()) |
| =now() |
| >A3.switch(State,A4:ABBR) |
| =interval@ms(A8,now()) |

State 字段值已转换为州表中的相应记录。

在执行 `switch` 函数之前，也会为另一个序表中的相应字段创建索引表。在本例中，为 A4 州表的 ABBR 字段创建索引表以提高匹配效率。当生成外键字段以引用记录时，学会正确使用该函数对您很有帮助。
