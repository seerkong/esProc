## 内容说明

### 3.7.1 基本用法

在银行交易表等类似表中，一个账户通常有许多交易记录。所有交易记录都包含时间、日期或日期时间数据，如交易时间和日期，通常需要根据它们处理查询。在这些情况下，时间键很有用。

假设我们有一个存储在 transaction.btx 中的银行交易表：

|   |   |
|---|---|
| =create(UID, Amount, Time) | 2021-01-01 |
| =5.(12000+rand(9)*1000) |   |
| for 12 | =date(2021, A2, 5) |
| for C1 | =datetime(B2, time(9+rand(9), rand(60), rand(60))) |
|   | >A1.insert(0, #B3, B3, C3) |
| for rand(200)+100 | =B1+rand(365) |
|   | =time(8+rand(15), rand(60), rand(60)) |
|   | =-(rand(200)+1)*10 |
|   | =datetime(B5, C5) |
|   | >A1.insert(0, int(rand(5)+1), B6, C6) |
| =A1.sort(Time).group(UID) |   |
| =create(UID, Time, Change, Amount) | =5.(10000+rand(200)*100) |
|   | >B9.run(A9.insert(0, B9.#, datetime(B1), 0, B9.~)) |
| for A8 | for A10 |
|   | >B9(#A10)=B9(#A10)+B10.Amount |
|   | >A9.insert(0, #A10, B10.Time, B10.Amount, B9(#A10)) |
| =A9.sort(Time) | transaction.btx |
| =file(B12) | >C12.export@b(A12) |
| =C12.import@b() |   |

要使用时间键，我们需要首先使用 `T.keys@t(K1, K2, ..., KT)` 定义一个。使用 @t 选项，指定字段参数中的最后一个是时间键。一个序表只能有一个时间键，所有其他键称为基本键。例如：

|   |
|---|
| =file("transaction.btx") |
| =A1.import@b() |
| >A2.keys@t(UID, Time) |
| =A2.find(3, date(2021,5,1)) |
| =A2.pfind(3, date(2021,5,1)) |
| =A2.find(3, datetime(2021,8,5,18,0,0)) |
| =A2.pfind(3, datetime(2021,8,5,18,0,0)) |
| =A2.find(3) |
| =A2.pfind(3) |
