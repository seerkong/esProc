# 3.7.2 在表关联中使用时间键

## 代码示例
```spl
=file("transaction.btx")
=demo.query("select EID, NAME, DEPT from EMPLOYEE where EID < 6")
=A1.import@b()
>A2.keys@t(UID, Time)
=B1.join(EID, A2, Time, Amount)
=B1.join(EID:date(2021,5,1), A2, Time, Amount)
=B1.join(EID:date(2021,5,1), A2:UID:Time, Time, Amount)
=file("transaction.btx")
=demo.query("select EID, NAME, DEPT from EMPLOYEE where EID < 6")
=A1.import@b()
>A2.keys@t(UID, Time)
=B1.derive(Date)
>A3.run(Date=A4+rand(365))
>A3.switch(EID:Date, A2:UID:Time)
=A3.new(EID.UID:ID, NAME, Date, EID.Time:Time, EID.Amount:Amount)
>B1.switch(EID, A2)
=B1.new(EID.UID:ID, NAME, EID.Time:Time, EID.Amount:Amount)
```

## 内容说明

### 3.7.2 在表关联中使用时间键

如果为其中一个表设置了时间键，也可以使用时间键处理表之间的关联。当将序表 T 与记录序列 A 关联时，`A.join(C:..., T:K, x:F, ...)` 函数将根据时间键搜索记录，如以下示例所示：

|   |
|---|
| =file("transaction.btx") |
| =demo.query("select EID, NAME, DEPT from EMPLOYEE where EID < 6") |
| =A1.import@b() |
| >A2.keys@t(UID, Time) |
| =B1.join(EID, A2, Time, Amount) |
| =B1.join(EID:date(2021,5,1), A2, Time, Amount) |
| =B1.join(EID:date(2021,5,1), A2:UID:Time, Time, Amount) |

结果集包含指定时间点之前具有最新时间和余额的记录。如果在执行关联的 `A.join(C:..., T:K, x:F, ...)` 函数中没有为序表 T 专门设置键 K，则使用现有主键，如 A4 中的情况。B4 通过指定关联的主键返回相同的结果。

时间键也用于执行表关联的 `A.switch()` 函数。例如：

|   |
|---|
| =file("transaction.btx") |
| =demo.query("select EID, NAME, DEPT from EMPLOYEE where EID < 6") |

| >A2.keys@t(UID, Time) |
| =B1.derive(Date) |
| 2021-1-1 |
| >A3.run(Date=A4+rand(365)) |
| >A3.switch(EID:Date, A2:UID:Time) |
| =A3.new(EID.UID:ID, NAME, Date, EID.Time:Time, EID.Amount:Amount) |
| >B1.switch(EID, A2) |
| =B1.new(EID.UID:ID, NAME, EID.Time:Time, EID.Amount:Amount) |
