## 内容说明

### 4.1.1 数据库连接与断开

使用 SQL 访问数据库首先需要连接到它。通常有两种连接数据库的方式：在数据源管理器中直接连接，或通过在网格中调用特殊函数连接。

（原文含示意图，图像资源未迁移）

|   |
|---|
| =connect("demo") |

在数据源管理器中连接的数据库可以通过其名称引用，在连接期间有效；对于通过函数连接的数据库，连接对象将作为单元格值存储，可以使用单元格名称引用；数据库在引用的连接对象关闭之前有效。

|   |
|---|
| =connect("demo") |
| =demo.query("select * from STATES") |
| =A1.query("select * from STATES") |
| >A1.close() |
