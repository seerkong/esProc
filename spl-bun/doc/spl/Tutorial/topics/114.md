# 4.1.2 SQL 语句的基本用法

## 代码示例
```spl
=connect("demo")
=A1.query("select * from STATES where ABBR like 'N%' order by POPULATION desc")
>A1.close()
=connect("demo")
=A1.query("select * from STATES where ABBR in (?) order by AREA",A2)
>A1.close()
=demo.query@1("select * from CITIES")
=demo.query@1("select NAME from CITIES where STATEID=5")
```

## 内容说明

### 4.1.2 SQL 语句的基本用法

使用 `db.query()` 函数可以在指定数据库中执行 SQL 命令。SQL 语句可以包含各种子查询和数据库函数。

|   |
|---|
| =connect("demo") |
| =A1.query("select * from STATES where ABBR like 'N%' order by POPULATION desc") |
| >A1.close() |

|   |
|---|
| =connect("demo") |
| [CA,ME,NM,SC,LA] |
| =A1.query("select * from STATES where ABBR in (?) order by AREA",A2) |
| >A1.close() |

特别地，`query` 函数使用 @1 选项时只返回第一条找到的记录。在这种情况下，查询结果将作为包含第一条记录字段值的序列返回。如果记录只有一个字段，将返回单个值。例如：

|   |
|---|
| =demo.query@1("select * from CITIES") |
| =demo.query@1("select NAME from CITIES where STATEID=5") |
