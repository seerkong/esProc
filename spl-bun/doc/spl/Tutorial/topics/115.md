# 4.1.3 不返回结果的 SQL 语句

## 代码示例
```spl
=connect("demo")
>A1.execute("update STATES set ABBR='CAA' where ABBR='CA'")
=A1.query("select * from STATES where NAME = 'California'")
>A1.close()
=connect("demo")
>A1.execute("update STATES set ABBR=? where ABBR=?",A2,A3)
=A1.query("select * from STATES where NAME = 'California'")
>A1.close()
```

## 内容说明

### 4.1.3 不返回结果的 SQL 语句

如果数据库操作由不返回结果集的 SQL 执行，如 create、update、delete 和其他 SQL 语句，则应使用 `db.execute()` 函数。此外，由于这些操作不向单元格赋值，它们的表达式将以">"而不是"="开头。例如：

|   |
|---|
| =connect("demo") |
| >A1.execute("update STATES set ABBR='CAA' where ABBR='CA'") |
| =A1.query("select * from STATES where NAME = 'California'") |
| >A1.close() |
