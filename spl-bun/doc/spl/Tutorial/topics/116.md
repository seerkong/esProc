# 4.1.4 直接从单元格执行 SQL 语句

## 代码示例
```spl
$(demo)select * from STATES where ABBR like 'N%' order by POPULATION desc
$select * from STATES where ABBR in (?) order by AREA;A2
$(demo) create table TESTTEMP (ID int, NAME varchar(20))
$(demo) insert into TESTTEMP values (2,'Tom Smith')
=demo.query("select * from TESTTEMP")
$(demo)update TESTTEMP set NAME='Jane White' where ID=2
=demo.query("select * from TESTTEMP")
$(demo)drop table TESTTEMP
```

## 内容说明

### 4.1.4 直接从单元格执行 SQL 语句

除了 `db.query(sql)` 和 `db.execute(sql)` 函数外，esProc 还使用 `$(db) sql;...` 语句直接执行 SQL 语句。如果省略 `(db)`，则连接到最后使用的数据库。如果 SQL 语句中使用参数，将它们放在分号后面。这种方法不需要在 SQL 语句前添加等号，也不需要用双引号包围语句；也不再支持 @1 选项。在这种情况下，不需要使用 `execute` 函数或 `query` 函数来判断语句是否返回结果集。SELECT 语句将返回结果集，但其他语句将分别返回不同的值。例如：

|   |
|---|
| $(demo)select * from STATES where ABBR like 'N%' order by POPULATION desc |
| [CA,ME,NM,SC,LA] |
| $select * from STATES where ABBR in (?) order by AREA;A2 |

该代码在功能上等同于"SQL 语句的基本用法"中的前两个程序，执行时得到相同的结果。A3 没有指定数据源名称，因此连接到最后使用的数据库，仍然是 (demo)。

另一种情况：

|   |
|---|
| $(demo) create table TESTTEMP (ID int, NAME varchar(20)) |
| $(demo) insert into TESTTEMP values (2,'Tom Smith') |
| =demo.query("select * from TESTTEMP") |
| $(demo)update TESTTEMP set NAME='Jane White' where ID=2 |
| =demo.query("select * from TESTTEMP") |
| $(demo)drop table TESTTEMP |
