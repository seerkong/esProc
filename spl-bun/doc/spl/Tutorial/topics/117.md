## 内容说明

### 4.1.5 使用 SQL 查询结果

在 esProc 中可以基于 SQL 查询结果执行各种操作，如过滤、排序和聚合，以提高查询效率或解决一些复杂问题。

在以下示例中，执行基于通过数据源管理器连接到数据源 demo 获得的 A1 查询结果：

|   |
|---|
| =demo.query("select * from STATES order by POPULATION desc") |

（原文含示意图，图像资源未迁移）

首先是过滤数据以选择具有特定缩写的州：

|   |
|---|
| =demo.query("select * from STATES order by POPULATION desc") |
| [CA,ME,NM,SC,LA] |
| =A1.select(A2.pos(ABBR)>0) |
| =A1.select(A2.contain(ABBR)) |

A3 使用 `A2.pos(ABBR)>0` 检查州缩写是否包含在指定序列中。或者您可以使用 `A.contain(x)` 函数做同样的事情。A3 和 A4 中的表达式是等价的，它们得到相同的结果如下：

（原文含示意图，图像资源未迁移）

此外，可以对数据执行聚合计算。例如，统计缩写以 C 开头的州：

|   |
|---|
| =demo.query("select * from STATES order by POPULATION desc") |
| =A1.count(left(ABBR,1)=="C") |

（原文含示意图，图像资源未迁移）

更重要的是，您可以根据某一个或多个条件对数据库数据进行分组，例如根据缩写的首字母对数据进行分组：

|   |
|---|
| =demo.query("select * from STATES order by POPULATION desc") |
| =A1.group(left(ABBR,1)) |

（原文含示意图，图像资源未迁移）

A2 根据每个州缩写的首字母对数据进行分组。双击每个组可查看详情。

与不产生真正分组的 SQL 分组操作不同，esProc 分组操作是真正的分组，这使得进一步计算更加方便。例如，选择包含三个或更多州的组，计算这些组中每个组的州总数和人口：

|   |
|---|
| =demo.query("select * from STATES order by POPULATION desc") |
| =A1.group(left(ABBR,1)) |
| =A2.select(~.count()>=3) |
| =A3.new(left(ABBR,1):Initial,~.count():Count,~.sum(POPULATION):TotalPopulation) |
