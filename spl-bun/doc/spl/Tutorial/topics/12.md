# 1.3.2 数据类型判断

## 代码片段
```spl
ifnumber(x)
ifstring(x)
ifdate(x)
iftime(x)
=ifnumber(3.5)
=ifstring(now())
```

## 内容摘要
esProc 提供以下函数来判断数据类型：

| 函数 | 说明 |
| --- | --- |
| ifnumber(x) | 检查 x 是否为实数 |
| ifstring(x) | 检查 x 是否为字符串值 |
| ifdate(x) | 检查 x 是否为日期或日期时间值 |
| iftime(x) | 检查 x 是否为时间值 |

| =ifnumber(3.5) | =ifstring(now()) |

在 A1 中，浮点数 3.5 是实数。A2 中的 now() 函数计算当前日期和时间，结果不是字符串。
