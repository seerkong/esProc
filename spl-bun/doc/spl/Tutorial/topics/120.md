# 4.2.1 通过数据源管理器访问数据库

## 内容说明

### 4.2.1 通过数据源管理器访问数据库

要连接到关系数据库，请按以下步骤操作：

1) 点击"工具"选项菜单中的"数据源连接"打开数据源管理器

2) 点击"新建"创建数据源并选择其类型。

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

3) 选择数据库类型和字符集等信息，并为数据源设置连接参数和名称。

（原文含示意图，图像资源未迁移）

4) 连接到数据库。数据源管理器将显示连接结果，并支持同时连接多个数据库。

（原文含示意图，图像资源未迁移）

esProc 有内置的系统数据源 - demo，可以通过"开始 -> 所有程序 -> esProc ->"启动

（原文含示意图，图像资源未迁移）

，或者通过运行位于 IDE 安装目录 esProc\bin 中的 startDataBase.bat 启动。

esProc 的集成开发环境（IDE）为各种数据库提供 JDBC 配置提示。您需要准备这些数据库的 JDBC 驱动程序（由数据库供应商提供），并将它们放在 esProc IDE 安装目录的 \common\jdbc 中。
