### 4.2.2 从数据库检索数据

在驱动程序 jar 包配置完成后，您可以方便地在 IDE 中将 esProc 连接到所需的数据库并从中检索数据。例如：

| | |
|---|---|
| | =demo.query("select * from CITIES") |
| | $ select * from CITIES |
| | =connect("demo") |
| | =A3.query("select * from CITIES") |

在网格中，A1 使用数据源管理器中连接的 demo 数据源来查询数据库中的数据。A2 通过默认数据库连接执行查询。A4 使用 A3 创建的数据库连接来查询数据。程序员也可以通过程序控制数据库连接。有关进一步讨论，请参阅"数据库连接管理"。A1、A2 和 A4 返回相同的结果：
