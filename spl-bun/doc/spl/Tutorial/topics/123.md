### 4.2.4 esProc JDBC

如果您不是专业程序员，可以选择跳过本节。这不会影响您学习本教程的其他内容。

esProc JDBC 通过调用和嵌入的方式使用 esProc 应用程序。在其他 Web 应用程序中，可以通过类似 JDBC 的连接调用网格程序。使用 esProc JDBC，打包为存储过程的网格程序可以像真正的存储过程一样被调用。

esProc 网格文件通过 return 函数返回结果集，如 test.splx 文件：

| | |
|---|---|
| | =connect("demo") |
| | =A1.query("select * from EMPLOYEE where EID=?",arg1) |
| | >A1.close() |
| | return A2 |

arg1 是一个网格参数，在调用脚本文件时应该被赋值。结果是通过 return 语句返回的序表。请注意，JDBC 调用的某些文件可能需要连接到另一个数据源，如本例中的"demo"，这也需要通过参数设置进行配置。但 esProc JDBC 中的数据源配置需要在配置文件 raqsoftConfig.xml 中处理。

**1) 配置数据源的方法一：** 直接在 raqsoftConfig.xml 文件中设置数据库数据源的连接参数：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Config Version="3">
  <Runtime>
    <!-- 加密的数据源列表 -->
    <DBList encryptLevel="0">
      <!-- 数据源名称，必须与脚本文件中的名称相同 -->
      <DB name="demo">
        <property name="url" value="jdbc:hsqldb:hsql://127.0.0.1/demo"/>
        <property name="driver" value="org.hsqldb.jdbcDriver"/>
        <property name="type" value="13"/>
        <property name="user" value="sa"/>
        <property name="password" value=""/>
        <property name="batchSize" value="1000"/>
        <!-- 是否自动连接。如果值为 true，可以直接使用 db.query() 函数访问数据库；
             如果为 false，连接不会自动建立，因此必须先使用 connect(db) 语句建立连接。 -->
        <property name="autoConnect" value="true"/>
        <property name="useSchema" value="false"/>
        <property name="addTilde" value="false"/>
      </DB>
    </DBList>
  </Runtime>
</Config>
```

**2) 配置数据源的方法二：** 在 raqsoftConfig.xml 文件中配置应用服务器连接池。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Config Version="3">
  <Runtime>
    <DBList encryptLevel="0">
    </DBList>
  </Runtime>
  <Server>
    <!-- 默认连接；连接的源可以是 DBList 中的一个或以下 JNDIList 中的一个 -->
    <defDataSource>demo</defDataSource>
    <!-- 设置 JNDI 数据源 -->
    <JNDIList>
      <JNDI name="jdbc/test">
        <!-- 数据库类型编号；0-14 依次代表数据库类型：
             [UNKNOWN:0; ORACLE:1; SQLSVR:2; SYBASE:3; SQLANY:4; INFMIX:5; 
              FOXPRO:6; ACCESS:7; FOXBAS:8; DB2:9; MYSQL:10; KINGBASE:11; 
              DERBY:12; HSQL:13; TERADATA:14;] -->
        <property name="type" value="1"/>
        <property name="batchSize" value="1000"/>
        <!-- 引用数据库的 JNDI 数据源，格式为：java:comp/env/数据源名称。
             通过 JNDI 名称查找数据源；不同 Web 服务器中用于搜索数据源的环境字符串前缀不同；
             例如，Tomcat 使用 java:/comp/env，Weblogic 和 Websphere 都不需要前缀，可以留空。 -->
        <property name="lookup" value="java:comp/env/jdbc/test"/>
      </JNDI>
    </JNDIList>
    <!-- 连接默认源，是 DBList 或以下 JNDIList 中的一个 -->
    <defDataSource>demo</defDataSource>
  </Server>
</Config>
```

| 服务器 | Tomcat | Weblogic | Websphere | Resin | Jboss |
|--------|--------|----------|-----------|-------|-------|
| JNDI前缀 | java:comp/env | 无 | 无 | java:comp/env | Java: |

配置时，配置文件的名称必须是 raqsoftConfig.xml，不允许更改。配置数据库连接信息时，禁止重复输入，且 esProc JDBC 本身不能作为数据源进行配置。

本节仅介绍 esProc JDBC 中数据源配置的方法。有关 esProc JDBC 的使用和配置，请参阅"部署 JDBC"。

数据源配置完成后，可以通过 Java 程序调用上述脚本文件：

```java
public void testDataServer(){
    Connection con = null;
    java.sql.CallableStatement st;
    java.sql.Statement st2;
    try{
        // 建立连接
        Class.forName("com.esproc.jdbc.InternalDriver");
        con = DriverManager.getConnection("jdbc:esproc:local://");
        // 调用存储过程，其中 test 是 splx/spl/dfx 文件的名称
        st = con.prepareCall("call test(?)");
        // 设置参数
        st.setObject(1,"3");
        // 以下语句的结果与使用上述调用方法得到的结果相同
        st = con.prepareCall("call test(3)");
        // 执行存储过程
        st.execute();
        // 获取结果集
        ResultSet set = st.getResultSet();
        // 直接创建 Statement
        st2 = con.createStatement();
        // 直接执行网格文件，得到与上面 call test(3) 相同的结果
        set = st2.executeQuery("test 3");
        // 立即执行语句并在指定数据源中查询数据
        set = st2.executeQuery("$(demo)select * from STUDENTS");
    }
    catch(Exception e){
        System.out.println(e);
    }
    finally{
        // 关闭数据库连接
        if (con!=null) {
            try {
                con.close();
            }
            catch(Exception e) {
                System.out.println(e);
            }
        }
    }
}
```

在上述代码中，esProc JDBC 的连接字符串是 "jdbc:esproc:local://"；在这种情况下，将使用默认配置；如果在连接字符串中使用 ...?config=...，则使用指定 .xml 文件的配置并忽略 raqsoftConfig.xml 中的定义。例如，`con=DriverManager.getConnection("jdbc:esproc:local:/?config=myconfig.xml")` 应使用 myconfig.xml 文件中的配置。
