### 4.2.5 esProc ODBC

如果您不是专业程序员，可以选择跳过本节。这不会影响您学习本教程的其他内容。

esProc-ODBC 数据源与其他 ODBC 数据源的用法类似。在访问 esProc-ODBC 数据源之前，需要安装 esProc ODBC 驱动程序并启动 ODBC 服务。该数据源不支持 JRE1.8 及更高版本。详细说明请参阅"部署 ODBC"。本节介绍如何配置和使用 esProc-ODBC 数据源。

上面窗口中的提示显示 esProc-ODBC 正在连接到 esProc ODBC 服务器。esProc ODBC 服务提供两个功能：

1. 使用简单的 SQL 语句直接从主路径指定的文件中查询数据。
2. 调用 esProc 搜索路径中指定的脚本文件并返回结果；可以使用绝对路径指定脚本文件。

esProc-ODBC 服务调用的脚本文件与 esProc JDBC 调用的脚本文件相同，如前面提到的 test.splx 文件：

| | |
|---|---|
| | =connect("demo") |
| | =A1.query("select * from EMPLOYEE where EID=?",arg1) |
| | >A1.close() |
| | return A2 |

以下展示如何使用 esProc-ODBC 执行查询：

| | |
|---|---|
| | =connect("esProcOdbc") |
| | =A1.query("call test(?)",20) |
| | =A1.cursor("select * from Order Electronics.txt ") |
| | =A3.fetch@x(100) |
| | >A1.close() |
