### 4.4.1 通过 SQL 命令更新数据库

db.execute(sql) 函数用于在数据库上执行不同的 SQL 命令以执行各种更新操作。例如：

| | |
|---|---|
| | /=demo.query("select * from TEST") |
| | >demo.execute("create table TEST(ID int,FULLNAME varchar(50), STATE varchar(20))") |
| | =demo.query("select * from TEST") |
| | >demo.execute("insert into TEST values (1,'Tom Smith','Florida')") |
| | >demo.execute("insert into TEST values (2,'Michael Jones','Montana')") |
| | =demo.query("select * from TEST") |
| | >demo.execute("update TEST set STATE='New York' where ID=1") |
| | =demo.query("select * from TEST") |
| | >demo.execute("delete from TEST where STATE='Montana'") |
| | =demo.query("select * from TEST") |
| | >demo.execute("drop table TEST") |
| | /=demo.query("select * from TEST") |

使用 esProc execute 函数执行 SQL 命令时可以使用参数：

| | |
|---|---|
| | /=demo.query("select * from TEST") |
| | >demo.execute("create table TEST(ID int,FULLNAME varchar(50), STATE varchar(20))") |
| | =demo.query("select * from TEST") |
| | >demo.execute("insert into TEST values (?,?,?)",1,"Tom Smith","Florida") |
| | >demo.execute("insert into TEST values (?,'Michael Jones','Montana')",2) |
| | =demo.query("select * from TEST") |
| | >demo.execute("update TEST set STATE='New York' where ID=?",1) |
| | =demo.query("select * from TEST") |
| | >demo.execute("delete from TEST where STATE=?","Montana") |
| | =demo.query("select * from TEST") |
| | >demo.execute("drop table TEST") |
| | /=demo.query("select * from TEST") |

在 execute 函数中使用参数时，它们在 SQL 语句中的位置由问号 (?) 占位，并按顺序写在语句之后。SQL 语句要赋的值可以全部或部分由参数表示，如 A3 和 A4 分别演示的那样。请注意，esProc 函数中的字符串应该用双引号括起来（形式为 "…"），这与 SQL 语法不同。

当执行 execute 语句时，默认情况下结果会自动提交到数据库。一旦发生错误，程序将停止。例如：

| | | |
|---|---|---|
| Tom Smith | Florida | |
| Michael Jones | Montana | |
| three | William Bush | New York |
| Violet Taylor | Montana | |

| | |
|---|---|
| | >demo.execute("create table TEST(ID int,FULLNAME varchar(50), STATE varchar(20))") |
| | =create(Fd1,Fd2,Fd3).record([A1:C4]) |
| for A6 | =demo.execute("insert into TEST values (?,?,?)",A7.Fd1,A7.Fd2,A7.Fd3) |
| | =demo.query("select * from TEST") |
| | =demo.execute("drop table TEST") |

只有两条记录被写入数据库，A9 中删除源表的代码尚未执行。显然，这不是预期的结果。

因此，我们需要控制错误代码并使用命令处理事务。为此，应放弃默认数据库连接，改用 connect@e() 创建到数据库的连接；然后使用 execute@k 执行 SQL 命令而不自动提交结果：

| | | |
|---|---|---|
| Tom Smith | Florida | |
| Michael Jones | Montana | |
| three | William Bush | New York |
| Violet Taylor | Montana | |

| | |
|---|---|
| | =connect@e("demo") |
| | >A5.execute("create table TEST(ID int,FULLNAME varchar(50), STATE varchar(20))") |
| | =create(Fd1,Fd2,Fd3).record([A1:C4]) |
| for A6 | >A5.execute@k("insert into TEST values (?,?,?)",A7.Fd1,A7.Fd2,A7.Fd3) |
| if A5.error()==0 | >A5.commit() |
| else | >A5.rollback() |
| | =A5.query("select * from TEST") |
| | >A5.execute("drop table TEST") |
| | >A5.close() |

在这个网格中，connect 函数中使用 @e 选项连接到数据库。当循环执行 B7 更新数据库时发生错误，它将被记录而不是导致程序中断。最后，检查 A8 看错误代码是否为零：

（原文含示意图，图像资源未迁移）

错误值不为零，这意味着执行期间发生了错误。由于 B7 中的 execute 函数使用了 @k 选项，每次插入结果不会自动提交。因此，当执行 B9 中的 rollback 时，您可以在 A10 中看到所有记录都没有提交，因为发生了错误：
