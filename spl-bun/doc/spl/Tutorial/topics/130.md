## 内容

### 4.4.2 使用序表或序列更新数据库

在上面的例子中，使用 for 语句执行循环操作，用另一个序表的数据更新一个序表。esProc 提供 update 函数，可以直接使用序列或序表中的数据更新序表。例如：

| | | |
|---|---|---|
| Tom Smith | Florida | |
| Michael Jones | Montana | |
| William Bush | New York | |
| Violet Taylor | Montana | |

| | |
|---|---|
| | =connect@e("demo") |
| | >A5.execute("create table TEST(ID int,FULLNAME varchar(50), STATE varchar(20))") |
| | =create(Fd1,Fd2,Fd3).record([A1:C4]) |
| | >A5.update(A6,TEST,ID:Fd1,FULLNAME:Fd2,STATE:Fd3;ID) |
| | =A5.query("select * from TEST") |
| | >A5.execute("drop table TEST") |
| | >A5.close() |

当定义了用于更新数据库的主键，但数据库中已经存在使用相同主键的数据时，会发生什么？看下面的例子：

| | | |
|---|---|---|
| Tom Smith | Florida | |
| Michael Jones | Montana | |
| William Bush | New York | |
| Violet Taylor | Montana | |

| | |
|---|---|
| | =connect@e("demo") |
| | >A5.execute("create table TEST(ID int,FULLNAME varchar(50), STATE varchar(20))") |
| | >demo.execute("insert into TEST values (1,'TOM SMITH','FL')") |
| | >demo.execute("insert into TEST values (20,'MICHAEL','MT')") |
| | =demo.query("select * from TEST") |
| | =create(Fd1,Fd2,Fd3).record([A1:C4]) |
| | >A5.update(A7,TEST,ID:Fd1,FULLNAME:Fd2,STATE:Fd3;ID) |
| | =A5.query("select * from TEST") |
| | >A5.execute("drop table TEST") |
| | >A5.close() |

具有相同主键值的记录已被更新，但具有不同主键值的 MICHAEL 记录保持不变。

不同的选项可以与 update 函数配合使用以执行不同的操作：@u 表示更新数据而不插入新记录；@i 表示插入记录而不更新现有值；@a 表示在执行更新之前从目标表中删除所有现有记录；@1 表示第一个字段是自增的，在更新期间不会被赋值。

如果我们将示例中 A8 的语句修改为 =A5.update@u(A7,TEST,ID:Fd1,FULLNAME:Fd2,STATE:Fd3;ID)，A9 中的查询结果将如下：

A8 执行 update@u 只修改现有记录。

但如果 A8 中的语句修改为 =A5.update@a(A7,TEST,ID:Fd1,FULLNAME:Fd2,STATE:Fd3;ID)，A9 中的查询结果将如下：

（原文含示意图，图像资源未迁移）

A8 将在执行 update@a 之前删除目标表中的原始记录。使用 update@a 可确保目标表与用于更新的源数据之间的数据一致性。

与直接执行 SQL 语句类似，update 函数也可以使用 @k 选项。在这种情况下，您应该考虑适当的数据库连接方式。更多信息请参阅"数据库连接管理"。
