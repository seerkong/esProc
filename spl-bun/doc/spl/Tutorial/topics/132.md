# 4.5.1 调用无返回值的存储过程

## 代码片段
```spl
=connect("ora")
>A1.execute("{call
proc1(?)}",4)
>A1.close()
=connect("ora")
>A1.proc("{call
proc1(?)}",4:0:"i":)
>A1.close()
```

## 内容

### 4.5.1 调用无返回值的存储过程

存储过程用于返回查询结果或仅实现数据库操作而不返回结果。让我们首先看看如何调用无返回值的存储过程。以 Oracle 存储过程为例。存储过程 proc1 只有一个输入参数，没有输出参数：

```sql
create or replace procedure pro1
(pid IN VARCHAR)
as
begin
  insert into emp values(pid,'mike')
  update emp set name='rose' where id=pid
  commit
end
```

您可以使用 execute 函数或 proc 函数来调用此存储过程：

| | |
|---|---|
| | =connect("ora") |
| | >A1.execute("{call proc1(?)}",4) |
| | >A1.close() |

A1 连接到数据库。A2 使用 execute 函数调用存储过程，其中输入参数值为 4。当存储过程执行完毕后，A3 关闭数据库连接。

| | |
|---|---|
| | =connect("ora") |
| | >A1.proc("{call proc1(?)}",4:0:"i":) |
| | >A1.close() |

A1 连接到数据库，A3 关闭连接。与前面的代码不同，当 A2 调用存储过程 proc1 时，在参数后面添加了描述。esProc 的 proc 函数可用于调用无返回参数的存储过程，如 proc1，尽管它主要用于调用返回值和结果集的存储过程。

调用存储过程的每个参数的完整格式是 a:t:m:v，其中 a 是参数值，t 表示参数的数据类型，m 是参数的输入或输出模式，v 是表示返回结果的变量名（如果存储过程有返回结果）。在这段代码中，4:0:"i": 定义了一个参数，其值为 4，数据类型由 0 指定，将由 esProc 自动识别，并且是由 "i" 指定的输入模式。要手动指定数据类型，代码可以写成 4:1:"i":，其中中间的 1 表示整数类型（int）。

有关 esProc 支持的参数数据类型的更多信息，请参阅"附录：参数数据类型定义"。
