## 内容

### 4.5.2 调用返回单个值的存储过程

有返回值的存储过程只能通过 proc 函数调用。下面的存储过程返回一个参数值，因此将使用 proc 函数而不是 execute 函数。

```sql
create or replace procedure testb
(para1 in varchar2, para2 out varchar2)
as
begin
  select name into para2 from emp where id= para1
end
testb
```

以下是 esProc 调用此存储过程的代码：

| | |
|---|---|
| | =connect("ora") |
| | =A1.proc("{call testb(?,?)}",1:0:"i":,:11:"o":name) |
| | =name |
| | >A1.close() |

A1 连接到数据库，A4 关闭连接。

A2 使用 proc 函数调用存储过程 testb。这里使用了两个参数：一个是 1:0:"i":，其值为 1，是输入模式，数据类型自动识别；另一个是 :11:"o":name，其中 11 表示字符串类型（有关更多信息，请参阅"附录：参数数据类型定义"），"o" 表示输出模式，name 定义了一个 esProc 变量来接收返回值。

A3 获取变量 name 的值，这是存储过程的输出结果。变量值的数据类型由存储过程确定。在此示例中，name 用于返回指定编号员工的姓名，返回结果的数据类型是字符串。

对于存储过程，有 3 种参数模式 - 输入、输出和输入输出 - 分别由 "i"、"o" 和 "io" 表示。输入输出参数既可以输入数据，也可以由存储过程赋值。
