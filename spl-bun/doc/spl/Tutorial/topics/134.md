## 代码片段
```spl
=connect("ora")
=A1.proc("{call
RQ_TEST_CUR(?,?)}",:101:"o":table1,1:0:"i":)

>A1.close()
```

## 内容

### 4.5.3 调用返回单个结果集的存储过程

在更多情况下，存储过程返回结果集。以下存储过程 RQ_TEST_CUR 返回单个结果集：

```sql
CREATE OR REPLACE PROCEDURE RQ_TEST_CUR
(
  V_TEMP OUT TYPE.RQ_REF_CURSOR,
  PID IN VARCHAR
)
AS
BEGIN
  OPEN V_TEMP FOR SELECT * FROM TEST WHERE ID =PID
END
RQ_TEST_CUR
```

该存储过程有一个输入参数，并使用游标返回结果集。以下是在 esProc 中调用该存储过程的代码：

| | |
|---|---|
| | =connect("ora") |
| | =A1.proc("{call RQ_TEST_CUR(?,?)}",:101:"o":table1,1:0:"i":) |
| | =table1 |
| | >A1.close() |

A2 使用 proc 函数调用存储过程：=A1.proc("{call RQ_TEST_CUR(?,?)}",:101:"o":table1, 1:0:"i":)。

以下解释 proc 函数中定义的参数。

SQL 字符串 "{call RQ_TEST_CUR(?,?)}" 包含存储过程名称。问号表示 SQL 参数。

让我们看看存储过程参数：

:101:"o":table1 定义了一个输出参数。它直接以冒号开头意味着它没有输入值。101 表示游标数据类型，"o" 表示输出模式，table1 定义了一个变量来引用返回的结果。

1:0:"i": 定义了一个输入参数。1 是参数值，0 表示其数据类型由 esProc 自动识别，"i" 表示输入模式。它直接以冒号结尾意味着不需要输出结果。

A3 使用 A2 的输出变量引用执行存储过程的结果。A2 和 A3 具有相同的结果，即包含查询 TEST 表结果的序表。
