## 代码片段
```spl
=connect("ora")
=A1.proc("{call
proAA(?,?)}",:101:"o":a,:101:"o":b)
=A2(1)
=a
=b
>A1.close()
```

## 内容

### 4.5.4 调用返回多个结果集的存储过程

存储过程也可以返回多个结果集。例如，以下 Oracle 存储过程使用游标返回两个结果集：

```sql
create or replace procedure proAA
(
  out_var out sys_refcursor,
  out_var2 out sys_refcursor
)
as
begin
  open out_var for select * from emp
  open out_var2 for select * from test
end
```

这个简单的存储过程返回查询两个表 emp 和 test 的结果集。

以下是调用该存储过程并接收两个结果集的 esProc 程序：

| | |
|---|---|
| | =connect("ora") |
| | =A1.proc("{call proAA(?,?)}",:101:"o":a,:101:"o":b) |
| | =A2(1) |
| | =a |
| | =b |
| | >A1.close() |

A2 使用 proc 函数调用存储过程：=A1.proc("{call proAA(?,?)}",:101:"o":a,:101:"o":b)，它返回两个结果集（序表）形成一组序表，即一个序列，赋值给 A2。以下解释 proc 函数中使用的参数。

SQL 字符串 "{call proAA(?,?)}" 包含存储过程名称。问号表示 SQL 参数。

:101:"o":a 定义了一个输出参数。101 表示游标数据类型，"o" 表示输出模式，a 是用于存储返回结果的变量。

:101:"o":b 定义了另一个输出参数。101 表示游标数据类型，"o" 表示输出模式，b 是用于存储返回结果的变量。

A3 返回 A2 的第一个序表（查询 emp 表的结果集）。

A4 和 A5 分别使用 A2 中的输出变量 a 和 b 来获取执行存储过程的相应结果。a 对应查询 emp 表的结果，赋值给 A4；b 对应查询 test 表的结果，赋值给 A5。实际上，A2 的结果是由 A4 和 A5 中的序表组成的序列。
