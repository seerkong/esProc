| 5 | DT_FLOAT | 32位浮点数 |
| 6 | DT_DOUBLE | 64位双精度浮点数 |
| 7 | DT_DECIMAL | 大十进制数 |
| 8 | DT_DATE | 日期 |
| 9 | DT_TIME | 时间 |
| 10 | DT_DATETIME | 日期时间 |

| 51 | DT_INT_SERIES | 整数序列 |
| 52 | DT_LONG_SERIES | 长整数序列 |
| 53 | DT_SHORT_SERIES | 短整数序列 |
| 54 | DT_BIGINT_SERIES | 大整数序列 |
| 55 | DT_FLOAT_SERIES | 浮点数序列 |
| 56 | DT_DOUBLE_SERIES | 双精度浮点数序列 |
| 57 | DT_DECIMAL_SERIES | 大十进制数序列 |
| 58 | DT_DATE_SERIES | 日期序列 |
| 59 | DT_TIME_SERIES | 时间值序列 |

| 101 | DT_CURSOR | 游标 |
