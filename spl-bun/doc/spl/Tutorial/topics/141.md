### 5.1 代码块

代码块的主格是其起始格。现在让我们看看代码块可以覆盖哪些格子。

代码块覆盖包含主格的行以及后续一行或多行连续的行（如果有的话），其中主格列和左侧列（如果有的话）中的格子都是空白的。这表明代码块可以延伸，直到出现主格列或左侧列中任何格子非空的行。从该行开始，网格就在此代码块之外了。

| | | |
|---|---|---|
| | D | |
| | >Code begin | |
| | Not null | |
| | Not null | |

在上面的网格中，假设 B2 是代码块的主格。绿色区域中的格子是空白的，因此从第二行到第五行构成主格的代码块。代码块在第 6 行之前结束，因为红色区域中的 A6 和 B6 都不是空白的，无论它是代码格、计算格、可执行格、常量格还是注释格。

代码块不仅可以包含单个语句，还可以通过在主格中放置相应的语句来执行循环过程或分支指令。例如：

| | |
|---|---|
| | =demo.query("select NAME as CITY, STATEID as STATE from CITIES") |
| | [] |
| for A1 | =demo.query("select * from STATES where STATEID=?",A2.STATE) |
| | if left(B2.ABBR,1)=="N" |
| | >A2.STATE=B2.NAME |
| | >B1=B1|A2 |

上面的代码包含代码块。以 A2 为主格的代码块执行循环，以 B3 为主格的代码块执行判断指令。B1 也获取了所在州缩写以"N"开头的城市。

然而，我们讨论的代码块不是使用语句引入各种指令的情况，而是根据顺序格规则将语句写在多个格子中，因此应该作为一个整体执行的情况。该规则允许写在计算格或可执行格中的语句在输入某些字符（包括","、";"和"("）时自动移动到下一个格子，直到没有这样的字符出现或语句到达末尾。

如果格子中的字符串以 // 开头，则以该格子为主格的代码块包含注释，因此称为注释块。esProc 在遇到注释块时会跳过整个注释块。例如：

| | |
|---|---|
| //comment | |
| 1.note... | |
| 2.note... | |
| 3.note... | |
| =1+1 | |
| =1+1 | |

在主格为 A1 的代码块中，所有格子（当然包括 B4）都自然被视为注释格，无需像注释格那样在前面用斜杠 / 标记。非空的 A5 标志着代码块的结束，A5 中的表达式将被正常解析和计算。

与计算块、赋值块和可执行块不同，注释块不包含要执行的表达式，因此不需要顺序格规则。
