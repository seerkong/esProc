### 5.2.1 宏

esProc 中的宏是指用于形成表达式的字符串，但通常这个字符串是动态生成的。一般来说，宏是参数的值或表达式的结果。在实际使用中，宏应该用符号 ${} 括起来。esProc 将首先计算 ${…} 括起来的表达式，然后用结果（即宏字符串值）替换 ${}。例如：

| | |
|---|---|
| [+,-,*,/] | |
| =A1(rand(4)+1) | |
| =rand(1000) | =rand(1000) |
| =A2${B1}B2 | |

B1 从 A1 中的运算符列表中随机获取一个算术运算符。A2 和 B2 生成两个小于 1,000 的随机整数，A3 执行算术运算。B1、A2 和 B2 的结果：

这里 ${B1} 是一个宏，用于动态构造带有不同符号的表达式。

| ="aabb${A1}ccdd" | |

从上面的说明可以看出，与字符串参数不同，宏是表达式的一部分，用于动态生成表达式。

宏通常用于使用名称动态调用格值和函数，以及动态使用参数。它们使用方便，因为上述需求很难用固定表达式实现。例如：

| | |
|---|---|
| AL | |
| AK | |
| AZ | |
| AR | |
| CA | |
| =[A1:A5].pselect(~>5000000) | |
| =B${string(A6)} | |

A6 找到包含人口大于 5,000,000 的第一个数据项的行。根据行号，A7 的表达式找到 B 列中对应的格子以获取州缩写。请注意，宏中的表达式必须返回字符串。因此，当使用宏生成格名时，A7 中需要 string() 函数将 A6 获得的行号转换为字符串。A6 和 A7 的结果如下：

还要注意，格子中的宏只会在第一次使用时被解析。因此，宏不适合循环操作。例如：

| | |
|---|---|
| AL | |
| AK | |
| AZ | |
| AR | |
| CA | |
| =[A1:A5].pselect@a(~>5000000) | |
| =A6.(B${string(A6.~)}) | |

这里 A6 返回所有包含人口大于 5,000,000 的数据项的行：

由于宏中的字符串只在表达式第一次解析时被赋值，所以获得的两个州缩写都是 AZ，这是宏的值第一次被替换时的结果。

应该明确的是，宏用于生成表达式，而不是用于生成命令语句，如 for 语句和 func 函数。
