### 5.2.2 eval 函数

esProc 的 eval(x, …) 函数可以将计算 x 得到的字符串转换为表达式并计算其值。与宏类似，该函数也生成表达式。但区别在于宏只转换表达式的一部分，而 eval 函数生成一个新的表达式，其中允许使用参数并返回其结果。

由于 eval 函数在计算时应该生成一个表达式，表达式 x 的结果必须是字符串。例如：

| | |
|---|---|
| [+,-,*,/] | |
| =A1(rand(4)+1) | |
| =rand(1000) | =rand(1000) |
| =eval("A2"+B1+"B2") | |

eval 函数比宏更强大。当在待计算表达式中使用参数时，它可以实现类似于自定义函数的功能。例如：

|---|---|
| =eval("?.count(~>5)",[2,3,4,5,6,7,8]) | |
| =eval("if (?1>0 && ?2>0 && ?3>0 && ?1+?2>?3 && ?1+?3>?2 && ?2+?3>?1)",3,2,5) | |
