### 5.2.3 字符串常量

我们要讨论的字符串常量既不是简单地用双引号括起来的字符串，也不是字符串类型的常量，而是用 $[…] 格式表示的字符串。

$[…] 和 "…" 有类似的用法。它们都表示表达式中由 … 表示的字符串。例如：

| | |
|---|---|
| ="abc"+$[ABC] | |
| ="\"[abc]\""+$["[ABC\]"] | |

可以看出 $[…] 和 "…" 基本上有相同的用法。它们括起来的字符串都使用反斜杠 \ 作为转义字符来字面解释歧义字符，如普通字符串中使用的引号 " 和普通字符串常量中的右括号 ]。

实际上，$[…] 格式的字符串常量通常用于宏或 eval 函数中。在 esProc IDE 中，$[…] 中表达式中的格名会在编辑期间自动调整，表达式也会在复制和粘贴操作期间自动调整。因此，当字符串常量需要返回格名时，如果网格结构有任何变化，这些特性可以防止表达式错误。例如：

| | |
|---|---|
| select * from STATES | |
| | =demo.query(A1) |
| POPULATION>10000000 | |
| | =demo.query($[${A1} where ${A2}]) |
| left(ABBR,1)='C' | |
| | =demo.query($[${A1} where ${A2} and ${A3}]) |

B2 和 B3 都通过在字符串常量中使用宏，用格值为 query 函数生成查询字符串。

现在如果在第二行之前插入一个空行，网格将变成这样：

| | |
|---|---|
| select * from STATES | |
| | =demo.query(A1) |
| POPULATION>10000000 | |
| | =demo.query($[${A1} where ${A3}]) |
| left(ABBR,1)='C' | |
| | =demo.query($[${A1} where ${A3} and ${A4}]) |

可以看出 B3 和 B4 中表达式中的格名相应地发生了变化。由于 "…" 表示的字符串不能使用宏，且 "…" 的内容不会随着编辑而改变，因此该格式在某些情况下不适用。
