# 5.3.1 将格值设为 null 和重置序表

## 代码片段
```spl
=file("Order_Appliances.txt").import@t()
=file("Order_Foods.txt").import@t()
=A1|A2
=A3.top(200;-Amount).new(ID,
=A4.sort(PName)
=file("Order_Appliances.txt").import@t()
=file("Order_Foods.txt").import@t()
=A1|A2
>A1.reset()
>A2=null
=A3.top(200;-Amount).new(ID,
>A3=null
=A4.sort(PName)
>A4=null
```

## 内容

### 5.3.1 将格值设为 null 和重置序表

在以下任务中，您需要根据订单总金额列出所有家电订单和食品订单中的前 200 条交易记录，并按产品名称排序。订单记录来自两个文本文件：Order_Appliances.txt 和 Order_Foods.txt。您需要首先连接两个表的记录，按订单总金额获取前 200 条订单记录，然后按产品名称排序。

| | |
|---|---|
| =file("Order_Appliances.txt").import@t() | |
| =file("Order_Foods.txt").import@t() | |
| =A1\|A2 | |
| =A3.top(200;-Amount).new(ID, PName,Type,Date,Amount) | |
| =A4.sort(PName) | |

实际上我们真正需要的是 A5 的数据。在 A4 获取所有必要的订单记录后，A1 和 A2 中的原始表变得无用。在获取中间数据后删除无用数据可以释放内存并使操作更稳定。

因此，上述网格程序可以重新安排如下：

| | | |
|---|---|---|
| =file("Order_Appliances.txt").import@t() | | |
| =file("Order_Foods.txt").import@t() | | |
| =A1\|A2 | >A1.reset() | >A2=null |
| =A3.top(200;-Amount).new(ID, PName,Type,Date,Amount) | >A3=null | |
| =A4.sort(PName) | >A4=null | |

如果将格子的值设为 null，格子中的数据将被删除，如 C3 和 B4 中的语句所做的那样。在 C3 中的语句清除 A2 的格值并且 B4 从 A3 中清除食品订单记录的引用后，原始食品订单表将从内存中删除。

而 B3 中的 T.reset() 函数略有不同，它将删除序表中的所有记录但保留其数据结构。执行 B3 后，A1 的值如下：

（原文含示意图，图像资源未迁移）

您可以根据不同情况选择其中之一来清除格值。将格值设为 null 更常用。T.reset() 仅在序表的数据结构值得保留时使用。

请注意，虽然 B5 中的语句将 A4 的值设为 null，但内存占用不会减少。因为 A5 返回的结果是一个记录序列，其记录是 A4 中序表的引用，这些记录仍将在 A5 中被引用，即使 A4 设为 null 也无法清除。因此，当使用将格值设为 null 的方法来释放内存时，您必须首先确定原始格子中的数据是否正在使用。

此外，A5 对 A4 记录的排序操作不会生成新记录。A5 存储的只是排序记录的指针，它们的内存占用有限，不会增加内存使用。
