### 5.3.2 使用 clear 语句清除格值

在执行一段代码后，可能有一批格子的值需要清除，只有最终结果值得保留，如以下网格：

| | |
|---|---|
| =file("Order_Appliances.txt").import@t() | |
| =file("Order_Foods.txt").import@t() | |
| =A1\|A2 | =B2.top(200;-Amount).new(ID, PName,Type,Date,Amount) |
| =A3.sort(PName) | |
| >A1=null | >A2=null |
| >B2=null | >A3=null |

与前面的例子类似，A4 根据总金额获取前 200 条订单记录并按产品名称排序。为了减少内存使用，A5、B5、A6 和 B6 在计算后清除无用格子的值。显然代码有点繁琐。为此 esProc 专门提供了 clear 命令：

| | |
|---|---|
| =file("Order_Appliances.txt").import@t() | |
| =file("Order_Foods.txt").import@t() | |
| =A1\|A2 | =B2.top(200;-Amount).new(ID, PName,Type,Date,Amount) |
| =A3.sort(PName) | |
| clear A1,A2,B2,A3 | |

这在功能上等同于上述方法。A5 中的 clear 命令可以一次删除多个格子的值。此外，clear 命令可以通过指定格子范围来删除格值。例如：

| | |
|---|---|
| =file("Order_Appliances.txt").import@t() | |
| =file("Order_Foods.txt").import@t() | |
| =A1\|A2 | =B2.top(200;-Amount).new(ID, PName,Type,Date,Amount) |
| =A3.sort(PName) | |
| clear A1:B3 | |

在 A5 的 clear 命令中，A1:B3 表示从 A1 到 B3 的矩形区域，包括 A1、B1、A2、B2、A3 和 B3。clear 命令将清除所有这些格子的值。单个格子和格子范围可以一起出现在 clear 命令中。例如，A5 的命令可以重写为 clear A1:B2, A3，功能相同。另一个网格：

| | |
|---|---|
| [Order_Appliances.txt,Order_Foods.txt] | =[0]*A1.len() |
| for A1 | =file(A2).import@t() |
| | =B2.top(100;-Amount) |
| | =B3.sort(PName) |
| | >B1(#A2)=B4 |
| =B1.merge(PName) | |
| =A6.new(ID, PName,Type,Date,Amount) | |

操作略有不同。它根据 A1 的文件名从两个文件导入数据，从每个表中按订单金额选择前 100 条记录，分别按产品名称排序，并将每个结果存储为 B1 中序列的成员。由于每个结果已按产品名称排序，它们可以在 A6 中按产品名称合并。然后 A7 生成最终的序表：

在这段代码中，在 A7 获得最终结果后，无用的格值也需要删除。除了通过指定格子或格子范围外，您还可以通过指定代码块的主格来清除格值，如以下网格所示：

| | |
|---|---|
| [Order_Appliances.txt,Order_Foods.txt] | =[0]*A1.len() |
| for A1 | =file(A2).import@t() |
| | =B2.top(100;-Amount) |
| | =B3.sort(PName) |
| | >B1(#A2)=B4 |
| =B1.merge(PName) | |
| =A6.new(ID, PName,Type,Date,Amount) | clear A1:B1,A2:,A6 |

在 B7 的 clear 命令中，A2: 的格式类似于定义格子范围，但它没有指定结束格子。这意味着清除主格为 A2 的代码块中所有格子的值，即删除从第二行到第五行的格子的值。代码执行后，除 A7 外所有格子的值都被清除。
