# 1.4.2 常量单元格

## 代码片段
```spl
=A1*1000
=interval@y(A1,now())
```

## 内容摘要
如果单元格可以将输入的数据字符串解释为常量，则该单元格可以被视为常量单元格。它的值就是该常量。

常量单元格中的文本默认以粉色显示。根据格式，文本字符串将被解析为相应数据类型的值，如整数类型、浮点数类型和日期时间类型。如果格式无法识别，将被解释为字符串类型数据。

在常量单元格中定义字符串时不需要双引号。

此外，在常量单元格中，数据可以用百分比表示，如 5%：

| 5% | =A1*1000 |

在常量单元格 A1 中，5% 将被转换为相应的浮点值 0.05。注意：像 5% 这样的格式在表达式中是禁止的，只允许在常量单元格中使用。

常量单元格中的值也可以是 true、false 或 null：

| True | False | Null |

这些是区分大小写的保留字。可以看出，常量单元格值是字符串而不是相应的布尔值或 null 值：

您可以使用字符串常量单元格将单元格的值指定为字符串。字符串常量单元格中的字符串以英文单引号 ' 开头。字符串常量单元格用于定义包含特殊字符或由数字组成的字符串：

| 'abc\d | '1234.5 | 1234.5 |

在上述网格中，常量单元格 A1 的值是字符串 abc\d；单元格 A2 的值是字符串 1234.5；单元格 A3 的值是数字 1234.5。注意字符串值带有下划线，其默认显示颜色不同：
