### 5.4.1 字符串中的特殊字符

字符串可能包含各种符号，其中一些可能会有问题。以下是在常量字符串中使用某些符号时可能出现的问题。例如：

| | | |
|---|---|---|
| =,>,<,+,- | ===== dividing line ===== | >100 |
| / is division sign | 34.55 | end |

A1 和 B1 中以"="开头的字符串如果直接输入到格子中，将被解释为错误的表达式而不是常量，并会在计算中导致错误。C1 中以">"开头的字符串不会按原样处理；相反，该格子将被视为可执行格。A2 中以"/"开头的字符串直接写在格子中时将被视为注释语句。B2 中的常量将被自动解析为整数而不是字符串。作为保留字，C2 中的字符串也不会被作为字符串常量处理。在这些格子中，只有 B2 有值；但该值不是字符串类型。

上述字符串常量无法正确识别的问题由两个因素造成。在大多数情况下，字符串本身是模糊的，在其他情况下，字符串的第一个字符是特殊字符，如"="、">"、"/"等。在 esProc 中，您只需在字符串常量前添加单引号 (') 即可使其正常识别。

| | | |
|---|---|---|
| '=,>,<,+,- | '===== dividing line ===== | '>100 |
| '/ is division sign | '34.55 | 'end |

由于表达式中使用的字符串应该用双引号括起来（如"…"），上述有问题的字符串在表达式中使用时不会造成歧义。但对于包含双引号 " 的字符串，您需要在 " 前放置转义字符 \ 以字面解释它；字符串中使用的斜杠 \ 也是如此。例如：

| | | |
|---|---|---|
| ="===== dividing line =====" | ="/ is division sign" | ="34.55" |
| ="\"How is Frank?\" he asked." | =$[$\{B1}"C:\\test"] | =$[${B1}"C:\\test"] |
