### 5.4.2 字段名中的特殊字符

在序表中，包含非字母和非数字特殊字符（如 %、(、)、" 或空格）的字段名在解析表达式时可能会导致歧义。例如：

| | |
|---|---|
| $(demo) select * from STATES order by STATEID | |
| =A1.new(NAME:STATE,POPULATION,AREA:'AREA(sq. mi.)') | |
| =A2.(round(POPULATION/AREA(sq. mi.),3)) | |

当 A3 使用 A2 中的数据计算人口密度时，表达式中字段名的解析出现了问题。为了防止解析问题，可以使用单引号将序表的字段名括起来（如 '…'），这样就不会将标识符识别为特殊字符。例如：

| | |
|---|---|
| $(demo) select * from STATES order by STATEID | |
| =A1.new(NAME:STATE,POPULATION,AREA:'AREA(sq. mi.)') | |
| =A2.(round(POPULATION/'AREA(sq. mi.)',3)) | |

除了表示序表中的字段名外，'…' 格式还可以用于调用包含特殊字符的参数。当然，序表中的字段可以通过其位置来引用，以避免直接使用字段名带来的麻烦。例如：

| | |
|---|---|
| $(demo) select * from STATES order by STATEID | |
| =A1.new(NAME:STATE,POPULATION,AREA:'AREA(sq. mi.)') | |
| =A2.derive(round(POPULATION/#3,3):Density) | |
