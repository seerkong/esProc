## 内容

### 5.5.1 子程序调用

子程序是一个代码块，其中主格包含 func 语句，并使用 return 语句返回结果。通过在表达式中使用 func(C, xi,…) 函数在 C 的代码块处调用子程序，其中 xi,… 是参数。例如：

| | |
|---|---|
| func | /create an ID |
| >id="" | |
| >A1.run(id=id+char(65+rand(26))) | |
| return id | |
| =func(A1,rand(3)+3) | |

根据给定字符的长度，在覆盖第一行到第四行并以 A1 为主格的代码块中创建一个随机的大写字母 ID。B2 将网格变量 id 设置为空字符串。根据子程序主格获得的字符长度，B3 运行循环，每次向 id 添加一个随机大写字母，同时在每次添加之前初始化网格变量 id。B4 使用 return 语句返回网格变量 id 的值。A5 使用 func 函数调用子程序。在表达式 =func(A1,rand(3)+3) 中，A1 是被调用子程序的主格；rand(3)+3 计算参数值（一个 3~5 个字符的随机整数），并将其传递给子程序进行计算。A5 的结果是一个由 3~5 个随机字符组成的字符串，如下所示：

| | |
|---|---|
| =5.(func(A2,2)) | =10.(func(A2,rand(3)+3)) |
| func | /create an ID |

| >A2.run(id=id+char(65+rand(26))) | |

根据这两段代码，子程序可以从网格的任何格子调用。实际上，在网格程序运行期间，子程序的代码块在子程序被调用之前不会执行。

子程序和循环语句都由代码块表示。后者只有在主格中的循环运行时才会执行，而子程序可以通过 func 函数从任何格子调用。子程序的代码块在子程序被调用之前不会执行。一旦子程序调用开始，它会继续直到代码块结束，或者直到第一个 return 命令出现并返回结果。但如果有多个结果要返回怎么办？看下面的例子：

| | |
|---|---|
| =create(Product,Customer) | |
| func | /create an ID |
| >id="" | |
| >A2.run(id=id+char(65+rand(26))) | |
| return id | |
| func | return [A7(A5),B7(B5)] |
| =5.(func(A2,2)) | =10.(func(A2,rand(3)+3)) |
| for | =func(A5,rand(5)+1,rand(10)+) |
| | >A1.insert(0,B8(1),B8(2)) |

以 A5 为主格的子程序根据参数获取产品名称和客户名称。B6 将它们作为序列返回。当调用子程序时，B8 随机创建产品编号和客户编号，并将它们作为参数传递给子程序。如果在调用子程序时使用多个参数，它们将从主格开始从左到右输入到格子中。

子程序不一定要返回值。当子程序的代码块中没有 return 语句时，代码将顺序执行直到结束。例如：

| | |
|---|---|
| =create(OID,Product,Customer,Amount) | |
| func | /create an ID |
| >id="" | |
| >A2.run(id=id+char(65+rand(26))) | |
| return id | |
| func | /add a record |
| >B1=B1+1 | |
| =(rand(1000)+1)*100 | |
| >A1.insert(0,B1,A5,B5,C6) | |
| =5.(func(A2,2)) | =10.(func(A2,rand(3)+3)) |
| for | =A8(rand(5)+1) |
| | =B8(rand(10)+1) |
| | >func(A5,B9,C9) |

A2 的子程序与前面例子中的相同。A5 的子程序没有 return 语句，所以它不会返回值，只会在每次执行时向 A1 的序表添加一条记录。这就是为什么 B10 在调用 A5 的子程序时可以以 > 开头。子程序调用将在 A5 代码块的末尾停止。

在子程序中不必使用 return 语句来返回结果集。没有 return 语句时，子程序将返回其范围内最后一个以 = 开头的计算格的值。例如：

| | | |
|---|---|---|
| func | /create an ID | |
| >id="" | | |
| >A1.run(id=id+char(65+rand(26))) | | |
| =id | Test | |
| =5.(func(A1,2)) | =10.(func(A1,rand(3)+3)) | |

这里 A1 的子程序没有 return 语句，所以它返回其范围内最后一个以 = 开头的计算格的值，即 B3 的格值，而不是常量格 C3 的值。这相当于在 B3 中使用 return id。在这种情况下，A4 的结果仍然是 5 个随机字符串，每个由 2 个字母组成，B4 仍然得到 10 个随机字符串，每个由 3~5 个字符组成。
