## 内容

### 5.5.2 跨网格调用

除了子程序调用外，esProc 还支持跨网格调用，它使用 call 函数从另一个网格运行程序或利用另一个网格的结果。这意味着整个网格将被视为要执行的子程序。return 语句用于返回结果。在返回结果后结束跨网格调用以释放内存。D:\files\createID.splx 是一个网格：

| | |
|---|---|
| /create an ID | |
| >size.run(A2=A2+char(65+rand(26))) | |
| return A2 | |

在网格中，B2 循环向 A2 添加字符以创建随机 ID，并使用 return 语句返回它们。与子程序调用类似，跨网格调用也不必使用 return 语句。返回的结果将是最后一个以 = 开头的计算格的值。例如，您可以将 A3 的代码更改为 =A2，仍然得到相同的结果。请注意，B2 使用了一个网格参数 size，需要在菜单栏的"程序参数"对话框中设置。

（原文含示意图，图像资源未迁移）

如果在跨网格调用期间需要参数，应通过被调用的 splx 文件中使用的网格参数传递。使用 call 函数调用另一个网格中程序的方式与调用子程序的方式类似：

| | |
|---|---|
| =call("D:\\files\\createID.splx",rand(3)+3) | |
| =call("createID.splx",rand(3)+3) | |

同样，参数放在被调用程序之后。区别在于，在 A2 的跨网格调用中，被调用的脚本文件直接通过其名称指定。请注意，\ 在字符串表达式中用作转义字符；因此，在 A1 的代码中，在它前面放置另一个 \ 以字面表示该字符。A1 和 A2 分别调用脚本文件并创建一个 3~5 个字符的 ID，如下所示：

要像 A2 那样编写语句，请确保脚本文件在 esProc 的主路径或搜索路径中。单击菜单栏上的"工具>选项"，在"环境"页面上设置主路径和搜索路径，如下图所示：

（原文含示意图，图像资源未迁移）

在上述配置中，无论脚本文件放在主路径或搜索路径的哪个目录中，都可以通过名称被 call 函数调用，而无需写完整路径。

如果要集成 splx 文件，需要在配置文件 raqsoftConfig.xml 中配置主路径和搜索路径：

```xml
<esProc>
  <splPathList>
    <splPath>E:\tools\raqsoft\esProc\demo\Case\Structural</splPath>
    <splPath>D:\files\txt;</splPath>
  </splPathList>
  <mainPath>D:\files\demo</mainPath>
</esProc>
```

跨网格调用可以使用多个参数或返回多个结果。如下面的 D:\files\findNames.splx 所示：

| | |
|---|---|
| /find a PNAME and a CNAME | |
| =rand(PNames.len())+1 | =rand(CNames.len())+1 |
| return PNames(A2),CNames(B2) | |

此子程序分别从 PNames 和 CNames 中获取一个随机成员并返回它们。PNames 和 CNames 是输入网格参数：

（原文含示意图，图像资源未迁移）

主程序调用网格程序如下：

| | |
|---|---|
| =create(Product,Customer) | |
| =5.(call("createID.splx",2)) | =10.(call("createID.splx",rand(3)+3)) |
| for | =call("findNames.splx",A2,B2) |
| | >A1.insert(0,B3(1),B3(2)) |

A2 和 B2 调用上述网格 createID.splx 创建产品名称序列和客户名称序列。A3 运行循环，在 B3 中调用网格 findNames.splx，将 A2 和 B2 作为参数输入。

**注意**：对于 call 函数中使用的参数，它们的值将分别赋给脚本文件的参数；这与脚本文件参数列表中的参数名称无关。也就是说，值按顺序赋给 splx 的参数：A2 的值赋给 PNames，B2 的值赋给 CNames。与子程序的 return 语句返回结果序列不同，被调用网格的 return 语句用逗号分隔多个结果，它们将自动作为序列返回。最后一次跨网格调用的返回结果可以在 B3 中查看：

通过重用现有的网格程序，跨网格调用使主网格中的代码更简洁。此外，需要加密的算法可以放入单独的网格中供另一个程序调用。

在网格文件中使用参数时，我们可以将最后一个参数设置为动态参数。在网格执行期间，最后一个参数的值将被连接为一个序列传递给网格文件，如下面的文件 D:\files\findEmployee.splx 所示：

| | |
|---|---|
| /find employees in given states | |
| =connect("demo") | |
| =A2.query@x("select EID, NAME, SURNAME, STATE, GENDER, DEPT from EMPLOYEE where DEPT=? and STATE in (?)", dept, states) | |
| return A3 | |

如果需要重复调用网格文件，使用 register(func, spl) 将脚本 spl 注册为函数 func。然后我们可以使用注册的函数名 func 直接调用执行网格文件的脚本，例如：

| | |
|---|---|
| =register("findEmps", "findEmployees.splx") | |
| =findEmps("Finance", "Texas", "New York", "Florida") | |
| =findEmps("R&D", "Pennsylvania", "North Carolina") | |

（原文含示意图，图像资源未迁移）

根据 A2 的结果，将脚本注册为函数后，调用它的结果与使用 call() 函数执行网格文件的结果相同。

注册的函数在 esProc 退出之前始终有效。例如，它可以在新创建的主网格中执行：

| | |
|---|---|
| =findEmps("Finance", "Texas") | |
| =findEmps("R&D", "Pennsylvania", "North Carolina") | |

并正确获得查询结果。
