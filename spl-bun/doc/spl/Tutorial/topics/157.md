# 6.1.1 无返回结果的网格文件

## 代码片段
```spl
=create(ID,Amount)
>A1.insert(0,#A2,rand(100*100))
=file("D:\\files\\Data1.txt")
>A3.export@t(A1)
=file("D:\\files\\Data1.txt")
=A1.import@t()
>B1.modify(A2,Value:Amount)
>A1.export@t(B1)
```

## 内容

### 6.1.1 无返回结果的网格文件

我们可以在命令行执行网格文件。例如，使用 esprocx.bat 文件，查看批处理文件，我们可以看到默认情况下将执行以下操作：

（原文含示意图，图像资源未迁移）

例如，以下网格文件 D:\files\output1.splx 生成一些模拟数据并将它们存储在文本文件 Data1.txt 中：

| | |
|---|---|
| =create(ID,Amount) | |
| for | >A1.insert(0,#A2,rand(100*100)) |
| =file("D:\\files\\Data1.txt") | |
| >A3.export@t(A1) | |

无返回结果的网格文件通常是那些访问文件或数据库中数据的文件。您只需在 esprocx.bat 后输入要执行的脚本文件。在执行期间，屏幕上将显示开始和结束的提示，如下所示：

（原文含示意图，图像资源未迁移）

执行后，随机生成的数据将写入 Data1.txt，如下所示：

（原文含示意图，图像资源未迁移）

如果 esprocx.bat 文件所在的路径包含在操作系统的路径列表中，则直接运行该文件，而不是在安装目录的 esProc\bin 路径中运行它。但要调用的脚本文件必须输入其完整路径，或者应位于当前路径中。例如：

（原文含示意图，图像资源未迁移）

如果要执行的网格文件使用参数，在执行 esprocx.bat 命令时，在脚本文件后输入它们的值，用空格分隔。以下面的网格文件 D:\files\output2.splx 为例：

| | |
|---|---|
| =file("D:\\files\\Data1.txt") | |
| =A1.import@t() | |
| for IDs | >B1.modify(A2,Value:Amount) |
| >A1.export@t(B1) | |

该文件使用两个参数：IDs 和 Value，如下所示：

（原文含示意图，图像资源未迁移）

该网格用于导入刚创建的 Data1.txt 文件，修改具有指定序号的某些记录，使其 Amount 字段等于指定的 Value，并再次将这些记录存储在文件中。执行期间屏幕上显示的提示如下：

（原文含示意图，图像资源未迁移）

在调用网格文件 output2.splx 时输入了两个参数，一个是序列 [2,3,5,7,11]，另一个是整数 99999。与跨网格调用类似，在命令行调用期间，输入参数将根据其顺序而不是名称分配给网格参数。在这种情况下，[2,3,5,7,11] 分配给第一个参数 IDs，99999 分配给第二个参数 Value。命令行执行后，Data1.txt 中的数据将被修改：

（原文含示意图，图像资源未迁移）
