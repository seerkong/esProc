# 6.1.2 有返回结果的网格文件

## 代码片段
```spl
=days(Day)
=string(Day,"EEE")
=days(Day)
=string(Day,"EEE")
$(demo)
$select
=A1.switch(STATEID,B1:STATEID)
=A2.new(CID,NAME:City,STATEID.NAME:State)
=B2.select(left(City,1)==Letter)
```

## 内容

### 6.1.2 有返回结果的网格文件

在命令行直接使用 esprocx 命令时，默认情况下结果不会显示在屏幕上。要显示脚本文件的返回结果，在执行时使用 -r 选项。与 call 函数调用的网格文件类似，脚本文件必须使用 return 语句返回结果。以下面的网格文件 D:\files\calculate1.splx 为例：

| | |
|---|---|
| =days(Day) | =string(Day,"EEE") |
| return A1 | return B1 |

此网格将返回指定日期所在月份的总天数，并计算指定日期是星期几。它使用 Day 作为其参数之一：

（原文含示意图，图像资源未迁移）

让我们首先看看使用 -r 选项的执行：

（原文含示意图，图像资源未迁移）

这里没有为执行设置参数，使用默认值 01/01/2000 进行计算。您可以看到 A2 和 B2 分别使用 return 语句返回结果。计算后结果将分别列出。

当我们在 esProc IDE 中执行网格文件并且有多个 return 语句时，执行在第一个 return 语句返回结果后停止。例如，在上述情况下，可以通过在 A2 中写入 return A1,B1 来一次返回多个结果集。这样，当在命令行执行网格文件时，两个结果都将由 A2 返回：

（原文含示意图，图像资源未迁移）

要设置参数，它应该是日期类型。由于日期类型或时间类型的参数有其自己的格式，您需要在位于 esProc 安装目录 esProc\config 路径中的配置文件 raqsoftConfig.xml 中设置格式：

```xml
<esProc>
  <dateFormat>yyyy-MM-dd</dateFormat>
  <timeFormat>HH:mm:ss</timeFormat>
  <dateTimeFormat>yyyy-MM-dd HH:mm:ss</dateTimeFormat>
</esProc>
```

这次您获得了 2012 年 2 月 22 日所在月份的总天数以及该日期是星期几。

| | |
|---|---|
| $(demo) select * from CITIES | $select * from STATES |
| =A1.switch(STATEID,B1:STATEID) | |
| =A2.new(CID,NAME:City,STATEID.NAME:State) | |
| =B2.select(left(City,1)==Letter) | |
| return A3 | |

网格文件使用一个参数 - Letter：

（原文含示意图，图像资源未迁移）

此网格使用数据库数据。这里需要在 esProc 安装目录 esProc\config 路径中的 raqsoftConfig.xml 文件中配置数据库连接：

```xml
<DBList encryptLevel="0">
  <DB name="demo">
    <property name="url" value="jdbc:hsqldb:hsql://127.0.0.1/demo"/>
    <property name="driver" value="org.hsqldb.jdbcDriver"/>
    <property name="type" value="13"/>
    <property name="user" value="sa"/>
    <property name="password" value=""/>
    <property name="batchSize" value="1000"/>
    <property name="autoConnect" value="true"/>
    <property name="useSchema" value="false"/>
    <property name="addTilde" value="false"/>
  </DB>
</DBList>
```

有关详细配置方法，请参阅相关文档。
