### 6.1.3 执行网格脚本和简单 SQL

我们可以在 esprocx 命令后添加 -c 选项来执行输入的网格脚本。在网格脚本中，列用制表符分隔，行用回车分隔。按 Ctrl+C 完成输入并开始执行。例如：

（原文含示意图，图像资源未迁移）

开始执行 esprocx -c 后，输入以下脚本：

```
[] >10.(A1=A1|#)
>output(A1)
```

根据网格脚本，十个数字被添加到 A1 的空序列中，第 2 行将序列导出到控制台。按 Ctrl+C 后，我们在控制台中获得输出结果。

要查看执行网格脚本的结果，常用方法是添加 -r 选项，如下所示：

（原文含示意图，图像资源未迁移）

通过执行 esprocx -r -c，我们获得计算网格脚本的结果。如果网格脚本中没有 return 语句，命令将返回执行最后一个格子的值。

执行简单 SQL 语句时通常使用 -r 选项。有关在命令行执行简单 SQL 的更多信息，请参阅"简单 SQL"。要查询数据库数据，需要首先在 raqsoftConfig.xml 文件中完成某些设置。
