## 内容

### 6.2.1 基本用法

esProc JDBC 类似于没有物理表的数据库 JDBC 驱动程序。它可以简单地被视为仅配备存储过程的数据库。作为完全嵌入式的计算引擎，它独立执行所有计算；而数据库 JDBC 仅作为连接接口，计算在单独的数据库服务器中执行。

要使用该应用程序，首先按照"部署 JDBC"中的说明进行部署。

**esProc JDBC 使用的网格文件**

与使用 call 函数的跨网格调用类似，esProc JDBC 中使用的网格代码通过 return 语句返回结果集，如以下网格文件 createTable1.splx 所示：

| | |
|---|---|
| =create(ID,Amount) | |
| for | >A1.insert(0,#A2,rand(100*100)) |
| return A1 | |

此网格中的计算很简单：创建一个 100 条记录的序表，其中 ID 字段按顺序设置，Amount 字段随机生成。在 A3 中，return 语句返回 A1 的序表。现在我们将使用此网格文件来解释如何通过 Java 调用 esProc JDBC。

**Java 调用的基本方法**

在调用 esProc JDBC 执行网格文件之前，您需要根据以下说明配置相关信息：

1) **加载启动 Java 应用程序所需的 jar 包**（有关 jar 包的信息，请参阅"部署 JDBC"）。对于 WEB 应用程序，这些 jar 包可以放入 WEB-INF/lib 文件夹中。

2) **部署 raqsoftConfig.xml 文件**。该文件包含配置 esProc 的基本信息，包括搜索路径、主路径、数据源配置、并发任务数、日志文件信息和连接池等。该文件位于 esProc 的 [安装目录]\esProc\config 文件夹中，包含与 esProc 选项页面上设置相同的信息。对于部署，可以首先调整其中的配置。

**注意**：配置文件应复制并放入应用程序项目的类路径中。名称必须保持为 raqsoftConfig.xml。更多详情请参阅"部署 JDBC"。

3) **部署脚本文件**。上述 createTable1.splx 可以放入应用程序项目的类路径中，或者放入 raqsoftConfig.xml 的 `<splPathList/>` 节点指定的搜索路径中，或者放入 `<mainPath/>` 指定的主路径中。

4) **在 Java 中调用脚本文件**

```java
public void testDataServer(){
    Connection con = null;
    java.sql.CallableStatement st;
    try{
        // 建立连接
        Class.forName("com.esproc.jdbc.InternalDriver");
        con = DriverManager.getConnection("jdbc:esproc:local://");
        // 调用存储过程；createTable1 是脚本文件的名称
        st = con.prepareCall("call createTable1()");
        // 执行存储过程
        st.execute();
        // 获取结果集
        ResultSet rs = st.getResultSet();
        // 通过打印其字段名和数据来简单处理结果集
        ResultSetMetaData rsmd = rs.getMetaData();
        int colCount = rsmd.getColumnCount();
        for (int c = 1; c <= colCount; c++) {
            String title = rsmd.getColumnName(c);
            if (c > 1) {
                System.out.print("\t");
            } else {
                System.out.print("\n");
            }
            System.out.print(title);
        }
        while (rs.next()) {
            for (int c = 1; c <= colCount; c++) {
                if (c > 1) {
                    System.out.print("\t");
                } else {
                    System.out.print("\n");
                }
                Object o = rs.getObject(c);
                System.out.print(o.toString());
            }
        }
    }
    catch(Exception e){
        System.out.println(e);
    }
    finally{
        // 关闭连接
        if (con!=null) {
            try {
                con.close();
            }
            catch(Exception e) {
                System.out.println(e);
            }
        }
    }
}
```
