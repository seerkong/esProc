### 6.2.2 调用不同的网格文件

"Java 调用的基本方法"解释了如何在 Java 程序中调用网格文件。但是对于不同的网格文件您会怎么做？以下面的网格文件 createTable2.splx 为例：

| | |
|---|---|
| =connect("demo") | |
| =A1.query("select * from EMPLOYEE") | |
| =A2.select(month(BIRTHDAY)==month(Date)&&day(BIRTHDAY)==day(Date)) | |
| >A1.close() | |
| if B2.len()>1 | return B2.new(EID,NAME+ " "+ SURNAME:NAME, GENDER, BIRTHDAY) |
| else | return "None" |

此网格文件从 demo 数据源获取数据，并使用日期类型参数 Date：

网格中使用的 demo 数据源需要在 raqsoftConfig.xml 文件中配置。详细方法请参阅"部署 JDBC"。在网格中建立的数据源连接在完成任务后应使用 db.close() 函数关闭。

对于从 Java 调用该文件，建立连接和输出结果的代码与前面的例子相同。区别在于调用文件的方法：

```java
// 调用存储过程；createTable2 是脚本文件的名称，? 表示参数
st = con.prepareCall("call createTable2(?)");
// 设置参数
java.util.Calendar calendar = java.util.Calendar.getInstance();
calendar.set(1980, 0, 4);
st.setObject(1, calendar.getTime());
// 执行存储过程
st.execute();
// 获取结果集
ResultSet rs = st.getResultSet();
```

此网格文件使用参数。因此，要调用网格，使用 "call createTable2(?)"，其中 ? 表示要赋值的参数。在这种情况下，应使用 st.setObject() 方法传入参数值。对于多个参数，值按顺序赋值，输入值与网格参数的名称无关。我们也可以为指定的参数设置值。为此，我们可以将上述语句修改为 st.setObject("Date", calendar.getTime())。此网格文件将列出生日在参数指定日期的员工。请注意，在 Calendar 类中设置日期时，月份从 0 开始。打印结果如下：

在参数设置期间，参数对象可以根据类型直接输入；但日期类型参数可以以字符串形式输入，esProc 将自动解析：

```java
// 设置参数
st.setObject(1, "1980-1-4");
```

请注意，输入的字符串格式应与 raqsoftConfig.xml 文件中设置的日期格式一致。程序执行后，结果与前面的例子相同。您也可以在语句中使用带有实际值的参数。例如：

```java
// 调用存储过程；createTable2 是脚本文件的名称，语句中的参数是实际值
st = con.prepareCall("call createTable2(\"1980-1-8\")");
// 执行存储过程
st.execute();
// 获取结果集
ResultSet rs = st.getResultSet();
```

使用这种调用方法，参数对象不能根据数据类型设置；它只能使用数值类型或将由 esProc 自动解析的字符串类型。执行上述代码后，结果如下：

由于没有员工出生在 1 月 8 日，B5 使用 return 语句返回字符串 "None"。从上述结果可以看出，即使从网格返回的数据是单个值，也会自动为结果集生成列名，使其成为标准的 ResultSet 返回。
