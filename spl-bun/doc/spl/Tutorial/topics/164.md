### 6.2.3 无返回结果或多个返回结果的网格文件

被调用的网格文件可以没有返回值。以下面的网格文件 outputData1.splx 为例：

| | |
|---|---|
| $(demo) select * from CITIES | |
| =A1.select(Arg.pos(left(NAME,1))>0) | |
| =file("cities.txt") | |
| >A3.export@t(A2) | |

该文件使用参数 Arg，类型为字符串序列：

A1 直接调用 demo 数据库查询数据，而不是首先使用 connect 语句建立连接。在这种情况下，raqsoftConfig.xml 数据库配置中 demo 数据源的 autoConnect 属性应为 true：

```xml
<property name="autoConnect" value="true"/>
```

详细配置请参阅"部署 JDBC"。以下是在 Java 中调用网格文件的代码：

```java
// 调用存储过程；outputData1 是脚本文件的名称
st = con.prepareCall("call outputData1(?)");
// 设置参数
com.scudata.dm.Sequence seq = new com.scudata.dm.Sequence();
seq.add("A");
seq.add("B");
seq.add("C");
st.setObject(1, seq);
// 执行存储过程
boolean hasResult = st.execute();
// 由于没有返回结果，无法获取结果集；hasResult 为 false
```

**注意**：网格文件使用序列类型的参数，只能通过生成 Sequence 对象来设置。如本例所示，设置序列参数 [A,B,C] 用于将首字母为 A、B 和 C 的城市信息写入 cities.txt 文件。如果没有指定存储输出文件的路径，则将其存储在主路径中，该路径由 raqsoftConfig.xml 的 `<mainPath/>` 节点指定。输出文件如下：

网格文件可以返回多个结果集，如 createTable3.splx 所示：

| | |
|---|---|
| $(demo) select EID, NAME+' '+SURNAME FULLNAME, GENDER, STATE, BIRTHDAY from EMPLOYEE | |
| =A1.select(STATE == State && Age(BIRTHDAY)<age) | |
| =A2.select(GENDER=="F") | =A2\A3 |
| return A3 | return B3 |

此网格根据性别将年龄小于指定年龄且来自指定州的员工作为两个序表返回。网格使用两个参数，分别指定最大年龄和员工来自的州：

执行时此网格文件将返回多个结果集。

```java
// 调用存储过程；createTable3 是脚本文件的名称，? 表示参数
st = con.prepareCall("call createTable3(?,?)");
// 按顺序设置参数
st.setObject(1, 30);
st.setObject(2, "California");
// 执行存储过程
boolean hasResult = st.execute();
// 获取多个结果集并打印它们
while (hasResult) {
    ResultSet rs = st.getResultSet();
    // 打印结果
    ResultSetMetaData rsmd = rs.getMetaData();
    int colCount = rsmd.getColumnCount();
    for (int c = 1; c <= colCount; c++) {
        String title = rsmd.getColumnName(c);
        if (c > 1) {
            System.out.print("\t");
        } else {
            System.out.print("\n");
        }
        System.out.print(title);
    }
    while (rs.next()) {
        for (int c = 1; c <= colCount; c++) {
            if (c > 1) {
                System.out.print("\t");
            } else {
                System.out.print("\n");
            }
            Object o = rs.getObject(c);
            System.out.print(o.toString());
        }
    }
    System.out.println();
    // 检查是否有其他返回结果
    hasResult = st.getMoreResults();
}
```
