### 6.2.4 自动执行语句

要在 Java 应用程序中使用 esProc 文件，除了调用网格文件外，您还可以直接执行语句。也就是说，网格文件的调用可以作为 call 语句自动执行。让我们看看如何做到这一点。例如：

```java
// 直接执行语句并返回结果集
st = con.createStatement();
ResultSet rs1 = st.executeQuery("=age(date(\"1/1/1990\"))");
ResultSet rs2 = st.executeQuery("=5.(~*~)");
```

这里使用 executeQuery 方法直接执行以 = 开头的 esProc 表达式并将其结果作为结果集返回。请注意，表达式中括起来的双引号前需要转义字符。如果使用类似代码输出结果集，输出文件如下：

请注意，如果返回的结果是序列，JDBC 将返回一列多行的结果集。还有另一种调用语句的方法：

```java
// 首先判断是否存在结果集；如果有则获取它
boolean hasResult1 = st.execute("=age(date(\"1/1/1990\"))");
ResultSet rs1, rs2;
if (hasResult1) {
    rs1 = st.getResultSet();
}
boolean hasResult2 = st.execute("=5.(~*~)");
if (hasResult2) {
    rs2 = st.getResultSet();
}
```

根据正在执行的语句，execute 函数将返回一个值以显示是否有结果集。该代码在功能上等同于前一个。

如果语句中需要参数，使用运算符 (x1, x2,…) 依次计算表达式并返回最后一个结果。例如：

```java
st = con.createStatement();
ResultSet rs1 = st.executeQuery("=(pi=3.14,r=4,r*r*pi)");
```

语句中使用的参数将根据在 PreparedStatement 中为它们设置的顺序以固定格式 ?1,?2,… 调用。例如：

```java
PreparedStatement pst = con.prepareStatement("=?1*?1*?2");
pst.setObject(1, 3);
pst.setObject(2, 3.14);
ResultSet rs = pst.executeQuery();
```

以 $ 开头的数据集查询语句可以与 esProc JDBC 一起使用。例如：

```java
// 执行数据集查询语句
st = con.createStatement();
ResultSet rs1 = st.executeQuery("$(demo) select * from CITIES where POPULATION > 2000000");
```

esProc JDBC 还支持在一个语句中执行具有多行多列的网格代码。为此，将代码组成一个字符串，行用 \n 分隔，同一行的列用 \t 分隔。请注意，当我们尝试执行多行多列的网格代码块时，代码字符串应以 == 而不是 = 开头。例如：

```java
ResultSet rs = st.executeQuery("==demo.cursor(\"select * from EMPLOYEE order by SALARY desc\")\t=[]\nfor A1;SALARY\n\t>B1.insert(0,A2)\nreturn B1");
```

执行此字符串等同于计算以下网格：

|---|---|

我们还可以在 Java 应用程序中执行简单的 SQL 语句来查询主目录中的数据文件。例如：

```java
st = con.createStatement();
ResultSet rs = st.executeQuery("$select * from cities.txt");
```

与数据集上的查询语句类似，esProc JDBC 中使用的简单 SQL 语句也以符号 $ 开头。区别在于您不需要指定数据源名称。以下是导出的 ResultSet：
