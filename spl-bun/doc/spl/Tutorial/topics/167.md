### 6.3 JDBC 网关

如果您不是专业程序员，可以选择跳过本节。这不会影响您学习本教程的其他内容。

通过 JDBC 调用 esProc 脚本时，我们可以通过配置 splx/spl/dfx 脚本文件创建 SQL 网关，让它处理所有要在 JDBC 中执行的 SQL 语句。网关脚本读入 SQL 语句及其参数，处理数据库连接，然后执行 SQL 并返回结果。以下是网关脚本 executeSQL.splx：

| | |
|---|---|
| =connect("demo") | |
| if args==null \|\| args.len()<2 | >B1=A1.query(sql) |
| else | >B1=A1.query(sql,args(1),args(2)) |
| >A1.close() | |
| return B1 | |

上述两个参数是必需的。第一个传递在调用 esProc 脚本时输入的 SQL 语句。第二个传递执行 SQL 语句时输入的参数。这里最后一个参数设置为动态，以序列形式将 sql 文件中使用的参数值传递给 args。

要使用 JDBC 网关，我们需要在 raqsoftConfig.xml 的 `<JDBC>` 节点下的 `<gateway>` 中指定网关脚本文件。要连接数据源，从 Runtime 或 Server 加载数据源连接配置：

```xml
<JDBC>
  <load>Runtime</load>
  <gateway>executeSQL.splx</gateway>
</JDBC>
```

请参阅"配置 raqsoftConfig.xml"以了解更多关于 JDBC 标签库的信息。

完成所需配置后，在从 Java 调用 esProc JDBC 期间，所有 SQL 语句都将交给网关脚本执行。例如：

```java
// 执行 SQL；问号 (?) 表示参数
st = con.prepareCall("select * from CITIES where STATEID = ? and POPULATION > ?");
// 设置参数
st.setObject(1, 5);
st.setObject(2, 400000);
// 执行存储过程
st.execute();
// 获取结果集
ResultSet rs1 = st.getResultSet();
// 直接执行没有输入参数的 SQL
ResultSet rs2 = con.createStatement().executeQuery("select STATEID,NAME,ABBR,CAPITAL from STATES where STATEID<8");
```

数据源的连接和断开由网关脚本处理。使用默认数据源时，我们可以在执行查询时直接使用其名称，无需处理数据源断开。

如果在 JDBC 中配置了远程服务器，使用网关文件的方式与使用其他数据文件相同：默认情况下，首先使用本地文件进行计算；如果在连接参数中配置了 ?onlyServer=true，则使用服务器端的网关文件。
