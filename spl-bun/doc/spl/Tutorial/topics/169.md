# 6.4.1 基本步骤

## 内容

### 6.4.1 基本步骤

按照以下说明部署 esProc JDBC：

**1) 加载必要的 jar 包**

在启动 Java 应用程序时加载 esProc 所需的 jar 包。在 Web 应用程序环境中，将以下 jar 包放在 WEB-INF/lib 目录下。esProc JDBC 需要两个基本 jar 包，可以在 [安装目录]\esProc\lib 中找到：

- **esproc-bin-xxxx.jar** - esProc 计算引擎和 JDBC 驱动程序（注意：社区版是 esproc-xxxx.jar）
- **icu4j_60.3.jar** - 处理国际化

\esProc\lib 目录下有专门用于某些功能的 jar 包：

- 要使用数据库作为数据源，需要它们的驱动程序 jar 包；hsqldb-2.7.3-jdk8.jar 专门用于 demo 数据库
- 要读写 Microsoft Office 文件需要 poi*.jar 和 xmlbeans-5.2.0.jar
- 要使用图形功能需要用于 SVG 类型图像处理的 jar 包，包括 batik-all-1.16.jar、xml-apis-1.4.01.jar、xmlgraphics-commons-2.8.jar 和 xml-apis-ext-1.3.04.jar

请注意，esProc JDBC 需要 JDK1.8 或更高版本。

**2) 部署 raqsoftConfig.xml 文件**

该文件可以在 [安装目录]\esProc\lib 中找到。它需要复制并放置在应用程序项目的类路径下。文件名应保持原样，不得更改。有关该文件的详细信息，请参阅"配置 raqsoftConfig.xml"。

**3) 部署脚本文件**

将必要的脚本文件放在应用程序项目的类路径中，或者放在 raqsoftConfig.xml 的 `<splPathList/>` 节点指定的搜索路径中，或者放在 `<mainPath/>` 指定的主路径中。

**4) 在 Java 中调用 esProc JDBC**

有关在 Java 中调用脚本文件和直接执行代码的方法，请参阅"Java 调用"。
