### 6.5.1 文件加密

esProc 提供了加密网格文件的方法，以保护它们免受未经授权的访问或使用。有两个级别的加密：

**执行权限**：拥有此权限，用户可以设置参数、执行网格并查看结果格值和网格描述，但不能修改它们。仅拥有执行权限时，用户既看不到格子中的字符串，也看不到任何网格变量。

**完全控制权限**：拥有此权限，用户可以完全访问网格文件并可以执行任何操作。

以下面的网格为例：

| | |
|---|---|
| Minimum Population | |
| $(demo) select * from CITIES | /Get data from table CITIES. |
| $(demo) select STATEID, ABBR from STATES | /Get data from table STATES. |
| =A3.select@1(ABBR==state).STATEID | /Find the STATEID of the given state. |
| =A2.select(POPULATION>B1&& STATEID==A4) | /Find the cities. |
| return A5 | |

在上述网格中，B 列包含注释样式的信息。
