### 6.6.2 启动 ODBC 服务

**启动 GUI 控制台**

在 esProc 的 [安装根目录]\esProc\bin 中，双击 esprocs.exe 文件或 ServerConsole.bat 文件（在 Linux 下，执行 ServerConsole.sh）以弹出 Odbc Server 窗口。

对于企业版，相应的启动文件是 esprocsEE.exe、ServerConsoleEE.bat 或 ServerConsoleEE.sh。执行启动文件时，将弹出以下 Odbc Server 窗口：

（原文含示意图，图像资源未迁移）

选择 Odbc Server 并单击"配置"打开 ODBC Server 窗口：

（原文含示意图，图像资源未迁移）

在上述窗口中，您可以配置端口号、临时文件超时、最大连接数、连接超时和检查间隔。窗口的中间部分是用户管理，您可以在其中配置授权用户及其密码。以下是一个示例：

（原文含示意图，图像资源未迁移）

单击"确定"，esProc 将根据配置的信息自动配置 [安装根目录]\esProc config 下的 OdbcServer.xml 文件。然后单击"启动"启动 esProc ODBC 服务。要停止服务，只需单击"停止"。

要在控制台启动时启用 Odbc Server 自动启动，请选中"自动启动服务器"。

**启动非 GUI 控制台**

在 Linux 下使用非 GUI 控制台，以下是启动方法：在安装根目录下的 esProc\bin 目录中执行命令 ./ServerConsole.sh -o（企业版下为 ./ServerConsoleEE.sh -o）以启动 ODBC 服务。完成 ODBC 服务配置后，我们可以通过 esProc-ODBC 建立 ODBC 连接。

**注意**：esProc ODBC 服务只能在 Linux 下的服务器端启用。
