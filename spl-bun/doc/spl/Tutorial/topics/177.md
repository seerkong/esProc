# 6.7.1 启动 GUI 控制台

## 内容

6.7.1 启动 GUI 控制台

在 esProc 的 [安装根目录]\esProc\bin 目录下，双击 esprocs.exe 文件或 ServerConsole.bat 文件（在 Linux 下执行 ServerConsole.sh）即可弹出 Http Server 窗口。企业版对应的启动文件是 esprocsEE.exe、ServerConsoleEE.bat 或 ServerConsoleEE.sh。执行启动文件后，将弹出以下 Http Server 窗口：

（原文含示意图，图像资源未迁移）

选择 Http Server 并点击 Config 打开 Http Server 窗口进行端口配置：

（原文含示意图，图像资源未迁移）

点击 OK，esProc 将根据配置信息自动配置 [安装根目录]\esProc\config 下的 HttpServer.xml 文件。然后点击 Start 启动 esProc HTTP 服务。要停止服务，只需点击 Stop。

（原文含示意图，图像资源未迁移）

如果在配置窗口中勾选了"Auto start server"，则启动 esProc 服务时 Http Server 将自动启动：
