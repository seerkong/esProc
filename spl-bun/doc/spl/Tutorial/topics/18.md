## 内容摘要

**常量单元格**

保存可以解释为常量的数据字符串的单元格是常量单元格。它的值就是该常量。

常量单元格具有以下类型的值：

| 43.31 | -4.45E3 | abcd | 2010-1-3 | 23:04:23 | raqsoft |

A1 的值被解释为整数；A2 的值为实数；A3 的值按科学计数法为实数；A4 的值为字符串；A5 的值为日期；A6 的值为时间；A7 的值为字符串。

常量单元格中的文本默认以粉色显示。根据格式，单元格值将被解析为相应的数据类型。对于无法识别的格式，值将被解释为字符串类型数据。

注意：3% 格式在任何表达式中都不可接受，但在常量单元格中是可以接受的。

**字符串常量单元格**

字符串常量单元格是保存以单引号 ' 开头的字符串的单元格，表示该单元格具有字符串值。值是单引号后面的字符串。在这种情况下，单引号后面的所有字符都将被解析为字符串类型，不需要任何额外的引号、转义字符等。前面章节已经引用了一个示例：

| 'abc\d | '1234.5 | 1234.5 |

A1 和 A2 中的字符串都以单引号开头，表示值是字符串类型。A3 的字符串自动解释为实数。

**计算单元格**

计算单元格是保存以 = 开头的表达式的单元格。它的值是表达式的结果，可以引用其他单元格的值。

```
=5*(3+2)
=A1*3
=A1/B2+B1
```

计算单元格中的文本默认为黑色。点击执行图标执行代码，您会发现计算单元格的背景变为浅黄色，表示其值已被计算。点击单元格，其值将显示在数值查看区域。这就是计算结果。

（原文含示意图，图像资源未迁移）

在表达式中，您可以使用各种基本运算符来计算单元格值：

- **a + b, a - b, a * b 和 a / b**：表示加、减、乘、除运算。
  - =3*4 → 12
  - =1+2*3 → 7

- **a % b**：获取 a 除以 b 的余数。
  - =121%11 → 0，表示 121 是 11 的倍数，可以被 11 整除
  - =100%7 → 2

- **a \ b**：执行整数除法，使用 a 和 b 的整数部分进行运算，返回结果的整数部分。
  - =11\4 → 2，舍弃结果的小数部分
  - =6.1\2.9 → 3，等于 6\2，结果也是 3

- **s1 + s2**：连接字符串 s1 和 s2。注意，如果字符串与实数相加，字符串将被忽略。
  - ="Stephen"+" "+"Rolfe" → 字符串 "Stephen Rolfe"
  - ="A"+3 → 整数 3，字符串 "A" 被忽略
  - ="A"+string(3) → 字符串 "A3"。如果确实需要连接字符串和实数，请先将实数转换为字符串。

**执行单元格**

执行单元格是保存以 > 开头的字符串的单元格，用于执行某种操作。执行单元格没有值。如果以保留字开头，如 if 和 for，则可以省略 >。

执行单元格可以通过将单元格作为变量引用来为另一个单元格赋值。

**注释单元格**

注释单元格是包含以 / 开头的字符串的单元格。它的值为 null。

注释单元格在执行期间将被忽略。

注释文本默认以绿色显示。
