# 6.8.1 下载、安装和配置 JDBC 企业版

## 内容

6.8.1 下载、安装和配置 JDBC 企业版

在 https://www.esproc.com/download-esproc/ 下载 esProc 企业版安装程序并安装。安装完成后，在 [安装目录]\esProc\lib 中可找到企业版 JDBC 使用的基本 jar 包。与其他 esProc 版本不同，企业版专用的 jar 文件 esproc-ent-xxxx.jar 是必需的。如果要使用扩展功能，需添加功能 jar 包 esproc-ext-xxxx.jar。

除了 [安装目录]\esProc\config\raqsoftConfig.xml 外，用于部署 JDBC 企业版的文件也可在 q-server\webapps\qvs\WEB-INF\home 中找到。这两个配置文件内容相似，但后者用于服务器加载，不会在 esProc 版本更改时自动调整。您需要根据需要自行编辑。

阅读《Scudata 云部署》了解更多关于 esProc 企业版服务器的信息。
