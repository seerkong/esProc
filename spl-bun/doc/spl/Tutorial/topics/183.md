## 内容

6.8.4 通过 JDBC 调用远程服务器

使用 esProc 企业版 JDBC 时，我们可以调用远程服务器执行计算。查阅《服务器集群》了解更多关于远程服务器的配置和启动信息。要通过 JDBC 调用远程服务器，需要在配置文件 raqsoftConfig.xml 中的 <JDBC> 节点下的 <Units> 中配置每个远程服务器的 IP 和端口号：

```xml
<JDBC>
    <load>Runtime</load>
    <gateway>executeSQL.splx</gateway>
    <Units>
        <Unit>192.168.0.197:8281</Unit>
    </Units>
</JDBC>
```

现在远程服务器配置完成。之后在 Java 应用程序中通过 JDBC 调用脚本时，除非出现某些问题（如缺少数据文件），否则计算将在本地执行。在这些情况下，计算将在远程服务器上执行。要在远程服务器上执行计算，需在连接字符串中添加参数 ?onlyServer=true。例如：

```java
Class.forName("com.esproc.jdbc.QDriver")
con = DriverManager.getConnection("jdbc:esproc:q:local://onlyServer=true")
st = con.createStatement()
ResultSet rs1 = st.executeQuery("=5.(~*~)")
ResultSet rs2 = st.executeQuery("select * from cities.txt where CID<30")
```
