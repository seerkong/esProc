6.8.4 QVS 和 QJDBC

安装 esProc 企业版后，产品安装目录下有完整的 QVS 项目，也称为 esProc 企业版多功能服务器。该项目所在的具体目录是 [安装目录]\esProc\q-server。在 [安装目录]\esProc\q-server\lib 中，有 esProc 企业版和 QJDBC 使用的基本 jar 文件。除此之外，您还需要 ecloud-xxxx.jar 来为 esProc 企业版部署云存储功能。

QVS 启动文件是 StartQVS.bat（Linux 下为 StartQVS.sh），位于 [安装目录]\esProc\bin。本地 QVS 服务器默认会自动启动。访问《Scudata SPL 云部署》了解更多信息或更改现有配置。以下是成功启动后的 QVS 界面：

QJDBC 是内置 QVS 功能的 JDBC 企业版。其驱动类是 com.esproc.jdbc.QDriver，URL 是 jdbc:esproc:q:local://。启动 QJDBC 后可以直接使用以下函数。

| =Qconnect("http://localhost:8090/qvs":"demoqvs",30,300) |
| =Qdirectory("test/") |
| =Qfile("test/cities.txt") |
| =A3.import@t() |
| =Qenv("arg1", "Sale") |
| =Qenv("arg1") |
| =A1.exec@x("test/FindEmployees1.splx";A6) |
| >A1.close() |

A1 执行 Qconnect(url:v, wt, it) 连接到指定 URL 的 QVS 服务器；验证码是 demoqvs，最大等待时间是 30 秒，最大空闲时间是 300 秒。连接后即可执行远程服务。

A2 使用 Qdirectory(path) 函数获取指定路径下所有文件的名称列表。

A3 使用 Qfile(fn) 函数检索指定文件并返回文件对象。然后可以进一步计算，例如将文件数据导入序表。

A5 使用 Qenv(name, value) 函数设置全局变量，A7 读取全局变量。

| $(demo) select * from EMPLOYEE where DEPT = ?;arg1 |
| >output("before return") |
| return A1 |

上述示例代码中使用的 Qconnect()、Qdirectory()、Qfile() 和 Qenv() 是执行 QJDBC 的函数，也称为 Q 函数。QJDBC 支持的其他 Q 函数有 Qmove()、Qload() 和 Qlock()。访问《函数参考》了解更多信息。

除了使用 Q 函数访问 QVS 外，我们还可以使用 esProc 企业版中的远程服务器。在《esProc 企业版中部署和使用 RSRV》中查找更多相关内容。
