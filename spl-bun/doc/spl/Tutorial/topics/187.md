# 7.1.1 什么是游标

## 内容

7.1.1 什么是游标

在数据库上使用游标可以分批返回数据，而无需一次性将所有数据检索到内存中。游标就像一个指针，通过移动位置每次从结果集中检索一行。这种逐行检索数据的机制通常用于处理无法完全加载到有容量限制的内存中的大数据表。

与直接返回整个结果相比，数据库游标足够灵活，可以避免内存溢出，但在处理数据检索时相对较慢。

然而，esProc 游标与数据库游标之间存在差异：

1) esProc 游标仅用于获取数据，不会修改结果集。

2) esProc 游标只能向前遍历数据一次，这类似于 JDBC 中的 TYPE_FORWARD_ONLY 设置。

3) esProc 游标可以基于数据库表、数据文件或内存记录序列创建。

不同类型的 esProc 游标具有相似的用途，可以组合使用以满足需求。
