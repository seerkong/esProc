7.1.2 数据库游标

db.cursor(sql) 函数可以将从数据库返回的数据转换为游标：

| =demo.cursor("select * from EMPLOYEE") |
| =A1.fetch(100) |
| =A1.fetch(100) |
| >A1.close() |

A1 创建数据库游标。A2 从中获取前 100 条记录，如下所示：

cs.fetch() 函数将从游标获取的数据作为序表返回。

A3 继续按顺序从结果集中获取另外 100 条记录，因为 esProc 只允许以向前方式单次遍历数据：

（原文含示意图，图像资源未迁移）

从员工 ID 可以看出，A3 从第 101 个员工开始获取记录。这只是使用 cs.fetch() 函数从游标获取数据的示例。有关 esProc 游标的更多信息，请参阅《游标的基本用法》。

如果数据获取结束时游标中的数据尚未全部取出，请使用 cs.close() 关闭游标。及时关闭游标非常重要，特别是数据库游标。因为数据库游标从数据库获取数据，它的存在意味着与数据库的连接保持，会造成不必要的内存使用，甚至超出数据库允许创建的游标数量。

与用于数据查询的 db.query() 函数类似，数据库游标创建也允许使用参数。例如：

| =demo.cursor("select EID, NAME, SURNAME, GENDER, STATE from EMPLOYEE where GENDER=? and EID>?","F",100) |
| =A1.fetch() |

在 SQL 语句中，参数用问号 (?) 表示，其值在语句后按顺序输入并用逗号分隔。A1 的游标返回 EID 大于 100 的女性员工。A2 返回 A1 游标中的所有记录：

（原文含示意图，图像资源未迁移）

A2 中的 cs.fetch() 函数没有指定要返回的记录数，因此返回游标中的所有记录。当游标中的数据全部取出后，游标将自动关闭，无需调用 cs.close()。
