7.1.3 外部文件游标

在实际应用中，特别是在大数据处理过程中，数据通常来自文件而非数据库。鉴于此，esProc 提供了使用游标从外部结构化文件检索数据的功能。例如，以下文本文件 PersonnelInfo.txt 包含大量人员信息：

（原文含示意图，图像资源未迁移）

在此文件中，每行包含一条记录，列之间用制表符分隔。游标用于从此外部文件检索数据，并将其也作为游标返回。例如：

| =file("PersonnelInfo.txt") |
| =A1.cursor@t() |
| >A2.skip(50000) |
| =A2.fetch(100) |
| >A2.close() |

A2 基于外部文件创建游标，并使用 @t 选项将文件的第一行作为结果集的列名。A3 跳过 A2 游标的前 50,000 行，然后 A4 获取 100 行：

（原文含示意图，图像资源未迁移）

与数据库游标一样，从外部文件游标获取数据是通过单次向前遍历完成的。因此，在 A3 使用 cs.skip() 跳过某些行后，A4 中的数据获取从第 50,001 行开始。您还可以指定文件的某些字段来创建游标：

| =file("PersonnelInfo.txt") |
| =A1.cursor@t(ID, Name, State, Gender) |
| >A2.skip(50000) |
| =A2.fetch(100) |
| >A2.close() |

这个示例在 A2 中使用指定字段创建外部文件游标。从 A4 获取数据：

（原文含示意图，图像资源未迁移）

注意：只有在使用 @t 选项导入字段名后，才能使用它们来指定字段。如果没有该选项，只能通过位置直接指定字段，如 =A1.cursor(#1, #2, #6, #3)。
