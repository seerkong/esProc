7.1.4 从游标返回纯序表

本节介绍的功能仅在 esProc 企业版中提供。使用其他版本的用户可以跳过本节。

与 db.query@v(sql) 类似，cs.fetch() 在查询游标中的数据时，也可以使用 @v 选项返回纯序表。例如：

| =demo.cursor@v("select EID, NAME, BIRTHDAY from employee") |
| =A1.fetch(20) |
| =ifpure(A2) |
| =A1.fetch@x(20) |
| =ifpure(A3) |
| =file("PersonnelInfo.txt") |
| =A4.cursor@tv(ID, Name, State, Gender) |
| >A5.skip(90000) |
| =A5.fetch@x(100) |
| =ifpure(A6) |
