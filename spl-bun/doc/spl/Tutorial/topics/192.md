# 7.2.1 数据获取

## 代码片段
```spl
=file("Order_Books.txt")
=A1.cursor@t()
=A2.fetch(1000)
>A2.close()
=A2.fetch(1000)
=file("Order_Books.txt")
=A1.cursor@t()
>A2.skip(45000)
=A2.fetch()
=A2.fetch(1000)
=file("Order_Books.txt")
=A1.cursor@t()
=A2.fetch(;Date)
=A2.fetch(1000)
>A2.close()
=file("Order_Books.txt")
=A1.cursor@t()
>A2.skip(;Date)
>A2.skip(;Date)
>A2.skip(;Date)
=A2.fetch(1000)
>A2.close()
```

## 内容

7.2.1 数据获取

创建游标后，可以使用 cs.fetch() 函数获取其数据。与普通表不同，通常不会一次性获取游标中的所有数据；而是通过指定要返回的行数或一个或多个数据获取条件来获取。例如：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| =A2.fetch(1000) |
| >A2.close() |
| =A2.fetch(1000) |

使用 fetch 函数，从游标获取的每批数据将作为序表返回。A4 调用 cs.close() 函数关闭游标。当游标关闭时，无法从中获取数据。这就是 A5 的结果为 null 的原因：

（原文含示意图，图像资源未迁移）

当游标完成其任务且不再需要时，应通过调用 cs.close() 函数关闭它以释放内存。

除了通过游标从文件或数据库结果集获取数据外，还可以使用 cs.skip() 函数跳过游标中指定数量的行。例如：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| >A2.skip(45000) |
| =A2.fetch() |
| =A2.fetch(1000) |

A2 创建游标，A3 跳过 45,000 行。然后 A4 从游标获取数据：

（原文含示意图，图像资源未迁移）

根据交易 ID，数据获取从第 45001 行开始。请注意，A4 中的 fetch 函数没有指定要返回的行数。在这种情况下，将获取游标中所有剩余的数据。一旦游标中的数据全部取出，游标将自动关闭，无需调用 cs.close() 函数。因此 A5 无法从 A2 的游标获取任何数据：

（原文含示意图，图像资源未迁移）

实际上，cs.skip() 函数和 cs.fetch() 函数都会以向前方式单次遍历游标数据。当数据获取结束或执行 cs.close() 函数时，游标就变得无用了。

另一种使用 cs.fetch() 函数从游标获取数据的方式是 cs.fetch(;x)，它指定条件，根据该条件数据获取将持续进行，直到表达式 x 的值发生变化。例如：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| =A2.fetch(;Date) |
| =A2.fetch(1000) |
| >A2.close() |

（原文含示意图，图像资源未迁移）

A3 获取所有 Date 值为 2013-01-01 的数据。当 A4 继续从 A2 的游标获取数据时，将从日期 2013-01-02 开始：

（原文含示意图，图像资源未迁移）

请注意，不应同时指定要返回的行数和数据获取条件；否则只有后者有效。此外，由于 A2 游标中的数据尚未全部取出，因此在完成工作后需要在 A5 中关闭游标。

同样，也可以在 cs.skip() 函数中指定条件来跳过某些记录：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| >A2.skip(;Date) |
| >A2.skip(;Date) |
| >A2.skip(;Date) |
| =A2.fetch(1000) |
| >A2.close() |

A2 创建游标。A3、A4 和 A5 分别跳过一天的记录。然后 A6 从第四天开始从游标获取数据：

（原文含示意图，图像资源未迁移）

同样，如果游标中的数据尚未全部取出，需要在 A7 中调用 cs.close() 函数关闭游标。
