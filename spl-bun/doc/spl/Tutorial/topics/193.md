7.2.2 游标循环

for 语句可用于通过循环从游标获取数据。例如：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| for A2,1000 |
| =A3.select(SalesID==1).sum(Amount) |
| >B2=B2+B3 |

A2 创建游标。A3 循环遍历游标的记录，每次获取 1000 条记录。遍历完所有记录后，游标将自动关闭。A3 的代码块根据游标返回的每个序表计算 ID 号为 1 的销售人员的总销售额，并将结果存储在 B2 中。最终结果如下：

但有时游标循环不需要遍历所有记录。例如：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| [] |
| for A2,1000 |
| =A3.select(SalesID==1) |
| >B2=B2|B3 |
| if B2.len()>=5 |
| >B2=B2(to(5)) |
| break |
| >A2.close() |

A2 创建游标，A3 执行游标循环，每次获取 1,000 条记录。A3 的代码块根据从游标获取的每批数据选择 ID 号为 1 的销售人员的销售记录，并将其存储在 B2 中。获取前 5 条记录后退出循环。此时 B2 中的结果如下：

特别值得注意的一点：当计算结束并通过 break 函数终止循环时，游标中仍有数据，这与前一个示例不同。因此游标不会自动关闭，需要在 A6 中调用 close 函数关闭它并释放内存。

与 cs.fetch() 和 cs.skip() 类似，可以为游标循环指定条件，以便在条件表达式的值发生变化时立即停止数据获取。例如：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| =create(Date,Count,Amount) |
| for A2;Date |
| =A3.count() |
| =round(A3.sum(Amount)) |
| >B2.insert(0,A3.Date,B3,C3) |
