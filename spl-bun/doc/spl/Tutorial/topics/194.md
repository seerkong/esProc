## 内容

7.2.3 基于游标的操作

除了从游标获取数据外，esProc 还提供直接使用某些函数执行常见数据计算的功能。以下示例是基于游标的条件查询：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| =B1.select(SalesID==1) |
| =A2.fetch() |
| =A2.fetch() |
| =B1.fetch() |

B1 创建外部文件游标，A2 从 B1 的游标中选择 ID 号为 1 的销售人员的销售数据。以下是 A2 的结果：

（原文含示意图，图像资源未迁移）

可以看到 A2 和 B1 得到相同的结果。与序表或记录序列的 select 函数不同，与游标一起使用的 select 函数返回游标本身。A2 的操作实际上并没有从游标获取数据。它实际上是一个捆绑操作。在 B2 执行 cs.fetch() 函数时，才根据条件从 B1 的游标查询和获取数据。以下是 B2 的结果：

（原文含示意图，图像资源未迁移）

B2 中使用的 cs.fetch() 函数没有指定要返回的行数或数据获取条件。因此将返回 A2 游标中的所有数据，即指定销售人员的所有销售数据，游标将自动关闭。A2 中的游标等同于 B1 中的游标，实际上在数据查询期间，遍历的是 B1 的游标数据，在此期间执行捆绑的数据获取。因此当 A2 游标中的数据取出后，B1 的游标也将取出并关闭。因此 A3 和 B3 尝试从 A2 和 B1 的游标获取数据肯定会失败。

如果文件中的数据已排序，可以使用 f.iselect(A,x,Fi,...;s) 或 f.iselect(a:b,x,Fi,...;s) 选择数据生成游标，这样更高效。例如：

| =file("Order_Books.txt").iselect@t(["S020000012 ", "S020000022"],ID; ID,PID,Date,Amount) |
| =A1.fetch() |
| =file("Order_Books.txt").iselect@ti(date(2013,2,1): date(2013,2,28),Date; ID,PID,Date,Amount) |
| =A2.fetch@x(100) |

由于文件包含字段名，使用 @t 选项。同样，如果是 bin 文件，可以添加 @b 选项。A1 使用 f.iselect(A,x,Fi,...;s) 按订单 ID 获取销售记录。默认情况下，iselect 函数在执行搜索时要求所需数据是唯一的。A2 使用带有 @i 选项的 f.iselect(a:b,x,Fi,...;s) 函数搜索指定时间段内的销售记录，表示可能有多个 Date，所有符合条件的记录都将返回。执行时，B1 和 B2 得到以下结果：

（原文含示意图，图像资源未迁移）

您还可以基于游标创建新记录或追加新字段。例如：

| =file("employee.txt") |
| =A1.cursor@t(EID, NAME,SURNAME, GENDER, STATE,BIRTHDAY) |
| =B1.new(EID, NAME+" "+SURNAME:FullName, GENDER,STATE,BIRTHDAY) |
| =B1.derive(age(BIRTHDAY):Age) |
| =A2.fetch(100) |
| =B2.fetch(100) |
| >A2.close() |
| =B2.fetch() |
| >B2.close() |

B1 使用外部文件 employee.txt 的部分字段创建文件游标。A2 通过连接 B1 游标中的 NAME 字段和 SURNAME 字段生成员工全名。B2 根据 B1 游标中的 BIRTHDAY 字段计算每个员工的年龄，并将结果输入 Age 字段。与 cs.select() 类似，cs.new() 和 cs.derive() 都返回游标，而不是直接返回数据。执行时，A2 和 B2 的游标值与 B1 相同：

使用 cs.new() 函数生成数据意味着对每条记录执行 new 语句。以下是从 B3 获取的前 100 行：

（原文含示意图，图像资源未迁移）

使用 cs.derive() 函数生成数据意味着将计算列追加到返回的序表。

B3 的数据与 A3 的数据具有相同的结构。它从第 101 个员工开始。这是因为 A2 和 B2 都与其游标有捆绑操作，同时都从同一个游标获取数据，而游标只能向前遍历一次。A3 执行后，前 100 行已被遍历。因此 B3 在执行 cs.fetch() 函数时只能从第 101 个员工开始按顺序继续遍历。

但由于两个游标中的数据都尚未全部取出，需要使用 cs.close() 函数关闭它们。当 A4 关闭 A2 中的游标时，B1 中的游标也同时关闭，因为 A2 和 B1 实际上是同一个游标。因此尝试获取更多数据会失败。

此外，cs.run() 函数可用于修改游标中某个字段的值：

| =file("employee.txt") |
| =A1.cursor@t(EID, NAME,SURNAME, GENDER, STATE,BIRTHDAY) |
| =demo.query("select STATEID, NAME, ABBR from STATES") |
| =B1.run((a=STATE,STATE=A2.select@1(NAME==a).ABBR)) |
| =B2.fetch(100) |
| >B2.close() |

与序表类似，游标允许使用 cs.switch() 函数在其某个字段与另一个序表中的相应记录之间进行切换。例如：

| =file("employee.txt") |
| =A1.cursor@t(EID, NAME,SURNAME, GENDER, STATE,BIRTHDAY) |
| =demo.query("select STATEID, NAME, ABBR from STATES").keys(STATEID) |
| =B1.switch(STATE,A2:NAME) |
| =B2.fetch(100) |
| >B2.close() |

cs.switch() 函数可以转换游标的多个字段。例如：

| =file("employee.txt") |
| =A1.cursor@t(EID, NAME,SURNAME, GENDER, STATE,BIRTHDAY) |
| [F,Female,M,Male] |
| =create(ID,Gender).record(A2).keys(ID) |
| =demo.query("select STATEID, NAME, ABBR from STATES").keys(STATEID) |
| =B1.switch(GENDER,B2;STATE,A3:NAME) |
| =B3.fetch(100) |
| >B3.close() |

《主键和索引》解释了 switch 函数在普通序表中的使用，这与外存计算中 cs.switch() 的使用类似。两个函数都会为维度表的某些字段创建索引表以提高效率。在使用游标时采用这种处理方法更为重要，因为通常处理的数据量很大。
