## 内容

7.3.1 单游标分组和聚合

最常见的分组和聚合操作是计数和求和。此外，还有其他操作，如查找最大值和最小值以及 top-n 数据项。cs.groups() 函数用于基于游标的数据汇总，各种聚合操作通过 count/sum/max/min/top/avg/iterate/icount/median 函数执行。例如：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t()) |
| =A5.merge(Date) |
| =A6.groups(Type;count(~):OrderCount,max(Amount):MaxAmount,sum(round(decimal(Amount),2)):Total) |

A7 按产品汇总数据，并计算每种产品的订单总数、最大交易金额和总金额。需要注意的一点是，双精度数据的精度通常不够。因此应使用 decimal() 函数将其转换为大十进制类型。在基于游标的分组和聚合操作中，游标中的所有记录将被遍历一次。在这一次遍历中，将执行涉及每条记录的分组操作和每组记录的聚合，并且可以处理多种类型的聚合。遍历完成后游标将自动关闭。

从结果可以看出，测试文本数据中每种产品有 50,000 条订单记录。每个文件的数据和 A6 游标的数据都按 Date 排序，但未按 Type 排序。在原始文本文件和 A6 的游标中，数据按 Date 排序但未按 Type 排序。但根据示例中 cs.groups() 函数的使用，它在游标中分组和聚合数据时不要求数据按分组值排序；它会自动按分组值对分组和聚合的结果进行排序。此外，由于 cs.groups() 返回序表，因此在对游标数据进行分组和聚合时，结果集不能超过内存大小——它不适用于结果集包含大数据的情况。

查找 top n 也是聚合操作之一。为此，使用聚合函数 top：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t()) |
| =A5.merge(Date) |
| =A6.groups(Type;top(3,Amount):MinAmount,top(3,-Amount):MaxAmount) |

A7 根据每种产品的订单查找总额最小的后 3 个订单金额和总额最大的前 3 个订单金额。请注意，在查找前 3 个订单金额时，聚合函数中添加了负号，即 top(3,-Amount)。
