## 内容

7.3.2 多游标聚合

处理多个游标的聚合操作时，可以先计算每个游标的聚合结果：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t()) |
| =A5.(~.groups(Date;count(~):Count,sum(round(decimal(Amount),2)):TotalAmount)) |

A6 分别对每个文件游标进行分组和聚合，计算每种产品的每日聚合值：

（原文含示意图，图像资源未迁移）

因为 cs.groups() 函数在执行分组和聚合时会按分组值对游标数据进行排序，所以无论原始数据以何种顺序排列，聚合每种产品的结果序表始终按 Date 排序。因此，可以进一步合并结果以计算所有产品的每日聚合值：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t()) |
| =A5.(~.groups(Date;count(~):Count,sum(round(decimal(Amount),2)):TotalAmount)) |
| =A6.merge(Date) |
| =A7.groups(Date;sum(Count):Count,sum(round(decimal(TotalAmount),2)):TotalAmount) |

由于每个文件中每种产品的数据已按 Date 排序，因此可以先合并游标然后再聚合：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t()) |
| =A5.merge(Date) |
| =A6.groups(Date;count(~):Count,sum(round(decimal(Amount),2)):TotalAmount) |

如您所见，此方法得到的结果与上述方法相同。对于数据按相同值排序的游标，先执行合并，然后再进行分组和聚合会更简单、更有效。请注意 merge 和 mergex 之间的区别。A.merge() 按一定顺序合并多个序列的成员或多个序表的记录，并返回一个序列。计算在函数执行完成时完成；而 CS.merge() 按一定顺序合并多个游标的记录，返回一个游标，并在从合并的游标获取数据时开始计算。两个函数都要求序列 A 和游标 CS 中的数据是有序的。关于如何使用 merge 的详细讨论将在《游标的合并和连接操作》中介绍。
