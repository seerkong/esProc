## 内容

7.4.1 按一定顺序合并数据

大多数情况下，源数据存储在多个表中，例如不同产品的销售记录和不同部门员工的档案。在这些情况下，需要合并来自多个数据表的数据以供使用。对于具有相同结构的多个普通序表，esProc 提供 A.conj() 或 A.merge(x) 函数将它们的记录合并成一个记录序列。对于包含大数据的数据表，使用 CS.conj() 和 CS.merge(x) 函数按一定顺序组合游标序列 CS 中相应游标的数据，从而可以获取数据。

由于游标中的数据只会被遍历一次，并且通常会逐步获取，因此在多个游标的数据合并并全部取出后执行排序是不可行的。因此，在合并多个游标时，每个游标中的数据必须以相同的方式按要求排序。

现在让我们通过示例了解 CS.conj() 和 CS.merge(x) 的用法和区别。首先，让我们看一个关于合并的简单案例。

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t()) |
| =A5.conjx() |
| for |
| =A6.fetch(B6) |
| if B7==null |
| break |
| =B7(1).Type |
| =B7(B6).Type |
| if B9!=C9 |
| break |
| >A6.close() |

有四个文本文件分别记录葡萄酒、电器、食品和书籍的订购信息。A6 连接来自四个文件游标的数据。为了找出数据检索的顺序，每次检索 300 条记录，一旦出现不同产品的记录就停止检索。B7 中的结果序表如下：

从结果可以看出，对于合并的游标，在第一个文本数据表中的所有葡萄酒数据检索完毕后，接着是第二个文本数据表中的电器数据。换句话说，使用 CS.conj() 函数合并数据后，结果游标中的记录将按照游标序列 CS 中游标的排列顺序检索。

但更多情况不仅仅需要将数据表中的记录一个接一个地合并，而是需要按一定顺序合并它们。CS.merge(x) 就是用于此目的的函数。它要求游标序列 CS 中每个游标的记录必须已按表达式 x 排序。例如，按销售日期对各种产品的订单数据进行排序和合并：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t()) |
| =A5.merge(Date) |
| for |
| =A6.fetch(B6) |
| break |
| >A6.close() |

此程序的目的是了解从按一定顺序排序的合并游标中检索记录的顺序。只检索前 300 条记录，B7 中的序表如下：

（原文含示意图，图像资源未迁移）

数据按指定的 Date 获取。在 1 月 1 日的所有葡萄酒数据取出后，开始获取同一天的所有电器数据。因为从游标获取数据是向前方向的，所以每个游标中的订购数据必须事先按 Date 排序。使用函数 CS.merge() 按指定顺序将多个游标合并成一个大游标后，将根据指定表达式的值从游标序列 CS 中的相应游标获取数据，从而获得按指定顺序排序的结果。实际的数据获取将只遍历每个文件游标的数据一次。

按一定顺序合并多个游标中的数据只是创建一个大游标，并调整从每个游标获取数据的顺序，而不添加或删除任何记录。如果游标数据不是所需的顺序，则必须在合并之前进行排序，如以下示例所示：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t().sortx(PID)) |
| =A5.merge(PID) |
| for |
| =A6.fetch(B6) |
| break |
| >A6.close() |

在按 PID 合并游标之前，每个游标中的数据必须已按 PID 排序。这就是为什么 A5 使用 cs.sortx() 函数对与产品对应的每个游标中的数据进行排序。

请注意，对游标中的数据进行排序的方式与对序表中的数据进行排序的方式不同。游标包含大量数据，无法一次性全部加载到内存中进行排序。因此，数据将按指定的数量分批获取和排序。每批排序后的数据将保存为临时数据文件。一旦数据全部取出并排序，临时数据文件将按相同顺序合并并作为游标返回。有关排序游标数据的详细信息，请参阅《外存排序方法》。
