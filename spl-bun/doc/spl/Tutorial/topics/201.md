## 内容

7.4.2 基于游标的对齐连接

cs.switch() 函数可用于将游标与序表连接。但有时，统计数据分析需要连接来自多个游标的数据，这类似于连接多个数据表。

通常无法从游标检索所有数据，那么如何处理多个游标的连接呢？esProc 提供 joinx() 函数来完成此操作。例如：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =A1.groupx(Type,Date;count(~):Count,sum(round(decimal(Amount),2)):TotalAmount;100) |
| =A2.groupx(Type,Date;count(~):Count,sum(round(decimal(Amount),2)):TotalAmount;100) |
| =A3.groupx(Type,Date;count(~):Count,sum(round(decimal(Amount),2)):TotalAmount;100) |
| =A4.groupx(Type,Date;count(~):Count,sum(round(decimal(Amount),2)):TotalAmount;100) |
| =joinx@1(A5:Wines,Date;A6:Electronics,Date;A7:Foods,Date;A8:Books,Date) |
| =A9.fetch(25) |
| >A9.close() |

A5~A8 对每种产品执行聚合操作，并为每个临时文件返回一个游标（有关 groupx 函数的详细说明，请参阅《大结果集的外存分组方法》）。A9 通过将每种产品的数据与日期对齐来连接各种产品的每日销售数据。然后 A10 获取前 25 天的统计结果：

（原文含示意图，图像资源未迁移）

游标的对齐连接也返回游标。从结果游标检索的数据表的每条记录都具有记录类型的字段值。这类似于序表之间连接的结果，与具有非记录类型字段值的数据表中的记录相比，每条记录会使用更多内存。需要注意的是，对于记录类型值，使用结果游标数据进行操作（特别是连接）的表达式格式。

对游标执行对齐连接的结果可以重复用于数据处理，如过滤或生成数据。例如：

| =joinx@1(A5:Wines,Date;A6:Electronics,Date;A7:Foods,Date;A8:Books,Date) |
| =A9.select(Foods.TotalAmount>Wines.TotalAmount) |
| =A10.new(Foods.Date:Date,Foods.TotalAmount:Foods,Wines.TotalAmount:Wines) |
| =A11.fetch(100) |
| >A11.close() |

（原文含示意图，图像资源未迁移）

在执行基于游标的对齐连接时，您应该记住游标数据只能以向前方向遍历一次，并且无法获取到内存中存储。因此，被连接的多个游标中的每个游标的数据必须已经以相同的方式排序，这与处理多数据库表连接和普通序表的 join() 操作不同。在上面的示例中，A5~A8 中所有游标的数据都按 Date 排序以确保正确连接。为了更好地解释这一点，使用两个小型内存序表生成游标：

| $select * from CITIES |
| $select * from STATES |
| =A1.cursor() |
| =A2.cursor() |
| =joinx(A3:City,STATEID;A4:State,STATEID) |
| =A5.fetch() |

通常，将游标与另一个游标连接的目的是从中获取某些信息，如上例中连接的目的是从序表中获取员工所属州的全名。在这种情况下，除了连接操作外，另一种方法是使用 cs.switch() 函数，它可以将游标 cs 的相关字段的值转换为序表的相应记录。该函数的使用在《游标的基本用法》中介绍。joinx() 和 cs.switch() 之间的区别在于前者连接来自不同游标的记录，而后者在游标的某个字段与用作维度表的序表或序列之间建立外键关系。用于连接游标的 joinx() 函数要求其数据按连接字段排序。cs.switch() 没有这样的要求，因为可以直接从内存引用相应的维度表。

我们还可以将游标连接到可分段的 bin 文件：

| =file("PersonnelInfo.txt") |
| =A1.cursor@t(ID,Name,City,State) |
| $(demo) select * from STATES order by ABBR |
| =file("StateFile.btx") |
| >A4.export@b(A3;ABBR) |
| =A2.joinx(State,A4:ABBR,NAME:SName,CAPITAL:SCapital;10000) |
| =A6.fetch(100) |
| >A6.close() |

A5 根据数据库中的州数据生成可分段的 bin 文件 StateFile.btx。bin 文件应按连接键排序，在本例中是 ABBR 字段。A6 使用 cs.joinx(C:..., f:K:..., x:F,...;...;n) 函数连接游标和 bin 文件。该函数将游标 cs 的 C:... 字段与 bin 文件 f 中的键 K:... 匹配以找到每个对应的记录，在记录上计算表达式 x，并将结果作为 F 字段值添加到游标。参数 n 设置最大缓冲行数。该函数只要求 bin 文件按键排序。A6 通过州缩写从包含州数据的 bin 文件中找到匹配的州记录，获取州名及其首府以形成两个新字段——Sname 和 SCapital。A7 从 A6 获取前 100 条记录：

要向游标追加字段，在建立外键关系时有时会使用复合外键来引用序表或另一个游标的记录。在这些情况下，使用 cs.join() 函数来完成。例如：

| =file("PersonnelInfo.txt") |
| =A1.cursor@t() |
| $(demo) select STATEID, NAME,ABBR from STATES |
| =create(Month,State,GroupID) |
| >A3.(12.((m=~,A4.insert(0,m,A3.ABBR,A3.ABBR+string(m))))) |
| =A2.join(month(Birthday):State,A3:Month:State,GroupID:Group) |
| =A6.fetch(100) |
| >A6.close() |
