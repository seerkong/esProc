7.5 大结果集的外存分组方法

从数据表导入数据后，通常可能需要按要求进行分组，或者需要聚合操作。在 esProc 中，groups 函数可以直接计算聚合结果；group 函数用于先对数据进行分组，然后进行进一步的分析和计算。

然而，对于大数据处理，记录无法一次性全部加载到内存中进行分组；有时分组很大，分组和聚合结果无法一次性返回。这两种情况都需要使用外存分组。

让我们创建一个包含员工信息的大型简单数据表，其中包括三个字段：员工 ID、州和生日。员工 ID 将按顺序生成；州以从 demo 数据库的 STATES 表中任意获取的缩写形式输入；生日是在 1994-1-1 之前 10,000 天内任意选择的日期。为方便起见，数据表将存储为 bin 文件。

| =file("BirthStateRecord.btx") |

| =demo.query("select ABBR from STATES") |

大多数情况下，对游标数据进行分组时，需要的是聚合结果，而不是每组中的详细数据。例如，要从 BirthStateRecord 获取每个州的员工数量，可以使用 groups 函数来完成：

| =file("BirthStateRecord.btx") |
| =A1.cursor@b() |
| =A2.groups(State;count(~):Count) |
| >A2.close() |

请注意，用于分组和聚合的 groups 函数在计算完成后返回序表作为结果。在大数据处理过程中，有时分组很多，结果集太大而无法一次性返回。实际案例包括电信公司根据某些分组条件计算的客户账单，以及网上商城中按某些条件分组的各种产品的销售信息等。在这些情况下，使用 groups 函数可能会导致内存溢出。或者，可以使用 groupx(x:F,...;y:F,...) 函数通过将结果集临时存储在外存中来执行分组和聚合。例如：

| =file("BirthStateRecord") |
| =A1.cursor@b() |
| =A2.groupx(Birthday;count(~):Count;1000) |
| =A3.fetch(1000) |
| >A2.close() |

A3 的 groupx 函数使用行缓冲参数，其值设置为 1000。我们使用此参数仅用于测试和说明外存分组方法。在实际编码中不需要它，因为当内存达到最大容量时，esProc 会自动创建缓冲文件。代码逐步执行直到 A4。A3 使用 groupx 函数利用外存执行分组和聚合。在基于游标的操作中，groupx 函数既用于将结果集存储在外存中的分组和聚合，也用于直接指定分组数的分组。两种操作的区别在于参数。A3 按 Birthday 对记录进行分组，以计算每个日期出生的员工数量。A3 返回如下游标：
