## 内容

7.6.1 大数据的外存排序

游标通常用于统计数据分析中获取海量数据。这适用于 esProc，它也使用游标处理大数据。与数据库存储过程中的游标类似，esProc 游标每次根据其位置读取一条或多条记录，而不是一次性返回所有数据。

游标每次只能获取整体数据的一部分，因此无法直接对所有数据执行排序和分组等操作。esProc 使用外存来解决这个大数据问题。数据将分批检索和处理，处理每批数据的结果将临时存储在硬盘中。然后这些中间结果将被合并，并返回一个游标以生成最终结果。

这里有一个例子。让我们创建一个大数据表，其中日期和 8 位电话号码（第一位和最后一位不应为零）是任意生成的，并将其存储为 bin 文件以方便使用。

| =A1/B1 |
| =file("PhoneRecord.btx") |
| =create(ID,Date,PhoneNum) |
| =date(now()) |
| for C1 |
| for B1 |
| >B3=B3+1 |
| =elapse(A3,-rand(1000)) |
| =rand(90000000)+10000000 |
| >B2.insert(0,B3,C5,C6) |
| >A2.export@ab(B2) |
| >B2.reset() |
| =A2.cursor@b() |
| >A10.skip(50000) |
| =A10.fetch(1000) |
| >A10.close() |

让我们使用生成的数据文件 PhoneRecord 来探索如何在 esProc 中执行外存排序。执行此操作的函数是 cs.sortx(x...)，它根据计算表达式 x... 的结果按升序对游标 cs 中的数据进行排序。例如：

| =file("PhoneRecord.btx") |
| =A1.cursor@b() |
| =A2.sortx(PhoneNum;20000) |
| =A3.fetch(1000) |
| >A3.close() |

然后继续执行前面的网格文件。您会发现当游标关闭时，临时文件将自动删除。sortx 函数还可以按多个字段对数据进行排序。例如：

| =file("PhoneRecord.btx") |
| =A1.cursor@b() |
| =A2.sortx(Date,-PhoneNum) |
| =A3.fetch(1000) |
| >A3.close() |
