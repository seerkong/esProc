## 内容

7.6.2 外存排序的应用

实际上，外存排序的过程暗示了基于游标排序的用途之一，即按一定顺序合并已排序的数据。该操作基于多个游标执行并计算排序表达式。数据将从当前具有最小（或最大）结果的游标中获取。显然，这种方法只能在每个游标的数据以相同方式排序时使用。此外，使用 joinx() 函数进行基于游标的对齐连接也要求多个游标中的每个游标的数据都已排序。关于如何使用 joinx() 函数，请参阅《游标的合并和连接操作》。

当游标的数据正确排序后，可以指定从游标连续获取数据，直到表达式发生变化。例如：

| =file("PhoneRecord.btx") |
| =A1.cursor@b() |
| =A2.sortx(Date,-PhoneNum;20000) |
| =A3.fetch(;Date) |
| >3.(A3.skip(;Date)) |
| =A3.fetch(;Date) |
| >A3.close() |
