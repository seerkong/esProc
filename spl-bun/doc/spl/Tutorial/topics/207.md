## 内容

7.7.1 文本数据的基本用法

file 函数和 import 函数用于从文本文件读取数据。例如，文本文件 employee.txt 包含 500 名员工的信息，如下所示：

| EID | NAME | SURNAME | GENDER | STATE | BIRTHDAY | HIREDATE | DEPT | SALARY |
| 1 | Rebecca | Moore | F | California | 1984-09-28 | 2015-01-18 | R&D | 7000 |
| 2 | Ashley | Wilson | F | New York | 1990-05-28 | 2018-01-23 | Finance | 11000 |
| ... |

esProc 为具有文本数据源的数据表格式设置了规则：记录必须用回车分隔，字段应用制表符分隔。可以使用简单代码导入文本数据：

| =file("employee.txt") |
| =A1.import@t() |
| =A1.import() |

在 esProc 中，import 函数用于将文件数据导入为序表。在上述网格中，A1 创建文件对象。如果文件名中未指定路径，可以在设置页面上指定的主路径中找到它。点击菜单栏上的 Tool>Options 在 Option 窗口的 Environment 页面上查看或设置主路径：

如果没有 @t 选项，序表的字段名将根据其位置自动生成并命名为 _1、_2、_3。

导入文本数据时，其数据类型将根据第一行的数据类型自动解析。由于 employee.txt 的第一行包含字段名，A3 所有字段的数据都将被解析为字符串，如上述结果中的 _1 列和 _9 列，它们是左对齐的。而 A2 的 EID 字段和 SALARY 字段的数据类型是整数，因此数据是右对齐的。

您可以只导入文本文件的部分字段来生成序表：

| =file("employee.txt") |
| =A1.import@t(EID,NAME,BIRTHDAY,SALARY) |
| =A1.import(#1,#2,#6,#9) |

如上所述，在文本数据导入期间，数据类型将根据第一行的数据类型自动解析。但如果需要特定的数据类型，可以为要导入的指定字段定义它。例如：

| =file("employee.txt") |
| =A1.import@t(EID:string,NAME,BIRTHDAY:date,SALARY:int) |
| =A1.import(#1:string,#2,#6:date,#9:int) |

esProc 提供以下数据类型规范选项：

| 设置 | string | int | float | long | decimal | date | datetime | time | bool |
| 数据类型 | 字符串 | 整数 | 浮点数 | 长整数 | 大十进制 | 日期 | 日期/时间 | 时间 | 布尔值 |

参阅《基本数据类型》了解更多信息。

esProc 还提供 T(fn, Fi, ...; s) 函数，通过指定文件名和要使用的字段名从文件检索数据并将其作为序表返回。例如：

| employee.txt |
| =T(A1, EID,NAME,BIRTHDAY,SALARY; "\t") |
| =T(A1, EID,NAME,BIRTHDAY,SALARY) |
| =T@b(A1, EID,NAME,BIRTHDAY,SALARY) |
| =T@c(A1, EID,NAME,BIRTHDAY,SALARY).fetch@x(100) |

在 T() 函数中，如果分隔符 s 是制表符 \t，可以省略；如果未指定要使用的字段 Fi, ...，将检索所有字段。该函数返回与 import() 函数相同的结果，因此 A2 和 A3 具有相同的结果，如下所示：

esProc 不仅允许将文本数据导入为序表，还允许将内存数据导出到文本文件。通常要导出的数据来自序表或记录序列，有时也来自普通序列。export 函数用于将数据导出到文件。

| =file("employee1.txt") |
| =create(EID,NAME).record([1,"Frank",2,"Harry"]) |
| >A1.export(A2) |

T() 函数可用于执行导出，例如：

| employee1.txt |
| =create(EID,NAME).record([1,"Frank",2,"Harry"]) |
| >T(A1:A2, NAME,EID ",") |
| =T@c(A1,EID,NAME ",") |
| >T@s(A1:A4) |

CSV 文件在数据分析和处理中很常用。CSV 文件是用逗号分隔的文本文件。要生成这样的文件，您可以直接在 export 函数中定义分隔符或使用 @c 选项。例如：

| =file("employee3.csv") |
| =create(EID,NAME).record([1,"Frank",2,"Harry"]) |
| >A1.export@tc(A2) |
