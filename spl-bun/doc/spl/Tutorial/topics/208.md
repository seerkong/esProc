## 内容

7.7.2 大文本文件的批处理

当文件包含大量数据时，将其全部加载到内存可能会导致溢出。在这种情况下，应分批导入。为此，在 import 函数中使用文件分段参数按段导入数据。例如：

| =file("PersonnelInfo.txt") |
| =A1.import@t(;100:500) |
| =A1.import@t(;101:500) |

文本文件 PersonnelInfo.txt 包含人员信息。A2 和 A3 都在 import 函数中使用类似 100:500 形式的文件分段参数。因此 A2 将数据分成 500 段并导入第 100 段。以下是其结果：

在批量导入期间，esProc 能够通过调整起点和终点位置来确保导入完整的记录，同时保持导入数据的连续性、完整性和唯一性。

注意：使用 import 函数时，当文件通过分成多个段进行批量导入时，每批导入的记录数会有所不同，因为记录具有不同的字节数。这也解释了为什么无法直接获取指定行的数据。要定位指定位置的记录，需要逐条遍历记录直到找到该记录。这根本不高效。然而，可以使用外部文件游标精确访问目标记录，这将在下一节中解释。

通过分段大文件，可以将计算任务分成多个子任务。该方法对于 esProc 企业版支持的集群计算非常重要。在《服务器集群》中，我们将讨论使用集群计算对大文件进行批处理。

将大数据表导出到文本文件也可能受到有限内存的阻碍。因为数据无法完全加载到内存中，所以无法一次性导出到文件。但同样，可以通过批处理来处理大文件的导出。在 export 函数中使用 @a 选项，在每批数据导出时将数据追加到现有数据。例如：

| =file("PersonnelInfo.txt") |
| =file("PersonnelInfo1.txt") |
| for |
| =A1.import@t(ID,Name,State;A2:500) |
| >B1.export@at(B2) |

A2 运行循环，分 500 批从 PersonnelInfo.txt 导入数据，并指定某些字段写入新文件 PersonnelInfo1.txt。@at 选项与 export 函数一起使用，通过将每批追加到现有数据来导出列名和详细数据。代码执行后，PersonnelInfo1.txt 获得以下数据：
