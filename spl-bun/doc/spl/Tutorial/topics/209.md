7.7.3 使用游标访问大文本文件

处理包含大量数据的文本文件的更便捷工具是游标。基于文本文件生成外部文件游标后，游标函数即可调用。例如：

| =file("PersonnelInfo.txt") |
| =A1.cursor@t(ID,Name,Gender,State) |
| >A2.skip(10000) |
| =A2.fetch(1000) |
| =A2.fetch(1000) |
| >A2.close() |

A2 使用 cursor 函数创建文件游标，其中 @t 选项用于将文件的第一行导入为列名。A3 跳过前 10,000 行。A4 和 A5 分别从 A2 的游标获取 1,000 行：

可以通过游标按位置方便快捷地获取数据。与第一节中的 f.import() 一样，可以使用 f.cursor() 检索某些字段来创建游标，并可以为某个字段指定数据类型。

使用外部文件游标，可以轻松处理各种操作。关于其用法，请参阅《游标的基本用法》和其他关于 esProc 外存计算的文档。

也可以通过游标将数据导出到文件。例如：

| =file("employee2.txt") |
| =demo.cursor("select * from EMPLOYEE") |
| >A1.export@t(A2,EID,NAME+" "+SURNAME:FullName,GENDER,STATE) |

通过游标导出数据方便且代码简洁。要在数据导出期间保留现有数据，请使用 @a 选项将每批数据导出追加到之前的数据。

esProc 还支持使用游标访问 bin 文件。bin 文件占用更少的内存空间并实现更高效的计算。有关 bin 文件的更多详细信息，请参阅《Bin 文件》。
