# 7.8.1 Bin 文件与文本文件的比较

## 代码片段
```spl
=now()
=file("PersonnelInfo.btx")
=A2.cursor@b()
=A3.groups(State;count(~):Count)
=interval@ms(A1,now())
=now()
=file("PersonnelInfo.txt")
=A2.cursor@t()
=A3.groups(State;count(~):Count)
=interval@ms(A1,now())
file (whose default extension is btx )
```

7.8.1 Bin 文件与文本文件的比较

它们的用法几乎相同，只是在处理 bin 文件时，import、export 和 cursor 等相关函数需要 @b 选项。这里有一个例子：

上述两个文件——PersonnelInfo.btx 和 PersonnelInfo.txt——分别以二进制格式和文本格式存储相同的人员信息。每个文件包含 6 个字段的 100,000 条记录。可以看出，bin 文件比文本文件占用更少的硬盘空间。

让我们看看基于这两种类型文件的数据检索：
