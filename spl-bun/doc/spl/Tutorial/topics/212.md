## 内容

7.8.2 使用游标按段检索数据

将大数据文件分成段然后分别计算每个段是一种常见方法。通过添加文件分段参数，文本文件和 bin 文件都可以按段导入。《文本文件》解释了通过按段导入数据生成基于文本的序表。通过游标导入数据几乎相同。例如：

| =file("PersonnelInfo.btx") |
| =A1.cursor@b(;1:5) |
| =A2.fetch() |
| =A1.cursor@b(;2:5) |
| =A4.fetch() |

A2 和 A4 在生成游标时都使用文件分段参数，如 1:5。根据文件分段参数，游标数据被分成 5 部分。A2 返回第 1 部分，A4 返回第 2 部分。A3 和 A5 分别获取数据如下：

PersonnelInfo.btx 文件共有 100,000 条记录。它被分成的五个部分大小大致相同，但不一定包含相同数量的记录。在执行分段检索时，esProc 可以自动调整被检索数据的范围以确保数据完整性，如示例中的第 1 段和第 2 段。这将确保正在处理的数据的连续性和唯一性。

对文本文件和 bin 文件执行分段检索的方式相同，只是前者将省略 @b 选项。要从 bin 文件按段检索数据，我们可以在调用时指定"按组分段"参数。有关详细信息，请参阅《分组游标》。按组分段数据是 bin 文件独有的功能；它不能用于文本文件。
