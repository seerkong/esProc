# 7.9.1 根据表达式按组获取数据

## 代码片段
```spl
=file("Order_Wines.txt")
=file("Order_Electronics.txt")
=file("Order_Foods.txt")
=file("Order_Books.txt")
=[A1:A4].(~.cursor@t().sortx(PID))
=A5.merge(PID)
=A6.skip(;PID)
=A6.fetch(;PID)
>A6.close()
```

## 内容

7.9.1 根据表达式按组获取数据

在 esProc 中，您可以使用 cs.fetch(;x) 函数或 cs.skip(;x) 函数根据表达式 x 的值获取或跳过一组连续记录。例如，通过每次检索一种产品的数据来检查销售信息：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t().sortx(PID)) |
| =A5.merge(PID) |
| for 19 |
| =A6.skip(;PID) |
| =A6.fetch(;PID) |
| >A6.close() |

A6 中的游标包含四种产品的销售数据，已按 PID 排序。从 A8 开始，检索了第 20 种产品的记录：

请注意，esProc 对游标数据的遍历是以向前方向执行一次。因此，当每次检索一组记录时，游标中的数据必须按要求排序。
