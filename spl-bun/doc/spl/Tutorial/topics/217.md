## 内容

7.10.1 基本用法

跨网格游标通常用于处理大数据分析和计算，但它对数据量没有最低限制。首先看一个数据量相对较小的案例。以下是网格文件 D:\files\FindEmployees1.splx：

| $(demo) select * from EMPLOYEE where DEPT = ?;arg1 |
| >output("before return") |
| return A1 |

网格中的程序很简单。它检索某个部门的员工数据，并使用 return 语句在 A3 中返回序表。A2 使用 output() 函数将执行信息和状态输出到控制台。A1 中使用的 arg1 是指定部门名称的网格参数。可以通过点击菜单栏上的 Program>Parameter 来设置参数：

（原文含示意图，图像资源未迁移）

《子程序》讨论了通过 call 函数执行另一个网格文件中程序的方法。跨网格游标有类似的用法，只是它将使用 cursor 函数返回游标。它在主网格程序中调用上述网格文件如下：

| =cursor("FindEmployees1.splx";"Sales") |
| >output("before fetch") |
| =A1.fetch() |

使用 cursor 函数创建跨网格游标时，直接写入要调用的脚本文件名。如果需要，在文件后输入参数，并使用分号分隔它们。程序执行后，A1 的结果是一个跨网格游标，其使用方式与普通游标相同：

（原文含示意图，图像资源未迁移）

使用 fetch 函数，A3 返回销售部门员工的序表：

两个网格都使用 output 函数在执行期间向控制台输出字符，因此您可以清楚地看到网格中的执行顺序。点击菜单栏上的 Tool>Options，然后在 General 页面上选择 Console takeover 以查看输出信息：

（原文含示意图，图像资源未迁移）

可以看出，只有当 fetch 开始获取数据时，才会调用指定网格中的程序来启动跨网格计算。

A1 调用脚本文件时没有使用完整路径。但这要求文件放置在 esProc 的主路径或搜索路径中，其配置与通过 call 函数进行跨网格调用的配置相同。下面将再次解释配置过程。

点击菜单栏上的 Tool>Options 在 Environment 页面上配置主路径和搜索路径，如下所示：

（原文含示意图，图像资源未迁移）

如上述配置所示，无论脚本文件放置在主路径还是搜索路径的任何目录下，都可以仅通过其名称调用，而无需写入完整路径。

在集成的情况下，脚本文件的主路径和搜索路径需要在配置文件 raqsoftConfig.xml 中配置：

```xml
<splPathList>
    <splPath>E:\tools\raqsoft\esProc\demo\Case\Structural</splPath>
    <splPath>D:\files\txt</splPath>
    <splPath>D:\files</splPath>
</splPathList>
<mainPath>D:\files\demo</mainPath>
```
