## 内容

7.10.2 返回多个结果的网格

通过跨网格游标调用的网格文件可以返回多个结果，如下面的 D:\files\FindEmployees2.splx 所示：

| $(demo) select * from EMPLOYEE where DEPT = ?;arg1 |
| return A1.select(GENDER=="F") |
| return A1.select(GENDER=="M") |

此网格程序查询数据库以获取某个部门的员工数据，并使用两个 return 语句分别在 A2 和 A3 中返回两个记录序列，分别由女性员工数据和男性员工数据组成。它设置与上一节相同的网格参数。

然后在主网格中调用网格程序以生成跨网格游标：

| =cursor("FindEmployees2.splx") |
| =A1.fetch() |

使用 cursor 函数创建跨网格游标时不指定参数，则使用默认网格参数值，在本例中是 HR 部门。执行后 A2 返回结果如下：

结果序表的前半部分是 HR 部门的女性员工，后半部分是该部门的男性员工。您可以看到，跨网格游标将按顺序连接被调用网格通过多个 return 语句返回的多个结果。

对于返回多个结果的网格调用，结果必须具有相同的数据结构，因为它们将由一个跨网格游标一起返回。否则会发生错误。

为了查看详细的执行过程，在要调用的网格中使用 output 语句，如以下网格 D:\files\FindEmployees3.splx 所示：

| $(demo) select * from EMPLOYEE where DEPT = ?;arg1 |
| >output("return GENDER F") |
| return A1.select(GENDER=="F") |
| >output("return GENDER M") |
| return A1.select(GENDER=="M") |

在此网格中，程序查询数据库以获取某个部门的员工数据，并使用两个 return 语句分别在 A3 和 A5 中返回两个记录序列，分别由女性员工数据和男性员工数据组成。这里使用相同的网格参数。网格程序由跨网格游标调用：

| =cursor("FindEmployees3.splx") |
| [] |
| for A1,5 |
| >output("fetch"+string(#A2)) |
| >B1=B1|A2 |

在我们的示例中，跨网格游标只包含非常小的数据量，但这足以解释通过游标进行的跨网格调用。A2 循环遍历游标中的数据，每次获取五条记录。B2 在循环期间输出执行信息。B3 将从游标返回的记录连接到 B1 的记录序列中。程序执行后，B1 获得与前一个实例相同的结果——HR 部门的女性和男性员工记录。控制台接收的输出信息如下：

（原文含示意图，图像资源未迁移）

从输出信息可以看出，在主网格调用 FindEmployees3.splx 期间，程序将根据指定的返回记录方式逐步执行。因此，只有在 A3 中的所有女性员工记录都返回后，才开始获取男性员工记录。
