7.10.3 通过循环返回数据的网格

当调用通过游标返回大量数据的网格程序以生成跨网格游标时，您可以使用多个 return 语句分别返回多个结果，然后在主网格中连接它们。但更常见的方式是运行循环分批返回大量游标数据，返回的结果将在主网格程序中获取时自动连接。D:\files\Order1.splx 就是这样一个用于调用的网格文件：

| =file("Order_Books.txt") |
| =A1.cursor@t() |
| for B1,5000 |
| return A2 |

A2 通过循环从游标获取数据，B2 使用 return 语句将每批数据作为序表返回。这不是前一个示例中使用的方式，即一次性返回整个序表或记录序列。在主网格中，跨网格游标的工作方式与上述完全相同：

| =cursor("Order1.splx") |
| =A1.fetch(1000) |
| >A1.close() |

跨网格游标返回大量数据。A2 只获取前 1,000 条记录：

由于跨网格游标中的所有数据都没有取出，因此需要在 A3 中刻意关闭它。一旦跨网格游标关闭，被调用网格中的游标将同时关闭。

游标数据也可以使用多个 return 语句作为多个游标返回。在这种情况下，每个游标中的数据将连接在一起并作为整体获取。这与返回多个记录序列的情况相同。因此，每个游标中的数据应具有相同的数据结构。
