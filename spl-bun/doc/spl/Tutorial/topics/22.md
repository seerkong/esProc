# 1.6.2 函数参数的省略

## 代码片段
```spl
=if(B1>=80
=create(Math,Writing,Result)
>A4.insert(0,A3:Result,B1:Math,B2:Writing)
>A4.insert(0,B1,B2,A3)
=if(
between(B1+B2,120:150):"C", B1+B2<120:"D")
=A1.to(4,)
=A1.to(,4)
```

## 内容摘要
某些 esProc 函数参数具有默认值，因此可以省略，使函数更加简洁。

冒号后的参数通常用于进一步指定使用另一个参数执行的操作。在默认模式下，该参数可以省略。例如：

| Math | Writing | =if(B1>=80 && B2>=60,"Pass","Fail") |
| =create(Math,Writing,Result) | >A4.insert(0,A3:Result,B1:Math,B2:Writing) | >A4.insert(0,B1,B2,A3) |

在 A5 中，冒号后的参数用于指定与插入记录值对应的字段名。因此 A6 可以根据已指定的字段名直接设置字段值，而无需重新定义它们。分别在 A5 和 A6 中插入两条记录后，A4 的结果如下：

在需要分号但它期望引入的参数不存在的情况下，可以省略分隔符。例如，如果 A.top() 函数中未设置 n 且只需要获取第一条记录；或者当 T.switch() 函数中不需要转换某个字段时。

然而，即使逗号后面的参数被省略，逗号分隔符也应该保留。例如：

| [a,b,c,d,e,f,g] | =A1.to(4,) | =A1.to(,4) |

A2 中的表达式等于 =A1.to(4,A1.len())，A3 中的表达式等于 =A1.to(1,4)。
