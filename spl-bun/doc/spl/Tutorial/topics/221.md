## 内容

7.11 管道

本节介绍如何使用 esProc 管道相关函数。如果您不是专业程序员，可以选择跳过本节。这不会影响您学习本教程的其他内容。

我们始终强调游标中的数据只能向前遍历一次。《基于游标的操作》讨论了如何创建游标以及如何对一个或多个游标执行操作。根据游标的只能向前遍历一次的特性，只有 cs.fetch() 函数才能真正从最后生成的游标中取出数据。当遍历结束时，计算期间生成的所有其他游标都无法获取数据。

在某些情况下，您需要在一次数据检索过程中同时计算多个不同的值。我们可以使用管道来做到这一点。管道类似于游标。esProc 提供 channel() 函数来创建管道，并使用 cs.push(ch) 函数将管道添加到游标 cs；或使用 ch2.push(ch) 函数将其添加到另一个管道 ch2。新创建的管道只存储要执行的计算操作，直到实际对游标执行 fetch 操作时才执行这些操作并记录结果。管道通过与游标支持的类似的相应函数支持多种操作，包括 ch.select()、ch.new()、ch.derive()、ch.()、ch.news()、ch.run()、ch.switch()、ch.join()、ch.conj() 和 ch.group()。管道函数可以定义多种类型的结果集。ch.fetch() 函数定义从管道返回所有数据；ch.id() 函数定义返回删除重复成员的结果集；ch.sortx() 函数定义返回排序后的结果集；ch.groupx() 和 ch.groups() 函数定义返回分组后的结果集。此外，我们可以使用 ch.joinx() 函数将管道中的数据连接到可分段的 bin 文件。因此我们知道有两种管道函数。一种用于将操作附加到管道，另一种用于获取最终结果集。只有当返回最终结果集的函数已附加到管道时，才能检索管道中的数据。ch.result() 函数用于从管道获取定义的结果集。例如：

| D |
| =file("Order_Wines.txt") |
| =A1.cursor@t() |
| =channel() |
| >A3.select(SalesID==1) |
| >A3.fetch() |
| >A2.push(A3) |
| =A2.select(month(Date)==8) |
| =channel() |
| >A4.push(A5) |
| >A5.select(SalesID==1) |
| >A5.fetch() |
| =A4.fetch() |
| =A3.result() |
| =A5.result() |

A3 和 A5 创建新管道。两者都将选择 SalesID 为 1 的记录，但 B6 和 C6 的结果不同。这是因为 A3 的管道添加到 A2 的游标，从中获取所有销售记录；而 A5 的管道添加到 A4 的游标，该游标与操作捆绑，从中只获取 8 月份的销售记录。

根据第 3 行和第 5 行的代码，在执行 push 函数后，管道仍然可以有效地执行操作。但是一旦您已经使用 ch.fetch() 和 ch.id() 等函数定义了要返回的结果集类型，管道就不能再用于执行任何操作。

管道根据附加的操作按指定顺序逐步计算和向前推送数据。它只保留返回最终结果的最后一个函数的结果。

除了获取所有数据的 ch.fetch() 函数外，您还可以在管道中执行排序、分组和聚合。例如：

| D |
| =file("Order_Wines.txt") |
| =A1.cursor@t() |
| =channel() |
| >A3.select(SalesID==1) |
| >A2.push(A3) |
| =channel() |
| >A4.sortx(Amount) |
| >A3.push(A4) |
| >A3.groups(month(Date) count(~):Count) |
| =A2.skip() |
| =A3.result() |
| =A4.result() |
| =C5.fetch() |

A4 向 A3 的管道添加管道，因此 A4 的管道在根据条件 SalesID==1 执行过滤的结果记录内执行其操作。A3 定义最后执行 groups 函数，因此它放在 C4 中 push 函数执行之后。管道函数（如 ch.sortx() 和 ch.groupx()）将定义的结果集作为游标返回，其数据需要使用 fetch 函数获取，如 D5 所做的那样。虽然 A5 对游标执行 skip 操作，但数据仍将流经管道以获取聚合结果。以下是 B5 和 D5 的结果：
