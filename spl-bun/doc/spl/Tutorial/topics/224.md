# 8.1.1 并行数据检索

## 代码片段
```spl
=file("PersonnelInfo.txt")
=now()
=A1.import@t()
=now()
=A1.import@mt()
=now()
=string(interval@ms(B1,B2))+"/"+string(interval@ms(B2,B3))
```

## 内容

8.1.1 并行数据检索

如果记录的顺序与结果无关，我们可以通过多线程处理从数据表检索数据。这种类型的处理可以充分利用系统资源，从而提高效率。在 f.import() 函数中使用 @m 选项来使用多线程并行处理。

您可以使用多线程并行处理从单个数据文件检索数据：

| =file("PersonnelInfo.txt") |
| =now() |
| =A1.import@t() |
| =now() |
| =A1.import@mt() |
| =now() |
| =string(interval@ms(B1,B2))+"/"+string(interval@ms(B2,B3)) |

并行检索数据可以显著提高性能。

当使用多线程从单个数据文件检索数据时，多线程系统会将文件分成多个段，每个段将通过文件游标检索。每个文件游标使用单独的线程进行数据检索，这类似于上面使用多线程处理检索文件的示例。有关在 esProc 中按段检索数据的更多信息，请阅读《Bin 文件》。

由于通过并行处理从单个数据文件检索数据，返回结果中记录的顺序也是不规则的。

使用 f.import@m() 时，它使用的线程数由指定的并行任务数决定。该属性通过点击 esProc 菜单栏上的 Tool>Option 在 General 页面上配置：
