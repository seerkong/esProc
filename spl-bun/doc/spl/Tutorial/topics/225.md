## 内容

8.1.2 按一定顺序合并游标

还有另一种特别需要并行处理的操作。那就是按一定顺序合并游标，即 CS.merge()。例如：

| =file("Order_Wines.txt").cursor@t() |
| =file("Order_Foods.txt").cursor@t() |
| =file("Order_Electronics.txt").cursor@t() |
| =file("Order_Books.txt").cursor@t() |
| =[A1:B2].merge(Date) |
| =A3.fetch(10000) |
| >A3.close() |

A3 按日期合并来自四个文本文件的订购数据并生成新游标。

在按一定顺序合并游标的过程中，您需要根据排序表达式判断应从哪个游标获取数据。因此游标应在整个计算过程中全部就位，这也由多线程处理。esProc 提供了智能使用并行处理来处理基于顺序的游标合并，而无需使用 @m 选项。
