# 8.2.1 使用fork语句进行多线程执行

```spl
$(demo)
=A1.select(DEPT==A2)
=B2.minp(BIRTHDAY)
$(demo)
>output(A2+"-begin")
=A1.select(DEPT==A2)
=B2.minp(BIRTHDAY)
>output(A2+"-end")
$(demo)
=A1.select(DEPT==A2(1) &&
=B2.minp(BIRTHDAY)
$(demo)
=A1.select(DEPT==A2(1)
>A1=B2
```

## 内容

### 8.2.1 使用fork语句进行多线程执行

多线程允许子任务在执行计算任务时拥有各自独立的线程进行并发计算。esProc使用fork语句来执行多线程。下面通过示例来说明其用法：

|
$(demo)
select * from EMPLOYEE
|
[Sales,R&D,Finance,Production]
|
fork
B1
|
=A1.select(DEPT==A2)
|
=B2.minp(BIRTHDAY)
|
return
B3

A2使用fork语句执行多线程操作，从每个部门中选出年龄最大的员工。执行后，A2得到如下结果：

（原文含示意图，图像资源未迁移）

在多线程代码执行期间，fork语句遍历序列参数，并根据参数序列的长度，使用多个并行运行的线程来执行fork语句所在的代码块。通过return语句从代码块返回的结果将在主线程中连接成一个序列。

你也可以使用result语句来返回结果。

虽然看起来像循环计算，但fork语句与for语句不同。for语句的代码块由单个线程顺序执行，而fork语句同时处理由序列参数确定数量的子任务。为了进一步理解每个线程的执行情况，在A2的代码块中使用output函数将执行信息输出到控制台：

|
$(demo)
select * from EMPLOYEE
|
[Sales,R&D,Finance,Production]
|
fork
B1
|
>output(A2+"-begin")
|
=A1.select(DEPT==A2)
|
=B2.minp(BIRTHDAY)
|
>output(A2+"-end")
|
return
B3
|

在A2代码块执行期间，B2和C3分别在计算开始和结束时输出信息。执行后的输出结果如下：

（原文含示意图，图像资源未迁移）

根据输出结果，一些子任务可以并发执行，而其他子任务则等待资源可用。系统根据CPU能力将子任务分配给多个线程并控制其执行。每个子任务的计算时间受其计算量和执行它的线程状态的影响。多线程子任务的执行因不同环境而异。

多线程执行可以使用多个参数。例如：

|
$(demo)
select * from EMPLOYEE
|
[Sales,R&D,Finance,Production]
|
[Texas,Illinois,Ohio,Florida]
|
fork
B1,["F","F","F","F"],C1
|
=A1.select(DEPT==A2(1) &&
GENDER==A2(2) && STATE==A2(3))
|
=B2.minp(BIRTHDAY)
|
return
B3
|

A2在执行多线程时使用三个参数。参数的成员将按顺序匹配进行计算，即[Sales,F,Texas]、[R&D,F,Illinois]、[Finance,F,Ohio]和[Production,F,Florida]。通过这种方式，指定部门、性别和州来选择年龄最大的员工。以下是A2的结果：

（原文含示意图，图像资源未迁移）

多线程执行中使用的序列参数必须具有相同的长度。

在上面的代码中，从每个部门选择员工时指定的性别相同。因此，相应的参数可以写成单个值，如下面的网格所示：

|
$(demo)
select * from EMPLOYEE
|
[Sales,R&D,Finance,Production]
|
[Texas,Illinois,Ohio,Florida]
|
fork
B1,"F",C1
|
=A1.select(DEPT==A2(1)
&& GENDER==A2(2) && STATE==A2(3))
|
>A1=B2
|
return
B2
|

当调用多线程操作时，单值参数将被复制到每个线程，其中将使用相同的参数值。顺便说一下，代码块中的return语句每次返回的是记录序列而不是单条记录，所以A2的结果是由记录序列组成的序列：

（原文含示意图，图像资源未迁移）

代码块中的C2通过将A1修改为通过查询子程序从中派生的记录序列来更新A1。在代码块执行后检查A1的数据，你会发现它没有被多线程操作的代码块修改。实际上，执行子程序的多个线程将分别复制当前网格，因此它们相互独立，彼此之间以及与主程序中的数据都没有影响。

fork语句也可以用于集群计算，这由esProc企业版支持。详细内容将在集群计算章节中介绍。
