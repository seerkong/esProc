# 8.2.3 设置合理的线程数

## 代码片段
```spl
=file("PersonnelInfo.txt")
=now()
to(4)
=A1.import@t(;A3:4)
B3.select(City=="San Diego")
=A3.conj()
=interval@ms(A2,now())
=now()
to(400)
=A1.import@t(;A8:400)
B8.select(City=="San Diego")
=A8.conj()
=interval@ms(A7,now())
```

## 内容

8.2.3 设置合理的线程数

既然多线程执行可以提高效率，那么使用更多线程会不会更显著地提高效率呢？让我们运行一个测试看看。

| =file("PersonnelInfo.txt") |
| =now() |
| fork to(4) |
| =A1.import@t(;A3:4) |
| return B3.select(City=="San Diego") |
| =A3.conj() |
| =interval@ms(A2,now()) |
| =now() |
| fork to(400) |
| =A1.import@t(;A8:400) |
| return B8.select(City=="San Diego") |
| =A8.conj() |
| =interval@ms(A7,now()) |

第 2 到第 5 行使用 4 个线程执行多线程操作，而第 7 到第 10 行使用 400 个线程执行。A5 和 A10 都得到与上一节相同的结果。现在让我们检查 B5 和 B10 中估计的计算时间：

（原文含示意图，图像资源未迁移）

尽管 A8 使用了这么多线程进行多线程操作，但效率并没有提高；相反，效率下降了。计算机的 CPU 容量有限，但太多线程必须排队等待执行，它们也会使用 CPU 资源。这就是为什么效率下降而不是提高的原因。在实际使用中，线程数略少于 CPU 核心数时可以获得良好的性能。
