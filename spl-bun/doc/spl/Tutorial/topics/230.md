## 内容

8.3 多游标操作

如果您不是专业程序员，可以选择跳过本节。这不会影响您学习本教程的其他内容。

游标是从单个文件或数据库生成的。但有时您可能需要多个这样的游标作为源数据。在这些情况下，您可以定义多游标来执行并行计算。

CS.cursor() 函数用于定义多游标，可以像普通游标一样使用 fetch 函数从中获取数据。例如：

| =file("Order_Wines.txt") |
| =file("Order_Electronics.txt") |
| =file("Order_Foods.txt") |
| =file("Order_Books.txt") |
| =[A1:A4].(~.cursor@t()).cursor() |
| =A5.select(SalesID==1).fetch() |

从多游标获取的数据将存储在一个序表中，因此游标序列中每个游标的记录需要具有相同的结构。此外，由于使用并行处理从游标获取数据，记录在获取到结果序表时的顺序会发生变化。

但并行处理可以有效加快计算速度。除了由多个游标组成的序列外，您还可以使用 cs.cursor@m(n) 函数基于单个游标 cs 生成若干个（数量为 n）并行子游标并创建多游标。如果省略 n，该函数将自动设置并行子游标的数量。例如：

| =file("Order_Wines.txt") |
| =A1.cursor@t() |
| =A2.cursor@m(4) |
| =A3.select(month(Date)==10) |
| =A4.fetch() |

从单个游标生成的多游标与普通游标的使用类似，只是多游标中的数据通过并行处理获取。对于从多游标检索数据，结果中数据的顺序是不固定的。以下是 A5 的结果：

除了可以从普通游标生成多游标的 cs.cursor@m() 函数外，您还可以使用 A.cursor@m() 函数和 f.cursor@m() 函数直接基于序列或文件创建多游标。

当 CS.merge(x) 函数合并游标序列 CS 中成员为多游标的游标时，这些多游标必须具有相同数量的并行（子）游标。同样，连接多个游标的 joinx() 函数要求，如果其中至少一个是多游标，则所有这些游标都必须是具有相同并行（子）游标的多游标。
