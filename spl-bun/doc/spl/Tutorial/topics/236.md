### 9.2 JSON数据

JSON是一种常见的数据交换格式。JSON数据可能来自外部Java程序、本地文件或HTTP服务器。esProc可以轻松解析JSON字符串并进行计算。

以下示例将详细展示如何编写esProc脚本来完成此任务。

在第一种情况下，JSON字符串通过参数从外部Java程序传递。

假设有一个员工信息的JSON字符串，包含以下字段：EID、NAME、SURNAME、GENDER、STATE、BIRTHDAY、HIREDATE和DEPT。现在解析该字符串并找出1981年1月1日（含）之后出生的女性员工。字符串如下：

[{EID:1,NAME:"Rebecca",SURNAME:"Moore",GENDER:"F",STATE:"California",BIRTHDAY:1974-11-20,HIREDATE:2005-03-11,DEPT:"R&D",SALARY:7000},
{EID:2,NAME:"Ashley",SURNAME:"Wilson",GENDER:"F",STATE:"New York",BIRTHDAY:1980-07-19,HIREDATE:2008-03-16,DEPT:"Finance",SALARY:11000},
{EID:3,NAME:"Rachel",SURNAME:"Johnson",GENDER:"F",STATE:"New Mexico",BIRTHDAY:1970-12-17,HIREDATE:2010-12-01,DEPT:"Sales",SALARY:9000},…]

**解决方案**：在Java程序中调用esProc脚本，同时输入JSON字符串；esProc解析并过滤JSON数据，然后以JSON字符串的形式将结果返回给Java程序。

要选择1975年1月1日（含）之后出生的女性员工，esProc脚本从外部程序输入两个参数——"jsonstr"和"where"，如下所示：

（原文含示意图，图像资源未迁移）

"where"是一个字符串，其值为BIRTHDAY>=date(1975,1,1) && GENDER=="F"。

注意：参数jsonstr是一个字符串，其输入值需要以单引号开头。

以下是完成此任务的esProc脚本：

|
=json(jsonstr)
|
（原文含示意图，图像资源未迁移）
|
=A1.select(${where})
|
（原文含示意图，图像资源未迁移）
|
=json(A2)
|
[{"EID":2,"NAME":"Ashley","SURNAME":"Wilson","GENDER":"F","STATE":"New York","BIRTHDAY":"1980-07-19","HIREDATE":"2008-03-16","DEPT":"Finance","SALARY":11000}…]
|
return A3
|

A1：将JSON数据解析为序表。结果可以在esProc的集成开发环境（IDE）中显示，如上图右侧所示。

A2：过滤序表的数据。使用宏来动态解析表达式，其中"where"是输入参数。esProc将计算${…}中的表达式以获取宏字符串值，并用它替换${…}，然后解释并执行生成的表达式。最终执行的代码是=A1.select(BIRTHDAY>=date(1975,1,1) && GENDER=="F")。

A3：以JSON字符串的形式导出过滤后的序表数据。

A4：将所需的结果集返回给外部程序。

有关在Java程序中调用esProc脚本的方法，请参阅相关教程章节。

另一种情况是JSON数据来自HTTP服务器。假设testServlet返回一个员工信息的JSON字符串。按如下方式检索和处理数据：

|
=httpfile("http://localhost:6080/myweb/servlet/testServlet?table=employee&type=json")
|
=A1.read()
|
=json(A2)
|
=A3.select(${where})
|
=json(A4)
|
return A5
|

A1：定义一个httpfile对象，URL是http://localhost:6080/myweb/servlet/testServlet?table=employee&type=json。

A2：读取httpfile对象返回的结果。

A3：解析JSON字符串并生成序表。

A4：根据指定条件过滤数据。

A5：将过滤后的序表转换为JSON字符串；json()函数会自动判断参数类型并导入/导出JSON字符串。

A6：将A5的结果返回给调用esProc脚本的Java程序。

esProc还可以解析和计算包含嵌套对象的JSON数据。例如，博客中的嵌套评论。esProc可以将它们解析为可引用的字段。以下是blogs.json文件：

```json
[
  { "id" : 1000,
    "content" : "It is too hot",
    "comment" :
    [
      { "author" : "joe", "score" : 3, "comment" : "just so so!" },
      { "author" : "jimmy", "score" : 5, "comment" : "cool! good!" }
    ]
  },
  { "id" : 1001,
    "content" : "It is too cold",
    "comment" :
    [
      { "author" : "james", "score" : 1, "comment" : "yes!" },
      { "author": "jimmy", "score" : 5, "comment" : "cool!" }
    ]
  },
  { "id" : 1002,
    "content" : "It is windy day today",
    "comment" :
    [
      { "author" : "tom", "score" : 3, "comment" : "I do not thinkso!" },
      { "author" : "jimmy", "score" : 5, "comment" : "cool!" }
    ]
  }
]
```

使用esProc编辑器编写脚本，从JSON文件导入数据，解析并计算：

|
=json(file("D:/files/work/txt/blogs.json").read())
|
