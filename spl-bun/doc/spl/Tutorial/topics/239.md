### 9.4.1 基本用法

esProc支持直接查询txt、csv和btx文件。它使用类似SQL的数据库语句来完成此操作。我们称之为简单SQL，而TXT和CSV文件作为可作为序表查询的外部数据，称为外部表。例如：

|
$()select * from
cities.txt
|
$select * from
D:/files/txt/cities.txt where STATEID=5
|
$select STATEID,
count(*) AS Cities from cities.txt group by STATEID

与连接数据源的数据库SQL查询类似，esProc直接在美元符号($)后面编写简单SQL语句来查询外部表的数据。如果存在数据库连接，$后面的语句将默认在数据库中执行。要使用简单SQL查询外部文件中的数据，我们可以在美元符号$后面添加()。以下是A1查询cities.txt的结果集：

A1中的简单SQL语句直接使用文件名而不是特定的表名。这是与SQL语句的区别。如果没有明确写出文件路径，文件应该在esProc的主路径中。在查询中，使用的文件类型由其扩展名确定。简单SQL语句支持使用txt或csv扩展名的文本文件、xls或xlsx扩展名的Excel文件以及btx扩展名的bin文件。

在简单SQL语句中，我们可以使用子句，如join/left join/right join/full join，连接多个表来执行多表查询。例如：

|
$()select * from
states.txt
|
$select C.CID as ID,
C.NAME as City, C.POPULATION as Pop, S.NAME as STATE from cities.txt C join states.txt S on
C.STATEID = S.STATEID
|
$select C.CID as ID,
C.NAME as City, C.POPULATION as Pop, S.NAME as STATE from cities.txt C full join states.txt
S on C.STATEID = S.STATEID
|
$()select C.CID as ID,
C.NAME as City, C.POPULATION as Pop, S.NAME as STATE from cities.txt C left join states.txt
S on C.STATEID = S.STATEID

执行分组操作时，我们可以使用group by n来指定select语句中使用的第n个字段或表达式作为分组字段/表达式。例如：

|
$select STATEID,
count(*) Cities from cities.txt group by STATEID
|
$select STATEID,
count(*) Cities from cities.txt group by 1
|
$select STATEID,
count(*) Cities from cities.txt group by STATEID having Cities > 1
|
$select STATEID,
count(*) Cities from cities.txt group by STATEID having Cities > 1 order
by Cities
