# 1.7.1 esProc 函数选项

## 代码片段
```spl
=interval(A1,B1)
=interval@y(A1,B1)
=interval@m(A1,B1)
```

## 内容摘要
esProc 中的许多函数可以使用函数选项，通过这些选项，同一个函数可以有多种工作模式。函数选项的基本格式是 f@o(…)，其中 o 是 f 函数的选项。例如：

| 2004-5-5 | 2014-7-7 | =interval(A1,B1) | =interval@y(A1,B1) | =interval@m(A1,B1) |

我们使用 interval 函数计算两个日期之间的天数。在 A3 和 A4 的表达式中，@y 和 @m 是 interval 函数的选项。使用这些选项，函数将在计算日期间隔时使用年和月作为计算单位。函数选项通过扩展功能使函数能够满足多种需求，精简函数库并避免使用过多的函数参数。两个日期之间的天数、年数和月数分别在 A2、A3 和 A4 中计算。
