### 9.4.2 在esProc ODBC中使用简单SQL

如果你不是专业程序员，可以选择跳过本节。这不会影响你学习本教程的其他内容。

esProc ODBC支持外部数据源，即具有常见格式（如txt、csv、xls和xlsx）的数据文件、esProc bin文件（在Bin文件章节中详细讨论）以及复合表的基表（在生成复合表章节中阐述）。

你也可以在esProc ODBC中使用简单SQL语句来查询外部表。例如：

|
=esProcOdbc.query("select
PName, SalesID, Date from Order_Electronics.txt where Amount>200000 and month(Date)=5")
|
$(esProcOdbc)
select Date, count(ID) as Count, sum(Quantity) as Sum from
Order_Electronics.txt group by Date
|
$(esProcOdbc)
select Date, count(ID) as Count, sum(Quantity) as Sum from
Order_Electronics.txt group by 1
|
$(esProcOdbc) select
Date, count(ID) Count, sum(Quantity) Sum from Order_Electronics.txt group by
Date having sum(Quantity)>110000 order by Sum

要使txt文件成为外部表，请使用制表符作为列分隔符。

简单SQL语句可以连接两个外部表。例如：

|
$(esProcOdbc)
select StateId, Name, Abbr from states.txt
|
$(esProcOdbc)
select NAME,POPULATION,STATEID from cities.txt
|
$(esProcOdbc)
select C.NAME,C.POPULATION, S.StateId, S.Abbr from states.txt S join
cities.txt C on S.StateId=C.STATEID
|
$(esProcOdbc)
select C.NAME,C.POPULATION, S.StateId, S.Abbr from states.txt S left join
cities.txt C on S.StateId=C.STATEID
