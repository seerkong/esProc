### 9.5.1 调用用户自定义函数的基本方法

invoke函数可用于调用指定用户自定义Java类中的静态方法。以下面的Java类test.Calc01为例：

```java
package test
public class Calc01 {
    public static Double distance1(Number loc) {
        double len = Math.abs(loc.doubleValue())
        len = Math.round(len*1000)/1000d
        return Double.valueOf(len)
    }
}
```

在这个简单的类中，静态方法distance1计算给定坐标与原点之间的距离，值四舍五入到三位小数。在esProc中调用的方法必须同时是static和public的。在调用之前，用户自定义函数类需要放在esProc的classpath中，即[安装目录]\esProc\classes。考虑到类本身的路径，这里类文件应该放在[安装目录]\esProc\classes\test中。如果在web环境中调用，需要放在WEB-INF/classes路径中。

单个类中可以有多个用户自定义函数。现在添加另一个方法：

```java
public static Double distance2(Number loc1, Number loc2) {
    double len = Math.abs(loc1.doubleValue()-loc2.doubleValue())
    len = Math.round(len*1000)/1000d
    return Double.valueOf(len)
}
```

新添加的distance2计算数轴上两个坐标之间的距离。由于esProc按名称调用方法，不同的用户自定义函数需要有不同的方法名。一旦类被放置在应用程序的classpath中，无论它们来自单个类还是多个类，都可以在同一个网格中调用用户自定义函数：

|
=invoke(test.Calc01.distance1,-12.3456)
|
=invoke(test.Calc01.distance2,12,-12)
