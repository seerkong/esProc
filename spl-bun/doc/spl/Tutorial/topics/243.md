### 9.5.2 根据需要返回结果

用户自定义函数可以返回结果，也可以不返回结果。例如：

```java
public static void distance3(Number loc1, Number loc2) {
    double len = Math.abs(loc1.doubleValue()-loc2.doubleValue())
    len = Math.round(len*1000)/1000d
    System.out.println(Double.toString(len))
}
```

当使用静态方法distance3完成计算时，结果只会打印到系统控制台，但不会返回。这类方法类似于网格中的可执行单元格，调用时可以使用>。例如：

|
>invoke(test.Calc01.distance3,-12.3,15)

如果用户自定义函数使用参数或返回结果，它应该使用esProc支持的数据类型；否则，在显示或调用期间可能会发生错误。以下列出了esProc中常用的数据类型及其在Java中的对应类型：

| esProc类型 | Java类型 |
|---|---|
| Integer（整数） | java.lang.Integer |
| Long integer（长整数） | java.lang.Long |
| Floating point number（浮点数） | java.lang.Double |
| Big decimal（大十进制数） | java.math.BigInteger |
| Real number（实数） | java.lang.Number |
| Boolean（布尔值） | java.lang.Boolean |
| String（字符串） | java.lang.String |
| Date（日期） | java.sql.Date |
| Time（时间） | java.sql.Time |
| Datetime（日期时间） | java.sql.TimeStamp |
| Sequence（序列） | com.scudata.dm.Sequence（或Object[]） |
| Binary data（二进制数据） | byte[] |

在前面的示例中，所有返回的结果都是Double对象，对应于esProc中的浮点数；所有参数都是Number数据类型，对应于esProc中的实数。用户自定义函数可以根据需要返回不同数据类型的结果。例如，向test.Calc01添加另外两个用户自定义函数以返回不同数据类型的结果：

```java
public static String distance4(Number loc1, Number loc2) {
    double len = Math.abs(loc1.doubleValue()-loc2.doubleValue())
    len = Math.round(len*1000)/1000d
    return Double.toString(len)
}

public static com.scudata.dm.Sequence distance5(Number loc1, Number loc2) {
    double len = Math.abs(loc1.doubleValue()-loc2.doubleValue())
    len = Math.round(len*1000)/1000d
    com.scudata.dm.Sequence result = new com.scudata.dm.Sequence()
    result.add(loc1)
    result.add(loc2)
    result.add(Double.valueOf(len))
    return result
}
```

这两个静态方法也用于计算数轴上两点之间的距离。distance4返回字符串类型的结果，distance5以序列的形式返回结果，存储两点的坐标和它们之间的距离。仍然使用invoke函数在网格中调用这两个方法：

|
=invoke(test.Calc01.distance2,-12.3,15)
|
=invoke(test.Calc01.distance4,-12.3,15)
|
=invoke(test.Calc01.distance5,-12.3,15)

注意A1和A2的结果是不同的数据类型，因此显示方式不同。用户自定义函数的返回结果可用于后续计算。

由于序列类com.scudata.dm.Sequence不是Java中的通用数据类型，esProc用户自定义函数可以使用Object[]来表示序列，如下面编写的distance5b：

```java
public static Object[] distance5b(Number loc1, Number loc2) {
    double len = Math.abs(loc1.doubleValue()-loc2.doubleValue())
    len = Math.round(len*1000)/1000d
    Object[] result = new Object[3]
    result[0] = loc1
    result[1] = loc2
    result[2] = Double.valueOf(len)
    return result
}
```

在这种情况下，调用invoke()函数时，需要配合@x选项将参数和返回值都转换为序列类型：

|
=invoke@x(test.Calc01.distance5b,-12.3,15)
