### 9.5.4 用户自定义游标

要基于用户自定义函数返回游标，返回类应该是实现com.scudata.dm.ILineInput接口的类。以下test.RandDataCursor文件就是这样一个示例：

```java
package test
public class RandDataCursor implements com.scudata.dm.ILineInput {
    private int rowno = 0
    private int range = 1000
    
    public RandDataCursor(Integer rg) {
        this.range = rg
    }
    
    public Object[] readLine() throws java.io.IOException {
        rowno++
        Object[] result = new Object[2]
        result[0] = Integer.valueOf(rowno)
        result[1] = Integer.valueOf((int) (Math.random() * range))
        return result
    }
    
    public boolean skipLine() throws java.io.IOException {
        rowno++
        if (rowno <= 10000) return true
        return false
    }
    
    public void close() throws IOException {
        rowno = 10001
    }
}
```

ILineInput类应该实现三个方法：readLine、skipLine和close。这里简单的RandDataCursor文件旨在生成一个由随机整数组成的序列，其范围可以通过参数指定。从readLine方法返回的每条记录由一个顺序递增的行号和一个随机整数组成，类似于序表的两个字段。skipLine方法跳过一条记录，然后返回游标中是否还有数据。在上面的文件中，它指定游标最多返回10000条记录。close方法用于关闭游标以删除不需要的资源，如数据库连接。

因此，返回游标的用户自定义游标可以将RandDataCursor作为返回类。例如：

```java
package test
public class Calc02 {
    public static test.RandDataCursor getCursor(Integer range) {
        RandDataCursor rdc = new RandDataCursor(range)
        return rdc
    }
}
```

这里用户自定义函数只需要定义一个参数，即随机整数的范围，并返回一个游标RandDataCursor，它将生成随机记录。但返回的ILineInput类不能直接用作游标。你需要调用com.scudata.dm.UserUtils类的newCursor方法将其转换为游标。例如：

|
=invoke(test.Calc02.getCursor,1000000)
|
=invoke(com.scudata.dm.UserUtils.newCursor,A1,"")
|
>A2.skip(100)
|
=A2.fetch@x(100)
