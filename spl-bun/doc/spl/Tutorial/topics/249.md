### 10.1.2 配置集群服务器

运行esProc企业版安装目录下esProc\bin路径中的esprocsEE.exe文件来启动或配置集群服务器。该文件所需的jar包将自动从安装目录加载。注意，配置文件——raqsoftConfig.xml和unitServer.xml——必须放在esProc安装目录的esProc\config路径下。服务器启动后弹出以下窗口：

在esprocsEE.exe执行期间，窗口显示加载的初始信息，这些信息在配置文件raqsoftConfig.xml中设置。

点击右侧菜单上的Options来配置集群服务器的信息。我们有以下弹出窗口并修改主路径：

（原文含示意图，图像资源未迁移）

在该页面上，你可以配置主路径、搜索路径、日期和时间格式、默认字符集、日志级别、文件缓冲区字节数和其他信息。对于日志级别，有OFF、SEVERE、WARNING、INFO和DEBUG，优先级从左到右递减。OFF级别关闭任何日志输出。INFO级别输出其级别及以下级别的信息，包括SEVERE、WARNING和INFO。其他级别也以这种方式输出信息。

配置信息与esProc IDE中的配置相同。可以在工具>选项>环境中查看或修改：

（原文含示意图，图像资源未迁移）

从esProc IDE退出集群服务器或更改节点配置时，当前或修改的配置参数将保存在raqsoftConfig.xml中。因此，需要修改时请注意可能的冲突。

点击右侧菜单上的Config在Node页面上配置节点信息：

（原文含示意图，图像资源未迁移）

Temp file timeout设置临时文件的生命周期（小时）。Check interval是两次过期检查之间的秒数，必须是正值或0。Proxy timeout是代理生命周期，即远程游标和任务空间的生命周期（小时）。如果Temp file timeout或Proxy timeout设置为0，则不执行过期检查。

在Host list下，你可以配置本地机器上所有可能运行服务器的节点的IP地址和端口号。服务器在启动时会自动搜索节点列表中的空闲节点，并分配任务执行。IP地址应该是真实的，当有多个网络适配器时允许多个IP地址。Auto start server一旦选中，将在服务器集群开始运行后自动启动集群服务器。

在Host list下，Max task num是允许节点执行的最大任务数。对于同一IP地址，你可以配置多个访问不同数据区域数据的节点。

Node Server的Enable clients选项卡提供客户端白名单设置：

（原文含示意图，图像资源未迁移）

选择Check clients在Clients hosts下配置可以调用集群服务器的IP白名单。不在白名单中的IP地址无法调用集群服务器进行计算。

集群服务器配置完成后，点击OK自动设置相应的配置文件unitServer.xml，如下所示：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<SERVER Version="3">
  <TempTimeOut>12</TempTimeOut>
  <Interval>6</Interval>
  <ProxyTimeOut>12</ProxyTimeOut>
  <Hosts>
    <Host ip="192.168.1.112" port="8281" maxTaskNum="3" preferredTaskNum="4">
    </Host>
  </Hosts>
  <EnabledClients check="true">
    <Host start="192.168.1.112">
    </Host>
  </EnabledClients>
</SERVER>
```
