# 10.2.2 维护集群文件

## 代码片段
```spl
=movefile@c(A2;"/",B1)
=movefile(A3,A1;"/",B1)
=movefile(A2,B1;B3)
=movefile@c(A2;"/",[A1:B1])
=movefile(A2;,[A1:B1])
=movefile@c(A3,B1;"/",A1)
=movefile(A3,A1;"/",B1)
```

### 10.2.2 维护集群文件

我们不需要专门访问节点上集群文件的主路径或搜索路径来操作它们。相反，我们使用函数来处理它们，如下所示：

|

|

这是因为目标目录中已经有同名文件。为了避免错误和由此导致的执行终止，我们在movefile()函数中使用@y选项，在文件移动或复制时强制覆盖目标路径中的同名文件。
