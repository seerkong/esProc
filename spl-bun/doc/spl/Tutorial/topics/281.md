# 12.2.1 坐标系统和坐标轴

## 内容

### 12.2.1 坐标系统和坐标轴

esProc提供两种常用的坐标系统——笛卡尔坐标系和极坐标系。不同的坐标系统有不同类型的坐标轴——x轴和y轴，或极轴和径向轴。每种类型的轴都有自己的绑图属性，用于处理相应的坐标变换操作。

**笛卡尔坐标系**

笛卡尔坐标系有两个相互垂直的轴，分别表示为x轴和y轴。水平x轴上的逻辑坐标决定图表的水平位置，垂直y轴上的逻辑坐标决定图表的垂直位置。实际上，在笛卡尔坐标系中，物理坐标的横坐标和纵坐标可以根据其对应的逻辑轴分别计算，互不影响。

在我们引用的所有示例中，都使用笛卡尔坐标系来定位图表元素。画布上的原生物理轴也属于笛卡尔坐标系。该系统用于绑制大多数图表，如柱状图、折线图、面积图、散点图、气泡图和股票图。

**极坐标系**

极坐标系中的轴是极轴和径向轴。对于极轴，您需要定义极点位置和极轴长度；对于径向轴，需要定义极坐标的起始角度和结束角度。按照惯例，从极点水平向右的角度为0，从极轴逆时针方向的角度为正。默认情况下，极坐标系的起始角度为0，结束角度为360。

极坐标系用于绘制饼图、环形图、雷达图等。

使用极坐标执行坐标变换操作时，点的线段长度根据极轴上的坐标计算，其极角根据径向轴上的坐标计算。
