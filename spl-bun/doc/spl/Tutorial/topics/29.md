## 内容摘要
esProc 可以通过 JDBC 访问各种数据库。

点击 Tool 菜单列表中的 Datasource Connection 查看数据源管理器：

（原文含示意图，图像资源未迁移）

您可以通过数据源管理器连接或断开某个数据源，以及配置要连接的数据库。demo 是 esProc 的内置数据源，可以通过执行安装目录下的 esProc\bin\startDataBase.bat 来启动。一旦连接到数据源，esProc 就可以访问数据库并使用 SQL 获取数据：

| =demo.query("select * from CITIES") | $select * from CITIES |

query 函数用于获取执行 SQL 命令的结果集并将其作为序表检索，如 A1 中的代码所示。当数据库连接时，SQL 语句可以紧跟在 $ 后面，如 A2 所示。A1 和 A2 的结果相同：

（原文含示意图，图像资源未迁移）

除了使用数据源管理器，您还可以使用 connect 函数连接到数据源。在这种情况下，从数据库检索数据后，应使用 close 函数关闭连接：

| =connect("demo") | =A1.query("select * from CITIES") | >A1.close() |

使用此方法，A2 也获得相同的城市信息序表。
