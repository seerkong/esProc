# 1.9.1 esProc JDBC jar 包说明

## 内容摘要
esProc JDBC 类似于一个不完整的数据库 JDBC 驱动程序，没有物理表。可以简单地将其视为只支持存储过程的数据库。此外，它有一个内置的计算引擎，因此不需要独立的服务器。

esProc JDBC 涉及两个基本 jar 包。两者都位于 [安装目录]\esProc\lib 中：

| jar 包 | 说明 |
| --- | --- |
| esproc-bin-xxxx.jar | esProc 计算引擎和 JDBC 驱动程序（注意：社区版为 esproc-xxxx.jar） |
| icu4j_60.3.jar | 处理国际化 |

如果要将其他数据库用作 esProc JDBC 的数据源，则需要这些数据库的驱动程序 jar 包。例如，使用 demo 数据库时需要 hsqldb-2.7.3-jdk8.jar。请注意，esProc JDBC 需要 JDK1.8 或更高版本。
