## 内容摘要
在网格代码中，结果集通过 return 语句返回。

| =connect("demo") | =A1.query("select * from EMPLOYEE where EID=?",arg1) | >A1.close() | return A2 |

在应用程序代码中，arg1 是网格参数。我们将此脚本文件命名为 test.splx。

注意：脚本文件的结果集通过 return 语句返回。调用脚本文件时，其参数将按出现顺序赋值，而不是按名称赋值。

**步骤说明：**

1. **加载必要的 jar 包**：在启动 Java 应用程序时加载上述基本 esProc JDBC jar 包。这些 jar 包可以放在 Web 应用程序的 WEB-INF/lib 目录下。

2. **部署 raqsoftConfig.xml 和脚本文件**：配置 raqsoftConfig.xml 文件，该文件包含 esProc 的基本配置信息，如搜索路径、数据源配置等。该文件可以在 esProc 安装目录的 esProc\config 路径中找到，其信息与 esProc Option 选项卡中设置的信息相同。允许在部署前调整配置（如修改用于搜索脚本文件的搜索路径）。

修改后，将 raqsoftConfig.xml 放在将使用它们的应用程序的类路径中。

将步骤 1 中创建的 test.splx 放在应用程序的类路径中，或放在配置文件中 `<splPathList/>` 节点指定的路径中（即上述搜索路径）。

3. **如有必要，手动进一步配置 raqsoftConfig.xml 文件**：更多详情请参阅相关文档。注意配置文件名不能更改。

4. **在 Java 程序中调用脚本文件**：

```java
public void testDataServer(){
    Connection con = null;
    java.sql.CallableStatement st;
    java.sql.PreparedStatement st2;
    try{
        // 建立连接
        Class.forName("com.esproc.jdbc.InternalDriver");
        con = DriverManager.getConnection("jdbc:esproc:local://");
        // 调用存储过程，其中 test 是脚本文件的名称
        st = con.prepareCall("call test(?)");
        // 设置参数
        st.setObject(1,"3");
        // 执行以下代码获得的结果与使用上述调用方法获得的结果相同
        st = con.prepareCall("call test(3)");
        // 执行存储过程
        st.execute();
        // 获取结果集
        ResultSet set = st.getResultSet();
    }
    catch(Exception e){
        System.out.println(e);
    }
    finally{
        // 关闭连接
        if (con!=null) {
            try {
                con.close();
            }
            catch(Exception e) {
                System.out.println(e);
            }
        }
    }
}
```

要了解更多关于调用方法和配置的信息，请参阅"集成与应用"章节。
