当 if 后的条件 x 为 true 时，将执行条件后的语句；否则将执行 else 后的语句。else 部分可以省略。else 和 if 必须在同一行。不一定有 else 部分。执行后，if 所在单元格的值是 x 的结果。

有时没有 else 部分。该语句只决定是否应该执行 if 语句后的代码：

| =demo.query("select * from EMPLOYEE") | for A1 | if age(A2.BIRTHDAY)>=40 | >A4=A4+1 |

A2 遍历每条员工记录；B3 检查当前员工是否年满 40 岁。如果结果为 true，该员工将被计入 A4，循环结束时您将获得所有年龄不小于 40 岁的员工数量。

（原文含示意图，图像资源未迁移）

条件语句中使用以下逻辑连接符：

| 连接符 | 说明 |
| --- | --- |
| a && b | "a 且 b"，只有当 a 和 b 都为 true 时结果才为 true |
| a \|\| b | "a 或 b"，只有当 a 或 b 为 true 时结果才为 true |
| !a | "非 a"，只有当 a 为 false 时结果才为 true |

| =demo.query("select * from EMPLOYEE") | for A1 | if age(A2.BIRTHDAY)>=40 && A2.GENDER=="M" | >A4=A4+1 |
