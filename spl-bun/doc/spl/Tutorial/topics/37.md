## 内容摘要
如果 x 为 true，将执行 if 代码块；否则，将执行 else 代码块。else 和 if 必须在同一列。else 部分可以不存在。esProc 使用代码块而不是 {} 等符号或 end if 等语句来确定语句的作用范围。

| =demo.query("select * from EMPLOYEE") | Male | [] | Female | [] |
| for A1 | if A4.GENDER=="M" | >B2=B2\|A4.(NAME+" "+SURNAME) | >C2+=1 |
| | else | >B3=B3\|A4.(NAME+" "+SURNAME) | >C3+=1 |

如示例所示，根据 B4 的判断结果，由 C4 和 C5 组成的 if 代码块和由 C6 和 C7 组成的 else 代码块交替执行，分别找出男性和女性员工的姓名和数量。计算完成后可以在 B2、B3、C2 和 C3 中查看结果：
