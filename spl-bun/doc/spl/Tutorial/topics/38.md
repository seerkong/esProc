# 2.1.4 多个 if x … else if y … 代码块

## 代码片段
```spl
>B12=A1+C1
>B12=A1-C1
>B12=A1*C1
>B12=A1/C1
>B12="Error"
```

## 内容摘要
这是 esProc 的多分支语句，可以无限重复编写。if … else if… 语句必须沿一列编写。您必须始终记住，esProc 中没有可以被认为是 end if 语句对应物的语句。

esProc 使用代码块的范围来确定 if 语句在哪里结束。

| 5 | * | 3 |
| if B1=="+" | >B12=A1+C1 |
| else if B1=="-" | >B12=A1-C1 |
| else if B1=="*" | >B12=A1*C1 |
| else if B1=="/" | >B12=A1/C1 |
| else | >B12="Error" |
| Result: |
