## 内容摘要
一个或多个分支语句可以嵌套到 if 或 else 代码块中以进行进一步判断。

| 2016-2 | =A1.split@p("-") | >year=A2(1) | >month=A2(2) |
| if [1,3,5,7,8,10,12].pos(month)>0 | >A8=31 |
| else if [4,6,9,11].pos(month)>0 | >A8=30 |
| else if month==2 |
| | if year%400==0 | >A8=29 |
| | else if year%100!=0 && year%4==0 | >A8=29 |
| | else | >A8=28 |
