## 内容摘要
这是无条件循环，主单元格的值根据循环计数而变化。通常使用 break 命令退出循环。

无条件循环或无限循环是最简单的循环结构，例如：

| =demo.query("select * from EMPLOYEE") | [] |
| for | =A1(A2) | if B2.STATE=="Texas" | >B1=B1\|B2 |
| | | if B1.len()==10 | break |

A2 执行无条件循环。B2 根据 A2 中的循环计数检索一条员工记录。以下代码将德克萨斯州员工的记录存储在 B1 中。检索到前 10 名德克萨斯州员工的记录后，循环在 C6 中通过 break 语句终止。或者，可以使用 break C 命令（break 语句的一种形式）退出使用单元格 C 作为主单元格的循环体。
