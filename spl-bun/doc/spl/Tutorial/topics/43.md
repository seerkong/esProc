# 2.2.3 for n

## 代码片段
```spl
>A1=A1/2
>C1=C1*2
=B1
>B1=A1
>A1=C3
```

## 内容摘要
该语句循环 n 次，主单元格的值依次是循环计数。

除了遍历序列中的所有成员外，指定循环次数也很常见。

假设有一张纸，尺寸为 1000mm*800mm，厚度为 0.1mm。如果我们将它折叠十次，最终的长度、宽度和厚度是多少？

| 1000 | 800 | 0.1 |
| for 10 | >A1=A1/2 | >C1=C1*2 |
| | if B1>A1 | =B1 | >B1=A1 | >A1=C3 |

在上述示例中，折叠重复十次。每次折叠后，长度减半，厚度加倍。如果折叠后宽度大于长度，则长度和宽度将交换值。执行后，A1、B1 和 C1 分别获得纸张的长度、宽度和厚度：

for n 语句也可以看作是 for to(1, n) 语句的简单形式，意思是从 1 循环到 n。
