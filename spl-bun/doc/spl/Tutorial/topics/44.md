# 2.2.4 for a, b, s

## 代码片段
```spl
>A2=A2+A1
=A2\100
=(A2\10)%10
=A2%10
=power(B2,3)
=power(C2,3)
=power(D2,3)
>A1=A1|A2
```

## 内容摘要
该语句以 s 为间隔从 a 循环到 b，即遍历由 to(a,b).step(s) 定义的数组的每个成员。s 的默认值为 1。

有时循环不是从第一个成员开始，或者增量值不是 1。这时可以使用 for a, b, s 语句执行循环。例如：

| for 1,100,2 | >A2=A2+A1 |

对于任何 n 位数，如果每个数字的 n 次方之和等于该数本身，则称为水仙花数。在以下示例中，要识别所有 3 位水仙花数：

| D | [] |
| for 100,999 | =A2\100 | =(A2\10)%10 | =A2%10 |
| | =power(B2,3) | =power(C2,3) | =power(D2,3) |
| | if B3+C3+D3==A2 | >A1=A1\|A2 |
