## 内容摘要
当 x 为 true 时，该语句执行循环。主单元格的值是 x 的结果。

通过指定循环条件，您可以控制何时结束循环。例如，for loop 中的问题也可以使用带有特定循环条件的 for 语句来解决：

| =demo.query("select * from EMPLOYEE") | [] |
| for B1.len()<10 | =A1(#A2) | if B2.STATE=="Texas" | >B1=B1\|B2 |

对于 for x 语句的主单元格，其值为 true 或 false，这是每次判断循环条件的结果。这里您无法根据主单元格的值获取循环次数。因此，要在 B2 中检索员工记录，B2 使用 #C 获取当前循环次数。对于 #C，C 是循环体的主单元格。执行时，代码获得与 for loop 中相同的结果。
