# 2.2.6 嵌套循环

## 代码片段
```spl
>A1=A1|A2
=100-A2-B3
=5*A2+3*B3+C3/3
>A1=A1|[[A2,B3,C3]]
```

## 内容摘要
在循环体中，您仍然可以使用一个或多个循环语句来形成嵌套循环或多层循环。例如：

| D | [] |
| for 2,1000 | for A1 | if A2%B2==0 | next A2 |
| | | | >A1=A1\|A2 |

在此示例中，A1 存储要生成的新素数序列；A2 遍历从 2 到 1000 的整数。B2 遍历素数序列。如果 A2 中的数字可以被某个素数整除，它将被 next A2 命令替换为 A2 中的下一个数字。如果 A2 中的所有数字都不能被当前素数列表中的数字整除，则找到了一个新的素数，它将被添加到 A1 的序列中。D2 中的 next C 命令跳过以单元格 C 为主单元格的循环体的其余部分，执行下一轮循环。执行后，A1 中 1000 以内的素数序列如下：

使用 next 语句时，不必指定主单元格 C，只需跳过 next 语句所在单元格所在的循环层级。

这是百鸡问题。每只公鸡值 5 美元，每只母鸡值 3 美元，但三只小鸡值 1 美元。假设您用 100 美元买 100 只鸡，有多少只公鸡、母鸡和小鸡？您可以用以下方式解决这个问题：

| D | [] |
| for | if 5*A2>100 | break |
| | for 100-A2 | =100-A2-B3 | =5*A2+3*B3+C3/3 |
| | | if D3>100 | next A2 |
| | | else if D3<100 | next |
| | | else | >A1=A1\|[[A2,B3,C3]] |

在代码中，A2 循环获取可能的公鸡总数。B2 检查公鸡的总价是否超过 100；如果结果为 true，则表示公鸡数量超过了实际数量。并使用 C2 中的 break 命令结束循环。B3 继续通过循环计算可能的母鸡数量。在此过程中，如果 C4 发现当前鸡的总价超过 100，则表示母鸡太多。然后 D4 使用 next A2 增加公鸡数量以尝试达到平衡。然而，如果 C5 的结果显示当前鸡的总价仍然小于 100，D5 使用 next 命令跳过由单元格 B3 定义的当前最内层循环以增加母鸡数量。
