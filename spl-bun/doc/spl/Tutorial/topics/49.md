## 内容摘要
esProc 继承了关系数据库中数据表的概念，并将其定义为序表。与关系数据库对数据表的定义一致，每个序表都有自己的数据结构，由字段组成。序表的成员称为记录。

大量结构化数据算法，如数据查询、数据排序、求和、求平均值和合并重复记录，都可以在序表上执行。例如：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>=20000 && month(Date)==5) |
| =A1.sort(SalesID,-Date) | =A1.groups(SalesID, month(Date); round(sum(Amount),2), count(~)) |

**序表——特殊的序列**

序表仍然是序列，因此它具有序列的集合性和有序性特征，可以使用与序列相关的函数。序表在序列的意义上不是通用的，因为它的成员必须是相同结构的记录。但是，记录的字段值可以是通用数据，从这个意义上说是另一种形式的通用性。由于这些特性，与传统编程语言相比，序表在处理复杂计算时更加方便。

例如，要计算销售额的月度增长率，esProc 利用序表的有序性编写以下算法：

| =file("Order_Books.txt").import@t() |
| =A1.groups(month(Date); sum(decimal(string(Amount))):TotalAmount, count(~):Count) |
| =A2.derive(round(TotalAmount/TotalAmount[-1]-1,4): compValue) |

A2 计算每月的总销售额。A3 计算最终结果。
