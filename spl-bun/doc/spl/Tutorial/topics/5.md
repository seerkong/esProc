# 1.1.2 基本使用

## 代码片段
```spl
=if(A1>=80,
=if(A1>=80:"Heavyweight",
```

## 内容摘要
运行 esProc 主程序打开 esProc 软件，点击图标创建一个网格文件。

（原文含示意图，图像资源未迁移）

左侧是网格区域，显示您正在编辑的代码网格。右侧上方是数值查看区域，下方是相关信息区域，其中系统信息区域显示系统输出。系统信息区域、数值查看区域和相关信息区域都可以折叠和展开。

（原文含示意图，图像资源未迁移）

在 esProc 中，如果单元格有值，则可以在计算单元格或可执行单元格中使用其名称来引用该单元格的值。具有值的单元格可以是常量单元格、计算单元格或由可执行单元格赋值的单元格。单元格名称包括表示列的字母和表示行序号的整数。在上述网格中，单元格 A2 中的表达式调用了单元格 A1 的值。以下是另一个示例：

（原文含示意图，图像资源未迁移）

与 Excel 不同，在 esProc 中单元格名称中的字母必须是大写的。

esProc 提供了丰富的函数来处理各种数据计算任务。例如：

| 66.8 | =if(A1>=80, "Heavyweight", "Others") | =if(A1>=80:"Heavyweight", A1>=68:"Middleweight", A1>=58:"Lightweight";"Flyweight") |

分别点击 A2 和 A3 在数值查看区域查看它们的值：

（原文含示意图，图像资源未迁移）

esProc 还具有函数编辑辅助功能，使单元格中的代码编写更加容易。在编辑单元格中的表达式时，按 Alt+↓ 可以打开或关闭此辅助功能。在函数编辑辅助功能界面上，您可以看到相应的函数语法、函数描述和其他信息：

（原文含示意图，图像资源未迁移）

当选择不同的单元格时，数值查看区域中的数据会自动刷新。在此区域的右上角，点击图标可以启用"显示焦点单元格值"。点击该图标后，当前焦点单元格的值将始终显示在数值查看区域中——即使选择了另一个单元格——除非禁用此设置。

我们可以在数值查看区域控制数据的显示和查看。右键点击标题行会弹出以下菜单：

（原文含示意图，图像资源未迁移）

选择"复制列名"可以复制当前显示的标题行中的列名。当选中的单元格包含单个值时，标题行显示"Value"；当选中单元格的值是表时，标题行显示列名。

选择"查看长文本"可以在字符串值太长无法完整显示在单元格中时，在特殊的长文本查看窗口中显示长文本数据。

选择"缩放至"可以控制数值查看区域的缩放比例：

（原文含示意图，图像资源未迁移）

以下是选择 150% 缩放比例后的效果：

（原文含示意图，图像资源未迁移）

我们可以为不同的单元格值设置不同的缩放比例。例如，当单元格值包含大量数据时，设置较小的缩放比例。
