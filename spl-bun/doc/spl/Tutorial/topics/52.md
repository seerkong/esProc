# 2.4.1 创建

## 代码片段
```spl
=[A1:C3]
=[3,A4,B4]
=to(2,6)
="1,a,b,c".split@c()
=periods@yx("2014-08-10",date(2018,2,1))
=file("sales.txt").import@t()
=file("sales.txt").import@t()
=A1.(STATE)
=A1.group(STATE)
```

## 内容摘要

**使用常量创建序列**

为了方便查看，esProc 在每个序列或序表显示的最左侧添加一个 Index 列。该列不是表结构的一部分。本教程中并非所有序列或序表的截图都显示 Index 列。

用"[]"括起一个或多个常量表示序列常量。用"[]"括起表达式也可以生成序列。例如：

| red | 2013-06-04 | blue | 27.49 | yellow | Tom |
| [15.2,b,1] | =[A1:C3] | =[3,A4,B4] |
| [1,2,3,3] | [] | [[]] |

在网格中，A4、A5、B5 和 C5 分别包含序列常量。B4 和 C4 包含通过计算表达式获得的序列。

A4 中序列的成员是各种数据类型，包括浮点数、字符串和整数。B4 序列中的成员是由单元格范围定义的单元格值。在 C4 中，序列的成员包含序列。A5 的序列中有相同的成员。

（原文含示意图，图像资源未迁移）

让我们看看 B5 和 C5 的值：B5 的值是空序列，而 C5 的值是非空序列，其唯一成员是空序列。

注意：序列的成员可以是任何数据类型，包括基本类型、序列、记录等。所有成员都是整数的序列称为整数序列。

**使用函数创建序列**

| =to(2,6) | ="1,a,b,c".split@c() | =periods@yx("2014-08-10",date(2018,2,1)) | =file("sales.txt").import@t() |

A1 中的代码表示由从 2 到 6 的连续整数组成的序列；如果序列从 1 开始，可以缩写为 to(6)。A2 拆分字符串形成序列。A3 创建两个给定日期之间的日期序列；@y 选项使用年作为间隔的时间单位，@x 选项表示排除右端点。

（原文含示意图，图像资源未迁移）

A4 从结构化文本文件导入记录并创建序列。成员是记录的序列是序表，通常用于执行结构化数据计算。这里序表不是我们的重点。更多信息请参阅"序表和记录序列的操作"。

**通过计算创建序列**

在以下网格中，A1 将文本文件 sales.txt 作为序表导入；A2 检索 STATE 列并生成序列；A3 按 STATE 分组记录并生成序列：

| =file("sales.txt").import@t() | =A1.(STATE) | =A1.group(STATE) |

（原文含示意图，图像资源未迁移）

可以看出 A3 序列的每个成员都是成员为记录的序列。
