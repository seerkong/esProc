## 内容摘要

**创建**

在下面的网格中，A1 从文件读取二维结构化数据以创建序表对象并存储它。B1 对 A1 执行查询以创建记录序列对象并存储它：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>20000) |

计算后 A1 获得以下序表。这里只显示部分序表。您可以拖动右侧的滚动条查看所有记录。

（原文含示意图，图像资源未迁移）

注意：序表对象可以基于数据库或文件创建，或通过向空对象插入记录来创建。记录序列源自一个或多个序表，但它不存储物理记录。它只存储序表中某些记录的引用。

**访问字段值**

在下面的网格中，A2 检索序表对象 A1 的第二十条记录的 PName 字段并存储它，B2 检索记录序列对象 B1 的第二条记录的 PName 字段并存储它：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>20000) |
| =A1(20).PName | =B1(2).PName |

由于 B1 中的第二条记录是 A1 中第二十条记录的引用，A2 和 B2 具有相同的结果。根据 A2 和 B2 的表达式，序表和记录序列具有完全相同的字段访问语法。

（原文含示意图，图像资源未迁移）

字段名可以用字段的序号替换，结果不会改变。如本例所示，A2 可以写成 =A1(20).#3。因为这种替换在 esProc 中普遍使用，我们在以下示例中不再详细说明。

要从序表或记录获取字段值，您还可以使用 field 函数和 array 函数。例如：

| =file("Order_Books.txt").import@t() | =A1.field(2) | =A1(20).field(2) |
| =A1(20).array(PName) | =A1(20).array(PID,PName) | =A1(20).array() |

使用 field 函数，您可以获取具有特定编号的字段的值。使用 array 函数，您可以通过指定一个或多个字段名从记录获取字段值。如果不指定，函数返回由记录的所有字段值组成的序列。

（原文含示意图，图像资源未迁移）

**访问列数据**

在下面的网格中，A2 根据名称从序表 A1 检索 PName 列并存储它，B2 再次从序表 A1 根据名称检索 PName 列和 Amount 列并存储它们。记录序列和序表具有相同的列访问语法。这里以序表为例：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>20000) |
| =A1.(PName) | =A1.new(PName,Amount) |

（原文含示意图，图像资源未迁移）

使用 T.(x) 语法，您只能检索一列数据作为没有结构化列名的序列。然而，使用 T.new() 函数，您可以检索一列或多列数据作为具有结构化列名的序表。

无论计算对象是序表还是序列，T.new() 函数和 A.new() 函数都将创建新的序表。这意味着 B1.new(PName, Amount) 的结果也是序表。

**访问行数据**

在以下网格中，A2 根据行号从序表 A1 获取前两条记录并存储它们。B2 根据行号从序表 B1 获取前两条记录并存储它们。记录序列和序表使用相同的行访问语法：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>20000) |
| =A1([1,2]) | =B1([1,2]) |
