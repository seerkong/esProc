# 2.5.2 循环函数

## 代码片段
```spl
=file("Order_Books.txt").import@t()
=A1.select(Amount>=20000
=file("Order_Books.txt").import@t()
=A1.select(Amount>20000)
=B1.sort(SalesID,-Date)
```

## 内容摘要
循环函数封装了复杂的循环语句，可以对序表/记录序列的每条记录执行相同的计算。例如，select 用于数据查询，sort 用于数据排序，id 用于获取不同的记录，pselect 用于获取满足指定条件的记录的序号。这里将说明最基本的 select 函数和 sort 函数。有关循环函数的更多信息，请参阅"循环计算"。

**数据查询**

以下网格代码找出 Amount 字段大于或等于 20,000 且 Date 在三月的记录。由于记录序列和序表具有相同的数据查询语法，我们只使用后者进行说明：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>=20000 && month(Date)==3) |

（原文含示意图，图像资源未迁移）

无论计算对象是序表还是记录序列，select 函数的结果始终是记录序列，即记录的引用而不是物理记录。

**数据排序**

在以下网格中，记录按 SalesID 字段升序排序，具有相同 SalesID 的记录然后按 Date 字段降序排序。排序记录序列和序表时语法相同。这里以 B1 中的记录序列为例：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>20000) | =B1.sort(SalesID,-Date) |

（原文含示意图，图像资源未迁移）

无论计算对象是序表还是记录序列，sort 函数的结果始终是记录序列。实际上，除了记录修改外，大多数函数都可以用于处理序表和记录序列。
