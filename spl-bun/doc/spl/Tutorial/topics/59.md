# 2.5.3 聚合函数

## 代码片段
```spl
=file("Order_Books.txt").import@t()
=A1.select(Amount>20000)
=A1.max(Amount)
=file("Order_Books.txt").import@t()
=A1.select(Amount>20000)
=A1.groups(SalesID,
month(Date); round(sum(Amount),2), count(~))
```

## 内容摘要

**查找最大值**

这里的计算目标是查找 Amount 字段的最大值。由于在记录序列和序表上执行此操作的语法相同，我们只以序表 A1 为例：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>20000) | =A1.max(Amount) |

（原文含示意图，图像资源未迁移）

其他聚合函数包括 min（查找最小值）、sum（计算总和）、avg（计算平均值）、count（计数）等。

**按组计算总和**

以下网格代码按 SalesID 和月份分组记录，然后对每组的 Amount 求和并计算订单数。在记录序列和序表上执行此操作的语法相同，我们只以序表 A1 为例：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>20000) |
| =A1.groups(SalesID, month(Date); round(sum(Amount),2), count(~)) |

（原文含示意图，图像资源未迁移）

注意：groups 函数生成新的序表。表达式 count(~) 中的符号"~"表示当前组。该表达式也可以写成 count(ID)。由于代码没有为结果指定字段名，因此使用默认字段名如 month(Date)。您可以使用冒号指定字段名，如 =A1.groups(SalesID, month(Date):Month;sum(Amount),count(ID))。
