# 1.1.3 Linux 下的安装与运行

## 内容摘要
如果您不是专业程序员，可以跳过本节。这不会影响您学习本教程的其他内容。

esProc 在 Linux 环境下提供通过 bin 文件进行安装的方式。

首先在 Linux 系统下安装 JDK（1.8 版本或更高版本）。然后从 Raqsoft 官方网站下载 Linux 版 esProc 安装文件（esProclinux.zip），解压到任意目录以获取 bin 文件 esProc-install.bin。

查阅 BeforeRunning.txt 了解安装说明。

为 /bin 目录下的每个 .sh 文件授予执行权限。然后在 /esProc/bin 目录下执行 ./startup.sh 启动 esProc IDE。

在 Linux 下，您无法直接从 IDE 菜单打开帮助文档。您需要安装支持查看 CHM 文件的工具（如 xCHM），然后从安装目录打开它们。
