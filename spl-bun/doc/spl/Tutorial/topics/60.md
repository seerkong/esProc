## 内容摘要
集合操作包括交集"^"、并集"&"、差集"\"和连接"|"等。

**交集和差集操作**

在以下网格中，A2 存储 Amount 大于等于 20,000 且 Date 在三月的订单记录，B2 存储 SalesID 等于 540 或 992 的订单记录。现在找出 A2 和 B2 的交集和差集，并分别将结果存储在 A3 和 B3 中：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>=20000 && month(Date)==3) | =A1.select(SalesID==540 \|\| SalesID==992) |
| =A2^B2 | =A2\B2 |

（原文含示意图，图像资源未迁移）

A3 计算交集。结果是记录序列。B3 通过从 A2 中移除 B2 的成员来计算差集。结果仍然是记录序列。

让我们继续看从不同序表生成的序列或记录序列的交集和差集操作。首先使用 derive() 函数复制记录序列（或其他时候的序列）生成新的序表，然后计算交集和差集：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>=20000 && month(Date)==3) | =A1.select(SalesID==540 \|\| SalesID==992) |
| =A2.derive() | =B2.derive() | =A3^B3 | =A3\B3 |

A4 计算 A3 和 B3 的交集。结果是空集。这意味着，作为物理成员的集合，不同的序表具有不同的成员，它们的交集始终为空。因此该操作在业务中没有实际意义。

B4 计算 A3 和 B3 的差集。由于两个序表的成员始终不同，差集操作的结果仍然是 A3。

只有在源自同一序表的记录序列上执行的集合操作才具有业务意义。在不同序表或源自不同序表的记录序列之间执行交集和差集在实际业务中没有意义。

**并集和连接操作**

在以下网格中，A2 从 B1 中的记录序列选择 SalesID 等于 540 和 992 的订单记录以创建另一个记录序列并存储它，B2 从 B1 的记录序列找出 SalesID 等于 540 和 668 的订单记录并存储它。现在找出 A2 和 B2 的并集和连接，并分别将结果存储在 A3 和 B3 中：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>=20000 && month(Date)==3) |
| =B1.select(SalesID==540 \|\| SalesID==992) | =B1.select(SalesID==540 \|\| SalesID==668) |
| =A2&B2 | =A2\|B2 |

（原文含示意图，图像资源未迁移）

A3 通过按顺序组合两个集合的成员并移除重复成员来计算 A2 和 B2 的并集。B3 通过按顺序连接两个集合的成员并保留重复成员来计算 A2 和 B2 的连接。

让我们看看不同序表之间的并集和连接操作：

| =file("Order_Books.txt").import@t() | =A1.select(Amount>=20000 && month(Date)==3) |
| =B1.select(SalesID==540 \|\| SalesID==992) | =B1.select(SalesID==540 \|\| SalesID==668) |
| =A2.derive() | =B2.derive() | =A3&B3 | =A3\|B3 |

A4 计算 A3 和 B3 的并集。由于两个序表的成员完全不同，并集操作意味着两者的简单全并集，与连接操作的结果相同。B4 计算 A3 和 B3 的连接。结果与 A4 中的并集相同。
