## 内容摘要
在以下网格中，记录 r1 被追加到 A1 中的序表；然后记录 r2 被插入到第二行的位置。r1 通过按顺序列出字段值来指定，r2 通过给出字段值后跟字段名来指定。最后，三条记录 r3、r4 和 r5（它们的 ID 和 NAME 字段有指定值，但其他字段为 null）被连续插入到第二行之前。

| =demo.query("select * from STUDENTS") |
| >A1.insert(0,111,"Jessica","F",18) |
| >A1.insert(2,25:ID,"William":NAME,20:AGE,"M":GENDER) |
| >A1.insert(2:3,25+#:ID,"William"+string(#):NAME) |

A2、A3 和 A4 依次向 A1 的序表添加记录。点击工具栏上的单步执行按钮逐步执行代码，查看原始序表的变化。

（原文含示意图，图像资源未迁移）

从上述代码可以看出，T.insert() 函数用于通过指定要插入记录的位置和新值的字段来向序表添加一条或多条记录。未赋值的字段具有 null 值。

与序表不同，记录序列是由记录引用组成的序列。因此只能向记录序列添加新的引用：

| =demo.query("select * from STUDENTS") | =A1.to() |
| >A1.insert(0,111,"Jessica","F",18) | >A2.insert(2, A1(8)) |

A2 是通过 to 函数从 A1 中序表的记录生成的记录序列。要通过复制原始序表创建另一个序表，需要使用 A.derive() 函数。

（原文含示意图，图像资源未迁移）

可以看出，新记录已追加到序表，而不影响其他记录。因此 A2 中的记录序列保持不变。A4 将新记录插入记录序列，但位置不同。

向序表添加记录和向记录序列添加记录的语法有很大区别。序表接收的是物理记录，因此您可以直接在序表 A1 上使用 insert 函数。但记录序列只能拥有已存在的物理记录的引用。

insert 函数的第一个参数为 0 表示在末尾追加记录；否则，从指定位置插入记录。这适用于序表和记录序列。

插入到序表的一条或多条记录可以来自记录序列或序表。例如：

| =demo.query("select * from STUDENTS") | =create(ID, NAME, GENDER, AGE) |
| >A2.insert(0:A1([1,2]), ID, NAME, GENDER, AGE) | >A2.insert@r(1:A1) |

A2 创建新的序表。A3 在序表末尾追加记录。要追加的记录来自 A1 的记录序列。如果记录序列具有相同的数据结构，您可以只使用 T.insert@r(k:P) 而无需显式写出字段名，如 A4 所做的那样。

（原文含示意图，图像资源未迁移）

如果记录序列具有不同的结构，您可以使用 T.insert@f(k:P) 根据共享字段添加记录。例如：

| =demo.query("select * from STUDENTS") | =create(ID, NAME, SEX, AGE) |
| >A2.insert(0:A1([1,2]), ID, NAME, GENDER:SEX, AGE) | >A2.insert@f(2:A1) |

A2 与 A1 具有不同的字段名。A3 在追加数据时指定 A1 记录序列的列对应于目标序表中的列。然而，A4 使用 T.insert@f() 进行追加。

（原文含示意图，图像资源未迁移）

您可以看到 A4 的追加操作只复制同名字段，并为不同名称的列输入 null。
