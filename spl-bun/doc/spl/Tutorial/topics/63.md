## 内容摘要
在以下网格中，首先删除第二条记录，然后删除第一和第二条记录，最后删除年龄大于 15 岁的学生记录：

| =demo.query("select * from STUDENTS") |
| >A1.delete(2) |
| >A1.delete([1,2]) |
| >A1.delete(A1.select(AGE>15)) |

A2、A3 和 A4 依次从 A1 的序表中删除记录。通过逐步执行代码，您可以看到其变化。

（原文含示意图，图像资源未迁移）

delete 函数用于从序表中删除记录。记录通过序号、由序号组成的序列或通过生成记录序列的查询来指定。A4 中的代码等于 >A1.delete(A1.pselect@a(AGE>15))。

让我们看一个记录序列的示例：

| =demo.query("select * from STUDENTS") | =A1.to() |
| >A2.delete(2) | >A2.delete([1,2]) |

A2 中的记录序列与前面示例中的原始序表具有相同的数据。首先 A3 删除一条记录，然后 A4 删除两条记录。逐步执行代码，您可以看到 A2 中记录序列的变化。

（原文含示意图，图像资源未迁移）

但检查 A1 中的数据显示序表中的原始数据保持不变。

（原文含示意图，图像资源未迁移）

从序表中删除的是物理记录，而从记录序列中删除的是记录的引用，这不会影响物理序表。
