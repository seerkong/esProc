## 内容摘要
在以下网格中，首先 A2 将第二条记录的 GENDER 字段修改为 Female，NAME 字段修改为 Violet；然后 A3 将从第二条开始的三条连续记录的每个 ID 加 10：

| =demo.query("select * from STUDENTS") |
| >A1.modify(2, "Female":GENDER, "Violet":NAME) |
| >A1.modify(2:3,ID+10:ID) |

A1 中的序表包含与上述示例中序表相同的原始数据。A2 和 A3 分别修改序表。通过逐步执行，您可以看到 A1 的变化。

modify 函数用于修改序表中的记录。它也用于修改单条记录的值。

禁止修改记录序列中的记录。修改必须在引用的序表上执行。

记录的字段值可以对齐更改为另一条记录的字段值：

| =demo.query("select * from STUDENTS") | >A1(5).modify@r(A1(1)) |

使用 modify@r 函数修改记录也称为记录粘贴。通过 A2 的记录粘贴操作，序表中的第五条记录已被更改。

（原文含示意图，图像资源未迁移）

被粘贴的记录可以来自同一个序表，也可以来自另一个序表。记录粘贴函数的主体是记录而不是序表，因此它适用于序表和记录序列。执行时该操作将更新原始序表。esProc 还提供 T.modify@r(k:P) 函数从第 k 条记录开始同时粘贴记录序列的多条记录；当 k 为 0 时在末尾追加记录。如果要追加的记录来自另一个结构不同的序表，您可以使用 T.modify@f(k:P) 函数只粘贴共享字段。

field 函数可以获取字段值以及修改序列或记录的字段值。例如：

| =demo.query("select * from STUDENTS") |
| >A1.field("AGE",20) |
| >A1(5).field(2, "Cindy") |

使用 field 函数修改记录与使用 modify 函数类似，只是前者可以同时指定字段编号和字符串类型的字段名。执行上述代码时，AGE 字段和第 5 条记录的 NAME 被修改。
