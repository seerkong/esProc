# 2.6.5 添加字段

## 代码示例
```spl
=demo.query("select * from STUDENTS")
=A1.derive(left(NAME,1):INIT)
```

## 内容说明

### 2.6.5 添加字段

序表不允许直接添加或删除字段。要向序表添加新字段（如计算列），需要使用 `derive` 函数创建一个新的序表：

|   |
|---|
| =demo.query("select * from STUDENTS") |
| =A1.derive(left(NAME,1):INIT) |

`derive` 函数同样适用于记录序列。无论数据操作的对象是序表还是序列，该函数都会创建一个新的序表。如果不需要原有的所有字段，可以使用 `new` 函数重新创建序表。在本例中，如果原序表 A1 中的数据不再需要，最好清除序表中的所有字段值，或使用 `reset` 函数重置它。
