# 2.7.1 单元格参数

## 代码示例
```spl
=3*5
=A1*B1
=B2
>B2=3.14
=B2/2
=demo.query("select * from CITIES")
>A2=A2+1
>B2=B2+1
```

## 内容说明

### 2.7.1 单元格参数

对于有值的单元格，esProc 允许计算单元格或可执行单元格通过直接使用单元格名称来引用该值。有值的单元格可以是常量单元格、计算单元格或被可执行单元格赋值的任意单元格。单元格名称由列字母和行号组成。例如：

|   |   |
|---|---|
| =3*5 | =A1*B1 |
| =B2 | >B2=3.14 |
| =B2/2 |   |

A1 是常量单元格，B1 包含表达式。两者的值都可以用作参数。B1 和 A2 的结果如下：

B2 中既没有常量也没有表达式。因此当 A3 调用 B2 时，结果为 null。实际上，任何单元格的初始值都是 null。

B3 为单元格 B2 设置了值。因此当 A4 调用 B2 时，其值变为 3.14。A4 的结果如下：

可以看到，如果单元格的值不为 null，默认情况下背景色为浅黄色。

在 esProc 中，您可以直接使用单元格参数，无需事先声明或定义参数名称。单元格参数也很容易查找，因此被广泛使用。

例如，以下程序使用单元格参数来存储和计算累计值：

|   |   |
|---|---|
| =demo.query("select * from CITIES") |   |
| for A1 | if A3.POPULATION>500000 |
|   | >A2=A2+1 |
|   | else |
|   | >B2=B2+1 |
