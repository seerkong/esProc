## 内容说明

### 2.7.2 程序参数

在网格文件中，您还可以定义程序参数，这些参数只能在当前网格中使用。

点击菜单栏"程序"菜单项中的"参数"，可以查看程序参数的设置：

（原文含示意图，图像资源未迁移）

您可以在"程序参数"对话框中设置网格文件中使用的参数。程序参数名称不允许包含空格和符号，也不能仅由数字组成；参数值可以是任意数据类型的常量，会自动解析为相应的数据类型。请注意，表达式不能用作程序参数。

如果勾选了"运行前设置参数"选项，在计算网格文件之前会弹出"输入参数"窗口：

（原文含示意图，图像资源未迁移）

您可以在计算开始前修改程序参数值，或使用默认值。要使用程序参数，直接通过其名称调用即可：

|   |
|---|
| =pi*4 |
| =arg1+" world!" |
| =arg2.(~*~) |

程序参数必须在使用前定义。在表达式中使用未定义的程序参数会导致表达式无法解析，从而引发错误。

由于程序参数的名称是用户自定义的，它们通常用于存储一些计算常量，如圆周率 Pi。此外，程序参数还用于设置需要在计算开始前赋值的数据。例如：

|   | D | Big | Small | SAME |
|---|---|---|---|---|
| for num | =rand(6)+1 | =rand(6)+1 | =rand(6)+1 |   |
| if B3==C3 && B3==D3 | >C2+=1 |   |   |   |
| else if B3+C3+D3>10 | >A2+=1 |   |   |   |

num 是预定义的程序参数，用于设置掷骰子的次数。计算目标是统计 3 个随机骰子的点数。如果总点数大于 10，标记为"大"并存入 A2；如果总点数小于或等于 10，标记为"小"并存入 B2；如果 3 个骰子点数相同，则将此次投掷存入 C2，不标记为大或小。现在将 num 设为 100 并执行计算，A2、B2 和 C2 的结果如下：

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

在网格中，表达式 `>C2+=1` 等同于 `>C2=C2+1`。对于类似 `a = a ? x` 的表达式，可以简写为 `a ?= x`。
