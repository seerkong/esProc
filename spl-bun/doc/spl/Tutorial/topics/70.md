## 内容说明

### 2.7.3 网格变量

#### 定义

除了直接使用单元格名称和调用预定义的程序参数外，您还可以使用具有指定名称的变量，这些变量称为"网格变量"。网格变量通过赋值自动创建，无需事先声明，并且在整个网格中有效。但引用未赋值的变量会导致错误。例如：

|   |   |
|---|---|
| >a=5 | >b=[1,3,2] |
| =a+3 | =b.(~+a) |

#### 判断变量

esProc 使用 `ifv` 函数检查变量是否已定义。例如：

|   |   |
|---|---|
| >a=5 | >b=[1,3,2] |
| if ifv(a) | >A2=b.(~+a) |
| else | >B2=b |
