## 内容说明

### 2.7.4 网格常量

您可以将网格中重复使用的参数设置为网格常量，其使用方式与程序参数相同，即通过名称调用。但网格常量与程序参数的区别在于：您可以为网格常量设置数据类型，但不允许在网格中为其赋值，而程序参数可以被赋值。

要查看网格常量，可以点击"工具"菜单中的"网格常量"按钮：

（原文含示意图，图像资源未迁移）

常量可以是任意数据类型，如字符串、整数、日期和序列等。您可以直接通过名称调用使用：

|   |
|---|
| =param1+" Smith" |
| =round(pi*3*3, 2) |
| =param2.sum() |
