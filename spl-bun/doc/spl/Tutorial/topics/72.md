### 2.7.5 参数、变量和常量的优先级

上文介绍了单元格参数、程序参数、网格变量和网格常量的用法。但当参数、变量或常量同时存在时，应该如何处理呢？

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

可以看出，当同名的网格常量和程序参数同时定义时，后者具有优先权。这就是 A1 的值为 3.14 的原因。但如果网格中存在同名的网格变量，则该网格变量具有优先权。因此，A3 的值是 A2 赋予的 3。

另一种情况：

（原文含示意图，图像资源未迁移）

|   |
|---|
| =A1 |
| >A1=3 |
| =A1 |

由于 A1 原本没有数据，A2 的结果为空。这也是因为定义为程序参数的"A1"无法被识别。因此，设置程序参数时不应使用单元格名称。

A3 为"A1"赋值后，单元格 A1 的背景变为浅黄色。但在界面右下角并没有名为"A1"的网格变量，这意味着 A3 实际上是为单元格赋值。现在 A1 和 A4 具有相同的数据：

（原文含示意图，图像资源未迁移）

因此，在 esProc 中定义程序参数、网格常量和网格变量时，应避免使用单元格名称。
