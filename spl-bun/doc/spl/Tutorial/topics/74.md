# 2.8.1 向量与矩阵

## 代码示例
```spl
=A1(3)
=A4(2)(1)
=transpose(A4)
=A1(2)
=A1.(~(2))
=A1.len()
=A1.max(~.len())
```

## 内容说明

### 2.8.1 向量与矩阵

esProc 分别使用序列和二维序列来表示向量和矩阵：

|   |   |
|---|---|
| [-5, 8, 11] | =A1(3) |
| [[-5, 8, 11]] |   |
| [[1,3,5],[2,4,7]] | =A4(2)(1) |
|   | =transpose(A4) |
