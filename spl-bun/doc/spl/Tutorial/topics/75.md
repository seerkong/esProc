# 2.8.2 基本矩阵运算

## 代码示例
```spl
=A1++B1
=A1--B1
=A2.(~++B2(#))
=A2.(~--B2(#))
=mul(A1,B1)
=mul([A1],B1)
=mul(A1,B1)
=mul([A1(2)], B1.(~(2)))
=mul(A1, A2)
=det(A1)
=det(B1)
=rankm(A1)
=rankm(B1)
=inverse(A1)
```

| [[1,3,5],[2,4,7]] | [[-5, 8, 11], [3, 9, 21]] |
| =A1++B1 | =A1--B1 |
| =A2.(~++B2(#)) | =A2.(~--B2(#)) |
