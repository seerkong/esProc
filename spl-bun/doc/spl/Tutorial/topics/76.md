# 2.8.3 数学运算

## 代码示例
```spl
=var(A1)
=var@s(A1)
=mse(A1, B1)
=mae(A1, B1)
=dis(A1, B1)
=dis@a(A1, B1)
=dis@m(A1, B1)
=pearson(A1, B1)
=spearman(A1, B1)
=pearson@r(A1, B1)
=pearson@a(A1, B1; 2)
=norm(A1)
=norm@0(A1)
=norm@s(A1)
=norm(B1)
=linefit(A1,B1)
=polyfit(A1,B1,1)
=polyfit(A1,B1,2)
=polyfit(A1,B1,3)
```

## 内容说明

### 2.8.3 数学运算

esProc 提供了与矩阵和向量相关的数学函数，用于计算方差、标准差等。例如：

|   |   |
|---|---|
| [4, 1, 10] | [-7, 4, 7] |
| =var(A1) | =var@s(A1) |
| =mse(A1, B1) | =mae(A1, B1) |
| =dis(A1, B1) | =dis@a(A1, B1) |
|   | =dis@m(A1, B1) |

esProc 还提供了相关函数对向量和矩阵进行数据处理。例如：

|   |   |
|---|---|
| [4, 1, 10] | [[8, 1, 6], [3, 5, 7], [4, 9, 2]] |

| [[1,-2, 3],[2,3,4],[3,5,7]] | [-10,5,7] |
