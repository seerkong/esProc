# 2.9.1 返回结果与相对引用

## 代码示例
```spl
=A1.()
=A1.(#*#)
=A1.(power(~,3))
=demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY,STATE from EMPLOYEE")
=A1.(STATE)
=A1.(age(BIRTHDAY))
>sum=0
=A1.(sum=sum+~, round(~/sum,2))
=A1.run(~=~*2)
>A1.run(GENDER=case(GENDER,"F":"Female","M":"Male"),BIRTHDAY=string(BIRTHDAY,"dd/MM/yyyy"))
=A1.(~[1]-~)
>A1.run(~=~+~[-1])
=A1.sort(BIRTHDAY)
=A2.(interval(BIRTHDAY[-1],BIRTHDAY))
=A2.(interval(~[-1].BIRTHDAY,BIRTHDAY))
=A1.groups(year(BIRTHDAY);count(~):Count)
=A2.(~[-1,1])
=A2.(Count[-1,1])
```

## 内容说明

### 2.9.1 返回结果与相对引用

在对序列进行循环计算时，可以通过循环函数的参数引用序列的每个成员。"~"用于表示当前处理的成员，即基准成员；"#"用于表示当前成员的序号。

在对序表或记录序列进行循环计算时，可以直接使用字段名 F 来引用当前记录的字段值。注意：对于记录序列，引用某个字段 F 的值的前提是所有记录都必须具有该字段 F。可以使用 ~.F、r.F 或 A.F 来指定记录 r 以及所引用字段所属的记录序列（或序表）A。

**特别说明**：如果内存中存在同名变量，应避免使用循环函数引用字段的简化形式。需要使用完整形式 ~.F 或 A.F，因为单独的 F 可能被解释为同名变量。

#### 用结果创建序列

对序列 A 的每个成员进行循环计算，并返回由结果组成的新序列。可以使用函数 `A.(x)` 实现此计算。例如：

|   |
|---|
| [2,5,-3,8] |
| =A1.() |
| =A1.(#*#) |
| =A1.(power(~,3)) |

由于 A2 的函数没有指定循环表达式，它直接返回 A1 中的序列。A3 生成由序号平方值组成的新序列。A4 生成由成员立方值组成的新序列。A1、A2、A3 和 A4 的结果如下：

在循环计算中，可以设置多个连续表达式，格式为 `A.(x, ...)`。在这种情况下，循环期间按顺序对每个成员计算表达式，存储最后一个表达式的结果，并返回所有结果的序列。例如：

#### 返回原序列

也可以使用 `A.run(x)` 函数循环遍历序列 A 的每个成员。同时，该函数会根据每个成员计算表达式 x，但会返回原序列 A。例如：

|   |
|---|
| [2,5,-3,8] |
| =A1.run(~=~*2) |

程序执行后，A1 和 A2 中得到相同的序列：

（原文含示意图，图像资源未迁移）

由于 `run` 函数返回原序列而不是新序列，它通常用于修改序列的成员。在本例中，原序列的成员被加倍。

`A.run(x)` 函数常用于在序表或序列中循环修改记录。例如：

|   |
|---|
| =demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY,STATE from EMPLOYEE") |
| >A1.run(GENDER=case(GENDER,"F":"Female","M":"Male"),BIRTHDAY=string(BIRTHDAY,"dd/MM/yyyy")) |

在 A2 中，`run` 函数将 GENDER 字段的值修改为 Male 或 Female，并更改 BIRTHDAY 字段的格式。代码执行后，A1 中的序表变为：

#### 相对引用

在循环计算中，可以使用 `A[i]` 或 `~[i]` 来引用序列中当前成员之后第 i 条记录的成员。i 可以是负数。例如：

|   |
|---|
| [2,5,-3,8] |
| =A1.(~[1]-~) |
| >A1.run(~=~+~[-1]) |

对于序列或记录序列，除了使用 `~[i]` 相对引用记录外，还可以使用 `F[i]` 相对引用记录的 F 字段。后者等同于 `A[i].F`。例如：

|   |
|---|
| =demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY,STATE from EMPLOYEE") |
| =A1.sort(BIRTHDAY) |
| =A2.(interval(BIRTHDAY[-1],BIRTHDAY)) |
| =A2.(interval(~[-1].BIRTHDAY,BIRTHDAY)) |

同样，可以相对引用多条记录，而不仅仅是一条记录。在这种情况下，使用 `A[a:b]`、`~[a:b]` 来引用由当前成员之后第 a 个成员到第 b 个成员组成的序列或记录序列。例如：

|   |
|---|
| =demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY,STATE from EMPLOYEE") |
| =A1.groups(year(BIRTHDAY);count(~):Count) |
| =A2.(~[-1,1]) |
| =A2.(Count[-1,1]) |
