## 内容说明

### 2.9.2 循环函数

循环函数按顺序对序列的每个成员执行某种计算。它通常写成 `A.f(x)` 的形式。实际上，聚合操作也是循环函数。循环函数的行为由函数名指定，如用于计算总和的 sum 函数和用于计算平均值的 avg 函数等。"序列相关函数"介绍了循环函数的一般用法，这些函数允许在对序表或记录序列进行操作时使用字段或表达式。

#### 聚合操作

聚合操作循环遍历序列、序表或记录序列的每个成员，根据函数指定的内容计算结果。例如：

|---|
| [2,5,-3,8] |
| =A1.sum() |
| =demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY,STATE from EMPLOYEE") |
| =A3.avg(age(BIRTHDAY)) |
| =A3.count(STATE=="California") |

特别地，`[x1, x2,... xn].f()` 形式的聚合操作也可以写成 `f([x1, x2,... xn])` 或 `f(x1, x2,... xn)`，前提是不会引起歧义。

#### 整数循环

#### 嵌套循环

循环函数可以嵌套使用，这意味着在一个表达式中编写多层循环操作，格式为 `A1.f1(A2.f2(x))`。在嵌套循环函数中，"~"和"#"分别表示最内层序列的当前成员和序号，而引用外层序列需要在符号前加上序列名，写成 `A.~` 和 `A.#`。例如：

|   |
|---|
| =demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY,STATE from EMPLOYEE") |
| =A1.group(year(BIRTHDAY)) |
| =create(Year,Male,Female) |
| >A2.run(A3.insert(0,year(BIRTHDAY),A2.~.count(GENDER=="M"),A2.~.count(GENDER=="F"))) |

#### 迭代函数

循环函数通过按顺序从序列或记录序列中检索成员来执行操作。迭代函数用于在计算过程中执行迭代操作。最基本的迭代函数是 `iterate(x, a; Gi,...)`，需要在循环过程中调用。迭代操作循环计算表达式 x，期间使用 ~~ 调用上一个值并存储计算表达式 x 的上一个结果。如果表达式 `Gi,...` 在计算过程中发生变化，表达式 x 将根据表达式 a 重新计算以获取初始值。例如：

|   |
|---|
| =demo.query("select * from CITIES") |
| =A1.sort(STATEID, left(NAME,1),CID) |
| =A2.derive(iterate(~~+1, STATEID*100; STATEID):Code1) |
| =A3.derive(iterate(~~+1, 0; STATEID,left(NAME,1)):Code2) |

A3 和 A4 中的表达式在 derive 函数中使用 iterate 函数添加字段。在 A3 中，iterate 函数对州内的城市进行编号，并通过将州代码乘以 100 获取每个城市的初始值。A4 使用迭代函数添加 Code2 字段，对州内具有相同首字母的城市进行编号；每次循环编号从 0 开始。以下是 A4 的结果：

（原文含示意图，图像资源未迁移）

如果计数通过累加执行且每次循环从 0 开始，迭代操作可以用更简单的 `seq(Gi,...)` 表示。在 A4 中输入表达式 `=A3.derive(seq(STATEID,left(NAME,1)):Code2)`，可以得到相同的结果。

除了在某些值保持不变时按顺序对成员编号的 `seq()` 函数外，还可以使用 `rank(F; Gi,...)` 或 `ranki(F; Gi,...)` 根据指定表达式 F 的变化对记录进行排序，并对具有相同 F 值的记录使用相同的编号。例如：

|   |
|---|
| =demo.query("select * from CITIES") |
| =A1.sort(STATEID, left(NAME,1),CID) |
| =A2.derive(iterate(~~+1, STATEID*100; STATEID):Code1) |
| =A3.derive(seq(STATEID,left(NAME,1)):Code2) |
| =A4.derive(rank(left(NAME,1);STATEID):Rank1) |
| =A5.derive(ranki(left(NAME,1);STATEID):Rank2) |
