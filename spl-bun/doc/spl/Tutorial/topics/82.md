## 内容说明

### 3.1.1 基于现有数据创建序表

`A.new()` 函数用于基于现有序列或序表创建新序表。例如：

|   |
|---|
| [1,2,3,4,5] |
| $(demo) select * from EMPLOYEE |
| =A2.select(STATE=="Texas") |
| =A1.new(~,~*~,~*~*~) |
| =A2.new(EID,NAME+" "+SURNAME,GENDER,age(BIRTHDAY)) |
| =A3.new(EID,NAME+" "+SURNAME,GENDER,STATE) |

A1 是一个简单序列。A2 是从数据库检索的包含员工信息的序表。A3 是由从 A2 中选择的德克萨斯州员工记录组成的记录序列。A4、A5 和 A6 分别使用 `new` 函数基于序列、序表和记录序列创建新序表。以下是 A4 中的序表：

从上述结果可以看出，`A.new()` 函数循环遍历 A 的每个成员来计算表达式，获取新记录并将其输入新序表。`new` 函数可以引用 A 的成员；如果 A 是序表或记录序列，它还可以引用记录的字段值进行计算。默认情况下，新序表的字段名是生成序表的表达式，例如 `age(BIRTHDAY)`。对于直接从旧序表迁移的新序表字段，如果没有给出新名称，它们将使用旧字段名，如 EID 和 GENDER，它们也是生成新字段的表达式。您可以只检索所需的数据来创建新序表。

表达式字段名对于序表来说使用不便。通常会为新序表的字段指定新名称。例如：

|   |
|---|
| [1,2,3,4,5] |
| $(demo) select * from EMPLOYEE |
| =A2.select(STATE=="Texas") |
| =A1.new(~:Value,~*~:Square,~*~*~:Cube) |
| =A2.new(EID,NAME+" "+SURNAME:FullName,GENDER,age(BIRTHDAY):Age) |
| =A3.new(EID,NAME+" "+SURNAME:NAME,GENDER,STATE) |

可以看出，要在 `new` 函数中重命名新字段，只需在生成字段的表达式后写上所需的名称，用冒号分隔名称和表达式，如 `NAME+" "+SURNAME:FullName`，这意味着根据原序表记录中的 NAME 和 SURNAME 字段获取员工全名，新字段命名为 FullName。

顺便说一下，如果是根据连续数字组成的序列创建新序表（如 A1 中的序列），表达式可以简写为 `n.new()`。例如：

|   |
|---|
| =5.new(~:Value,~*~:Square,~*~*~:Cube) |
| $(demo) select * from EMPLOYEE |
| =100.new(A2(~).(NAME+" "+SURNAME):Name,rand(5)+1:Group) |

创建新序表时，`new` 函数可以在其表达式中引用新序表的字段。例如：

|   |
|---|
| $(demo) select * from EMPLOYEE |
| =A1.new(EID,NAME+" "+SURNAME:FullName,FullName[-1]:PREV) |
| =A1.new(EID,NAME+" "+SURNAME:NAME) |
| =A1.new(EID,NAME+" "+SURNAME:NAME,NAME[-1]:PREV) |
| =A1.new(EID,NAME+" "+SURNAME:NAME,NAME[-1]+" "+SURNAME[-1]:PREV) |

可以将 @i 选项与 `new` 函数一起使用。如果用记录计算给定字段表达式的结果为 null，则该记录不会被添加到新序表中。例如：

|   |
|---|
| $(demo) select * from EMPLOYEE |
| =A1.new@i(EID,NAME+" "+SURNAME:NAME,if(GENDER=="M","Male"):Gender) |

当 A2 计算 Gender 字段时，它将男性员工的值 M 更改为 Male，同时将女性员工的值保持为 null。因此结果不会包含女性员工的记录。A2 的结果如下：

（原文含示意图，图像资源未迁移）

在等价判断中，`if` 函数可以用 `case` 函数替代。在这种情况下，`if(GENDER=="M","Male")` 等同于 `case(GENDER, "M":"Male")`。

要通过对特定序表的每条记录或指定序列的每个成员执行相同操作来为新序表生成记录，可以使用 `A.news(X; xi:Fi, ...)` 函数。例如：

|   |
|---|
| [1,2,3,4,5] |
| =A1.news(to(10,15) A1.~:x,~:y,x*y:x_times_y) |
| =A1.news(["Square","Cube"] A1.~:Value,~:Method,if(#==1,A1.~*A1.~,A1.~*A1.~*A1.~):Result) |
| $(demo) select * from EMPLOYEE |
| =A4.select(DEPT=="Finance") |
| =A5.news(rand(3) ~:BusinessTrip,A5.NAME:Name,rand(1000)*10:Cost) |
