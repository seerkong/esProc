### 3.1.2 基于现有数据创建序列

循环函数 `A.(x)` 也可用于使用现有序列、序表或记录序列生成数据。这里我们将讨论它的用法并与 `A.new()` 进行比较。例如：

|   |
|---|
| $(demo) select * from EMPLOYEE |
| =A1.(NAME+" "+SURNAME) |
| =A1.(age(BIRTHDAY)) |
| =5.([~,~*~,~*~*~]) |
