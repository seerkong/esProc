# 3.1.3 通过向序表/记录序列添加字段派生序表

## 代码示例
```spl
$(demo)
=A1.derive(age(BIRTHDAY))
=A2.derive(NAME+" "+SURNAME:FullName)
=A1.derive(:FullName)
$(demo)
=A1.derive(age(BIRTHDAY),NAME+" "+SURNAME:FullName)
=A1.derive(age(BIRTHDAY):Age,string(Age)+GENDER:Group)
$(demo)
=A1.derive(age(BIRTHDAY),:FullName)
>A2.run(FullName=NAME+" "+SURNAME)
```

## 内容说明

### 3.1.3 通过向序表/记录序列添加字段派生序表

有时不需要创建新序表。只需使用 `derive` 函数根据需要向现有序表或记录序列添加一个或多个计算列，即可生成不同的序表。例如：

|   |
|---|
| $(demo) select EID,NAME,SURNAME,BIRTHDAY,GENDER from EMPLOYEE |
| =A1.derive(age(BIRTHDAY)) |
| =A2.derive(NAME+" "+SURNAME:FullName) |
| =A1.derive(:FullName) |

从 BIRTHDAY 字段派生的年龄字段被附加到原字段之后。新字段使用生成它的表达式 `age(BIRTHDAY)` 作为名称，因为它没有被重命名。实际上，`derive` 函数可以被视为 `new` 函数的简化形式。它在执行时也会生成新序表。这就是为什么 A2 完成创建新序表后 A1 的序表可以保持不变的原因。

A3 向 A2 中的序表添加 FullName 字段，得到以下序表：

很明显，A2 序表的所有字段都被复制了，只是附加了新字段。在 A3 的表达式中，新字段被命名为 FullName。同样，A3 中的操作不会影响 A2 的结果。

|   |
|---|
| $(demo) select EID,NAME,SURNAME,BIRTHDAY,GENDER from EMPLOYEE |
| =A1.derive(age(BIRTHDAY),NAME+" "+SURNAME:FullName) |
| =A1.derive(age(BIRTHDAY):Age,string(Age)+GENDER:Group) |

A3 向原序表添加 Age 字段和用 Age 字段与 GENDER 字段计算的 Group 字段。结果如下：

（原文含示意图，图像资源未迁移）

A3 中的表达式不仅一次向原序列添加两个字段，还在 Group 字段中引用了新添加的 Age 字段。使用 `derive` 函数，一个字段可以被比它晚生成的字段引用。顺便说一下，在 esProc 中，要将实数与字符串连接，首先需要将实数转换为字符串。

另一个值得注意的是，与 `new` 函数一样，`derive` 函数也会创建新序表，而不是纯粹向现有序表添加列。执行期间，每条记录都会在新序表中重新创建。因此，`derive` 函数和 `new` 函数的效率都不够高。但如果只执行一次 `derive` 来添加多个字段，效率可以大大提高。所以 A2 中的编码方法比前一个示例中的逐步方法更好。即使某些数据在开始时无法知道，也可以在执行 `derive` 函数期间为它们生成 null 字段，然后通过 `A.run()` 函数为它们赋值。例如：

|   |
|---|
| $(demo) select EID,NAME,SURNAME,BIRTHDAY,GENDER from EMPLOYEE |
| =A1.derive(age(BIRTHDAY),:FullName) |
| >A2.run(FullName=NAME+" "+SURNAME) |

这种方法比多步执行 derive 操作更高效，因为不需要在新序表中重新创建记录，只需要赋值。

与 `new` 函数类似，`derive` 函数也可以与 @i 选项一起使用。当用表达式计算要添加的列时，如果出现 null 值，则不会添加该记录。
