# 3.1.4 使用 new 和 derive 函数创建序表

## 代码示例
```spl
$(demo)
=A1.derive(NAME+" "+SURNAME:FullName).new(EID,FullName,GENDER,BIRTHDAY)
=A1.derive(NAME+" "+SURNAME:FullName)
=A3.new(EID,FullName,GENDER,BIRTHDAY)
$(demo)
=A1.new(EID,NAME+" "+SURNAME:FullName,GENDER,age(BIRTHDAY):Age).derive(string(Age)+GENDER:Group)
```

## 内容说明

### 3.1.4 使用 new 和 derive 函数创建序表

在某些情况下，新序表需要添加一些计算列，但同时要放弃原序表的所有字段或调整新字段的顺序。可以结合使用 `new` 函数和 `derive` 函数来实现这一点。例如：

|   |
|---|
| $(demo) select EID,NAME,SURNAME,BIRTHDAY,GENDER from EMPLOYEE |
| =A1.derive(NAME+" "+SURNAME:FullName).new(EID,FullName,GENDER,BIRTHDAY) |
| =A1.derive(NAME+" "+SURNAME:FullName) |
| =A3.new(EID,FullName,GENDER,BIRTHDAY) |

根据 A1 序表中员工的 NAME 和 SURNAME 获取 FullName 后，不再需要 NAME 和 SURNAME。此外，字段需要重新排列。例如，将 FullName 前移，因为 `derive` 函数生成的字段总是在末尾。为此，A2 同时使用 `derive` 函数和 `new` 函数。A2 的结果如下：

A2 相当于 A3 和 A4 两步执行的效果。因此，当连续使用时，`new` 函数实际上是基于执行 `derive` 函数的结果执行的，如 A3：

（原文含示意图，图像资源未迁移）

所以 `new` 函数不仅可以引用原序表的字段（如 EID），还可以引用通过 `derive` 函数派生的新生成字段（如 FullName）。

当它们一起使用时，更常见的是先使用 `derive` 函数添加字段，然后使用 `new` 函数排列结果。但也可以先使用 `new` 函数排列所需字段，然后使用 `derive` 函数生成计算字段。例如：

|   |
|---|
| $(demo) select EID,NAME,SURNAME,BIRTHDAY,GENDER from EMPLOYEE |
| =A1.new(EID,NAME+" "+SURNAME:FullName,GENDER,age(BIRTHDAY):Age).derive(string(Age)+GENDER:Group) |

在本例中，获取 Group 字段需要新的 Age 字段，因此 A2 首先使用 `new` 函数排列 A1 的序表，然后使用 `derive` 函数计算 Group 字段。A2 的结果如下：

（原文含示意图，图像资源未迁移）

需要明确的是，这次 `derive` 函数是基于 `new` 函数的结果执行的，因此 `derive` 函数不能引用原序表的字段，如 NAME、SURNAME 等。
