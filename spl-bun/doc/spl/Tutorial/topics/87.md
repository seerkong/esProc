# 3.2.1 查找不重复值

## 代码示例
```spl
=file("Order_Books.txt").import@t()
=A1.id(SalesID)
=A1.id(PName)
=demo.query("select * from EMPLOYEE")
=A1.id(STATE)
=demo.query("select distinct STATE from EMPLOYEE")
=A1.id@o(STATE)
=A1.id@u(age(BIRTHDAY))
```

## 内容说明

### 3.2.1 查找不重复值

在所有记录的字段中，有些字段包含彼此不同的值（如序号），但很多字段可能有重复值。有时需要列出所有不同的值，这种情况下会用到 `id` 函数。例如：

|---|
| =file("Order_Books.txt").import@t() |
| =A1.id(SalesID) |
| =A1.id(PName) |

但有时您可能希望保持数据的原始顺序。要实现这一点，使用 @o 选项。例如：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.id@o(STATE) |

`id@o` 函数不对数据排序，而是直接删除相邻的相同值数据。因此，结果中可能有重复值，如上述结果中的 Texas 和 California。

如果 `id()` 函数中只指定了一个字段且该字段包含自然数，该函数可以使用 @n 选项或 @b 选项来加速比较。

`id` 函数可以列出某个表达式的所有不同结果，而不仅仅是字段的所有不同值：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.id@u(age(BIRTHDAY)) |
