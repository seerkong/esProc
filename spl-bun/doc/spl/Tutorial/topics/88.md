# 3.2.2 等值分组

## 代码示例
```spl
=demo.query("select * from EMPLOYEE")
=A1.group(DEPT)
=A1.group@o(DEPT)
=A1.group(year(BIRTHDAY))
=demo.query("select * from EMPLOYEE")
=A1.group(DEPT)
=A2.new(DEPT,count(~):Count,~.sum(SALARY):TotalSalary)
=A2.new(DEPT,~.count(GENDER=="M"):Male,~.count(GENDER=="F"):Female)
=ntile(123,40)
=demo.query("select * from EMPLOYEE")
=A2.group(ntile(#,60))
=A3.new(#:GID,~.count():Count,~:Emps)
=demo.query("select * from EMPLOYEE")
=A1.len()
=A1.group(ntile(#,6,A2))
=A3.new(#:GID,~.count():Count,~:Emps)
```

## 内容说明

### 3.2.2 等值分组

您经常需要根据某个值对数据进行分组，例如按部门对员工分组、按性别对人员分组。esProc 提供 `group` 函数对序表或记录序列的数据进行分组，并返回由组组成的序列。例如：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.group(DEPT) |
| =A1.group@o(DEPT) |
| =A1.group(year(BIRTHDAY)) |

A2 按 DEPT 对员工记录进行分组。结果如下：

结果是一个序列，其成员是按部门字母顺序排序的组。每个组是由同一部门员工记录组成的记录序列。

`group` 函数也可以与 @o 选项配合使用，通过只将相邻的相同值数据放入一组来保持原始顺序，如 A3 所做的那样。按部门分组数据时，它只将同一部门的相邻员工放入一组。结果如下：

您也可以按给定表达式对数据进行分组，将使表达式产生相同结果的数据放入一组。例如，A4 按出生年份对员工进行分组。结果如下：

（原文含示意图，图像资源未迁移）

`group` 函数类似于 SQL 中的 `group by` 操作。它的返回值是由组组成的序列，是一个由序列组成的序列。分组结果可以重复用于进一步的数据分组和聚合。这与 SQL 不同，SQL 没有显式的集合数据类型，因此无法存储分组结果。使用 SQL 时，执行 `group by` 时必须立即汇总每组数据，之后分组结果将被丢弃，因此无法重用。

esProc 允许在数据分组后以不同方式重复汇总每组数据。例如：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.group(DEPT) |
| =A2.new(DEPT,count(~):Count,~.sum(SALARY):TotalSalary) |
| =A2.new(DEPT,~.count(GENDER=="M"):Male,~.count(GENDER=="F"):Female) |

使用分组结果，A3 计算每个部门的员工人数和总工资。A4 计算每个部门的男性员工人数和女性员工人数。两者都以序表形式返回汇总结果，如下所示：

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

A3 和 A4 基于 A2 的相同分组结果执行不同的汇总操作。重用分组结果是 esProc 的重要特性之一。

对 A3 中表达式 `=A2.new(DEPT,count(~):Count,~.sum(SALARY):TotalSalary)` 的解释：由于 A2 是对 A1 序表分组的结果，它的每个成员都是一组记录，即记录序列。因此，当 `new` 函数对 A2 执行循环计算时，其表达式的目标是记录序列。例如，`DEPT` 表示获取当前记录序列第一条记录的 DEPT 字段值；`~.sum(SALARY)` 表示对当前记录序列的 SALARY 字段求和。

与 SQL 中的 `group by` 子句类似，`group` 函数也支持同时按多个字段（表达式）分组数据。在这种情况下，只有指定字段的值都相同的记录才会被分到一组。

有时您需要将一定量的数据分成指定数量的组，这种情况下 `ntile(i,n)` 函数很有用。例如：

|   |
|---|
| =ntile(123,40) |
| =demo.query("select * from EMPLOYEE") |
| =A2.group(ntile(#,60)) |
| =A3.new(#:GID,~.count():Count,~:Emps) |

该函数查找如果每组包含 n 个成员，则第 i 个成员将落入哪个组。A1 的表达式查找如果每 40 个放入一组，则第 123 个成员将在哪个组。结果如下：

（原文含示意图，图像资源未迁移）

要将 n 条记录均匀分成 k 组，使用 `ntile(i,k,n)` 函数：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.len() |
| =A1.group(ntile(#,6,A2)) |
| =A3.new(#:GID,~.count():Count,~:Emps) |

该函数查找第 i 条记录将落入哪个组。A3 使用该函数将员工记录均匀分成 6 组。A4 计算每组的员工人数。以下是 A4 的结果：
