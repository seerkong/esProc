# 3.2.3 分组聚合函数

## 代码示例
```spl
=demo.query("select * from EMPLOYEE")
=A1.group(DEPT;~.count():Count,~.sum(SALARY):TotalSalary)
=A1.group(DEPT;~.count(GENDER=="M"):Male,~.count(GENDER=="F"):Female)
=A1.group(DEPT;round(~.avg(age(BIRTHDAY)),2):AverageAge)
=demo.query("select * from EMPLOYEE")
=A1.groups(DEPT;count():Count,sum(SALARY):TotalSalary)
=A1.groups(DEPT;count(GENDER=="M"):Male,count(GENDER=="F"):Female)
=demo.query("select * from EMPLOYEE")
=A1.groups(DEPT;top(3,age(BIRTHDAY)))
=demo.query("select * from EMPLOYEE")
=A1.groups(DEPT;top(3,BIRTHDAY))
=A2.new(DEPT,#2.(age(~)))
=A1.groups(DEPT;top(-3,age(BIRTHDAY)))
```

## 内容说明

### 3.2.3 分组聚合函数

上一节说明了如何对序表中的记录进行分组，然后使用分组结果汇总每组的记录。您也可以使用 `group` 函数直接获取聚合结果，省去逐步计算的麻烦。例如：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.group(DEPT;~.count():Count,~.sum(SALARY):TotalSalary) |
| =A1.group(DEPT;~.count(GENDER=="M"):Male,~.count(GENDER=="F"):Female) |
| =A1.group(DEPT;round(~.avg(age(BIRTHDAY)),2):AverageAge) |

esProc 还提供 `groups` 函数通过累加计算分组和汇总结果。例如：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.groups(DEPT;count():Count,sum(SALARY):TotalSalary) |
| =A1.groups(DEPT;count(GENDER=="M"):Male,count(GENDER=="F"):Female) |

A2 和 A3 同时按 DEPT 字段对数据进行分组和汇总。注意这里省略了"~."。这与上面的代码不同，但结果与先分组后汇总得到的结果相同：

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

`groups` 函数在同时分组和汇总数据时也返回序表。它不会记录每组中的数据，而只根据分组表达式计算累计值。与 `group` 函数相比，`groups` 函数效率更高。

**注意**：`groups` 函数只能与简单的聚合函数配合使用，如 sum/count/max/min/top/avg/iterate/icount/median，以同时执行分组和聚合。要执行复杂的分组和聚合操作，应该只使用 `group` 函数。

特别地，`top` 是聚合函数之一，可用于计算 n 个最小值。例如：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.groups(DEPT;top(3,age(BIRTHDAY))) |

A2 通过数据分组计算每个部门三个最年轻员工的年龄：

（原文含示意图，图像资源未迁移）

`top` 只能计算 n 个最小值。要找出三个最年长员工的年龄，可以使用以下方法：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.groups(DEPT;top(3,BIRTHDAY)) |
| =A2.new(DEPT,#2.(age(~))) |
| =A1.groups(DEPT;top(-3,age(BIRTHDAY))) |
