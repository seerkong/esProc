# 1.2.2 类似文本编辑的插入和删除

## 内容摘要
按 Ctrl+Enter、Ctrl+BackSpace 和 Ctrl+Del 将产生类似于回车、退格和删除当前单元格的效果。这类似于在文本编辑器中按 Enter、Backspace 和 Delete 键。按 Ctrl+Insert 将在当前行插入一个单元格。

1. Ctrl+Enter：执行回车操作。

（原文含示意图，图像资源未迁移）

2. Ctrl+BackSpace：执行向前删除。

（原文含示意图，图像资源未迁移）

3. Ctrl+Delete：删除当前单元格，同时将其后的单元格向左移动以填补空位。

（原文含示意图，图像资源未迁移）

4. Ctrl+Insert：插入一个单元格，同时其后的单元格向右移动。
