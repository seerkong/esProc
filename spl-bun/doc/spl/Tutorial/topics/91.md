# 3.3.1 序列成员的排序与排名

## 代码示例
```spl
=A1.sort()
=A1.psort()
=A1.ranks()
=A1.rank(5.5)
=A1.ranks()
=A1.ranks@i()
=A1.rank@i(3.8)
=A1.ranks@s()
=A1.rank@s(2)
=A1.sort()
=A1.sort@0()
=demo.query("select * from EMPLOYEE where EID<6")
=A1.(NAME+" "+SURNAME)
=A2.sort()
=A2.ranks()
=A1.(BIRTHDAY)
=A3.sort()
=A3.ranks()
=A1.(age(BIRTHDAY))
=A4.sort@z()
=A4.ranks@z()
=A1.sort()
=A1.sort(;"esp")
```

## 内容说明

### 3.3.1 序列成员的排序与排名

esProc 使用 `psort`、`sort`、`rank`、`ranks` 等函数对数据进行排序或排名。现在让我们看看如何对序列执行这些操作。

|   |
|---|
| [8,1,2,7,0,5,3] |
| =A1.sort() |
| =A1.psort() |
| =A1.ranks() |
| =A1.rank(5.5) |

A4 的结果是原序列成员按升序排列的排名。A5 通过将 5.5 与原序列的每个成员进行比较，找出 5.5 在相同顺序中的排名。

当期望结果中有相同排名时，可以使用 @i 选项和 @s 选项来调整排序结果。例如：

|   |
|---|
| [2,1,2,3,4,4,5] |
| =A1.ranks() |
| =A1.ranks@i() |
| =A1.rank@i(3.8) |
| =A1.ranks@s() |
| =A1.rank@s(2) |

A2 获取默认排名。A3 使用 @i 选项，A4 使用 @s 选项。A2、A3 和 A4 的结果如下：

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

（原文含示意图，图像资源未迁移）

默认情况下，相同排名会占用位置，使后面成员的排名推迟。例如，有两个第二名时，下一个成员将被记录为第 4 名。但使用 @i 选项可以消除这种影响，这意味着无论有多少个相同的第二名，下一个成员始终被记录为第 3 名。添加 @s 选项后，如果有相同排名，函数将计算相同排名的平均值作为它们的记录排名，这更能反映实际情况。例如，两个第二名实际上占用了第二和第三位置，因此认为它们的真实排名是平均值 2.5 是合理的。

**注意**：执行 `A.rank@s(y)` 函数时，如果 y 已包含在 A 中，函数将返回 y 对应值在 A 中的排名，而不是将 y 投影到 A 中计算相同排名的平均值。

当序列中有空值时，排序时空值将被视为最小值。在某些情况下，可以使用 @0 选项使空值成为最大值。例如：

|   |
|---|
| [1,2,,,4,3,2,1] |
| =A1.sort() |
| =A1.sort@0() |

所有与排序相关的函数，如 `psort` 和 `sort`，都可以使用 @0 选项。

在实际情况中，很少对常量序列进行排序。通常，要排序的序列来自计算。例如：

|   |
|---|
| =demo.query("select * from EMPLOYEE where EID<6") |
| =A1.(NAME+" "+SURNAME) |
| =A2.sort() |
| =A2.ranks() |
| =A1.(BIRTHDAY) |
| =A3.sort() |
| =A3.ranks() |
| =A1.(age(BIRTHDAY)) |
| =A4.sort@z() |
| =A4.ranks@z() |

添加 @z 选项后，`sort` 函数和 `rank` 函数获取结果的顺序仍然相反。您可以注意到年龄中有重复值。如结果所示，两个 42 的排名都是 2，而下一个 37 的排名变成了 4。这意味着默认情况下相同排名会占用一个位置。排名操作将在第三节详细介绍。

根据每个字符的 ASCII 码对字符串排序的方式，如果目标字符串不是英语，可能会导致错误。在这种情况下，需要通过参数 loc 在 `A.sort(...;loc)` 中指定语言。例如：

|   |
|---|
| [Íker,Álvaro,Estela,Alba,César,Sancho] |
| =A1.sort() |
| =A1.sort(;"esp") |
