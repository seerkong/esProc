# 3.3.2 记录排序

## 代码示例
```spl
=demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY from EMPLOYEE where EID<6")
=A1.sort(NAME+" "+SURNAME)
=A1.sort(BIRTHDAY)
=A1.sort@z(age(BIRTHDAY))
=demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY from EMPLOYEE")
=A1.sort(SURNAME,NAME)
=A1.sort(GENDER,-SURNAME,-NAME)
=demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY from EMPLOYEE")
=A1.top(5,age(BIRTHDAY))
=A1.ptop(5,age(BIRTHDAY))
=A1.top(5;age(BIRTHDAY))
=A1.top(-5,age(BIRTHDAY))
```

### 3.3.2 记录排序

在数据计算过程中，按要求对数据表中的记录进行排序是另一个常见需求。例如：

|   |
|---|

因此，您可以看到 `sort` 函数可以方便地用于对序表或记录序列中的记录进行排序，并生成和返回新的记录序列。

让我们看看 A2 的结果，它已按全名排序。但大多数时候，员工记录首先按姓氏排序，姓氏相同的员工再按名字排序。因此涉及多个字段。

|---|
| =demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY from EMPLOYEE") |
| =A1.sort(SURNAME,NAME) |
| =A1.sort(GENDER,-SURNAME,-NAME) |

根据上一节，可以在 `sort`、`psort`、`rank`、`ranks` 等函数中添加 @z 选项来改变排序顺序。要按多个字段排序数据时，不能使用 @z 选项，因为每个字段的排序顺序可能不同。但可以在表达式前添加负号进行反向排序。例如，在 A3 的表达式中，`GENDER` 表示按性别升序排序，`-SURNAME` 表示按姓氏降序排序。没有这些符号时，数据将按升序排序。A3 的排序结果如下：

如果排序字段包含非英语字符串，可以在 `sort` 函数中定义语言参数。

有时您需要的是排在前几位的记录。这时可以使用 `top` 函数或 `ptop` 函数。例如：

|   |
|---|
| =demo.query("select EID,NAME,SURNAME,GENDER,BIRTHDAY from EMPLOYEE") |
| =A1.top(5,age(BIRTHDAY)) |
| =A1.ptop(5,age(BIRTHDAY)) |
| =A1.top(5;age(BIRTHDAY)) |
| =A1.top(-5,age(BIRTHDAY)) |
