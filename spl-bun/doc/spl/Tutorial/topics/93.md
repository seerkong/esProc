# 3.3.3 基于序表计算排名

## 代码示例
```spl
=demo.query("select * from EMPLOYEE")
=A1.ranks(SALARY)
=A1.ranks@i(SALARY)
=A1.rank(10000,SALARY)
=A1.rank@i(10000,SALARY)
```

## 内容说明

### 3.3.3 基于序表计算排名

计算排名有两种常见方式：计算排名时是否计入重复值。例如，如果比赛中有两名选手并列第一，且计入重复排名值，则紧随其后的选手将排名第三。但如果不计入重复排名值，则第二名将紧随其后，不考虑额外的排名值。esProc 有 `ranks` 函数计算排名，`rank` 函数计算某个值的排名。在函数中使用 @i 选项将计算排名时不计入额外排名。例如：

|   |
|---|
| =demo.query("select * from EMPLOYEE") |
| =A1.ranks(SALARY) |
| =A1.ranks@i(SALARY) |
| =A1.rank(10000,SALARY) |
| =A1.rank@i(10000,SALARY) |
