# 3.4.1 对齐操作

## 代码示例
```spl
=A1.sort()
=A1.align(B1)
=demo.query("select EID,NAME,GENDER,STATE,DEPT from EMPLOYEE")
=A3.align(B3,STATE)
```

## 内容说明

### 3.4.1 对齐操作

通常使用 `sort` 函数对序列或序表中的数据进行排序，结果按升序或降序列出。要按指定顺序对数据排序，esProc 提供了 `align` 函数。例如：

|   |   |
|---|---|
| [three,one,four,six,two] | [one,two,three,four,five,six] |
| =A1.sort() | =A1.align(B1) |
| =demo.query("select EID,NAME,GENDER,STATE,DEPT from EMPLOYEE") | [California,Texas,Florida,Illinois] |
| =A3.align(B3,STATE) |   |

`sort` 函数只按字母顺序升序或降序对成员排序，而 `align` 函数根据标准序列成员的位置对它们排序。如果标准序列中的成员在目标序列中找不到匹配的成员，则相应位置的值将为 null。

`align` 函数最常见的应用场景是对序表或记录序列的记录进行排序。例如，A3 选择一些员工的记录，A4 按指定顺序从中获取某些州的记录。A3 的结果如下：
