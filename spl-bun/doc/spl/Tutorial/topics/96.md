# 3.4.2 对齐分组

## 代码示例
```spl
=demo.query("select EID,NAME,GENDER,STATE,DEPT from EMPLOYEE")
=A1.align@a(B1,STATE)
=A2.new(STATE,~.count(GENDER=="M"):Male,~.count(GENDER=="F"):Female)
=A1.align@n(B1,STATE)
=demo.query("select EID,NAME,GENDER,STATE,DEPT from EMPLOYEE")
=A1.groups(STATE;count(~):Count)
=A2.sort(-Count)
=A1.align@a(A3:STATE,STATE)
=demo.query("select EID,NAME,GENDER,STATE,DEPT from EMPLOYEE")
=A1.align@a(26,asc(left(NAME,1))-64)
=A1.align@a(A3.len(),A3.pos(DEPT))
```

## 内容说明

### 3.4.2 对齐分组

在前面的示例中，执行对齐操作后，每个州只获取了第一条符合条件的记录。但在许多情况下，您需要所有符合条件的记录，这可以通过 `align@a` 实现。例如：

|   |   |
|---|---|
| =demo.query("select EID,NAME,GENDER,STATE,DEPT from EMPLOYEE") | [California,Texas,Florida,Illinois] |
| =A1.align@a(B1,STATE) | =A2.new(STATE,~.count(GENDER=="M"):Male,~.count(GENDER=="F"):Female) |
| =A1.align@n(B1,STATE) |   |

在对齐分组中，可能有一些数据无法与标准序列的任何成员匹配。对于这种情况，esProc 提供 @n 选项来实现另一种对齐分组，它将所有在标准序列中没有对应成员的记录放入单独的组。如 A4 的分组结果所示：

通过比较 A2 和 A4 的对齐分组结果，您可以注意到 A4 的结果多了一个组，用于存储不来自四个指定州的员工记录。

进行对齐分组所基于的序列也可以通过计算获得。例如：

|   |
|---|
| =demo.query("select EID,NAME,GENDER,STATE,DEPT from EMPLOYEE") |
| =A1.groups(STATE;count(~):Count) |
| =A2.sort(-Count) |
| =A1.align@a(A3:STATE,STATE) |

第四种对齐分组是 `P.align(n, y)`，它将成员分成 n 组，然后通过计算分组表达式 y 直接将每个成员放入相应的组。例如：

|   |
|---|
| =demo.query("select EID,NAME,GENDER,STATE,DEPT from EMPLOYEE") |
| =A1.align@a(26,asc(left(NAME,1))-64) |
| [HR,R&D,Finance,Marketing] |
| =A1.align@a(A3.len(),A3.pos(DEPT)) |

在 A2 的表达式 `=A1.align@a(26,asc(left(NAME,1))-64)` 中，`left(NAME,1)` 获取员工姓名的首字母，然后通过 `asc` 函数转换为 ASCII 码，再减去 64，首字母将被放入 1~26 范围内的某个组号。对齐分组结果如下：
