# 3.4.3 查找包含成员的条件

## 代码示例
```spl
=A1.penum(100)
=A1.penum(66)
=A1.penum(54)
=A1.penum@n(54)
=A3.penum(54)
=A1.penum@r(100)
=A1.penum@r(66)
=A1.penum@r(54)
```

## 内容说明

### 3.4.3 查找包含成员的条件

有时数据不是按等值分组，而是按某些条件分组，如订单金额范围和员工年龄组。

分组条件可以用字符串表示，如"?>3"、"[2,3,5,7].pos(?)>0"。`penum` 函数用于根据条件表达式字符串序列判断一个数字可以满足哪些条件。例如：

|   |
|---|
| [?>=85,?>=70,?>=60] |
| =A1.penum(100) |
| =A1.penum(66) |
| =A1.penum(54) |

如结果所示，当某个数字满足多个条件时，只返回第一个找到的条件的序号。例如，100 可以满足所有三个条件，但返回的结果是 1。

由于 A4 表达式中的数字 54 不满足任何条件，返回的结果是 null。

与对齐分组类似，`penum` 函数也使用 @n 选项，当数据不满足 k 个条件中的任何一个时返回 k+1。特别地，如果条件表达式为 null，则任何数据都可以满足它。例如：

|   |
|---|
| [?>=85,?>=70,?>=60] |
| =A1.penum@n(54) |
| [?>=85,?>=70,?>=60,null] |
| =A3.penum(54) |

A2 和 A4 的结果如下：

（原文含示意图，图像资源未迁移）

A2 中的数字 54 不满足三个条件中的任何一个，所以 `penum@n` 函数返回结果 4。但在 A4 中，它满足第四个条件 - null。注意，如果 null 列在条件中，它必须放在最后。

`penum` 函数也使用 @r 选项，允许返回指定数据可以满足的重叠条件。在这种情况下，将返回由所有符合条件的序号组成的序列。例如：

|   |
|---|
| [?>=85,?>=70,?>=60,null] |
| =A1.penum@r(100) |
| =A1.penum@r(66) |
| =A1.penum@r(54) |

A2、A3 和 A4 分别返回由 100、66 和 54 满足的条件序号组成的序列。结果如下：

**注意**：使用 `penum@r` 函数时，虽然条件 null 被定义为任何数据都可以满足，但如果至少有一个符合的条件，其序号不会出现在结果中。此外，使用 @r 选项时，即使只有一个符合的条件，函数也返回序列而不是数字。
