# 3.4.4 枚举分组

## 代码示例
```spl
=demo.query("select EID,NAME,GENDER,BIRTHDAY,SALARY from EMPLOYEE")
=A1.enum(A2,SALARY)
=demo.query("select EID,NAME,GENDER,BIRTHDAY,SALARY from EMPLOYEE")
=A1.enum@n(A2,SALARY)
=A1.enum(A4,SALARY)
=demo.query("select EID,NAME,GENDER,BIRTHDAY,SALARY from EMPLOYEE")
=A1.enum@r(A2,SALARY)
```

## 内容说明

### 3.4.4 枚举分组

您可以使用 `P.enum(E, y)` 函数根据由条件表达式字符串组成的序列 E 对序列 P 的成员进行分组。该操作将使用序列 P 的每个成员计算表达式 y，判断结果满足哪些条件，并将 P 的成员放入与条件对应的组中。默认情况下，P 的每个成员将根据它满足的第一个条件进行分组。例如：

|   |
|---|
| =demo.query("select EID,NAME,GENDER,BIRTHDAY,SALARY from EMPLOYEE") |
| [?>=15000,?>=12000,?>=9000] |
| =A1.enum(A2,SALARY) |

（原文含示意图，图像资源未迁移）

在枚举分组产生的每个组中，并非所有 SALARY 值都相等；它们只是满足相同的条件。同样，虽然一条记录可能同时满足第一个条件和其他两个条件，但默认情况下，它将被放入只满足第一个条件的组中。对于不满足任何条件的记录（如第一条和第四条记录），它们不会被分组。

与 `penum` 函数类似，可以在末尾附加一个 null 条件，在执行枚举分组时，所有不满足前面所有条件的记录都可以放在该条件下。或者您可以使用 `enum@n`，效果相同。例如：

|   |
|---|
| =demo.query("select EID,NAME,GENDER,BIRTHDAY,SALARY from EMPLOYEE") |
| [?>=15000,?>=12000,?>=9000] |
| =A1.enum@n(A2,SALARY) |
| [?>=15000,?>=12000,?>=9000,null] |
| =A1.enum(A4,SALARY) |

A3 和 A5 的结果相同：

（原文含示意图，图像资源未迁移）

通过与前一个示例的结果比较，可以看出使用 `enum@n` 函数和在条件序列末尾附加 null 都会将所有不满足其他条件的记录放入单独的组。

默认情况下，`enum` 函数假设没有重叠的组，即 P 的每个成员不会同时满足多个条件表达式。如果成员应该被放入多个组，则需要 @r 选项。例如：

|   |
|---|
| =demo.query("select EID,NAME,GENDER,BIRTHDAY,SALARY from EMPLOYEE") |
| [?>=15000,?>=12000,?>=9000] |
| =A1.enum@r(A2,SALARY) |

A3 使用 `enum@r` 执行允许重叠组的枚举分组。结果如下：

（原文含示意图，图像资源未迁移）

可以看出，记录被重复分组后，第一组的成员出现在所有三个组中，第二组的成员在后两个组中重复出现。
