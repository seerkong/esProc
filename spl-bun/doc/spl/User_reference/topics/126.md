# 启用函数提示

## 内容

You can open or close the function prompt through this option. Check it and when you enter the first several letters, all functions starting with these letters will be listed in the function prompt box; enter "=function name()" in the tool bar, put the cursor in the parentheses, and you can view the function description. The option is case-sensitive. You can view the functions listed here by clicking the Up/Down arrow. Click the TAB key and the selected function will be automatically entered to the cell. When the option is checked, enter "=function name()" in the toolbar, put the cursor in the parentheses, and the corresponding function description will be displayed.
