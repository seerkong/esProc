# 输出接管

## 内容

This option determines whether to write the esProc execution log to the Output panel or not. If it is unselected, the Output panel won't appear on the right of the designer. If it is selected, users can view system log information through the Output panel. The advantage of the output system over a DOS window is that it won't overwrite the existing log when there is too many of it and thus provides more comprehensive log information. Besides, it provides easier copy and paste of the log.
