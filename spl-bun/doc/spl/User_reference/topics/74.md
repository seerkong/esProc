# 配置文件

## 内容

In esProc options, some property values are stored in the configuration file. The system default configuration file is [installation root directory]/esProc/config/raqsoftConfig.xml . You can update the options in batch by switching between different configuration files. The configuration file name can be user-defined. The file's path can be an absolute one or a relative one; the latter is relative to [installation root directory]/esProc .
